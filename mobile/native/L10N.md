# Native resource validation

The repository-root source mappings select the English Apple `.strings` and Android
XML catalogs. This scoped command validates candidates at their real output paths
using Node 22, available in the translation sandbox. It does not require Xcode,
Android SDK, Python, a network connection, or additional packages.

Translate resource values only. Preserve every source key, format argument and its
type/position, XML attributes, escapes, and directional isolates. Keep user/server
content verbatim; do not turn paths, language tags, or program identifiers into UI
strings. Apple catalogs are UTF-8; Android catalogs use the quoted string form.
