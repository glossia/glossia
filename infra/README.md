# glossia/infra

Private production infrastructure for [Glossia](https://glossia.ai).

## Layout

- `k8s/mgmt/flux/` — Flux bootstrap: `GitRepository` sources, top-level `Kustomization` definitions, image automation.
- `k8s/workload-apps/` — `HelmRelease` definitions for the workload cluster's application layer (`glossia`, `community`).
- `k8s/workload-platforms/` — `HelmRelease` definitions for platform components (`observability`, `platform`) and Pomerium.
- `k8s/clusters/` — Cluster API profiles.
- `helm/` — Internal Helm charts (`discourse`, `observability`, `platform`, `tailscale-apiserver-proxy`, `glossia-alloy`).
- `values/` — Ancillary values overlays used out-of-band (e.g. `alloy-production.yaml`).

Two source repositories feed the production Flux cluster:

- **`infra`** (this repo) — all Kustomization sources, private overlays, internal charts.
- **`flux-system`** — the public [`glossia/glossia`](https://github.com/glossia/glossia) repo, referenced only for the Glossia application chart at `deploy/helm/glossia/`.

The `glossia` HelmRelease pulls its chart from `flux-system` (public) and layers private production values on top via two ConfigMaps generated by `k8s/workload-apps/glossia-production/kustomization.yaml`.

`babel` is deployed from [`glossia/babel`](https://github.com/glossia/babel) and is not managed from this repo.
