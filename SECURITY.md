# Security policy

Do not report security vulnerabilities through public GitHub issues or
discussions.

Use a [private GitHub security advisory](https://github.com/glossia/glossia/security/advisories/new)
and include a clear description, impact assessment, reproduction steps, and
any suggested mitigation. We will acknowledge the report and coordinate a fix
before public disclosure.

Supported releases are the latest commit on `main` and the latest published
command-line interface release.
