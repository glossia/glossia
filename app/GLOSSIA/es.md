# Spanish Translation Context

Use neutral Spanish that works across Spain and Latin America.

## Terminology

- Keep "Glossia" untranslated.
- Translate "translation session" as "sesion de traduccion" unless a shorter interface label
  is needed.
- Translate "setup session" as "sesion de configuracion".
- Translate "sandbox" as "entorno aislado" when space allows.
- Translate "lockfile" as "archivo de bloqueo".

## Style

- Use a respectful, clear tone.
- Prefer concise interface labels over long explanatory phrases.
- Preserve placeholders such as `%{count}` and `%{client_name}` exactly.
