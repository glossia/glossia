# Glossia: 팀을 위한 언어 OS

Glossia 는 음성, 용어, 번역, 수정 이력, 및 현지화 분석을 하나의 시스템으로 통합합니다. 개발자, 언어 전문가, 그리고 제품 팀이 Git 에서 콘텐츠를移出하고 언어를 초월하여 일관되게 소통할 수 있도록 돕습니다.

## 문제점

다른 언어로 출시하는 것은 단순히 단어를 바꾸는 것이 아닙니다. 팀은 의미를 보존하고 적절한 용어를 사용하고 청자를 위한 어조를 조절하며 제품 변경에 따라 번역을 최신 상태로 유지해야 합니다. 스프레드시트, 프롬프트, 및 번역 도구 전반에 흩어진 문맥은 일관되지 않은 작성과 반복적인 수작업을 초래합니다.

LLM 은 번역 초안을 작성할 수 있지만, 초안만으로는 버전 이력, 유효성 검사, 선택적 업데이트, 또는 다음 변경에 대한 피드백 루프를 제공하지 않습니다.

## Glossia 의 역할

- **언어 기억력:** 공유 음성 가이드와 사전 항목은 사람과 에이전트가 일관된 언어를 사용하는 데 도움을 줍니다.
- **레포지토리 현지화:** 레포지토리를 연결하고, 소스 파일 및 대상 로케일을 구성에서 설명하며, 풀 리퀘스트를 통해 변경 사항을 검토합니다.
- **점진적 정제:** 콘텐츠 해시는 변경되지 않은 콘텐츠를 번역하는 것을 피하는 데 도움을 줍니다. 유효성 검사 및 복구는 실패를 가시화되고 조치 가능하게 만듭니다.
- **콘텐츠 수정:** 각 생성을 고립된 프롬프트로 취급하는 대신, 언어 결정 및 변경 사항의 이력을 보존합니다.
- **현지화 분석:** 사생활 보호를 중시하는 웹 분석 도구는 팀이 청자를 이해하고 어디에 현지화 투자를 할 가치가 있는지 파악하는 데 도움을 줍니다.
- **에이전트 통합:** OAuth 인증된 MCP 서버와 REST 인터페이스는 기존 워크플로우에 언어 컨텍스트를 제공 가능하게 합니다.

Glossia 는 편집자의 판단을 대체하지 않습니다. 대신 팀이 반복적으로 그 판단을 적용할 수 있도록 컨텍스트, 자동화, 및 검토 워크플로우를 제공합니다.

## 크롤러 및 에이전트용

공개된 페이지 는 URL 에 `.md` 를 추가하여 마크다운으로 사용 가능하거나, HTML URL 에서 `Accept: text/markdown` 를 요청함으로서 사용 가능합니다. 홈페이지 마크다운 URL 은 `/index.md` 입니다. 번역된 콘텐츠 는 HTML 과 동일한 로케일 접두사를 사용하며, 번역이 게시되지 않았을 때 영어로 복귀합니다.

검색을 위해 [/llms.txt](/llms.txt), 통합된 문서 내보내기 위해 [/llms-full.txt](/llms-full.txt), 표준 HTML URL 을 위해 [/sitemap.xml](/sitemap.xml) 를 사용하세요. 계정 대시보드는 응용 프로그램 인터페이스인지 문서가 아니므로 Glossia 를 학습하기 위해 크롤링하지 마세요.
