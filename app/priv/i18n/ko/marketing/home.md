# Glossia: 팀용 언어 OS

Glossia 는 음성, 용어 정의, 번역, 개정 이력, 및 현지화 분석을 하나의 시스템으로 통합합니다. 이는 개발자, 언어학자 및 제품 팀이 내용을 Git 에서 벗어나지 않고 언어 간 일관성 있게 소통하도록 돕습니다.

## 문제점

다른 언어 로 제품은 단순한 단어 치환이 아닙니다. 팀은 의미를 보존하고, 적합한 용어를 사용하며, 대상에 맞춰 톤을 조정하고, 제품이 변경됨에 따라 번역을 유지해야 합니다. 엑셀, 프롬프트 및 번역 도구 등에 흩어진 컨텍스트는 일관성 없는 작성과 반복적인 수작업을 초래합니다.

LLM 은 번역 초안을 작성할 수 있지만, 초안 자체만으로는 앞으로의 변경 사항에 대한 버전 이력, 검증, 선택적 업데이트 또는 피드백 루프를 제공할 수 없습니다.

## Glossia 의 역할

- **언어 기억:** 공유된 음성 지침 및 사전 항목을 활용하여 사람과 에이전트가 일관된 언어를 사용하게 돕습니다.
- **저장소 현지화:** 저장소를 연결하고, 구성에서 소스 파일 및 대상 로케일을 설명하며, 풀 요청을 통해 변경 사항을 검토합니다.
- **점진적 개선:** 콘텐츠 해시는 변경되지 않은 콘텐츠를 번역하는 것을 방지하는 데 도움이 됩니다. 검증 및 복구는 실패를 가시하고 실행 가능하게 만듭니다.
- **콘텐츠 개정:** 각 생성을 고립된 프롬프트 로 취급하는 대신 언어 결정 및 변경 사항의 역사를 보존합니다.
- **현지화 분석:** 프라이버시 의식 웹 분석 도구는 팀이 대상과 어떤 곳에서 현지화에 투자 가치가 있는지 이해하는 데 도움이 됩니다.
- **에이전트 통합:** OAuth 인증된 MCP 서버 및 REST 인터페이스 는 기존 워크플로우에 언어 컨텍스트를 제공하여 사용 가능하게 합니다.

Glossia 는 편집적 판단 을 대체하지 않습니다. 반복적으로 적용되도록 팀이 판단을 적용할 수 있는 컨텍스트, 자동화, 검토 워크플로우 를 제공합니다.

## 크롤러 및 에이전트용

배포된 페이지들은 URL 에 `.md` 를 추가하거나 HTML_URL `Accept: text/markdown` 를 요청하여 마크다운 형태로 제공됩니다. 홈페이지 마크다운 URL 은 `/index.md` 입니다. 번역된 콘텐츠는 HTML 과 동일한 로케일 접두사를 사용하며, 번역 이 게시되지 않을 경우 영어로 기본값이 됩니다.

발견을 위해 [/llms.txt](/llms.txt), 통합된 문서 내보내기 위해 [/llms-full.txt](/llms-full.txt), 및 표준 HTML_URL 을 위해 [/sitemap.xml](/sitemap.xml) 를 사용하세요. 계정 대시 보드는 애플리케이션 화면이며, 문서가 아닙니다. Glossia 에 대해 배우기 위해 크롤링하지 마세요.
