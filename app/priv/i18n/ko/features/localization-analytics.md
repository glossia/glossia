## 데이터를 기반으로 다음 로케일을 결정하세요

대부분의 팀은 직감에 따라 타겟 언어를 선택합니다. 현지화 분석은 이를 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 가 방문자의 브라우저에서 요청하는 언어, 그들이 오고 있는 국가, 그리고, 특히 현재 지원 중인 언어와의 중첩을 보여줍니다.

주요 지표는 **로컬라이제이션 격차**입니다: 선호 언어가 지원되지 않는 방문자의 비율입니다. 국가, 리퍼러, 페이지별로 세부 사항을 파고들어 수요가 집중된 곳과 어떤 새로운 로케일이 효과를 낼 수 있는지 정확히 파악하세요.

## 타협 없는 프라이버시

Glossia 분석은 필요 없는 것만 수집하지 않으며 식별 가능한 정보도 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 시간대 및 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 매일 회전되는 해시에서 고유 방문자를 도출한 후 삭제합니다. 쿠키 설정은 없고, 지문 처리도 없으며, 방문자는 날짜나 사이트 간에 추적되지 않습니다.

결과적으로 동의 배너 없이 배포할 수 있는 분석이며, 이는 당신의 국제 방문자들이 이미 가지고 있는 프라이버시 기대치와 일치합니다.

## 몇 초 만에 설치하세요

사이트에 코드를 한 줄 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하시나요? `@glossia/web` 를 설치하고 `init({ domain })` 를 호출하세요. 어떤 경우든, 페이지 뷰, 클라이언트 측 네비게이션 및 커스텀 이벤트는 당신의 로컬라이제이션 기회를 순위로 정하는 동일한 대시보드에 흘러 들어갑니다.
