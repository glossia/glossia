## 데이터를 바탕으로 다음 로케일을 결정하세요

대부분의 팀은 직감으로 대상 언어를 선택합니다. 로케일라이제이션 분석은 이를 데이터 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 는 방문자 브라우저가 요청한 언어와 그들이 온 국가, 그리고 무엇보다 중요한 기존에 지원하는 언어와의 중첩 범위를 보여줍니다.

핵심 지표는 **로케일라이제이션 격차**: 선호 언어에 대한 지원 번역이 없는 방문자의 비율입니다. 국가별, 리퍼러별, 페이지별 세부 분석을 통해 수요 지원이 부족한 집중 지점과 어떤 신규 로케일이 상황을 개선할지 확인하세요.

## 타협 없는 프라이버시

Glossia 분석은 필요 없는 것은 수집하지 않으며, 식별 가능한 것은 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 시간대, 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 일일 회전 해시를 기반으로 고유 방문자를 도출한 후 삭제합니다. 쿠키는 설정되지 않으며, 식별 지문도 생성되지 않으며 방문자는 날짜나 사이트 간 추적될 수 없습니다.

그 결과는 동의 배너 없이 배포 가능한 분석 데이터입니다. 이는 여러분의 국제 방문자들이 이미 가지고 있는 프라이버시 기대와 일치합니다.

## 몇 초 만에 설치

웹사이트에 한 줄 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하시나요? 설치 `@glossia/web` 그리고 호출 `init({ domain })`. 어쨌든, 페이지 조회수, 클라이언트 측 내비게이션 및 커스텀 이벤트는 귀하의 로컬라이제이션 기회를 우선 순위로 매기는 동일한 대시보드에 유입됩니다.
