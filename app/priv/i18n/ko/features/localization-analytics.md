## 데이터로 다음 진출 언어 결정

대부분의 팀은 직감적으로 목표 언어를 선택합니다. 현지화 분석은 이를 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 는 방문자 브라우저에서 요청하는 언어, 방문자 기원 국가, 그리고, 특히, 이미 지원하고 있는 언어와의 중첩을 보여줍니다.

핵심 지표는 **현지화 격차** 입니다: 지원되지 않는 선호 언어를 가진 방문자의 비율입니다. 국가별, referrer 별, 페이지별로 데이터를 확인하여 수요가 집중되는 정확한 위치와 어떤 새로운 지역이 차이를 만들어낼지 파악할 수 있습니다.

## 타협 없는 개인정보 보호

Glossia 분석은 필요한 정보 외에는 수집하지 않으며 식별 가능한 정보를 저장하지 않습니다. 브라우저는 페이지 URL, referrer, 선호 언어, 시간대, 화면 크기를 보냅니다. 서버는 IP 와 User-Agent 의 일일 회차 해싱에서 고유 방문자를 파생한 뒤 이를 삭제합니다. 쿠키는 설정되지 않으며, 정보는 지문 처리되지 않으며, 어떤 방문자도 날짜 간이나 사이트 간에 추적될 수 없습니다.

결과적으로 동의 배너 없이 출시할 수 있는 분석 데이터는, 당신의 국제 방문자들이 이미 가지고 있는 개인정보 기대치와 일치합니다.

## 수 초 만에 설치

사이트의 한 줄을 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하십니까? `@glossia/web` 를 설치하고 `init({ domain })` 를 호출하세요. 어느 경우든 페이지뷰, 클라이언트 측 네비게이션, 커스텀 이벤트는 당신의 현지화 기회를 순위로 정리하는 동일한 대시보드에 들어갑니다.
