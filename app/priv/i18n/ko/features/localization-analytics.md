## 데이터로 다음 로케일을 결정하세요

대부분의 팀은 목표 언어를 직감으로 결정합니다. 로컬라이제이션 분석은 이를 확실한 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 가 방문자 브라우저가 요청한 언어, 그들이 유입되는 국가, 그리고 특히 이미 지원하는 언어와의 겹침 영역을 보여줍니다.

주요 지표는 **로컬라이제이션 격차**: 선호 언어నికి 대한 지원 번역이 없는 방문자 비율입니다. 국가, 리퍼러, 페이지별로 세밀하게 분석하여 수요가 부족한 지역이 어디에 집중되어 있는지, 그리고 어떤 새로운 로케일을 도입하면 실제 효과를 거둘 수 있는지 파악하실 수 있습니다.

## 타협 없는 개인정보 보호

Glossia 분석은 불필요한 정보를 수집하지 않으며 식별 가능한 데이터를 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 타임존, 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 를 기반으로 일별 회전 해시에서 고유 방문자를 도출한 후 이를 폐기합니다. 쿠키는 설정되지 않으며, 아무것도 지문화되지 않으며, 어떤 방문자도 여러 날이나 사이트 간에 추적될 수 없습니다.

결국 동의 배너 없이 배포 가능한 분석 결과입니다. 이는 귀하의 국제 방문자 들이 이미 갖는 개인 정보 보호 기대와 부합합니다.

## 여러 초 만에 설치

사이트에 한 줄을 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하시나요? 설치 `@glossia/web` 그리고 호출 `init({ domain })`. 어쨌든 페이지 조회수, 클라이언트 사이드 내비게이션 및 사용자 정의 이벤트는 현지화 기회를 순위 매기는 동일한 대시보드에 집계됩니다.
