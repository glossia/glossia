## 데이터로 다음 로케일을 결정하세요

대부분의 팀은 직감에 따라 목표 언어를 선택합니다. 현지화 분석은 이를 명확한 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 는 방문자 브라우저에서 요청한 언어, 그들이 온 국가, 그리고 무엇보다 이미 지원 중인 언어와의 중첩도를 보여줍니다.

주요 지표는 **현지화 격차**: 선호 언어로 지원되지 않는 번역이 없는 방문자의 비율입니다. 국가, 추천 사이트, 페이지별로 상세 분석하여 수요가 집중되는 곳을 정확히 파악하고, 어떤 새 로케일이 실질적인 변화를 이끌어낼 수 있는지 확인하세요.

## 절충 없는 프라이버시

Glossia 분석은 필요 없는 정보는 수집하지 않으며, 식별 가능한 정보를 저장하지 않습니다. 브라우저는 페이지 URL, 추천 사이트, 선호 언어, 시간대, 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 일일 갱신 해시를 통해 고유 방문자를 식별하고 버립니다. 쿠키가 설정되지 않으며, 핑거프린팅되지 않고, 방문자는 날짜나 사이트 간에 추적될 수 없습니다.

결과적으로 동의 배너 없이 제공할 수 있는 분석입니다. 이는 귀사의 국제 방문자들이 이미 갖추고 있는 사생활 보호 기대와 일치합니다.

## 초 만에 설치

사이트에 한 줄만 추가하고 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하나요? 설치 `@glossia/web` 그리고 호출 `init({ domain })`. 어떤 경우든 페이지뷰, 클라이언트 측 내비게이션 및 커스텀 이벤트는 현지화 기회를 순위화하는 동일한 대시보드로 유입됩니다.
