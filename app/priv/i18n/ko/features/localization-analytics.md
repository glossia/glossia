## 데이터를 기반으로 다음 로케일을 결정하세요

대부분의 팀은 직감에 따라 목표 언어를 선택합니다. 로컬라이제이션 분석은 이를 데이터 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 는 방문자의 브라우저에서 요청하는 언어, 그들이 유래한 국가, 그리고 무엇보다도 이미 지원하는 언어와의 중첩을 보여줍니다.

다크니스트 메트릭은 **localization gap**: 선호하는 언어에 해당 지원 번역이 없는 방문자의 비율입니다. 국가, 리퍼러, 페이지별로 특징을 조사하여 미시계 수요 집중 위치와 어떤 새 로케일이 가능한지를 확인하세요.

## 타협 없는 프라이버시

Glossia 분석은 필요 없는 것은 수집하지 않으며, 식별 가능한 것도 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 시간대, 및 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 일일 회전 해시에서 고유한 방문자를 도출한 후 이를 삭제합니다. 쿂�는 설정되지 않으며, 어떤 지문도 생성되지 않고, 어떤 방문자도 일별이나 사이트 간 추적될 수 없습니다.

결국 동의 배너 없이 배포할 수 있는 분석 데이터를 얻을 수 있습니다. 이는 국제 방문자들이 이미 가지고 있는 프라이버시 기대와 일치합니다.

## 몇 초 만에 설치

사이트에 한 줄을 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하나요? `@glossia/web` 를 설치하고 `init({ domain })` 를 호출하세요. 어느 방식이든, 페이지뷰, 클라이언트 측 네비게이션 및 커스텀 이벤트는 현지화 기회를 상위 순위로 평가받는 동일한 대시보드에 통합됩니다.
