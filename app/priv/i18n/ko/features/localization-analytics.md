## 데이터로 다음 로케일을 선택하세요

대부분의 팀은 타겟 언어를 직감에 선택합니다. 로컬라이제이션 분석은 이를 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 가 방문자의 브라우저에서 요청한 언어와 방문자가 온 국가, 그리고 무엇보다도 중요하게는 이미 지원 중인 언어와 겹치는 부분을 보여줍니다.

주요 지표는 **로컬라이제이션 갭**: 선호 언어를 지원하지 않는 방문자 비율입니다. 국가별, 출처별, 페이지별로 자세히 살펴보세요. 충족되지 않은 수요가 어디서 집중되는지 어떤 새로운 로케일이 큰 영향을 미칠지 정확히 파악하세요.

## 타협 없는 프라이버시

Glossia 분석은 필요 없는 것은 수집하지 않으며 식별 가능한 정보도 저장하지 않습니다. 브라우저는 페이지 URL, 출처, 선호 언어, 시간대, 및 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 일일 회전 해싱을 통해 고유 방문자를 도출한 후 버립니다. 쿠키는 설정되지 않으며, 지문 식별은 이루어지지 않습니다. 방문자는 날짜나 사이트 사이에서 추적되지 않습니다.

이 결과는 동의 배너 없이도 배포 가능한 분석입니다. 이는 귀하의 국제 방문자들이 이미 가지고 있는 프라이버시 기대와 맞춥니다.

## 수 초 만에 설치하세요.

사이트에 한 줄 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하십니까? 설치 `@glossia/web` 그리고 호출 `init({ domain })`. 어떤 방식이든, 페이지뷰, 클라이언트 측 네비게이션 및 커스텀 이벤트는 현지화 기회를 우선순위를 정하는 동일한 대시보드에 모입니다.
