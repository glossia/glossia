## 데이터를 바탕으로 다음 로케일을 결정하세요.

대부분의 팀은 타겟 언어를 직감에 따라 선택합니다. 현지화 분석은 이를 데이터 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 는 방문자의 브라우저가 요청한 언어와 그들이 속한 국가를 보여줍니다. 특히, 이미 지원 중인 언어 와의 중복 여부를 정확히 확인해드립니다.

주요 지표는 **현지화 격차**: 선호 언어가 지원되지 않는 방문자의 비율입니다. 국가, 리퍼러, 페이지별로 파고들어 수요가 집중된 곳과 어떤 새로운 로케일이 실질적인 영향을 줄 수 있는지 정확히 파악하세요.

## 타협 없는 프라이버시

Glossia 분석은 필요 없는 데이터는 수집하지 않으며, 식별 가능한 정보는 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 시간대, 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 일일 회전 해싱을 통해 고유 방문자를 도출한 후 즉시 삭제합니다. 쿠키는 설정되지 않으며, 지문 식별도 이루어지지 않아 방문자가 기간이나 사이트 간 추적되지 않습니다.

결과적으로 동의 배너 없이도 배포할 수 있는 분석입니다. 이는 당신의 국제 방문자들이 이미 가지고 있는 프라이버시 기대와 일치합니다.

## 여러 초 만에 설치

사이트에 한 줄을 추가하고 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하나요? 설치 `@glossia/web` 그리고 호출 `init({ domain })`. 어떤 경우든, 페이지뷰, 클라이언트 사이드 내비게이션 및 커스텀 이벤트는 현지화 기회 우선순위를 정하는 동일한 대시보드에 모입니다.
