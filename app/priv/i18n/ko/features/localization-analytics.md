## 데이터로 다음 로케일을 결정하세요

대부분의 팀은 직감으로 대상 언어를 선택합니다. 로컬라이제이션 분석은 이를 신호로 대체합니다. 웹 SDK 를 추가하면 Glossia 가 방문자의 브라우저에서 요청하는 언어, 그들이 거주하는 국가, 무엇보다도 이미 지원하고 있는 언어와의 중첩을 보여줍니다.

주요 지표는 **로컬라이제이션 갭**입니다: 선호 언어에 대한 지원 번역이 없는 방문자의 비율입니다. 국가별, 리퍼러별, 페이지별로 자세히 분석하여 수요가 집중되는 곳과 어떤 새로운 로케일이 변화를 이끌어낼지 정확히 파악하세요.

## 타협 없는 개인정보 보호

Glossia 분석 서비스는 필요한 것 외엔 모든 데이터를 수집하지 않으며 식별 가능한 데이터를 저장하지 않습니다. 브라우저는 페이지 URL, 리퍼러, 선호 언어, 시간대, 그리고 화면 크기를 전송합니다. 서버는 IP 와 User-Agent 의 매일 회전하는 해시를 통해 고유 방문자를 특정하고 그 후에는 저장합니다. 쿠키는 설정되지 않으며, 어떤 정보도 지문으로 등록되지 않고, 방문자는 날짜나 사이트를 건너뛰어 추적될 수 없습니다.

결과적으로, 동의를 위한 배너 없이 배포 가능한 분석을 얻게 되며, 이는 국제 방문자들이 이미 가지고 있는 개인정보 보호 기대와도 부합합니다.

## 여러 초 만에 설치

사이트에 한 줄을 추가하면 Glossia 가 측정을 시작합니다:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm 을 선호하나요? `@glossia/web` 를 설치하고 `init({ domain })` 를 호출하세요. 어느 경우든, 페이지뷰, 클라이언트 측 네비게이션, 커스텀 이벤트는 귀사의 로컬라이제이션 기회를 순위로 정렬하는 동일한 대시보드에 통합됩니다.
