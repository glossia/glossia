## MCP 는 무엇인가요?

해당 [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io)는 AI 도우미와 외부 도구 및 데이터 소스를 연결하는 개방 표준입니다. 각 코딩 어시스턴트에 맞게 커스텀 통합을 구축하는 대신, 단 하나의 MCP 서버를 노출하고 호환 가능한 클라이언트가 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어 핵심, 곧 음성 설정, 용어 관리, 조직 관리, 프로젝트 목록에 직접적인 アクセス를 제공합니다.

## 사용 가능한 도구

MCP 서버는 일일 작업하는 리소스를 기준으로 16 개의 도구를 노출합니다. [도구 참조](/docs/reference/mcp/tools)를 통해 파라미터 및 사용 방법을 확인하세요.

**계정 및 조직** -- 계정을 나열하고 조직을 생성 및 관리하며 구성원을 초대하고 접근을 제어하세요. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 의 콘텐츠 생성 및 수정 방식을 제어하는 음성 설정을 읽거나 업데이트하세요. 어조, 격식, 대상 청중 및 로케일별 오버라이드를 편집기 없이 조정하세요.

**용어 관리** -- 모든 콘텐츠에서 용어의 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 용어 항목을 추가, 업데이트 및 버전 관리하세요.

**프로젝트** --组织中의 프로젝트를 나열하고 검토하세요.

## 작동 원리

MCP 클라이언트를 `https://your-glossia-instance/mcp`로 표시하고 OAuth beara token 과 인증하세요. [MCP 설정 가이드](/docs/reference/mcp/overview)는 동적 클라이언트 등록 및 PKCE 를 포함하는 전체 연결 흐름을 안내합니다. [REST API](/features/rest-api)와 동일한 인증 및 승인 시스템을 사용하므로 API 에서 작동하는 모든 토큰도 MCP 에서 작동합니다.

그린으로 전환되면 AI 도우미는 16 개 도구 중 어느 것도 호출할 수 있습니다. "Acme 라는 조직을 생성"하거나 "내 음성 톤을 전문적 으로 업데이트"하도록 지시하면 에이전트가 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우를 위해

MCP 는 단순한 편의 레이어일 뿐입니다. Glossia 를 더 큰 에이전트 파이프라인으로 제련하기 위한 토대로 작동합니다. 

단일 클라이언트로 고정되어 있지 않았고 표준화된 프로토콜에서는 Claude, Cursor, 또는 사용자 정의 에이전트로 전환할 수 있습니다.
