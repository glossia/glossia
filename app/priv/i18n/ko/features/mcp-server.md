## MCP 는 무엇인가요?

The [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 외부 도구와 데이터 소스에 AI 어시스턴트를 연결하기 위한 개방형 표준입니다. 각 코딩 어시스턴트에 대해 세련된 통합을 구축하는 대신 단일 MCP 서버를 노출하면 호환 가능한 클라이언트를 모두 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어 핵심 기능에 대한 직접적인 접근을 제공합니다: 목소리 설정, 용어집 관리, 조직 관리, 프로젝트 목록

## 사용 가능한 도구

MCP 서버는 매일 사용하는 리소스를 중심으로 구성된 16 개의 도구를 제공합니다. 다음 [전체 도구 참조](/docs/reference/mcp/tools) 파라미터 및 사용 세부 사항입니다.

**계정 및 조직** -- 계정을 확인하고 조직을 생성 및 관리하며, 멤버를 초대하고 접근 권한을 제어합니다. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 확인 및 업데이트하세요. 편집기를 떠나지 않고 톤, 형식성, 대상 청중 및 지역별 오버라이드를 조정할 수 있습니다.

**용어집 관리** -- 전체 콘텐츠 내에서 용어집 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 용어집 항목을 추가, 업데이트 및 버전 관리하세요.

**프로젝트** -- 조직 간 프로젝트 목록 확인 및 검사

## 작동 방식

MCP 클라이언트를 대상에 연결하고 `https://your-glossia-instance/mcp` OAuth Bearer 토큰으로 인증하고. 다음 [MCP 설정 가이드](/docs/reference/mcp/overview) 동적 클라이언트 등록 및 PKCE 를 포함한 전체 연결 절차를 설명합니다. 다음 [REST API](/features/rest-api), API 에서 작동하는 토큰 은 API 에서 MCP 에서도 작동합니다.

그런 다음 AI 비서는 16 개의 도구 중 어떤 것도 호출할 수 있습니다. "Acme 라는 조직 생성"하거나 "내 음성 톤을 전문적으로 설정"하라고 요청하면, 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우용으로 구축됨

MCP 는 단순한 편의 계층이 아닙니다. Glossia 를 보다 큰 에이전트 파이프라인에 구성하기 위한 토대입니다. 코딩 어시스턴트는 코드베이스를 읽을 수 있으며, 현지화되지 않은 콘텐츠를 감지하고, 새 용어로 용어 사전을 업데이트하고, 특정 로케일에 맞는 음성 설정을 조정하며, 단일 대화 속에서 현지화 실행을 트리거할 수 있습니다.

프로토콜이 표준화되어 있으므로 특정 클라이언트에도 고정되어 있지 않습니다. 설정 한 줄도 변경하지 않고 Claude, Cursor 나 자체 커스텀 에이전트 사이를 전환할 수 있습니다.
