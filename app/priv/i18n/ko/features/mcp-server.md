## MCP 는 무엇인가요?

이 [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 외부 도구 및 데이터 출처에 AI 어시스턴트를 연결하기 위한 공개 표준입니다. 각 코딩 어시스턴트를 위한 맞춤형 통합을 구축하는 대신, 단일 MCP 서버를 노출하면 호환 가능한 클라이언트는 이를 사용할 수 있습니다.

Glossia MCP 서버는 에이전트에게 플랫폼의 언어 핵심, 음성 설정, 용어 관리, 조직 관리 및 프로젝트 목록에 직접 접근할 수 있게 합니다.

## 사용 가능한 도구

MCP 서버는 평소 사용하는 리소스를 중심으로 구성된 16 개의 도구를 제공합니다. 확인 [전체 도구 참조](/docs/reference/mcp/tools) 매개변수 및 사용 세부 사항.

**계정과 조직** -- 계정을 나열하고, 조직을 생성 및 관리하며, 회원을 초대하고 접근 권한을 제어하세요. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 확인하고 업데이트하세요. 에디터를 떠나지 않고 톤, 공식성, 대상 청중 및 로케일별 오버라이드를 조정하세요.

**용어 관리** -- 모든 콘텐츠에서 용어의 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 용어 항목을 추가, 업데이트 및 버전 관리하세요.

**프로젝트** -- 조직 간 프로젝트 목록 확인 및 검사

## 작동 방법

MCP 클라이언트를 연결하여 `https://your-glossia-instance/mcp` 및 OAuth Bearer 토큰으로 인증합니다. 그 [MCP 설정 가이드](/docs/reference/mcp/overview) 전체 연결 과정을 설명하며, 동적 클라이언트 등록 및 PKCE 를 포함합니다. 그 [REST API](/features/rest-api), 따라서 API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

여기서부터 당신의 AI 어시스턴트는 16 개 도구 중 어떤 것을든 호출할 수 있습니다. "Acme 라는 조직 생성"하거나 "내 목소리 톤을 전문적으로 업데이트"하라고 요청하면, 에이전트가 당신의 의도를 올바른 도구 호출로 변환합니다.

## 에이전틱 워크플로우를 위해 구축됨

MCP 는 단순한 편의 계층이 아닙니다. 이는 Glossia 를 더大的 에이전틱 파이프라인으로 구성하는 기초입니다. 코딩 어시스턴트는 당신의 코드베이스를 읽으며, 번역되지 않은 콘텐츠를 감지하고, 새로운 용어로 용어를 갱신하며, 특정 로케일에 맞는 목소리 설정을 조정하고, 단일 대화에서 로컬라이제이션 실행을 트리거할 수 있습니다.

프로토콜이 표준화되어 있으므로, 당신은 특정 클라이언트에도 얽매이지 않습니다. 설정의 한 줄도 수정 없이 Claude, Cursor, 또는 당신만의 커스텀 에이전트 간에 전환할 수 있습니다.
