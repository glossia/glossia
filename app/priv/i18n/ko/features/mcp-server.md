## MCP 는 무엇입니까?

이 [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 외부 도구 및 데이터 소스와 AI 어시스턴트를 연결하기 위한 개방형 표준입니다. 모든 코딩 어시스턴트마다 맞춤형 통합을 구축하는 대신, 단일 MCP 서버를 노출하여 호환 가능한 클라이언트가 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어 핵심인 음성 설정, 용어 관리, 조직 관리 및 프로젝트 목록에 대한 직접적인 접근을 제공합니다.

## 사용 가능한 도구

MCP 서버는 일상적으로 작업하는 리소스를 중심으로 구성된 16 개의 도구를 제공합니다. 참고해 [전체 도구 참조](/docs/reference/mcp/tools) 파라미터 및 사용 세부 사항에 대해.

**계정과 조직** -- 계정을 확인하고 조직을 생성 및 관리하며, 멤버를 초대하고 접근 권한을 제어하세요. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 구성** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 확인하고 업데이트하세요. 편집기를 떠나지 않고 톤, 공식성, 대상 독자 및 로케일별 오버라이드를 조정하세요.

**용어 관리** -- 모든 콘텐츠에서 용어 일관성을 유지하세요. 용어 항목을 추가, 업데이트 및 버전 관리하여 에이전트가 항상 올바른 용어를 사용할 수 있도록 합니다.

**프로젝트** -- 조직 전체의 프로젝트를 나열하고 검토합니다.

## 작동 방식

MCP 클라이언트를 다음 주소로 설정하고 `https://your-glossia-instance/mcp` 그리고 OAuth bearer 토큰으로 인증합니다. 이 [MCP 설정 가이드](/docs/reference/mcp/overview) 전체 연결 흐름을 안내하며, 동적 클라이언트 등록 및 PKCE 를 포함합니다. 서버는 동일한 인증 및 권한 부여 시스템과 동일한 [REST API](/features/rest-api), 따라서 API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

이후 AI 어시스턴트는 16 가지 도구 중 하나를 호출할 수 있습니다. "Acme 라는 조직을 생성하세요"하거나 "내 보이스 톤을 전문적으로 업데이트하세요"라고 요청하면 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우를 위해 구축됨

MCP 는 단순한 편의성 레이어가 아닙니다. 더 큰 에이전트 파이프라인에 Glossia 를 조립하기 위한 기반입니다. 코딩 어시스턴트는 코드베이스를 읽거나 로컬라이제이션되지 않은 콘텐츠를 감지하거나 용어를 새 용어로 업데이트하거나, 특정 로케일을 위한 보이스 설정을 조정하거나 로컬라이제이션 실행을 트리거할 수 있으며, 모든 작업은 단일 대화에서 완료됩니다.

프로토콜이 표준화되어 있으므로 특정 클라이언트에 제한되지 않습니다. 설정 한 줄도 변경하지 않고 Claude, Cursor 또는 자체 커스텀 에이전트 사이에서 전환할 수 있습니다.
