## MCP 란 무엇인가요?

[모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 AI 어시스턴트를 외부 도구 및 데이터 소스에 연결하는 개방형 표준입니다. 모든 코딩 어시스턴트에 대해 커스텀 통합을 구축하는 대신, 단일 MCP 서버를 노출하여 호환 가능한 모든 클라이언트에서 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어적 핵심인 음성 설정, 어휘 관리, 조직 관리, 프로젝트 목록에 직접적인 액세스를 제공합니다.

## 사용 가능한 도구

MCP 서버는 일일 리소스를 기준으로 16 개의 도구를 노출합니다. 매개변수 및 사용 세부 사항에 [전체 도구 참조](/docs/reference/mcp/tools) 를 참조하십시오.

**계정과 조직** -- 계정 확인, 조직 생성 및 관리, 멤버 초대 및 액세스 제어. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 읽기 및 수정. 톤, 공식성, 대상 사용자, 그리고 지역별 오버라이드를 편집기를 떠나지 않고 조정하세요.

**어휘 관리** -- 모든 콘텐츠의 어휘 일관성 유지. 어휘 항목을 추가, 업데이트, 버전 관리하여 에이전트가 항상 올바른 용어를 사용할 수 있도록 합니다.

**프로젝트** -- 조직 간 프로젝트 목록 나열 및 검사.

## 동작 방식

MCP 클라이언트를 `https://your-glossia-instance/mcp` 으로 지시하고 OAuth bearer 토큰으로 인증하세요. [MCP 설정 가이드](/docs/reference/mcp/overview) 는 동적 클라이언트 등록 및 PKCE 를 포함한 전체 연결 흐름을 안내합니다. 서버는 [REST API](/features/rest-api) 와 동일한 인증 및 권한 시스템을 사용하여, API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

이후, AI 어시스턴트는 16 개 도구 중 하나를 호출할 수 있습니다. ""Acme 라는 조직 생성"" 이거나 ""내 음성 톤을 전문으로 업데이트"" 라고 요청하면 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우를 위한 구축

MCP 는 단순한 편의 레이어에 그치지 않습니다. 그것은 Glossia 를 더 큰 에이전트 파이프라인으로 구성하기 위한 기반입니다. 코딩 어시스턴트는 코드베이스를 읽거나, 미국소화 콘텐츠를 감지하거나, 새 용어로 어휘를 업데이트하거나, 특정 지역의 음성 설정을 조정하거나, 로컬라이제이션 실행을 트리거하는 모든 작업을 단일 대화에서 수행할 수 있습니다.

프로토콜이 표준화되어 있으므로 단일 클라이언트에 제한되지 않습니다. 설정 라인 변경 없이 클로드, 커서 또는 자체 커스텀 에이전트 간 전환 가능합니다.
