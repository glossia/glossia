## MCP 란 무엇인가요?

[모델 컨텍스트 프로토콜](https://modelcontextprotocol.io)은 AI 어시스턴트를 외부 도구 및 데이터 소스에 연결하기 위한 개방형 표준입니다. 모든 코딩 어시스턴트마다 커스텀 통합을 구축하는 대신 단일 MCP 서버를 노출하면 호환 가능한 모든 클라이언트가 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어학적 핵심을 직접적인 접근 권한을 제공합니다: 음성 설정, 용어 관리, 조직 관리, 및 프로젝트 목록입니다.

## 사용 가능한 도구

MCP 서버는 매일 사용하시는 리소스를 기반으로 16 개의 도구를 노출합니다. 파라미터와 사용 세부 정보를 위해 [전체 도구 참조](/docs/reference/mcp/tools)를 확인하세요.

**계정과 조직** -- 계정을 목록化管理, 조직을 생성하고 관리, 멤버를 초대하고 액세스를 제어합니다. 에이전트는 대화로 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 읽거나 업데이트하세요. 어조, 공식성, 대상 청중, 및 로케일별 오버라이드를 편집기를 떠나지 않고 조정할 수 있습니다.

**용어 관리** -- 모든 콘텐츠에 걸쳐 용어 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 용어 항목을 추가, 업데이트 및 버전 관리합니다.

**프로젝트** -- 조직 전체에 샌다 프로젝트 목록 관리 및 검증을 수행합니다.

## 작동 방식

MCP 클라이언트를 `https://your-glossia-instance/mcp` 로 연결하고 OAuth 베어어 토큰으로 인증하세요. [MCP 설정 가이드-setup膏서](/docs/reference/mcp/overview) 는 동적 클라이언트 등록 및 PKCE 를 포함한 전체 연결 흐름을 안내합니다. 서버는 [REST API](/features/rest-api) 와 동일한 인증 및 인증 시스템을 사용하므로, API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

이제부터, AI 어시스턴트는 16 개 도구 중 임의의 도구를 호출할 수 있습니다. "Acme 라는 조직 생성" 또는 "내 음성 어조를 전문적인 것으로 업데이트"라고 요청하면, 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우를 위한

MCP 는 단순한 편의 계층만은 아닙니다. Glossia 를 더 큰 에이전트 파이프라인으로 구성하는 기초입니다. 코드 어시스턴트는 코드베이스를 읽거나 로컬화되지 않은 콘텐츠를 감지하고, 새 용어로 용어 데이터베이스를 업데이트하며, 특정 로케일을 위한 음성 설정을 조정하고 로컬화 실행을 트리거하는 등 단일 대화에서 모든 작업을 수행할 수 있습니다.

프로토콜이 표준화되어 있으므로, 단일 클라이언트에 한정되지 않습니다. 구성 한 줄도 변경하지 않고 Claude, Cursor, 또는 자체 커스텀 에이전트 사이로 전환할 수 있습니다.
