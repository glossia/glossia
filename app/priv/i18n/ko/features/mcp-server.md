## MCP 는 무엇인가요?

이 [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 외부 도구 및 데이터 소스와 AI 어시스턴트를 연결하는 개방형 표준입니다. 모든 코딩 어시스턴트에 대한 커스텀 통합을 구축하는 대신, 단일 MCP 서버를 노출하면 호환 가능한 클라이언트는 모두 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어학적 핵심 recursos, 즉 목소리 설정, 용어 관리, 조직 관리 및 프로젝트 목록에 대한 직접적인 접근을 제공합니다.

## 사용 가능한 도구

MCP 서버는 일상적으로 작업하는 리소스를 중심으로 16 개의 도구를 노출합니다. 보십시오 [전체 도구 참조](/docs/reference/mcp/tools) 매개변수와 사용 세부 사항에 대해.

**계정 및 조직** -- 계정을 확인하고 조직을 생성 및 관리하며 구성원을 초대하고 액세스를 제어합니다. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**음성 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 확인 및 업데이트하세요. 톤, 공식성, 대상 및 로캘별 오버라이드를 편집기를 떠나지 않고 조정하세요.

**용어 관리** -- 모든 콘텐츠 전반의 용어 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 용어 항목을 추가, 업데이트 및 버전 관리합니다.

**프로젝트** -- 조직 간 프로젝트를 나열하고 검토하세요.

## 작동 방식

MCP 클라이언트를 연결 대상에 설정하고 `https://your-glossia-instance/mcp` OAuth bearer 토큰으로 인증합니다. 다음 [MCP 설정 가이드](/docs/reference/mcp/overview) 동적 클라이언트 등록 및 PKCE 를 포함한 전체 연결 흐름을 안내합니다. 서버는 동일한 인증 및 권한 부여 시스템을 [REST API](/features/rest-api), API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

현재부터 AI 비서는 16 가지 도구 중 임의의 도구를 호출할 수 있습니다. "Acme 라는 조직 생성" 이나 "내 음성 톤을 전문적으로 업데이트" 라고 요청하면, 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우 를 위한

MCP 는 단순한 편의 레이어가 아닙니다. 그것은 Glossia 를 더 큰 에이전트 파이프라인으로 구성하는 기반입니다. 코딩 보조 도구는 코드베이스를 판독하고, 현지화되지 않은 콘텐츠를 감지하고, 새로운 용어로 용어를 업데이트하며, 특정 로케일을 위한 음성 설정을 조정하고, 단일 대화에서 현지화 작업 실행을 트리거합니다.

프로토콜이 표준화되어 있으므로, 당신은 단일 클라이언트에 묶이지 않습니다. 설정 코드 한 줄도 변경하지 않고 Claude, Cursor, 또는 자체 커스텀 에이전트 간 전환이 가능합니다.
