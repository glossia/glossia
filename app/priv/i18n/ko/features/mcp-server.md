## MCP란 무엇인가요?

[Model Context Protocol](https://modelcontextprotocol.io)은 인공지능 어시스턴트를 외부 도구 및 데이터 소스에 연결하기 위한 개방형 표준입니다. 각 코딩 어시스턴트에 맞는 통합을 별도로 구축하는 대신, 단일 MCP 서버를 제공하면 호환되는 모든 클라이언트에서 이를 사용할 수 있습니다.

Glossia의 MCP 서버는 에이전트가 플랫폼의 언어 핵심 기능인 보이스 구성, 용어 관리, 조직 관리 및 프로젝트 목록에 직접 접근할 수 있도록 지원합니다.

## 사용 가능한 도구

MCP 서버는 일상적으로 사용하는 리소스를 중심으로 구성된 16개의 도구를 제공합니다. 매개변수와 사용법에 관한 자세한 내용은 [전체 도구 참조](/docs/reference/mcp/tools)를 확인하세요.

**계정 및 조직**: 계정 목록을 조회하고, 조직을 생성 및 관리하며, 구성원을 초대하고, 접근 권한을 제어합니다. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**보이스 구성**: Glossia가 콘텐츠를 생성하고 수정하는 방식을 제어하는 보이스 설정을 조회하고 업데이트합니다. 편집기를 벗어나지 않고 어조, 격식 수준, 대상 독자 및 로케일별 재정의를 조정할 수 있습니다.

**용어 관리**: 모든 콘텐츠에서 용어의 일관성을 유지합니다. 에이전트가 항상 올바른 용어를 사용하도록 용어 항목을 추가하고 업데이트하며 버전을 관리할 수 있습니다.

**프로젝트**: 여러 조직의 프로젝트를 나열하고 살펴봅니다.

## 작동 방식

MCP 클라이언트가 `https://your-glossia-instance/mcp`을 가리키도록 설정하고 OAuth 전달자 토큰으로 인증합니다. [MCP 설정 가이드](/docs/reference/mcp/overview)에서는 동적 클라이언트 등록과 PKCE를 포함한 전체 연결 절차를 안내합니다. 서버는 [REST API](/features/rest-api)와 동일한 인증 및 권한 부여 시스템을 사용하므로, API에서 작동하는 모든 토큰을 MCP에서도 사용할 수 있습니다.

연결 후에는 인공지능 어시스턴트가 16개의 도구를 모두 호출할 수 있습니다. "Acme이라는 조직을 생성해 줘" 또는 "내 보이스 어조를 전문적으로 변경해 줘"라고 요청하면 에이전트가 의도를 적절한 도구 호출로 변환합니다.

## 에이전트 워크플로에 최적화

MCP는 단순한 편의 계층이 아닙니다. Glossia를 더 큰 에이전트 파이프라인에 통합하기 위한 기반입니다. 코딩 어시스턴트는 한 번의 대화에서 코드베이스를 읽고, 현지화되지 않은 콘텐츠를 감지하고, 새로운 용어로 용어 항목을 업데이트하고, 특정 로케일의 보이스 설정을 조정하며, 현지화 실행을 시작할 수 있습니다.

프로토콜이 표준화되어 있으므로 특정 클라이언트에 종속되지 않습니다. 구성 코드를 한 줄도 변경하지 않고 Claude, Cursor 또는 자체 개발한 에이전트로 전환할 수 있습니다.
