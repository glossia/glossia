## MCP 란 무엇인가요?

[모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 은 AI 어시스턴트를 외부 도구 및 데이터 소스에 연결하는 오픈 표준입니다. 모든 코딩 어시스턴트에 대한 맞춤형 연동을 구축하는 대신 단일 MCP 서버를 노출하면 호환 가능한 모든 클라이언트가 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어적 핵심인 음성 설정, 사전 관리, 조직 관리 및 프로젝트 목록에 대한 직접적인 접근 권한을 제공합니다.

## 사용 가능한 도구

MCP 서버는 일상적으로 사용하는 리소스를 기준으로 16 개 도구를 노출합니다. 매개변수와 사용 세부 사항은 [전체 도구 참조](/docs/reference/mcp/tools) 에서 확인하세요.

**계정과 조직** -- 계정을 나열하고, 조직을 생성 및 관리하며, 구성원을 초대하고 액세스를 제어합니다. 에이전트는 대화를 통해 전체 팀 구조를 구성할 수 있습니다.

**음성 설정** -- 콘텐츠를 생성하고 수정하는 방식을 제어하는 음성 설정을 읽거나 업데이트하세요. 편집을 떠날 필요 없이 톤, 격식, 대상 청중 및 로컬 오버라이드를 조정하세요.

**사전 관리** -- 모든 콘텐츠의 사전 일관성을 유지하세요. 에이전트가 항상 올바른 용어를 사용할 수 있도록 사전 항목을 추가, 업데이트 및 버전화하세요.

**프로젝트** -- 조직 전체의 프로젝트를 나열하고 검사합니다.

## 작동 방식

MCP 클라이언트를 `https://your-glossia-instance/mcp` 으로 설정하고 OAuth bearer 토큰으로 인증하세요. 전체 연결 흐름 (동적 클라이언트 등록 및 PKCE 포함) 을 안내하는 [MCP 설정 가이드](/docs/reference/mcp/overview) 를 확인하세요. 서버는 [REST API](/features/rest-api) 와 동일한 인증 및 권한 부여 시스템을 사용하므로 API 에서 작동하는 모든 토큰은 MCP 에서도 작동합니다.

그로부터 AI 어시스턴트는 16 개 도구 중 하나를 호출할 수 있습니다. "Acme 라는 조직을 생성하세요" 또는 "내 음성 톤을 전문적으로 업데이트하세요" 라고 요청하면 에이전트는 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 워크플로우용으로 구축됨

MCP 는 단순한 편의 계층이 아닙니다. 그것은 Glossia 를 더 큰 에이전트 파이프라인으로 조립하는 기초입니다. 코딩 어시스턴트는 코드베이스를 읽을 수 있고, 로컬라이제이션되지 않은 콘텐츠를 감지하며, 새로운 용어로 사전 업데이트하고, 특정 로컬의 음성 설정을 조정하고, 단일 대화 안에서 로컬라이제이션 실행을 시작할 수 있습니다.

프로토콜이 표준화되어 있으므로 특정 단일 클라이언트로 고정될 필요가 없습니다. 설정 한 줄을 변경하지 않고 Claude, Cursor, 또는 사용자 제작 에이전트 사이를 전환할 수 있습니다.
