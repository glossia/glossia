## MCP 는 무엇인가요?

이 [모델 컨텍스트 프로토콜](https://modelcontextprotocol.io) 외부 도구 및 데이터 소스와 AI 비서를 연결하는 오픈 표준입니다. 코딩 비서마다 맞춤형 통합을 구축하는 대신 단일 MCP 서버를 노출하고, 호환 가능한 클라이언트는 모두 이를 사용할 수 있습니다.

Glossia 의 MCP 서버는 에이전트에게 플랫폼의 언어 핵심 기능에 대한 직접적인 접근을 제공합니다: 음성 설정, 용어 관리, 조직 관리, 프로젝트 목록.

## 사용 가능한 도구

MCP 서버는 일상적으로 사용하는 리소스를 중심으로 16 개의 도구를 노출합니다. 보려면 [전체 도구 참조](/docs/reference/mcp/tools) 매개변수 및 사용 세부 정보에 대한.

**계정 및 조직** -- 계정 목록을 확인하고 조직을 생성 및 관리하며 구성원을 초대하고 액세스를 제어합니다. 에이전트는 대화를 통해 전체 팀 구조를 설정할 수 있습니다.

**목소리 설정** -- Glossia 가 콘텐츠를 생성하고 수정하는 방식을 제어하는 목소리 설정을 확인하거나 업데이트하세요. 톤, 격식, 대상 청중 및 로케일별 오버라이드를 편집기를 떠나지 않고 조정할 수 있습니다.

**용어 관리** -- 모든 콘텐츠에서 용어 일관성을 유지하세요. 용어 항목을 추가하고 업데이트하며 버전 관리하여 에이전트가 항상 올바른 용어를 사용할 수 있도록 합니다.

**프로젝트** -- 조직 간 프로젝트를 나열 및 검사.

## 작동 방식

MCP 클라이언트를 `https://your-glossia-instance/mcp` 및 OAuth Bearer 토큰으로 인증하세요. 이 [MCP 설정 가이드](/docs/reference/mcp/overview) 전체 연결 흐름을 안내하며 동적 클라이언트 등록 및 PKCE 를 포함합니다. 서버는 동일한 인증 및 권한 부여 시스템을 사용하는 것으로, [REST API](/features/rest-api), 따라서 API 에서 작동하는 토큰은 MCP 에서도 작동합니다.

그로부터 당신의 AI 도우미는 16 가지 도구 중 어떤 것을든 호출할 수 있습니다. "Acme 라는 조직을 생성하시오" 또는 "내 음성 톤을 전문적으로 업데이트하시오"라고 요청하면 에이전트는 당신의 의도를 올바른 도구 호출로 변환합니다.

## 에이전트 기반 워크플로우를 위해 구축됨

MCP 는 단순한 편의성 계층이 아닙니다. Glossia 를 더 거대한 에이전트 파이프라인으로 조립하는 기초입니다. 코딩 보조 에이전트는 코드베이스를 읽어 현지화되지 않은 콘텐츠를 감지하고, 새 용어로 용어를 업데이트하며, 특정 로케일을 위한 음성 설정을 조정하고, 현지화 실행을 트리거할 수 있습니다. 모든 작업은 단 한 번의 대화로 가능합니다.

프로토콜이 표준화되어 있으므로 특정 클라이언트에 구애받지 않습니다. 설정 한 줄도 변경하지 않고 Claude, Cursor, 또는 자체 커스텀 에이전트 사이를 전환하세요.
