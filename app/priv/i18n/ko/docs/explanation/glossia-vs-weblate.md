**Glossia 를 선택할 때는 언어 자동화가 나머지 소프트웨어 배포와 비슷하게 작동할 때을 원할 때입니다**: 버전 관리된 지침, 자체 모델 토큰, 저장소 내장 검사, 그리고 검토를 위한 Pull Request

[Weblate](https://weblate.org/) 는 웹 번역 인터페이스, 버전 제어 통합 및 자체 호스팅 옵션을 갖춘 오픈소스 현지화 시스템입니다. 공개 코드 및 Git 통합은 Glossia 고유의 것이 아닙니다. Glossia 를 선택하는 이유는 저장소 중심 배포, 모델 기반 변환,그리고 인간 및 에이전트 모두에게 재사용 가능한 언어 컨텍스트의 조화입니다.

## Glossia 선택 이유

| 우선순위 | Glossia 의 장점 |
|---|---|
| 프로덕트 워크플로우 내에서 검토 유지 | 저장소 변경 사항 및 Pull Request 를 통한 실제 버전 관리된 결과 검토 |
| 빠르게 변하는 소스 저장소 대응 | 변경 감지와 배치 발행은 변경되지 않는 입력을 반복 번역하지 않고도 지속적인 로케일 루프를 지원합니다. |
| 자체 모델 토큰 제공 | 계정 범위 제공자 인증서를 사용하여 지원 모델을 구성하고 저장소 소유 핸들을 통해 해당 모델을 선택합니다. |
| 내장 검증 재사용 | 후보를 실제 타겟 경로의 저장소 자체 검증 명령에 대해 실행합니다. |
| 번역 너머 컨텍스트 재사용 | 공유 음성 및 용어는 새 콘텐츠 및 에이전트 통합을 MCP 와 REST 인터페이스를 통해 안내합니다. |

## 저장소를 검토 대상으로 유지하세요

Glossia 는 Git 을 사용하여 무엇을 배포할지 결정하는 팀을 위해 설계되었습니다. 현지화 설정은 콘텐츠와 인접하며, 제안된 출력물은 제품 변경庆祝活动과 동일한 프로세스를 통해 검토할 수 있습니다.

Weblate 도 버전 제어와 통합됩니다. 웹 기반 번역 인터페이스는 기여자 커뮤니티에 딱 맞을 수 있습니다. Glossia 의 강조점은 다릅니다: 저장소 검토 경계를 유지하고 언어 자동화를 그로 전달하는 것, 다른 편집 인터페이스를 팀 작업의 중심으로 만드는 것 대비입니다.

## 자체 토큰 가져오기 및 모델 선택 명확화

Glossia 는 제공자 API 토큰으로 구성된 지원 모델을 사용합니다. 저장소 구성은 안정적인 모델 핸들을 참조하며, 기밀 정보는 계정 설정에 유지됩니다. 콘텐츠 범위나 타겟 로케일에 따라 다른 구성 모델을 선택하거나 모든 저장소를 변경하지 않고 인증 정보를 회전할 수 있습니다.

그것은 팀이 콘텐츠를 작성하는 모델을 명확하게 선택할 수 있는 공간을 제공합니다. 어떤 토큰이나 모델이 지원되는지, 또는 생성이 인간 검토 필요성을 제거하는지 약속하지는 않습니다. [모델 제공자 설정](/docs/how-to/configure-a-model-provider) 을 참조하세요

## 예산을 정의하는 검증 항목 재사용

Glossia 의 내장 구조 검증은品質력의 일부일 뿐입니다. `L10N.md`, 실제 타겟 경로의 후보에 저장소 내장 검증 스크립트, 파서, 컴파일러 또는 문서를 실행할 수 있습니다.

일조는 번역된 콘텐츠가 단순 문자열 이상인 경우에 유용합니다: 앱 전용 형식, 마크다운 컴포넌트, 구조화된 메타데이터 및 프로젝트가 이미 검증할 수 있는 제약 조건. 검증 및 복구는 파이프라인이 게시할 실제 파일과 연결되어 있습니다.

실행 환경은 여전히 검증 환경 의존성이 필요하며, 구조적 검증만으로는 언어적 정확성을 확립하지 않습니다. [L10N.md](/docs/reference/l10n-md) 및 [번역 복구](./translation-recovery) 를 참조하세요.

## 공개 소스 는 기준일뿐 종합된 것이 아닙니다

Glossia 의 코어는 공개되어 [Apache-2.0](https://github.com/glossia/glossia/blob/main/LICENSE-APACHE)说要, 그리고 협력 호스팅 서비스를 허용합니다. `ee/` 의 코벌리면 별도로 [라이선스](https://github.com/glossia/glossia/blob/main/ee/LICENSE.md) 가 있어 상용 사용을 위해 서면 계약이 필요해야 합니다. 이 오픈 코어 모델은 Weblate 의 GPL 기반 라이선싱과 다릅니다.

GPL 기반 라이선스 및 확립된 웹 번역 인터페이스가 최우선 기준이라면 Weblate 를 고려할 가치가 있습니다. 목표가 **자체 모델 인증서, 기존 저장소 검증 및 소프트웨어 배포를 따르는 언어 작업**이라면 Glossia 는 이러한 선택을 언어 OS 로 통합합니다.

이 비교는 Weblate 가 자동화, 검증 기능 또는 제공자 통합이 부재라고 주장하지 않으며 자동 전환이나 기능 동등성을 약속하지 않습니다. 현재 기능은 [Weblate 문서](https://docs.weblate.org/) 와 자동으로 확인하세요.
