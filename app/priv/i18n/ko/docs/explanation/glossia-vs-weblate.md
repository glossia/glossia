**언어 자동화가 나머지 소프트웨어 배포 와 동일하게 작동하기를 원할 때 Glossia 를 선택하세요:** 소스 제어 지침, 자신의 모델 토큰, 레포지토리에 본토의 검증, 그리고 검토용 Pull Request.

[Weblate](https://weblate.org/) 는 웹 번역 인터페이스, 버전 관리 통합 및 자체 호스팅 옵션이 있는 오픈 소스 현지화 시스템입니다. 퍼블릭 코드 및 Git 통합은 Glossia 에 만 국한된 것이 아닙니다. Glossia 를 선택하는 이유는 저장소 중심의 배포, 모델 기반 변환, 그리고 인간과 에이전트 모두에게 재사용 가능한 언어 컨텍스트의 조합 때문입니다.

## 강화 선택 Glossia

| 우선 순위 | Glossia 의 장점 |
|---|---|
| 프로덕트 워크플로우에 검토를 유지 | 레포지토리의 변경사항 및 Pull Request 를 통해 실제 소스 제어 출력을 검토합니다. |
| 신속하게 변하는 소스 레포지토리에 대응 | 변경 감지 및 배치 발행은 변경되지 않는 입력을 반복적으로 번역하지 않고 지속적인 현지화 순환을 지원합니다. |
| 자신의 모델 토큰 가져오기 | 계정 범위의 Provider 자격 증명을 사용하여 지원 모델을 설정하고 레포지토리가 소유한 핸들로 선택합니다. |
| 내장 유효성 검사 재사용 | 후보의 실제 타겟 경로에서 레포지토리의 자체 유효성 검사 명령을 실행합니다. |
| 번역 이상의 컨텍스트 재사용 | 공유된 음성 및 전문 용어가 새로운 콘텐츠와 에이전트 통합을 MCP 와 REST 인터페이스를 통해 안내할 수 있습니다. |

## 저장소를 검토 표면으로 유지

Glossia 는 Git 을 사용하여 무엇을 배포할 준비가 되었는지 결정하는 이미 Git 을 사용하는 팀을 위해 설계되었습니다. 현지화 설정은 콘텐츠 옆에 있으며, 제안된 출력은 제품 변경 과 동일한 프로세스를 통해 검토할 수 있습니다.

Weblate 도 버전 관리와 통합됩니다. 웹 기반 번역 인터페이스 는 기여자 커뮤니티가 필요한 것일 수 있습니다. Glossia 의 강조점은 다릅니다: 저장소 검토 경계를 유지하고 언어 자동화를 가져오며, 팀 작업의 중심이 되는 또 다른 편집 인터페이스 대신입니다.

## 자신의 토큰 가져오고 모델 선택 명확화

Glossia 는 제공자 API 토큰을 사용하여 구성된 지원 모델을 사용합니다. 레포지토리 설정은 안정적인 모델 핸들을 참조하며, 비밀은 계정 설정에 유지됩니다. 콘텐츠 범위나 타겟 지역 으로 구성된 모델을 선택하고 모든 레포지토리를 변경하지 않고 자격 증명을 회전시킬 수 있습니다.

이는 팀이 콘텐츠를 작성하는 모델을 선택할 수 있는 명확한 장소를 제공합니다. 어떤 토큰이나 모델이 지원되거나 생성이 인간 검토를 제거한다는 보장은 없으며, [모델 제공자 구성](/docs/how-to/configure-a-model-provider) 을 참조하세요.

## 납품 가능 변경을 정의하는 검사 재사용

Glossia 의 내장 구조적 검사는 품질 경계의 일부일 뿐입니다. `L10N.md` 를 통해 레포지토리의 네이티브 유효성 검사 스크립트, 파서, 컴파일러 또는 문서 검사를 후보의 실제 타겟 경로에서 실행할 수 있습니다.

이것은 번역된 콘텐츠가 단순한 문자열을 넘어 애플리케이션별 형식, Markdown 구성 요소, 구조화된 메타데이터, 그리고 프로젝트가 이미 검증할 수 있는 제약 사항을 포함할 때 유용합니다. 유효성 검사 및 복구 는 파이프라인이 게시할 실제 파일과 연결되어 있습니다.

실행 환경은 여전히 검증자의 의존성을 필요로 하며, 구조적 유효성 검사는 언어적 정확성을 확립하지 않습니다. [L10N.md](/docs/reference/l10n-md) 및 [번역 복구](./translation-recovery) 를 참조하세요.

## 공개 소스는 전체 비교가 아닌 기준으로만 존재합니다.

Glossia 의 구현은 공개되어 있으며, [O'Saasy](https://github.com/glossia/glossia/blob/main/LICENSE.md)에서 검사, 수정 및 자체 호스팅할 수 있습니다. 라이선스는 경쟁 호스팅 서비스를 제한하며, 이는 Weblate 의 GPL 기반 오픈 소스 라이선스와 다릅니다.

제한 없는 오픈 소스 라이선 계약과 확립된 웹 번역 인터페이스 가 주요 기준이라면 Weblate 가 고려될 자격이 있습니다. 목적이 **자신의 모델 자격 증명, 기존 레포지토리 검사와 소프트웨어 배포 와 일치하는 언어 작업**이라면 Glossia 는 언어 OS 에서 이러한 선택을 하나로 모읍니다.

이 비교는 Weblate 가 자동화, 유효성 검사 기능 또는 제공자 통합을 가지지 못한다는 주장을 하지 않으며, 자동 마이그레이션이나 기능 동등성을 보장하지 않습니다. 현재 기능은 [Weblate 의 문서](https://docs.weblate.org/) 를 참조하세요.
