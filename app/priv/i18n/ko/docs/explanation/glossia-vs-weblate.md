**언어 자동화가 나머지 소프트웨어 배포처럼 작동되려면 Glossia 를 선택하세요**: 소스 제어 지침, 자체 모델 토큰, 저장소 네이티브 체크 및 검토용 풀 리퀘스트입니다.

[Weblate](https://weblate.org/) 은 웹 번역 인터페이스, 버전 관리 통합 및 자체 호스팅 옵션이 있는 오픈소스 현지화 시스템입니다. 공개 코드 및 Git 통합은 Glossia 에 독점되지 않습니다. Glossia 를 선택해야 하는 이유는 저장소 중심 배포, 모델 기반 변환 및 인간과 에이전트 모두를 위한 재사용 가능한 언어 컨텍스트의 조합에 있습니다.

## 왜 Glossia 를 선택해야 할까요

| 우선순위 | Glossia 의 장점 |
|---|---|
| 제품 워크플로우에서 검토 유지 | 저장소 변경 및 풀 리퀘스트를 통해 실제 소스 제어 출력을 검토합니다. |
| 빠른 원본 저장소와 일치하기 | 변경 감지 및 배치 출력이 변경되지 않는 입력을 반복 번역하지 않고 지속적인 현지화 루프를 지원합니다. |
| 자체 모델 토큰 가져오기 | 계정 범위의 공급자 자격증명으로 지원 모델을 구성하고 저장소 소유 핸들자로 선택합니다. |
| 네이티브 유효성 검사 재사용 | 후보에 대해 실제 타겟 경로에서 저장소의 자체 유효성 검사 명령을 실행합니다. |
| 번역 이상의 컨텍스트 재사용 | 공유 음성 및 용어는 새 콘텐츠 및 에이전트 통합을 MCP 와 REST 인터페이스를 통해 안내할 수 있습니다. |

## 저장소를 검토 표로 유지하기

Glossia 는 이미 Git 를 사용해 무엇을 배포할 준비되인지 결정하는 팀을 위해 설계되었습니다. 현지화 설정은 콘텐츠 옆에 있으며 제안된 출력물은 제품 변경과 동일한 프로세스를 통해 검토될 수 있습니다.

Weblate 도 버전 관리와 통합됩니다. 브라우징 기반 번역 인터페이스는 기여자 커뮤니티가 필요로 하는 것일 수 있습니다. Glossia 의 강조점은 다릅니다: 작업 수준의 다른 편집 인터페이스 المركز을 만들기보다 저장소 검토 경계를 유지하고 언어 자동화를 여기에 추어넣는 것입니다.

## 자신의 토큰 가져오기 및 모델 선택 명시하기

Glossia 는 공급자 API 토큰으로 구성ైన 지원 모델을 사용합니다. 저장소 구성은 안정적인 모델 핸들을 참조하며, 비밀은 계정 설정에 남습니다. 콘텐츠 범위 또는 목표 로케일에 따라 다른 구성된 모델을 선택하고 모든 저장소를 변경하지 않고 자격증명을 교체할 수 있습니다.

팀에게 콘텐츠 작성 모델을 선택할 명시된 장소를 제공합니다. 어떤 토큰이나 모델이 지원되거나, 생성이 인간 검토 필요성을 제거한다는 약속은 아닙니다. [모델 제공자 구성](/docs/how-to/configure-a-model-provider) 참조.

## 데리발러블 변경을 정의하는 체크 재사용

Glossia 의 내장 구조적 체크는 품질 경계의 일부일 뿐입니다. `L10N.md` 를 통해, 실제 타겟 경로에서 후보의 저장소 네이티브 유효성 검사 스크립트, 파서, 컴파일러 또는 문서 검사를 실행할 수 있습니다.

번역된 콘텐츠가 단순 문자열을 넘어 애플리케이션별 형식, Markdown 컴포넌트, 구조화된 메타데이터 및 프로젝트가 이미 입증된 التحقق 기준을 포함할 때 유용합니다. 유효성 검사 및 복구는 파이프라인이 게시할 실제 파일과 연결되어 유지됩니다.

실행 환경은 여전히 유효성 검사자의 종속성을 필요로 하며, 구조적 유효성 검증은 언어적 정확성을 확립하지 않습니다. [L10N.md](/docs/reference/l10n-md) 및 [번역 복구](./translation-recovery) 참조.

## 공용 소스는 전체 비교가 아닌 기준선입니다.

Glossia 구현은 공개되어 상호 검별과 수정, [O'Saasy](https://github.com/glossia/glossia/blob/main/LICENSE.md) 하에 자체 호스팅이 가능합니다. 라이선스는 경쟁 호스팅 서비스를 제한하며 Weblate 의 GPL 기반 오픈소스 라이선스와는 다릅니다.

무제한 오픈소스 라이선스 및 확립된 웹 번역 인터페이스가 주요 기준이라면 Weblate 가 고려될 가치가 있습니다. 목표가 **자신의 모델 자격증명, 기존 저장소 체크 및 소프트웨어 배포를 따르는 언어 작업**이라면 Glossia 는 언어 OS 를 통해 이러한 선택을 하나로 모읍니다.

이 비교는 Weblate 가 자동화, 유효성 검사 기능, 또는 공급자 통합을 갖추지 않았다고 주장하지 않으며 자동 이주나 기능 동등성을 보장하지 않습니다. 현재 기능 확인을 위해 [Weblate 문서](https://docs.weblate.org/) 참조.
