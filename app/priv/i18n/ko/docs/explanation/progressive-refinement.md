초안 [대규모 언어 모델](https://en.wikipedia.org/wiki/Large_language_model) 구조적으로는 맞지만 뉘앙스, 톤, 또는 도메인 특화된 표현을 놓칠 수 있습니다. 이는 설계입니다. Glossia 는 콘텐츠 생성을 소프트웨어 팀이 코드를 다룰 때와 동일하게 취급합니다: 작동하는 버전을 출시하고 검토하고 반복적으로 개선합니다.

## 정제 루프

1. **초안**: Glossia 는 소스 파일과 컨텍스트를 기반으로 구조적으로 유효한 첫 번째 패스를 생성합니다 내 `L10N.md`.
2. **검토**: 귀 팀은 코드가 아닌 여전히 사용 중인 워크플로우인 pull request 와 diff 를 통해 이슈를 제기합니다.
3. **정제**: 업데이트된 컨텍스트 파일, 사전 교정, 및 리뷰 피드백이 다음 실행에 반영됩니다.
4. **수렴**: 각 사이클은 프로덕션 품질과의 거리를 좁힙니다. 시스템은 귀희 제공하는 컨텍스트를 통해 제품 목소리를 배웁니다.

## 이것이 왜 작동하는지

핵심 통찰은 컨텍스트가 누적된다는 것입니다. `L10N.md` 또는 교정된 사전 항목은 리뷰를 트리거한 파일뿐만 아니라 모든 향후 실행을 개선합니다.

이는 제조업의 카이젠과 엔지니어링의 점진적 근사 원리와 동일한 철학을 따릅니다: 충분한 수준의 기준선에서 시작하여 인간 판단이 개입된 환경에서 체계적으로 개선합니다.

## 실제적 함의

- 첫 번째 실행에서 완벽함을 기대하지 마세요. 하나 또는 두 번의 검토 주기를 계획하세요.
- 명확한 컨텍스트 파일 작성에 시간을 투자하세요. 이는 최대한 효과를 볼 수 있는 개선 사항입니다.
- 서버 번역 세션을 사용하여 번역된 파일을 추적하고,
  건너뛰었거나, 실패했습니다.
