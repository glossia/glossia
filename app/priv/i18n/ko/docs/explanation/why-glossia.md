제품은 지속적으로 출시될 수 있지만 번역은 별도의 릴리스 주기에 갇혀 있을 수 있습니다. Git 에서 소스 콘텐츠가 변경되면 누군가가 이를 번역 시스템으로 내보내고, 이를 정리하여 편집자가 작업한 후 누군가 결과물을 가져옵니다. 그 결과 제품은 언어 버전과 멀어집니다.

Glossia 는 제품 자체가 따르는 것과 같은 버전화되고 검토 가능한 배포 루프를 따르는 전제에 기반한 언어 OS 입니다.

## 번역 이상의 문제

팀은 의미를 보존하고 전문 용어를 적용하며 청중의 어조에 맞도록 콘텐츠를 업데이트해야 합니다. 이러한 결정은 문서화, UI 문자열, 마케팅 페이지, 에이전트 생성 작성에 모두 영향을 미칩니다.

모델은 유용한 초안을 생성할 수 있습니다. 하지만 그것만으로는 조직의 언어 결정을 알거나 문구 변경 이유를 기록하며 파일 형식을 검증하거나 다음 소스 수정을 동기화하는지 모릅니다. 프롬프트 반복은 배포 시스템이 아닙니다.

Glossia 는 언어 컨텍스트와 생성 주위의 메커니즘을 결합합니다: 설정, 변경 감지, 유효성 검사, 실패 복구, 버전 역사, 및 검토.

## 콘텐츠는 제품과 함께 남아있습니다

저장소는 발행된 콘텐츠의 권위입니다. 소스 파일, 설정, 생성된 번역, 검토 가능한 변경 사항이 Git 과 pull request 를 통해 이동할 수 있습니다. 로컬라이즈드 릴리스를 배포하기 전에는 팀이 모든 문장에 대해 호스팅 편집 인터페이스를 권위로 설정할 필요가 없습니다.

이를 통해 언어 변경 사항은 동기를 부여한 제품 변경 사항과 함께可见 됩니다. 검토자는 diff 를 검토하고, CI 는 출력을 검증하며, 동일한 배포 파이프라인이 이를 게시할 수 있습니다.

배포 모델에 대해서는 [연속적 현지화](./continuous-localization) 를, 해당의 이동성 관련 사항에 대해서는 [콘텐츠 소유권](./content-ownership) 를 확인하세요.

## 컨텍스트는 입력이며, 갇힘이 아닙니다

목소리 가이드와 전문 용어는 인간과 에이전트가 일관되게 작성하는 것을 돕습니다. 이는 재사용 가능한 언어 결정이며, 단순한 소스-타겟 섹션 쌍의 소유 모음이 아닙니다.

번역 메모리는 확립된 번역과 반복 콘텐츠에도 여전히 유용합니다. 버리는 것이 목적은 아닙니다. 대신 회사의 언어 지식이 사는 유일한 장소로 만드는 단일 벤더의 메모리 형식이나 편집 워크플로를 피해야 합니다.

## 개선 과정은 순환입니다

Glossia 의 점진적 세분화 모델은 중복 작업을 피하기 위해 콘텐츠 해시를 사용하고, 변환 주위의 유효성 검사를 실행하며 실패를 노출하여 커널 복구를 가능하게 합니다. 인간 수정은 고립된 생성으로 사라지지 않고 다음 개선에 정보를 제공합니다.

지역화 분석은 또 다른 입력을 제공합니다: 청중이 사용하는 언어와 장소를 이해하는 것은 팀이 투자할 지역을 결정하는 데 도움이 됩니다. 이것은 임기가 번역이 성장을 약속하는 증거가 아니라 우선순위선택을 위한 증거입니다.

## 어떤 대상에게 적합합니다

개발자, 언어 전문가, 제품 팀이 저장소 관리 콘텐츠를 협업하고 지속적으로 릴리스하고 싶을 때 Glossia 가 특히 관련이 있습니다. 모든 조직이 기존 TMS 를 포기해야 한다는 주장은 아닙니다. 중앙 요구사항이 올바른 브라우저 기반 편집기, 번역 대행사 조정, 또는 큰 확립된 메모리인 팀은 다른 워크플로우를 선호할 수 있습니다.

## 검사 가능한 구현

Glossia 의 코드는 공개되어 있으며, Phoenix 애플리케이션, Rust CLI, 웹 SDK, 배포 인프라를 포함합니다. 이는 언어 작업의 메커니즘이 검 discapable 하지 않고 검체할 수 있습니다.

Glossia는 오픈 코어 모델을 따릅니다. 코어에는 [Apache-2.0](https://github.com/glossia/glossia/blob/main/LICENSE-APACHE)이 적용되며, 해당 조건에 따라 상업적 이용, 수정, 배포, 자체 호스팅 및 경쟁 호스팅 서비스를 제공할 수 있습니다. `ee/`의 코드는 열람할 수 있지만 오픈 소스는 아닙니다. 별도의 [Enterprise 라이선스](https://github.com/glossia/glossia/blob/main/ee/LICENSE.md)가 적용되며 프로덕션 사용에는 서면 상업 계약이 필요합니다.
