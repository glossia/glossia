용어 사전은 번역이 매번 동일한 방식으로 렌더링되어야 하는 정리된 단어들의 집합입니다. 버전 관리적 의미의 "Commit" 은 유지됩니다. `commit` 스페인어에서는 바뀝니다. `提交` 간체자 중국어에도, 그리고 `コミット` 일본어에도 됩니다. 언어마다 하나의 결정이며, 모든 곳에서 강제됩니다.

## 용어 사전이 저장될 수 있는 두 곳

Glossia 는 용어 사전 항목을 검색하는 두 장소를 확인하여 번역 시간에 이를 병합합니다:

- **본인의 저장소**이미 사용 중인 번역 설정 파일에 있습니다. `L10N.md` 용어를 명시하며, 각 언어의 `L10N/<locale>.md` 번역을 명시합니다. 이는 개발자 주도 사전입니다: 변경 사항은 풀 리퀘스트를 통해 이루어지며, 각 언어별 리뷰어는 자신의 파일을 관리하고, 중첩 파일은 저장소 일부의 내용을 세분화하여 다듬을 수 있습니다.
- **서버**, 계정에 저장됩니다. 이는 번역가 주도 사전입니다: 리뷰어와 현지화 기여자는 코드를 건드리지 않고 대시보드를 통해 항목을 추가하거나 다듬으며, [REST API](/docs/reference/apis), 또는 [MCP 서버](/docs/reference/mcp). 계정에서 번역하는 모든 저장소에 적용됩니다.

두 곳 모두 유용하며, 서로를 대체하지 않습니다.

## 어떤 것을 언제 사용하는지

에서 용어를 정의합니다 **서버** 적용 시기:

- **여러 저장소에 적용됩니다.** 제품명, 브랜드 용어 및 회사 어휘는 한 번 정의되어 전체에 사용됩니다.
- **이를 결정하는 사람들은 저장소에서 근무하지 않습니다.** 언어학자, 검토자 및 외부 기여자는 레포지토리가 폐쇄 소스이거나 작성 권한이 없더라도 용어 사전을 개선할 수 있습니다.
- **코드를 변경하지 않고 용어를 수정하고 싶다면.** 수정된 번역은 다음 실행에서 적용되며, 코드베이스에 대한 풀 리퀘스트 없이 진행됩니다.
- **변경 사항은 검토와 기록이 필요합니다.** 각 편집은 변경 노트를 포함하여 새 버전을 생성하며, 기여자는 승인 요청을 위한 제안으로 변경 사항을 제출할 수 있고 이전 버전도 계속 유지됩니다.
- **다른 도구들도 이를 필요로 합니다.** 에이전트 및 통합은 REST API 와 MCP 서버를 통해 용어 사전을 읽을 수 있으며, 예를 들어 승인된 용어를 이미 사용하는 새 콘텐츠를 작성하는 데 활용할 수 있습니다.

용어를 정의합니다. **본 리포지토리** 다음과 같은 경우:

- **이는 본 코드베이스에 속합니다.** 프로젝트에 고유한 의미를 가진 용어, 예를 들어 버전 관리 작업인 "commit" 은 해당 용어를 사용하는 코드와 나란히 위치합니다.
- **이는 소스 텍스트와 함께 수정되어야 합니다.** 이 용어와 이를 도입한 문구는 같은 Pull Request 에 포함되어 함께 검토됩니다.
- **리포지토리의 일부만 이를 필요로 합니다.** 중첩 `L10N.md` 또는 `L10N/<locale>.md` 하나의 디렉토리에 항목을 추가하거나 덮어 쓸 수 있습니다. 마케팅 페이지와 같은 경우입니다.
- **이는 서버 항목을 반드시 덮어 써야 합니다.** 동일한 용어에 대해 번역 대상 언어에서의 서버 항목보다 저장소 항목이 우선합니다.

## 결합 방식

각 파일 및 대상 언어마다 Glossia 는 두 사전을 하나의 유효한 집합으로 통합합니다:

1. 대상 언어의 서버 사전 항목으로 시작합니다.
2. 해당 언어의 저장소 항목을 중첩합니다: 해당 파일의 `L10N.md` 번역이 있는 체인 `L10N/<locale>.md` 체인입니다. 저장소 항목이 서버 항목과 동일한 소스 단어를 사용할 경우, 저장소 항목이 우선합니다.
3. 저장소 용어가 특정 언어에 대한 번역을 갖지 못한 경우, 해당 언어의 서버 항목은 여전히 적용됩니다. 저장소는 번역하지 않은 언어를 차단하지 않습니다.

병합은 **대상 언어별로**, 항목별로가 아닙니다. "commit"에 대한 스페인어 번역이 `L10N/es.md` 서버의 "commit" 스페인어 항목을 대체하지만 동일한 단어의 서버 일본어 항목에는 영향을 주지 않습니다. 리뷰어는 대체된 서버 항목을 확인할 수 있습니다: 번역 세션 요약은 덮어씌워진 항목 수를 보여주고 각 파일의 잠금 파일은 이를 아래에 나열합니다 `glossary.shadowed`.

## 용어집이 변경되면 파일이 다시 번역됩니다.

번역사전 항목을 수정할 때, Glossia 는 해당 파일의 *유효 번역사전이 변경된*. 수정된 용어의 원본 텍스트에 일치 항목이 없으면 해당 번역은 유지됩니다. 용어를 사용하는 파일의 경우 다음 번역 패스에 업데이트된 지침이 포함됩니다.

역으로 동일한 원칙이 적용됩니다. 일부 파일에만 사용되는 용어를 추가하면 전체 재생성을 강제하지 않습니다.

## 번역사전이 아닌 것

- 기계 번역 사전이 아닙니다. Glossia 의 모델은 주변 문맥을 파악하며 문장에 따라 용어를 다르게 렌더링할 수 있습니다. 번역사전은 가이드이지 대체가 아닙니다.
- 전체 스타일 가이드가 아닙니다. 목소리, 톤, 격식 및 대상은 귀하의 계정의 목소리 설정 및 `L10N.md`번역사전에는 개별 용어와 승인된 번역만 포함됩니다.
- 침묵하지 않습니다. 적용된 모든 용어는 파일의 잠금 파일에 기록되므로, 검토자가 모델에 도달한 용어집 항목을 정확히 추적할 수 있습니다.
