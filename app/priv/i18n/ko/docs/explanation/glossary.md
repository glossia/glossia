용어집은 번역이 항상 동일한 방식으로 렌더링되어야 하는 정리된 용어 모음입니다. 버전 제어 의미의 "커밋" 은 `commit` 스페인어에서는, 됩니다 `提交` 간체 중국어에서는, 그리고 `コミット` 일본어에서는 됩니다. 언어마다 하나의 결정이며, 모든 곳에서 강제됩니다.

## 용어집이 저장될 수 있는 두 곳

Glossia 는 용어 항목을 찾도록 두 곳을 확인하고 번역 시점에 병합합니다:

- **당신의 레포지토리**, 번역 설정에서 이미 사용하는 파일에. `L10N.md` 용어를 명시하며, 각 언어의 `L10N/<locale>.md` 번역을 명시합니다. 이는 개발자 주도 어휘록입니다: 변경 사항은 풀 리퀘스트를 통해 이루어지며, 각 언어별 심의자는 자신의 파일을 관리하며, 중첩된 파일은 저장소의 일부에 대해 세부 사항을 다듬을 수 있습니다.
- **Glossia 계정**, 호스팅된 대시보드를 통해 관리됩니다. 이는 언어학자 주도 어휘록입니다: 심의자와 현지화 기여자는 코드를 건드리지 않고 항목을 추가하거나 다듬으며, 대시보드를 통해, 이 [REST API](/docs/reference/apis)또는 이 [MCP 서버](/docs/reference/mcp). 이는 계정이 번역하는 모든 저장소에 적용됩니다.

두 곳 모두 유용하며, 서로를 대체하지 않습니다.

## 어떤 것을 언제 사용할지

여기에서 **여러분의 Glossia 계정** 다음 경우:

- **여러 저장소에 적용됩니다.** 제품명, 브랜드 용어, 회사 어휘는 한 번 정의되어 모든 곳에 사용됩니다.
- **이를 결정하는 사람들은 해당 저장소에서 일하지 않습니다.** 언어 전문가, 검토자 및 외부 기여자는 저장소가 폐쇄 소스이거나 작성 권한이 없더라도 용어집을 개선할 수 있습니다.
- **코드 변경 없이 용어를 수정하고 싶으세요.** 수정된 번역은 다음 실행 시 적용되며 코드베이스에 대한 Pull 요청이 필요하지 않습니다.
- **변경 사항은 검토와 기록이 필요합니다.** 각 수정은 변경 노트가 포함된 새 버전을 생성하며, 기여자는 승인 요청 형태로 변경 사항을 제안할 수 있고 이전 버전은 계속 유지됩니다.
- **다른 도구도 이를 필요로 합니다.** 에이전트 및 통합기는 REST API 와 MCP 서버를 통해 용어집을 읽을 수 있으며, 승인된 용어를 이미 사용하는 새로운 콘텐츠를 작성하는 등의 작업을 수행할 수 있습니다.

용어를 정의하세요 **귀하의 저장소** 다음과 같은 경우:

- **이 코드베이스에 속합니다.** 프로젝트별 의미가 국한된 용어 (예: 버전 제어 작업인 "commit") 는 해당 코드를 사용하는 코드와 인접합니다.
- **원문과 함께 변경되어야 합니다.** 해당 용어와 이를 소개한 설명은 동일한 풀 리퀘스트에 포함되어 함께 검토됩니다.
- **저장소의 일부만이 해당됩니다.** 중첩된 `L10N.md` 또는 `L10N/<locale>.md` 하나의 디렉토리 (예: 마케팅 페이지) 에 항목을 추가하거나 재정의할 수 있습니다.
- **이는 계정 사전 항목을 반드시 재정의해야 합니다.** 동일한 용어에 대해 해당 용어를 번역하는 언어마다 저장소 항목이 계정 항목보다 우선합니다.

## 결합 방법

각 파일과 대상 언어마다 Glossia 는 두 사전을 하나의 유효한 집합으로 통합합니다:

1. 대상 언어의 계정 사전 항목부터 시작합니다.
2. 해당 언어의 저장소 항목을 중첩합니다: 파일의 용어에서 `L10N.md` 그 안에 번역이 있는 체인 `L10N/<locale>.md` 체인입니다. 저장소 항목이 계정 항목과 동일한 출처 용어를 가질 경우, 저장소 항목이 우선합니다.
3. 저장소 용어가 특정 언어에 대한 번역이 없으면 해당 언어의 계정 항목이 여전히 적용됩니다. 저장소는 번역하지 않은 언어를 차단하지 않습니다.

병합은 발생합니다. **목표 언어마다**, 항목 단위로는 아닙니다. 스페인어 번역 "커밋" 이 `L10N/es.md` 계정 스페인어 항목의 "커밋" 을 대체하지만, 동일한 용어에 대한 계정 일본어 항목에는 영향을 미치지 않습니다. 리뷰어는 대체된 계정 항목을 확인할 수 있으며, 번역 세션 요약은 대체된 횟수를 표시하고, 각 파일의 잠금 파일은 아래에 나열합니다. `glossary.shadowed`.

## 용어집이 변경되면 파일은 다시 번역됩니다

용어사전 항목을 수정하면 Glossia 는 해당 파일의 *유효한 용어 사전이 변경된 경우에만*. 파일의 원본 텍스트에 수정된 용어의 매칭이 없다면 해당하는 번역은 변하지 않으며 용어를 사용하는 경우 다음 번역 단계에는 갱신된 지침이 포함됩니다.

이 원리는 반대 방향에도 적용됩니다: 특정 파일에만 사용되는 용어를 추가하면 전체 재실행을 강요하지 않습니다.

## 용어사전이 아닌 것

- 기계 번역 사전이 아닙니다. Glossia 는 문맥을 읽어 문장에 따라 용어를 다르게 표현할 수 있습니다. 사전은 대안을 제시하는 가이드이므로 치환용은 아닙니다.
- 스타일 가이드 전체가 아닙니다. 목소리, 톤, 형식, 그리고 대상은 계정의 voice 설정과 `L10N.md`. 사전은 개별 용어와 승인된 번역에만 사용됩니다.
- 침묵하지 않습니다. 적용된 모든 용어는 파일의 잠금 파일에 기록되어 검토자가 모델에 도달한 용어 사전 항목을 정확히 추적할 수 있습니다.
