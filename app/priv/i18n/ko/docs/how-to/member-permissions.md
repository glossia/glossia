조직 관리원은 각 멤버가 접근할 수 있는 제품 영역을 선택할 수 있습니다. 기본 읽기 액세스부터 시작하고 필요에 따라 추가 권한을 부여하세요.

## 멤버 액세스 변경

1. 조직을 열고 **조직 → 멤버**로 이동하세요.
2. 비관리자 멤버를 찾아 **권한**을 선택하세요.
3. 영역 내에서 개별 권한을 선택하세요. 예를 들어 **프로젝트 → 작성**과 같이. 해당 영역의 모든 사용 가능한 권한을 활성화하려면 **전체 선택**을 선택하세요. 해당 항목을 다시 선택하면 영역이 비워집니다. 부분적으로 선택된 영역에는 중간 상태의 체크박스가 표시됩니다.
4. 제목 위, 페이지 오른쪽 상단에 있는 **권한 저장**을 선택하세요. 권한이 저장되면 확인 메시지가 나타납니다. 체크박스 변경 사항은 저장 후에만 적용됩니다.
5. 제목 위 왼쪽 화살표와 함께 **멤버**를 선택해 멤버 목록으로 돌아옵니다.

권한은 하나의 카드에 정렬된 압축 행으로 그룹화됩니다. 화면이 좁을 경우 각 영역의 권한은 해당 레이블 아래로 표시됩니다. 탐색 및 저장은 페이지 제목 위쪽에 유지됩니다.

## 새 멤버에 기본 액세스 부여

[조직 로그인](/docs/how-to/organization-sign-in)을 통해 가입하거나 초대를 수락하는 새로운 비관리자 멤버는 계정, 조직, 프로젝트, 음성, 사전, 토론, 그리고 티켓에 대한 읽기 액세스를 받습니다. 기본 keyValue 로 작성, 삭제, 또는 관리자 권한은 제공되지 않습니다.

관리자가 명시적 권한을 저장할 때까지 기존 멤버는 이전 역할 기반 권한을 유지합니다. 저장은 선택된 권한으로 해당 액세스를 대체합니다. 모든 체크박스를 선택 해제하고 저장하면 멤버의 위임된 권한이 제거되며, 멤버십은 제거되지 않습니다.

## 관리자 responsibility 분리

관리자는 관리자 역할을 사용하며 이 화면을 통해 권한을 편집할 수 없습니다. 멤버 초대 및 관리, 액세스 자격 증명, 언어 모델 편집, 조직 삭제는 관리자 책임입니다. 멤버 권한을 선택하여 위임할 수 없습니다.

멤버 제거는 멤버 목록에서 별도의 작업입니다. 제거 또한 관리자가 명시적으로 해당 사람을 다시 추가하거나 초대할 때까지 조직 로그인을 통한 자동 등록을 차단합니다.
