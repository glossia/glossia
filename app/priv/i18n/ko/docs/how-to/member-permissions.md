조직 관리자는 각 구성원이 접근할 수 있는 제품 영역을 선택할 수 있습니다. 기본 읽기 접근 권한으로 시작하여 필요에 따라 추가 권한을 부여하세요.

## 구성원 접근 변경

1. 조직을 열고 다음으로 이동하세요 **조직 → 구성원**.
2. 관리자가 아닌 구성원을 찾아 선택하세요 **권한**.
3. 영역 내에서 개별 권한을 선택하는 경우, 예를 들어 **프로젝트 → 작성**. 선택 **전체 선택** 해당 영역에서 사용 가능한 모든 권한을 활성화하려면 선택합니다. 해당 항목을 다시 선택하면 영역이 초기화됩니다. 부분 선택 상태에서는 확인란이 중간 상태로 표시됩니다.
4. 선택 **권한 저장** 페이지 우측 상단, 제목 위에 있습니다. 권한이 저장되면 확인 메시지가 표시됩니다. 체크박스 변경사항은 저장된 후에만 적용됩니다.
5. 선택 **멤버**, 제목 위쪽의 왼쪽 화살표를 눌러 멤버 목록으로 돌아갑니다.

권한들은 하나의 카드에 간결한 줄로 그룹화됩니다. 좁은 화면에서는 각 영역의 권한이 레이블 아래로 넘겨집니다. 내비게이션 및 저장 버튼은 페이지 제목 위에 유지됩니다.

## 기본 액세스 권한으로 새 멤버 시작

새로운 비관리자 멤버는, 조직 로그인을 통해 참여하는 사람들 포함, [조직 로그인](/docs/how-to/organization-sign-in) 또는 초대 수락 시, 계정, 조직, 프로젝트, 음성, 용어사전, 토론, 티켓에 읽기 액세스만 부여됩니다. 기본적으로 쓰기, 삭제 또는 관리자 권한은 부여되지 않습니다.

기존 구성원들은 관리자가 해당 구성원에 대해 명시적 권한을 저장할 때까지 이전 역할 기반 권한을 유지합니다. 저장은 선택한 권한으로 해당 접근 권한을 대체합니다. 모든 확인란을 해제하고 저장할 경우 구성원의 위임 권한이 제거되지만, 이는 그 구성원의 소속을 제거하지는 않습니다.

## 관리자 책임을 분리하여 유지합니다

관리자는 관리자 역할을 사용하며, 이 화면을 통해 자신의 권한을 편집할 수 없습니다. 구성원 초대 및 관리, 접근 자격 증명, 언어 모델 편집, 조직 삭제는 관리자의 책임입니다. 이를 구성원 권한 선택을 통해 위임할 수 없습니다.

구성원 제거는 구성원 목록에서 별도의 작업입니다. 또한 제거는 관리자가 명시적으로 다시 추가하거나 초대할 때까지 조직 로그인을 통한 자동 등록이 차단됩니다.
