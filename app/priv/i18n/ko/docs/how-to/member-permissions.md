조직 관리자는 각 구성원이 액세스할 수 있는 제품 영역을 선택할 수 있습니다. 기본 읽기 권한으로 시작하여 필요한 경우 추가 권한을 부여하세요.

## 멤버의 접근 권한 변경

1. 조직을 열고 **조직 → 멤버**로 이동하세요.
2. 비관리자 구성원을 찾아 **권한**을 선택합니다.
3. 해당 영역 내의 개별 권한을 선택하세요. 예를 들어 **프로젝트 → 작성**. 해당 영역의 모든 사용 가능 권한을 활성화하려면 **전체 선택**을 선택합니다. 이 항목을 다시 선택하면 영역이 해제되며, 부분적으로 선택된 영역은 '미결정' 체크박스를 표시합니다.
4. 페이지 상단 우측의 제목 위쪽에 있는 **권한 저장**을 선택합니다. 권한이 저장되면 확인 메시지가 표시됩니다. 체크박스 변경 사항은 저장 후에만 적용됩니다.
5. 제목 위의 왼쪽 화살표와 함께 **멤버**를 선택하여 멤버 목록으로 돌아가세요.

권한은 하나의 카드에 압축된 행으로 그룹화됩니다. 좁은 화면에서 각 영역의 권한은 레이블 아래로 줄바뀌게 됩니다. 탐색 및 저장은 페이지 제목 위에 유지됩니다.

## 새 멤버에게 기본 액세스 권한으로 시작하기

새로운 비관리자 구성원 (조직 [로그인](/docs/how-to/organization-sign-in)을 통해 가입하거나 초대를 수락하는 사람)은 계정, 조직, 프로젝트, 음성, 용례 사전, 토론 및 티켓에 대한 읽기 권한을 받습니다. 기본으로 작성, 삭제 또는 관리자 권한은 받지 않습니다.

기존 구성원은 관리자가 명시적으로 권한을 저장할 때까지 이전 역할 기반 권한을 유지합니다. 저장은 해당 액세스를 선택한 권한으로 대체합니다. 모든 체크박스를 해제하여 저장하면 구성원의 위임 권한은 제거되지만 멤버십은 유지됩니다.

## 관리자 책임을 분리하여 유지하기

관리자는 관리자 역할을 사용하며 이 화면을 통해 권한이 편집될 수 없습니다. 구성원 초대 및 관리, 액세스 자격 증명, 언어 모델 편집, 조직 삭제는 관리자 책임입니다. 구성원 권한 선택을 통해 위임할 수 없습니다.

구성원 제거는 멤버 목록에서 별도의 동작입니다. 제거는 구성원이 명시적으로 다시 추가되거나 초대를 받기 전까지 조직 로그인 을 통한 자동 조정을 차단합니다.
