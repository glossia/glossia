자동 설정이 실패하면 Glossia 는 예비 프로젝트를 삭제하여 저장소를 다시 선택할 수 있게 합니다. 설정 흐름에서 실패 알림이 나타날 수 있으나, 실패한 프로젝트와 진행 내역은 보존되지 않습니다.

## 1\. 실패 확인

설정 흐름을 떠나기 전에 실패 알림을 확인하세요. 일반적인 원인은 다음과 같습니다:

- 계정에 설정된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia GitHub 앱이 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 필수 조건 수정

모델 문제라면, 열기 **설정 → 모델**. 저장소 접근 문제일 경우, GitHub 에서 Glossia GitHub App 설치를 업데이트하고 해당 저장소에 접근 권한을 부여하세요.

## 3\. 설정 다시 시작

열기 **프로젝트 → 새 프로젝트**, 저장소를 선택하고, 선택 **자동 설정**, 그리고 대상 언어를 다시 선택하세요. 새로운 설정 시도가 완료될 때까지 계속 진행하세요.

실패한 프로젝트 가 여전히 표시되고 다음 동작을 제공하는 경우 **설정 재실행**, 해당 동작은 다른 시도를 시작합니다. 지속적으로 사용할 수 있다고 기대하지 마세요: 실패한 임시 프로젝트 는 정리 도중 제거됩니다.

## 4\. 완료 검토

설정이 완료되면 생성된 GitHub 풀 리퀘스트를 검토하세요. 다음을 참고하세요: [프로젝트 설정](/docs/reference/project-setup) 수명 주기 및 정리 동작 에 대하여 열람하세요.
