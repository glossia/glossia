사용 **설정 재시도** 프로젝트 설정 실패 원인을 해결한 후.

## 1\. 실패 내용 확인

프로젝트 개요를 여세요. 설정 진행 상태 카드에는 실패 내용과 최신 설정 작업이 표시됩니다.

일반적인 원인은 다음과 같습니다.

- 계정에 설정된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia GitHub 앱이 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 필수 조건 수정

모델 문제가 있는 경우 여세요, **설정** 및 **모델**. 저장소 접근 문제가 발생하는 경우 GitHub 에서 Glossia GitHub 앱 설치를 업데이트하고 저장소에 액세스 권한을 부여하세요.

## 3\. 재시도

프로젝트 개요로 돌아가고 선택하세요 **설정 재시도**.

카드가 다시 되돌아옵니다 **대기 중**, 그 다음 **실행 중**"\`, 작업 진행 시 새 활동을 표시합니다. 프로젝트가 **실패** 상태, 두 회의 설정 시도가 동시에 실행되는 것을 방지합니다.

## 4\. 완료 검토

상태가 변경될 때 **완료**", 생성된 풀 리퀘스트를 GitHub 에서 검토하세요. 재실패 시 이전 시도 대신 카드의 새 활동을 사용하여 다음 작업을 식별하세요.
