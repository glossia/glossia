사용 **설정 재시도** 프로젝트 설정 실패를 유발한 상태를 해결한 후입니다.

## 1\. 실패 내용 읽기

프로젝트 개요를 엽니다. 설정 진행 카드에는 실패 내용과 최신 설정 활동이 표시됩니다.

일반적인 원인:

- 계정에 설정된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia 깃허브 앱은 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 선결사항을 해결하세요.

모델 문제가 발생할 경우, **Settings** 및 **Models**. 저장소 액세스 문제일 경우, 깃허브 에서 Glossia 깃허브 앱 설치를 업데이트하고 저장소에 접근 권한을 부여하세요.

## 3\. 재시도

프로젝트 개요로 돌아가서 선택하세요 **설정 재시도**.

카드가 다음 상태로 복귀합니다 **대기 중**, 그 다음 **실행 중**, 작업이 진행됨에 따라 새 활동이 표시됩니다. 프로젝트가 **실패** 상태이며, 이는 두 번의 설정 시도가 동시에 실행되는 것을 방지합니다.

## 4\. 완료 검토

상태가 다음으로 변경될 때 **완료**, GitHub 에서 생성된 pull request 를 검토하세요. 다시 실패할 경우 이전 시도 대신 카드의 새 활동을 사용하여 다음 조치를 식별하세요.
