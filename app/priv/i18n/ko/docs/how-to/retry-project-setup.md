사용 **설정 재시도** 프로젝트 설정 실패의 원인을 해결한 후

## 1\. 실패 확인

프로젝트 개요를 여세요. 설정 진행 카드는 실패 내용과 최신 설정 활동을 표시합니다.

일반적인 원인은 다음과 같습니다:

- 계정에 구성된 모델이 없습니다.
- 제공자 키가 누락되었거나 유효하지 않습니다.
- Glossia GitHub 앱이 저장소를 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 필수 요건 수정

모델 문제가 있는 경우 설정을 열기 **설정** 및 **모델**. \`저장소 접근 문제가 있는 경우, GitHub 에서 Glossia GitHub 앱 설치를 업데이트하고 저장소 접근 권한을 부여하세요.

## 3\. 다시 시도

프로젝트 개요로 돌아가고 선택하세요 **프로젝트 설정 재시도**.

카드가 다음으로 **대기 중**, 그리고 **실행 중**, 하며 작업이 진행됨에 따라 새 활동이 표시됩니다. 재시도는 프로젝트가 **Failed** 상태인 동안만 가능합니다. 이는 두 번의 설정 시도를 동시에 실행하는 것을 방지합니다.

## 4\. 검토 완료

상태가 변경되면 **완료되었습니다.**, 결과물인 GitHub merge 원 (풀 리퀘스트) 을 검토하세요. 특히 이번 실패를 해결하지 않고 다시 실패하면, 카드에 제공된 새 활동 정보를 사용하여 다음 작업을 파악하세요.
