사용 **설정 재시도** 프로젝트 설정 실패 원인을 해결한 후.

## 1\. 실패 내용 확인

프로젝트 개요를 여세요. 설정 진행 상태 카드는 실패 내용과 최신 설정 활동을 보여줍니다.

주요 원인은 다음과 같습니다:

- 계정에는 설정된 모델이 없습니다.
- 제공자 키가 누락되어 있거나 유효하지 않습니다.
- Glossia GitHub 앱은 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 선행 조건 수정

모델 문제가 있는 경우, **설정** 및 **모델**. 저장소 접근 문제인 경우, GitHub 에서 Glossia GitHub 앱 설치를 업데이트하고 저장소에 접근 권한을 부여하세요.

## 3\. 재시도

프로젝트 개요로 돌아가고 선택 **설정 재시도**.

카드가 다시 **대기중**, 그리고 **진행중**, 작업이 진행될수록 새로운 활동이 표시됩니다. 재시도는 프로젝트가 **실패** 상태입니다. 이는 동시에 두 회의 세팅 시도를 실행하는 것을 방지합니다.

## 4\. 완료 완료

상태가 변경될 때 **완료됨**, GitHub 에서 생성된 풀 리퀘스트를 검토하세요. 다시 실패하면 이전 시도 대신 카드의 새 활동을 사용하여 다음 행동을 식별하세요.
