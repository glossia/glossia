프로젝트 설정 실패의 원인을 해결한 후 **설정 재시도**를 사용하십시오.

## 1. 실패 내용 확인

프로젝트 개요를 엽니다. 설정 진행 상황 카드에 실패 원인과 최신 설정 활동이 표시됩니다.

일반적인 원인은 다음과 같습니다.

- 계정에 구성된 모델이 없습니다.
- 공급자 키가 없거나 더 이상 유효하지 않습니다.
- Glossia GitHub App이 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인하지 못했습니다.

## 2. 필수 조건 해결

모델 문제의 경우 **설정**에서 **모델**을 엽니다. 저장소 접근 문제의 경우 GitHub에서 Glossia GitHub App 설치를 업데이트하고 해당 저장소에 대한 접근 권한을 부여합니다.

## 3. 재시도

프로젝트 개요로 돌아가 **설정 재시도**를 선택합니다.

카드 상태가 **대기 중**으로 돌아간 후 **실행 중**으로 변경되며, 작업이 진행됨에 따라 새로운 활동이 표시됩니다. 재시도는 프로젝트가 **실패** 상태일 때만 사용할 수 있으므로 두 개의 설정 시도가 동시에 실행되지 않습니다.

## 4. 완료 확인

상태가 **완료됨**으로 변경되면 GitHub에서 생성된 풀 리퀘스트를 검토합니다. 다시 실패하면 이전 시도가 아닌 카드의 새로운 활동을 사용하여 다음 조치를 파악합니다.
