사용 **설정 다시 시도** 프로젝트 설정 실패 원인을 해결한 후.

## 1\. 실패 내용 확인

프로젝트 개요를 엽니다. 설정 진행 카드는 실패 내용과 최신 설정 활동을 표시합니다.

일반적인 원인은 다음과 같습니다:

- 계정에 설정된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia GitHub 앱은 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 전제 조건을 수정하십시오

모델 문제가 있는 경우 여십시오 **설정** 및 **모델**.

## 3\. 재시도

프로젝트 개요로 돌아가고 선택하세요 **설정 재시도**.

카드가 다음 상태로 돌아갑니다 **대기 중**, 그리고 **진행 중**, 작업이 진행됨에 따라 새 활동 내용이 표시됩니다. 재시도는 프로젝트가 인 **실패** 상태는 두 번의 설정 시도가 동시에 실행되는 것을 방지합니다.

## 4\. 완료 검토

상태가 변경되면 **완료**결과 GitHub 풀 리퀘스트를 검토합니다. 다시 실패할 경우, 이전 시도 대신 카드의 새 활동 내용을 통해 다음 조치를 파악합니다.
