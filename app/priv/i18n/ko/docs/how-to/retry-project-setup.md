사용 **설정 재시도** 프로젝트 설정 실패 원인을 해결한 후.

## 1\. 실패 내용 확인

프로젝트 개요를 여세요. 설정 진행 카드에는 실패 내용 및 최신 설정 활동이 표시됩니다.

주요 원인으로는 다음과 같습니다:

- 계정에 구성된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia GitHub 앱은 저장소에 접근할 수 없습니다.
- 저장소를 준비하거나 확인할 수 없습니다.

## 2\. 필수 요건 수정하기

모델 문제의 경우 열으세요 **설정** 및 **모델**. 저장소 접근 문제가 발생한 경우 GitHub 에서 Glossia GitHub 앱 설치를 업데이트하고 해당 저장소에 접근 권한을 부여하세요.

## 3\. 다시 시도

프로젝트 개요로 돌아가고 선택 **설정 재시도**.

카드가 되돌아갑니다 **대기 중**, 그런 다음 **실행 중**, 및 작업 진행 시 새로운 활동이 표시됩니다. 재시도는 프로젝트가 해당 — **실패** 상태, 이는 동일한 시간 동안 두 번의 설정 시도를 실행하는 것을 방지합니다.

## 4\. 완료 확인

상태가 다음으로 변경될 때 **완료**, 생성된 풀 리퀘스트를 깃허브에서 확인하세요. 다시 실패할 경우, 이전 시도 대신 카드의 최신 활동을 참고하여 다음 조치를 확인하시기 바랍니다.
