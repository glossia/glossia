사용 **설정 재시도** 프로젝트 설정 실패의 원인을 해결한 후.

## 1\. 실패 내용 읽기

프로젝트 개요를 여세요. 설정 진행 카드는 실패 내용과 최신 설정 활동을 표시합니다.

일반적인 원인은 다음과 같습니다:

- 계정에 설정된 모델이 없습니다.
- 제공자 키가 누락되었거나 더 이상 유효하지 않습니다.
- Glossia GitHub 앱은 레포지토리에 액세스할 수 없습니다.
- 레포지토리를 준비하거나 확인하지 못했습니다.

## 2\. 전제 조건 해결

모델 문제가 발생하면 **설정** 및 **모델**. 레포지토리에 대한 액세스 문제의 경우, GitHub 에서 Glossia GitHub 앱 설치를 업데이트하고 해당 앱에 레포지토리에 대한 액세스 권한을 부여하세요.

## 3\. 재시도

프로젝트 개요로 돌아가고 선택 **설정 재시도**.

카드가 되돌아옵니다 **대기 중**그리고 **진행 중**, 작업을 진행함에 따라 새로운 활동을 표시합니다. 재시도는 프로젝트가 **실패** 상태, 이는 두 가지 설정 시도가 동시에 실행되는 것을 방지합니다.

## 4\. 완료 검토

상태가 변경되면 **완료**GitHub 에서 생성된 Pull Request 를 검토하십시오. 재 실패하는 경우, 이전 시도 대신 카드의 새 활동을 사용하여 다음 조치를 식별하십시오.
