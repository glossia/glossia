%{title: "새 언어 추가", summary: "기존 Glossia 설정에 대상 언어를 추가하는 방법.", category: "가이드", order: 1}
---
이미 Glossia 를 구성하셨다면 다른 목표 언어를 추가하려면 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

여러분의 파일을 열어보세요. `L10N.md` 새로운 언어 코드를 `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택사항)

새로운 언어에 특별한 지침 (예: 공식성 수준 또는 문자 집합 고려 사항)이 필요하다면 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

그 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역의 기본 컨텍스트와 병합합니다.

## 3\. 설정 변경 게시하기

업데이트된 설정을 커밋하고 푸시하세요. 리포지토리가 Glossia 와 연결되어
Glossia 는 새로운 대상 언어를 감지하고 번역
세션을 시작합니다.

다른 언어에 대한 기존 번역은 해당 입력이
변경되지 않았을 때 유효 컨텍스트도 유지됩니다.

## 4\. 번역 풀 리퀘스트 검토하기

Glossia 에서 번역 세션을 확인하고, 생성된 번역을 검토하세요.
서버에서 열린 풀 리퀘스트의 파일들.
