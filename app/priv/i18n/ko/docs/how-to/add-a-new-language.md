---
Glossia가 이미 구성되어 있고 대상 언어를 추가하려면 다음 단계를 따르십시오.

## 1. GLOSSIA.md 업데이트

`GLOSSIA.md`을 열고 새 언어 코드를 `targets` 배열에 추가하십시오.

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 언어별 컨텍스트 추가(선택 사항)

새 언어에 격식 수준이나 문자 집합 고려 사항과 같은 특별 지침이 필요한 경우 컨텍스트 재정의 파일을 생성하십시오.

```
GLOSSIA/
  ja.md
```

해당 파일에 언어별 지침을 작성하십시오. Glossia는 일본어 번역을 위해 이 지침을 기본 컨텍스트와 병합합니다.

## 3. 구성 변경 사항 게시

업데이트된 구성을 커밋하고 푸시하십시오. 저장소가 Glossia에 연결되어 있으면 서버가 새 대상 언어를 감지하고 번역 세션을 시작합니다.

다른 언어의 기존 번역은 입력과 적용된 컨텍스트가 변경되지 않은 경우 그대로 유지됩니다.

## 4. 번역 풀 리퀘스트 검토

Glossia에서 번역 세션을 확인한 다음, 서버가 생성한 풀 리퀘스트에서 언어 파일을 검토하십시오.
