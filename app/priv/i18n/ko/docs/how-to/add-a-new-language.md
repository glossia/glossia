%{title: "새로운 언어 추가", summary: "기존 Glossia 설정에 대상 언어를 추가하는 방법.", category: "가이드", order: 1}
---
Glossia 설정이 이미 되어 있고 추가 대상언어를 추가하려는 경우 다음과 같은 절차를 따르십시오.

## 1\. L10N.md 업데이트

반환하여 `L10N.md` 및 새로운언어코드를 `targets` 배열에 추가하십시오:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택적)

새로운 언어에 특별한지침 (예:존경수위나 문자셋 고려피수) 이 필요한 경우 컨텍스트 오버라이드 파일을 만드십시오:

    L10N/
      ja.md

해당 파일에언어별지침을 작성합니다. Glossia 는 이를 일본어 번역의 기반 컨텍스트와 함께 병합합니다.

## 3\. 설정 변경 사항 게시

업데이트된 설정을 커밋하고 푸시하세요. 저장소가
Glossia 에 연결되면, 서버는 새 대상 언어를 감지하고 시작하는 번역을
세션.

기존 번역은 입력값이
그리고 유효한 컨텍스트도 변경되지 않았습니다.

## 4\. 번역 병합 요청 검토

Glossia 에서 번역 세션을 확인한 후 생성된 번역 결과를 검토하세요.
서버가 생성한 풀 리퀘스트의 파일.
