이미 Glossia 가 설정되어 있고 다른 대상 언어를 추가하려면 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

열고 사용 중인 `L10N.md` 및 새 언어 코드를 `targets` 배열에 추가하세요:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택 사항)

새 언어가 양식 수준이나 문자셋과 같은 특수 지시가 필요한 경우 컨텍스트 오버라이드 파일을 생성하세요.

    L10N/
      ja.md

그 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역의 기본 컨텍스트와 결합합니다.

## 3\. 설정 변경사항 게시

업데이트된 설정을 커밋하고 푸시합니다. 저장소가 연결되어 있다면
Glossia, 서버는 새 대상어를 감지하고 번역을 시작합니다.
세션.

기타 언어의 기존 번역은 입력값이 변경되지 않았을 때 변경되지 않습니다.
유효한 컨텍스트도 변경되지 않았습니다.

## 4\. 번역 변경 요청 검토

Glossia 에서 번역 세션을 추적한 후 생성된 언어를 검토하십시오.
서버에서 열린 풀 리퀘스트의 파일입니다.
