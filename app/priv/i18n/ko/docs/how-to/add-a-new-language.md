이미 Glossia 가 설정되어 있고 다른 목표 언어를 추가하려는 경우 다음 단계를 따르세요.

## 1. L10N.md 수정

`L10N.md` 를 열어 새로운 언어 코드를 `targets` 배열에 추가하세요:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 언어별 컨텍스트 추가 (선택 사항)

새로운 언어가 특별한 지침 (예: 격식 수준 또는 문자셋 고려사항) 을 필요로 한다면 컨텍스트 오버라이드 파일을 생성하세요:

```
L10N/
  ja.md
```

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역용 기본 컨텍스트와 병합합니다.

## 3. 구성 변경사항 게시

변경된 구성을 커밋하고 푸시하세요. 레포지토리가 Glossia 와 연결되어 있다면 서버는 새 목표 언어를 감지하고 번역 세션을 시작합니다.

입력과 유효한 컨텍스트가 변경되지 않은 경우 다른 언어에 대한 기존 번역은 그대로 유지됩니다.

## 4. 번역 풀리퀘스트 검토

Glossia 에서 번역 세션을 추적한 다음, 서버에서 열린 풀리퀘스트에 생성된 언어 파일을 검토하세요.
