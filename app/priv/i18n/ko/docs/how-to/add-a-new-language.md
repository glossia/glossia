이미 Glossia 가 설정되어 있고 추가할 목표 언어가 있는 경우 이 단계를 따르세요.

## 1. L10N.md 업데이트

`L10N.md` 을 열고 새 언어 코드를 `targets` 배열에 추가하세요:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 언어별 컨텍스트 추가 (선택 사항)

새 언어에 격식 수준이나 문자셋 고려 사항과 같은 특수 지침이 필요한 경우 컨텍스트 오버라이드 파일을 생성하세요:

```
L10N/
  ja.md
```

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역을 위한 기본 컨텍스트와 병합합니다.

## 3. 구성 변경 게시

업데이트된 구성을 커밋하고 푸시하세요. 리포지토리가 Glossia 와 연결되어 있으면 서버는 새 목표 언어를 감지하여 번역 세션을 시작합니다.

입력과 유효 컨텍스트가 변경되지 않았다면 다른 언어의 기존 번역은 변경되지 않습니다.

## 4. 번역 풀 리퀘스트 검토

Glossia 에서 번역 세션을 진행한 후 서버에서 열린 풀 리퀘스트에 생성된 언어 파일을 검토하세요.
