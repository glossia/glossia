%{title: "새로운 언어 추가", summary: "기존 Glossia 설정에 대상 언어 추가하는 방법.", category: "사용 가이드", order: 1}
---
이미 Glossia 가 설정되어 있고 다른 목표 언어를 추가하려는 경우, 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

자신의 열기 `L10N.md` 그리고 새 언어 코드를 해당에 추가하여 `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택 사항)

새로운 언어가 공식적 수준이나 문자셋 고려 사항과 같은 특별한 지시사항이 필요한 경우 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역용 기본 컨텍스트와 병합합니다.

## 3\. 구성 변경 게시

업데이트된 구성을 커밋하고 푸시하세요. 레포지토리가 Glossia 에 연결되어 있
Glossia 는 새 목표 언어를 감지하고 번역
세션.

기존 번역은 입력
및 유효한 컨텍스트가 변경되지 않았을 경우 유지됩니다.

## 4\. 번역 풀 리퀘스트 검토

Glossia 의 번역 세션을 추적한 후 생성된 번역을 검토하세요.
