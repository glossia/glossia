%{title: "새로운 언어 추가", summary: "기존 Glossia 설정에 목표 언어를 추가하는 방법", category: "사용 가이드", order: 1}
---
이미 Glossia 가 구성되어 있고 다른 대상 언어를 추가하려는 경우 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

열어보세요 `L10N.md` 그리고 새 언어 코드를 해당 `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택사항)

새 언어가 격식 수준이나 문자 세트 고려 사항 등 특별한 지침을 필요로 하는 경우 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역 기본 컨텍스트와 병합합니다.

## 3\. 설정 변경 게시

업데이트된 구성을 커밋하고 푸시하세요.리포지토리가 연결되어 있다면
Glossia 는 새 대상 언어를 감지하고 번역을 시작합니다.
세션.

다른 언어의 기존 번역은 입력이 변경되지 않았을 때에도
유효 컨텍스트가 변경되지 않았을 때도 유지됩니다.

## 4\. 번역 풀리퀘스트 검토

Glossia 에서 번역 세션을 추적하고 생성된 언어를 검토하세요.
서버에서 생성한 풀 리퀘스트의 파일.
