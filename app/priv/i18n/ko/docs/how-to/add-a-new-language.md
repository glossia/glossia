%{title: "새 언어 추가", summary: "기존 Glossia 설정에 대상 언어를 추가하는 방법.", category: "사용법", order: 1}
---
Glossia 가 이미 구성되어 있고 다른 대상 언어를 추가하려면 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

열고 `L10N.md` 새 언어 코드를 추가하고 해당 `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택 사항)

새 언어에 별도 지침이 필요하면 (예: 격식 수준 또는 문자셋 고려 사항), 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

그 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역의 기본 컨텍스트와 병합합니다.

## 3\. 설정 변경 게시

변경된 설정을 커밋하고 푸시합니다. 저장소가 연결되어 있다면
Glossia 와 연결되면 서버는 새로운 목표 언어를 감지하고 번역
세션을 시작합니다.

기타 언어의 기존 번역은 입력
및 유효한 컨텍스트가 변경되지 않은 경우에도 유지됩니다.

## 4\. 번역 풀리퀘스트 검토

Glossia 에서의 번역 세션을 추적한 후 생성된 언어를 검토하십시오.
서버에서 열린 풀 리퀘스트에 포함된 파일.
