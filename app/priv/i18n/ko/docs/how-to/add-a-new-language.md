%{title: "새 언어 추가", summary: "기존 Glossia 설정에 새 대상 언어를 추가하는 방법.", category: "가이드", order: 1}
---
이미 Glossia 가 설정되어 있고 표적 언어를 추가하려면 다음 단계를 따르세요.

## GLOSSIA.md 업데이트

열고`GLOSSIA.md`새로운 언어 코드를 배열 에 추가하세요: добавить `targets`배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 언어별 컨텍스트 추가 (선택 사항)

새로운 언어가 격식 수준, 문자셋 고려 사항 등 특별한 지침이 필요한 경우 컨텍스트 오버레이 파일을 생성하세요:

    GLOSSIA/
      ja.md

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역의 기본 컨텍스트와 병합합니다.

## 설정 변경 사항 게시

변경된 설정을 커밋하고 푸시하세요. 저장소가
Glossia 에 연결되어 있는 경우, 서버는 새 표적 언어를 감지하여 번역
세션을 시작합니다.

기타 언어의 기존 번역은 입력
및 유효한 컨텍스트가 변경되지 않은 채로 유지됩니다.

## 번역 풀 리퀘스트 검토

Glossia 의 번역 세션을 보고 생성된
파일들을 리뷰하세요.
