%{title: "새로운 언어 추가", summary: "기존 Glossia 설정에 대상 언어 추가 방법.", category: "가이드", order: 1}
---
Glossia 가 이미 설정되어 있고 다른 대상 언어를 추가하려면 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

열어서 `L10N.md` 새로운 언어 코드를 해당 목록에 추가하세요. `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 컨텍스트 추가 (선택 사항)

새로운 언어가 형식 수준이나 문자셋 고려사항과 같은 특수 지침이 필요한 경우 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역용 기본 컨텍스트와 병합합니다.

## 3\. 설정 변경 게시하기

변경된 설정을 커밋하고 푸시하세요. 레포지토리가 Glossia 와 연결되어 있다면
Glossia 서버는 새로운 대상 언어를 감지하고 번역
세션을 시작합니다.

다른 언어의 기존 번역은 입력
및 유효한 컨텍스트가 변경되지 않았을 때 동일하게 유지됩니다.

## 4\. 번역 Pull request 검토하기

Glossia 에서 번역 세션을 추적한 후 생성된 번역을 검토하세요.
서버가 열린 풀 리퀘스트의 파일.
