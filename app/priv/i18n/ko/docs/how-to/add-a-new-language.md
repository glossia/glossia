%{title: "새로운 언어 추가", summary: "기존 Glossia 설정에 대상 언어를 추가하는 방법.", category: "가이드", order: 1}
---
이미 Glossia 가 설정되어 있고 다른 목표어를 추가하려면 다음 단계를 따르세요.

## 1\. L10N.md 업데이트

열고 `L10N.md` 그리고 새로운 언어 코드를 해당에 추가하세요 `targets` 배열:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 언어별 맥락 추가 (선택 사항)

새 언어가 존댓말 수준이나 문자셋 고려 사항과 같은 특수 지침이 필요한 경우 컨텍스트 오버라이드 파일을 생성하세요:

    L10N/
      ja.md

해당 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역용 기본 컨텍스트와 병합합니다.

## 3\. 설정 변경 게시

변경된 설정을 커밋하고 푸시합니다. 저장소가 연결되어 있다면
Glossia, 서버는 새로운 대상 언어를 감지하고 번역을 시작합니다
세션.

기타 언어의 기존 번역은 입력
및 유효한 컨텍스트가 변경되지 않았습니다.

## 4\. 번역 풀 리퀘스트 검토

Glossia 에서 번역 세션을 추적하고, 생성된 언어를 검토하세요
서버에서 열린 풀 리퀘스트 내 파일.
