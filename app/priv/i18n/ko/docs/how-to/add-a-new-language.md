이미 Glossia 가 구성되어 있고 다른 타겟 언어를 추가하고 싶다면 다음 단계를 따르세요.

## 1. L10N.md 업데이트

`L10N.md` 을 열어 새로운 언어 코드를 `targets` 배열에 추가하세요:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 언어별 컨텍스트 추가 (선택 사항)

새로운 언어가 특별한 지침이 필요한 경우 (예: 격식 수준이나 문자셋 고려 사항), 컨텍스트 오버라이드 파일을 생성하세요:

```
L10N/
  ja.md
```

그 파일에 언어별 지침을 작성하세요. Glossia 는 이를 일본어 번역을 위한 기본 컨텍스트와 병합합니다.

## 3. 구성 변경 사항 게시

업데이트된 구성을 커밋하고 푸시하세요. 저장소가 Glossia 와 연결되어 있으면 서버는 새로운 타겟 언어를 감지하고 번역 세션을 시작합니다.

다른 언어의 기존 번역은 해당 입력과 유효한 컨텍스트가 변경되지 않을 때는 그대로 유지됩니다.

## 4. 번역 풀 리퀘스트 검토

Glossia 에서 번역 세션을 진행한 후, 서버에서 열린 풀 리퀘스트에 생성된 언어 파일을 검토하세요.
