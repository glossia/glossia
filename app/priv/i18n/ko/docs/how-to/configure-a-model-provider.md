프로젝트 설정 및 번역 실행에서는 현재 Glossia 계정에 구성된 모델을 사용합니다. 프로젝트를 생성하기 전에 모델을 하나 이상 구성하십시오.

## 모델 추가

1. **설정**을 열고 **모델**을 선택합니다.
2. **새 모델**을 선택합니다.
3. `translation-default`과 같은 고유한 핸들을 입력합니다.
4. 모델 선택기를 열고 제공업체 또는 모델 이름의 일부를 입력하여 목록을 필터링합니다.
5. 모델을 선택하고 해당 제공업체 키를 입력합니다.
6. 모델을 저장합니다.

나중에 핸들이 가리키는 제공업체 모델을 변경하더라도 핸들은 그대로 유지됩니다. 계정에 처음 추가된 모델이 기본 모델로 설정됩니다.

## 저장소에서 모델 참조

관련 `GLOSSIA.md` 프런트매터에 `model`을 설정합니다.

```yaml
---
model: translation-default
---
```

저장소에는 핸들만 저장됩니다. 제공업체 키는 계정 설정에 유지됩니다.

## 기본으로 사용할 모델 선택

`GLOSSIA.md`에서 `model`을 생략하면 Glossia는 계정의 기본 모델을 사용합니다. 기본 모델을 변경하려면 기본값으로 설정할 모델을 열고 **기본값으로 설정**을 선택합니다.

여러 모델을 사용할 때 예측 가능한 동작을 보장하려면 `GLOSSIA.md`에서 핸들을 명시적으로 참조하십시오.

특정 콘텐츠 영역에는 중첩된 `GLOSSIA.md`에 다른 `model` 핸들을 지정하거나, 특정 대상 로캘에는 `GLOSSIA/<locale>.md`에 지정할 수 있습니다. Glossia는 각 문서와 로캘에 가장 가까이 적용되는 설정을 사용합니다. 구성된 여러 모델에 작업을 자동으로 분배하지는 않습니다.

명시적으로 지정한 핸들이 계정에 없으면 번역이 오류와 함께 중단됩니다. 다른 모델로 대체하지 않습니다.

## 제공업체 키 변경 또는 교체

**설정**을 열고 **모델**을 선택한 다음 모델 핸들을 엽니다. 새 제공업체 키를 입력하고 저장합니다. 키 필드를 비워 두면 현재 키가 유지됩니다.

핸들을 참조하는 저장소는 변경할 필요가 없습니다.
