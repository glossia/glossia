프로젝트 설정 및 번역 작업은 현재 Glossia 계정에 설정된 모델을 사용합니다. 프로젝트 생성 전에 최소 하나의 모델을 설정하세요.

## 모델 추가

1. 열기 **설정** 그리고 선택 **모델**.
2. 선택 **새 모델**.
3. 고유한 핸들을 입력하세요. 예를 들어, `translation-default`.
4. 모델 선택기를 열고 공급자 또는 모델 이름의 일부를 입력하여 목록을 필터링하세요.
5. 모델을 선택하고 해당 제공자 키를 입력하세요.
6. 모델을 저장하세요.

핸들은 나중에 제공자 모델을 변경해도 동일하게 유지됩니다. 계정에 처음 추가된 모델이 기본 모델로 설정됩니다.

## 저장소에서 모델을 참조하세요

설정 `model` 관련 `L10N.md` frontmatter:

```yaml
---
model: translation-default
---
```

저장소는 handle 만 저장합니다. provider key 는 계정 설정 에 유지됩니다.

## 기본적으로 사용할 모델을 선택

다음과 같은 경우 `L10N.md` 제외 `model`, Glossia 는 계정 기본 모델을 사용합니다. 변경하려면 기본값으로 설정하려는 모델을 선택하십시오. **기본 설정**.

여러 모델을 통한 예측 가능한 동작을 위해 handle 을 명시적으로 참조하십시오. `L10N.md`.

다른 것을 배치할 수 있습니다. `model` handle 을 중첩된 `L10N.md` 하나의 콘텐츠 영역에, 또는 `L10N/<locale>.md` 하나의 대상 지역에 적용됩니다. Glossia 는 각 문서 및 지역에 대해 가장 적합한 설정을 사용합니다. 설정된 모델들 사이에서 작업을 자동으로 분할하지 않습니다.

계정에 명시된 핸들이 존재하지 않으면 번역 작업이 오류로 중단됩니다. 다른 모델로 자동으로 대체되지 않습니다.

## 제공자 키 변경 또는 회전

열기 **설정**, 선택 **모델**, 모델 핸들을 엽니다. 새 제공자 키를 입력하여 저장하세요. 키 필드를 비워 두면 현재 키가 유지됩니다.

해당 핸들을 참조하는 레포지토리는 변경할 필요가 없습니다.
