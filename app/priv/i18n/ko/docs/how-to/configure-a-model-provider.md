프로젝트 설정 및 번역 작업에는 현재 Glossia 계정에 구성된 모델이 사용됩니다. 프로젝트를 생성하기 전에 최소 하나의 모델을 설정하세요.

## 모델 추가

1. 열기 **설정** 및 선택 **모델**.
2. 선택 **새 모델**.
3. 고유한 핸들, 예를 들어 `translation-default`.
4. 모델 선택기를 열고 제공자 또는 모델 이름 일부를 입력하여 목록을 필터링하세요.
5. 모델을 선택하고 제공자 키를 입력하세요.
6. 모델을 저장하세요.

연결된 제공자 모델을 변경하더라도 핸들은 안정적입니다. 계정에 추가된 첫 번째 모델은 기본 모델이 됩니다.

## 저장소에서 모델을 참조하세요

설정 `model` 적용되는 `L10N.md` frontmatter:

```yaml
---
model: translation-default
---
```

저장소는 핸들만 저장하며, 제공자 키는 계정 설정에 유지됩니다.

## 기본적으로 사용할 모델을 선택하세요

이 경우 `L10N.md` 제외 `model`, Glossia 는 계정의 기본 모델을 사용합니다. 변경하려면 기본으로 설정하고 싶은 모델을 열고 선택하세요 **기본값으로 설정**.

여러 모델 간 예측 가능한 동작을 위해 핸들을 명시적으로 참조하여 `L10N.md`.

다른 값을 배치할 수 있습니다 `model` 핸들을 중첩된 `L10N.md` 하나의 컨텐츠 영역에, 또는 `L10N/<locale>.md` 하나의 대상 로케일에도 적용됩니다. Glossia 는 각 문서와 로케일에 대해 가장 적합한 설정을 사용합니다. 구성된 모델들 사이에서 작업을 자동으로 분할하지 않습니다.

계장에 명시적인 핸들이 존재하지 않으면 번역 작업은 에러로 중단됩니다. 다른 모델로 대체되지 않습니다.

## 제공자 키 변경 또는 회전

열기 **설정**, 선택 **모델**, 모델 핸들을 열고 새 제공자 키를 입력하여 저장합니다. 키 필드를 비워두면 현재 키가 유지됩니다.

해당 핸들을 참조하는 레포지토리는 변경할 필요가 없습니다.

## 번역 품질 결정을 위한 Jev 추가

1. 열기 **설정 → 모델 → 새 모델** 선택하고 **결정** 카테고리로 설정합니다.
2. 다음과 같은 핸들을 사용하세요. `translation-quality`. 유지 `typesafe/jev-latest`, 또는 고정된 TypeSafe Jev 모델 버전을 입력하세요.
3. TypeSafe 제공자 키를 입력하세요. 기본 주소를 비우면 네이티브 TypeSafe 엔드포인트를 사용할 수 있습니다. 사용자 정의 주소는 버전 접두어를 포함해야 하며, `https://api.typesafe.ai/v1`.
4. 최소 품질 점수를 1 에서 10 까지 설정한 후 저장하세요. 첫 번째 결정 모델이 기본 결정 모델이 되어 평가가 자동으로 활성화됩니다.
5. 번역 실행. 품질 차원 오류 시 다음... 예산 내에서 수정 요청. `retries` 리포지토리에서 구성된 예산입니다.

생성형 및 결정 모델은 별도의 기본값을 가집니다. 번역 모델 핸들은 변경하지 마십시오. 결정 모델은 리포지토리 번역 핸들 또는 로케일 라우팅 규칙을 통해 선택할 수 없습니다. 모든 결정 모델을 제거하여 평가를 비활성화하십시오.
