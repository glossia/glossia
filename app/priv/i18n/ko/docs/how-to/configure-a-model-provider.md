프로젝트 설정 및 번역 작업은 현재 Glossia 계정에 설정된 모델을 사용합니다. 프로젝트를 생성하기 전에 최소 하나의 모델을 구성하세요.

## 모델 추가

1. 열기 **설정** 및 선택 **모델**.
2. 선택 **새 모델**.
3. 고유한 핸들 입력, 예를 들어, `translation-default`.
4. 모델 선택기를 열고 제공자 또는 모델 이름의 일부를 입력하여 목록을 필터링하세요.
5. 모델을 선택하고 제공자 키를 입력하세요.
6. 모델 저장.

핸들은 향후 관련 제공자 모델을 변경하더라도 안정적입니다. 계정에서 추가된 첫 번째 모델이 기본값이 됩니다.

## 레포지토리에서 모델을 참조

설정 `model` 해당 `L10N.md` frontmatter:

```yaml
---
model: translation-default
---
```

레포지토리에는 핸들만 저장되며, 제공자 키는 계정 설정에서 유지됩니다.

## 기본 사용 모델을 선택하세요

다음과 같이 `L10N.md` 제외합니다 `model`\]., Glossia 는 계정의 기본 모델을 사용합니다. 변경하려면 기본으로 설정할 모델을 열고 선택하세요 **기본으로 설정**.

여러 모델에 걸쳐 예측 가능한 동작을 위해, 명시적으로 핸들을 참조하세요 `L10N.md`.

다른 것을 배치할 수 있으며 `model` 중첩된 핸들을 `L10N.md` 한 콘텐츠 영역에서, 또는 `L10N/<locale>.md` 하나의 대상 로케일을 사용합니다. Glossia 는 각 문서와 로케일에 가장 적합한 설정을 사용합니다. 설정된 모델들 사이에서 작업을 자동으로 분할하지 않습니다.

계정에 명시적 핸들이 존재하지 않으면 번역 작업이 에러로 중단됩니다. 다른 모델로 전환되지 않습니다.

## 제공자 키 변경 또는 회전

열기 **설정**, 선택 **모델**, 및 모델 핸들을 엽니다. 새 제공자 키를 입력하고 저장합니다. 키 필드를 비워두면 기존 키가 유지됩니다.

핸들을 참조하는 레포지토리는 변경할 필요가 없습니다.
