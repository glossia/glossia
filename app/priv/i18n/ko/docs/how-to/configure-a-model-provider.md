프로젝트 설정 및 번역 실행에는 현재 Glossia 계정에 구성된 모델을 사용합니다. 프로젝트를 생성하기 전에 최소 하나의 모델을 설정하세요.

## 모델 추가

1. 열기 **설정** 선택하고 **모델**.
2. 선택 **새로운 모델**.
3. 고유한 핸들 입력, 예를 들어 `translation-default`.
4. 모델 선택기를 열고 제공자 또는 모델 이름의 일부를 입력하여 목록을 필터링합니다.
5. 모델을 선택하고 해당 제공자 키를 입력합니다.
6. 모델을 저장합니다.

핸들은 나중에 뒤에 있는 제공자 모델을 변경하더라도 안정적입니다. 계정에 추가된 첫 번째 모델이 기본 모델이 됩니다.

## 저장소에서 모델을 참조하세요

설정 `model` 관련된 `L10N.md` frontmatter:

```yaml
---
model: translation-default
---
```

저장소는 핸들만 저장하며, 제공자 키는 계정 설정에서 유지됩니다.

## 기본적으로 사용할 모델을 선택하세요

다음에 `L10N.md` 제외합니다 `model`, Glossia 는 해당 계정의 기본 모델을 사용합니다. 변경하려면 기본으로 지정할 모델을 열고 선택합니다. **기본값으로 설정**.

여러 모델을 사용할 때 예측 가능한 동작을 위해 명시적으로 handle 을 참조하십시오. `L10N.md`.

다른 것 을 배치할 수 있습니다 `model` 핸들이 중첩된 곳에 `L10N.md` 하나의 콘텐츠 영역을 위해, 또는 `L10N/<locale>.md` 하나의 대상 로케일을 위한 것입니다. Glossia 는 각 문서 및 로케일에서 가장 적합한 설정을 사용합니다. 구성된 모델들 사이에서 작업을 자동으로 분할하지 않습니다.

계정에 명시적인 핸들이 없으면, 번역은 오류로 중단됩니다. 다른 모델로 되돌아가지 않습니다.

## 제공자 키 변경 또는 교체

열기 **설정**, 선택 **모델**, 그리고 모델 핸들을 엽니다. 새로운 제공자 키를 입력하고 저장합니다. 키 필드를 비우면 현재 키가 유지됩니다.

해당 핸들을 참조하는 레포지토리는 변경할 필요가 없습니다.
