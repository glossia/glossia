프로젝트 설정 및 번역 실행에는 현재 Glossia 계정에 구성된 모델을 사용합니다. 프로젝트를 생성하기 전에 적어도 하나의 모델을 구성하세요.

## 모델 추가

1. 열기 **설정** 및 선택 **모델**,.
2. 선택 **새 모델**,.
3. 고유 핸들을 입력하세요, 예를 들어 `translation-default`,.
4. 모델 선택기를 열고 제공자나 모델 이름의 일부를 입력하여 목록을 필터링합니다.
5. 모델을 선택하고 제공자 키를 입력하십시오.
6. 모델을 저장합니다.

핸들은 나중에 해당 뒤에 있는 제공자 모델을 변경하더라도 안정적으로 유지됩니다. 계정에 추가된 첫 번째 모델이 기본 모델이 됩니다.

## 저장소에서 모델을 참조합니다.

설정 `model` 관련된 `GLOSSIA.md` frontmatter:

```yaml
---
model: translation-default
---
```

저장소는 핸들만 저장합니다. 제공자 키는 계정 설정에 그대로 유지됩니다.

## 기본으로 사용되는 모델을 선택하십시오.

...할 경우 `GLOSSIA.md` 제외됩니다 `model`, Glossia 는 계정 기본 모델을 사용합니다. 변경하려면 기본 설정으로 만들 모델 을 열고 선택 **기본 설정**.

여러 모델 간 예측 가능한 동작을 위해 핸들을 명시적으로 참조 `GLOSSIA.md`.

다른 핸들 `model` 중첩된 `GLOSSIA.md` 하나의 콘텐츠 영역용, 또는 `GLOSSIA/<locale>.md` 대상 현지화를 위한 것입니다. Glossia 는 각 문서와 현지화별로 가장 적합한 설정을 사용합니다. 설정된 모델 간 작업을 자동으로 분할하지 않습니다.

계정에서 명시적인 핸들이 없으면 번역은 오류로 중단됩니다. 다른 모델로 되돌아가지 않습니다.

## 제공자 키 변경 또는 회전

열기 **설정**, 선택 **모델**, 그리고 모델 핸들을 엽니다. 새 제공자 키를 입력하고 저장합니다. 키 필드를 비우면 현재 키가 유지됩니다.

핸들을 참조하는 저장소는 변경할 필요가 없습니다.
