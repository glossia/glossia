Glossia 는 호스팅 서비스의 대시보드 링크를 위한 소셜 이미지를 생성합니다.

## 링크 미리보기

대시보드 페이지는 [오픈 그래프](https://ogp.me/) 및 트위터 대형 이미지 메타데이터를 통해 1200 × 630 이미지를 표시합니다. 이 메타데이터를 읽는 서비스에서 링크를 공유하면 미리보기를 표시할 수 있습니다. 공유 서비스는 해당 이미지를 가져오거나 새로 고침하는 시점을 결정합니다.

공개 프로젝트는 프로젝트명, 섹션, 업로드된 로고 정보를 포함합니다. 공개 계정은 섹션별 전용 미리보기를 받습니다. 개인 계정과 개인 설정은 일반적인 Glossia 브랜딩을 사용합니다.

## 프로젝트 브랜딩

Glossia 에서 프로젝트의 로고를 업로드하거나 교체하여 공개 미리보기에 쓰이는 브랜딩을 변경하세요. 로고는 프로젝트 업로드 제한과 일치하여 최대 500 만 바이트로 제한됩니다.

공개 소셜 이미지 미리보기에는 개인 프로젝트 정보가 포함되어 있지 않습니다. 미리보기는 연결된 대시보드 페이지에 대한 액세스권을 부여하지 않습니다.

## 이미지 업데이트

표시 중인 콘텐츠, 프로젝트 로고, 일일 이미지 버전 또는 Glossia 렌더링 구현이 변경되면 이미지 주소가 변경됩니다. 성공적으로 생성된 이미지는 하루 동안 캐시될 수 있습니다. 공유 서비스는 자체 캐시된 미리보기를 유지할 수 있으므로, 로고를 교체한다고 해서 모든 곳에서 즉각적인 업데이트가 보장되지는 않습니다.

Glossia 는 이미지 생성, 저장, 폰트 및 캐싱을 관리합니다.

## 가용성

| 결과 | 응답 |
|---|---|
| 이미지 사용 가능 | 200 |
| 유효하지 않거나 만료된 이미지 주소 | 404 |
| 이미지 일시적 사용 불가 | 503, 60 초 재시도 대기 시간 포함 |
| 요청 한도 초과 | 429, 응답 내 재시도 대기 시간 포함 |

미리보기가 누락되어 있으면 대시보드 페이지를 열고 현재 링크를 공유하세요. 일시적 오류가 발생하면 지시된 대기 시간 후 다시 시도하세요. 문제가 지속되면 Glossia 지원팀과 연락하세요.
