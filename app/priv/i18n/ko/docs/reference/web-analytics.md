## 이벤트 엔드포인트

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` 는 호환성을 위해 여전히 사용 가능합니다. 호스팅 스크립트는 자체 오효 인 `/v1/collect` 을 유도하며; 패키지 통합에는 `endpoint` 을 명시적으로 설정해야 합니다.

`@glossia/web` SDK 에서 JSON 이벤트를 받습니다. 알려지지 않은 도메인 또는 잘못된 페이로드라도 Siempre responds `202 Accepted` 으로 응답하며, SDK 가 어떤 프로젝트가 통계 분석을 수집하는지 누출되지 않도록 합니다.

프로젝트는 스니펫이 선언한 사이트 도메인에 따라 해결됩니다. `d` 이 권한이 있습니다; 누락되었을 때는 서버는 `u` 의 호스트로 되돌아가며 (페이지 URL), 그 후 요청 `Origin`/`Referer` 입니다.

### 요청 본문

| 필드 | 형식   | 설명                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | string | 프로젝트를 식별하는 사이트 도메인 (예: `example.com`). 브라우저 라이브러리에 의해 전송되며; 이비차 해결 방식은 여기서 상술됩니다. |
| `n`   | string | 이벤트 이름. 기본값은 `pageview` 입니다.                          |
| `u`   | string | 페이지 URL (`location.href`).                                  |
| `r`   | string | 참조원 (`document.referrer`).                              |
| `l`   | string | 브라우저언어 (`navigator.languages.join(",")`).         |
| `sl`  | string | 실제 페이지 언어 (`document.documentElement.lang`). 선언되지 않았을 경우 빈 문자열로 남습니다. |
| `al`  | string | `link[rel="alternate"][hreflang]` 에서 가져온 쉼표로 구분된 번역 언어, `x-default` 를 제외합니다. |
| `cl`  | string | 명확히 선택된 언어, 또는 관찰된 선택이 없으면 빈 문자열입니다. SDK 는 BCP 47 태그를 표준화하며 입력을 64 자로 제한합니다. |
| `tz`  | string | IANA 시간대 (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | number | CSS 픽셀 단위의 화면 너비입니다.                                  |
| `sid` | string | 탭별 세션 ID (sessionStorage, 닫힘 시 초기화).       |

CORS 는 `Access-Control-Allow-Origin: *` 으로 열린 상태이며, 엔드포인트가 인증 정보를 허용하지 않기 때문입니다.

## 명확한 언어 선택

`selectLanguage(language)` 는 네임드 내보내기로, 기본 SDK 내보내기의 상과 호스팅 스크립트의 `glossia` 글로벌에서 사용할 수 있습니다. 초기화 후 사용 행동 처리자에서 호출하고, 네비게이션 전에 호출하세요. 유효하지 않은 언어태그와 초기화 전 호출은 무시됩니다.

이 방법은 즉시 `language_selection` 이벤트를 전송합니다. `sl` 는 여전히 현재 페이지를 설명하며, 목적지가 아닙니다. 이후 이벤트에서 선택은 `cl` 에 포함되어 약치할 때까지 유지됩니다. 관찰된 선택이 없다면 `cl` 는 빈 문자열입니다. 선택은 동일한 원산, 탭별 `sessionStorage` 에 `__glossia_selected_language` 로 저장되며; 저장 실패 시 메모리에서 unload 까지 유지됩니다.

링크에 있어서, `data-glossia-language="zh-Hans"` 은 신뢰할 수 있고 수정되지 않은 주요 클릭을 위한 위임 추적 활성화를 포함하여 포함합니다. 스크립트된 클릭, 이미 취소된 클릭, 다운로드, 크로스 오리진 링크, 다른 탭 또는 프레임 타켓팅 링크는 무시됩니다. 리스너는 라우터가 네비게이션하는 점 나사자 전 캡처 단계에서 실행되며, 네비게이션을 방지하지 않고 동적으로 삽입된 링크도 처리합니다. 작업에는 주석이나 API 를 처음 사용하세요, 둘 다 사용할 수 없습니다.

이것은 클라이언트 보고 의도 신호이며, 네비게이션 성공의 증거가 아닙니다. URL 변경, 리디렉션, 그리고 HTML 언어 변경은 선택으로 해석되지 않습니다. 선택은 `l` 또는 `sl` 을 무시하지 않습니다. 유효한 선택은 `has_locale_gap` 계산시 브라우저 선호도보다 우선합니다: 선택된 언어는 프로젝트 타겟 또는 광고 번역 (`al`) 또는 실제 페이지 언어 (`sl`) 와 일치해야 합니다. 선택 자체는 사용 가능 여부 증거가 아닙니다. 매칭은 브라우저 선호도에 사용하는 표준화된 정확한 또는 기본 언어 매칭과 같습니다.

예를 들어, 일본어를 선호하는 방문자가 이용 가능한 영어 번역을 명확히 선택하면 간극이 없습니다. 영어를 선호하는 방문자가 이용 불가능한 일본어를 선택해도, 영어 페이지에서도 간극이 남습니다. 네비게이션 전 에미트된 선택 이벤트는 현재 페이지의 `sl` 을 유지하며; 목적지 언어는 프로젝트 타겟이나 `al` 를 통해 네비게이션을 성공했다고 가정을 하지 않고 인식할 수 있습니다.

누락, 잘못형, 또는 크기 이상인 선택은 브라우저 선호도로 되돌아갑니다. 선택이나 브라우저 선호도 모두 알려져 있지 않으면 간극이 없습니다. 대시보드 총액 및 배지는 저장된 이벤트별 플래그를 읽습니다. 선택이 간극 계산에 영향을 준 이전 플래그 포함, 과거 플래그는 재계산되지 않습니다: 과거 광고 번역과 전체 브라우저 선호도는 저장되지 않습니다.

## 서버에서 유도된 필드

이것은 ingestion 에서 계산되어 서버측에 저장됩니다. 원시 IP 와 User-Agent 는 결코 저장되지 않습니다.

| 필드             | 출처        | 설명                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + UA + 프로젝트의 일일 회전 해시. 날짜를 기준으로 연결할 수 없습니다.  |
| `country_code`    | Cloudflare / GeoIP | 신뢰할 수 있는 `CF-IPCountry` 헤더에서 가져온 ISO 3166-1 알파 2 코드 또는 구성된 IP 지리 위치 어댑터. 둘 다 국가를 해결하지 않을 경우 공란입니다. |
| `device`          | User-Agent    | `desktop`, `mobile`, `tablet`, `bot`, 또는 `unknown`&gt;.                 |
| `browser`         | User-Agent    | `chrome`, `safari`, `firefox`, `edge`, `opera`, 또는 `unknown`&gt;.       |
| `os`              | User-Agent    | `windows`, `macos`, `ios`, `android`, `linux`, 또는 `unknown`&gt;.        |
| `hostname`        | 페이지 URL      | 소문자 호스트입니다.                                                    |
| `pathname`        | 페이지 URL      | 경로 구성 요소입니다.                                                     |
| `referrer_source` | Referrer      | Referrer 호스트, 전치 `www.`/`m.` 제거됨.                        |
| `browser_language`| 언어들     | 가장 선호하는 정규화된 로케일 (예: `pt-BR`)                    |
| `served_locale`   | 페이지 언어 | 정규화된 `sl`, 또는 수집되지 않은 경우 공란입니다. 페이지 언어가 공백인 행은 브라우저 언어 분석에서 제외됩니다. |
| `selected_locale` | 명시 선택 | 정규화된 `cl`, 또는 누락,잘못형, 또는 크기 초과 입력의 경우 공란입니다. 브라우저 선호도와 페이지 언어와 별도로 저장됩니다. |
| `has_locale_gap`  | 계산된      | `1`, 프로젝트 타겟, 광고 번역 (`al`) 또는 페이지 언어(`sl`) 에서 일치하는 명시 선택이 없을 경우. 유효한 선택이 없으면 브라우저 선호도가 비어있지 않고 매칭하는 경우에만 `1` 입니다. |

### 클라이언트 IP 해결

사내 입구 Peer 들로부터의 요청에 대해, Glossia 는 nginx 가 덮어쓰는 `X-Real-IP` 헤더를 사용하며, 호출자 contrôler 된 첫 번째 항목인 `X-Forwarded-For` 를 사용하지 않습니다. 직접적인 공개 연결은 소켓 주소를 사용합니다. Hetzner 의 경우, 로드 밸런서와 nginx 는 모두 PROXY 프로토콜을 활성화해야 nginx 가 로딩 밸런서 주소 대신 방문자 주소를 수신합니다. 다른 역 프록시 또한 인증된 출처를 사용하여 `X-Real-IP` 을 덮어써야 하며, 제한되지 않는 수신 `X-Forwarded-For` 헤더를 사용할 수 없습니다. 일반적인 차트의 전달-헤더 정책만으로는 이것을 보장할 수 없습니다. 사내 Peer 들은 신뢰할 수 있는 인프라이므로 직접적인 Pod 접근은 제한되어야 합니다.

`GLOSSIA_TRUST_CLOUDFLARE_CLIENT_IP_HEADER=true` 는 `CF-Connecting-IP` 가 프라이빗 인그레스 페어에서 발생하는 요청에 대한 공식 주소를 덮어쓰도록 허용합니다. 이것은 **기본 설정으로 비활성화됩니다**, 국가 헤더 신뢰도와 무관합니다. 에지가 Cloudflare 을 인증하거나 Cloudflare 을 우회하는 요청에서 위조된 헤더를 제거한 후에만 이를 활성화해야 합니다. DNS 전용 배포에서는 이를 비활성화 상태로 둬야 합니다. 이 주소는 또한 IP 속도 제한 및 일일 방문자 해시의 기준이 됩니다.

### 국가 해결

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` 은 `CF-IPCountry` 빠른 경로를 활성화합니다. 기본값으로는 **비활성화됨**으로 설정됩니다. Cloudflare 가 인증되거나 Cloudflare 를 우회하는 요청을 제거하거나, 입구가 헤더의 비신뢰 복사본을 제거한 후에만 활성화하세요. Cloudflare 의 IP 위치 설정은 지역별로 추가로 활성화해야 합니다. `CF-Connecting-IP`, `CF-Ray` 및 nginx 의 `use-forwarded-headers` 은 자체적으로 요청을 인증하지 않습니다.

헤더 신뢰가 활성화되면, 단일 유효한 ISO 국가 코드가 즉시 사용되며, IP 조회 또는 캐시 접근 없이 수행됩니다. 현재 엣지 값은 캐시 조회보다 항상 우선하며, 누락, 중복, 잘못형, 또는 알 수 없는 코드, Cloudflare 의 `XX` (알 수 없음) 과 `T1` (Tor) 값을 포함한 것이 모두 구성된 지리 위치 어댑터로 fallback 됩니다.

구성된 MaxMind 데이터베이스가 없는 경우, fПлл백 조회는 `api.ipapi.is` 을 사용하며, 기본 요청이 실패하거나 인식된 국가를 반환하지 않을 때 `api.country.is` 를 사용합니다. 각 요청에는 리트라이가 비활성화된 1 초 연결 및 반응 타임아웃이 있습니다. 두 제공자 중 한쪽의 성공 결과는 Cachex 에 의해 24 시간 캐시되며, 100,000 엔입스의 정해진 크기 제한과 자동 만료 압축이 적용됩니다. `Cachex.fetch/3` 는 같은 IP 용 동시 누락을 하나의äs 일해로 축소합니다. 실패는 캐시되지 않습니다. 사내 및 예약 주소는 어떠한 제공자에도 전송되지 않습니다.

### 누락된 페이지 언어

브라우저 언어 분석은 `sl` 이 없는 이벤트를 제외합니다. 여기에는 오래된 추적기로 수집된 이벤트와 HTML `lang` 속성이 없는 페이지가 포함됩니다. 이러한 이벤트는 여전히 전체 트래픽에 기여합니다. 페이지 언어는 브라우저 선호도 또는 URL 로 추정되지 않습니다. 과거 이벤트는 수집 당시 메타데이터를 유지하며, 새로운 추적 버전은 이를 채우지 않습니다.

## 개인정보 모델

- **지속적인 크로스 세션 식별자가 없습니다.** SDK 는 쿠키를 설정하지 않으며, 탭별 세션 ID 와 명시적으로 선택된 언 어 만 `sessionStorage` 에 저장되는데, 브라우저는 닫을 때 이를 지웁니다.
- **지문 수집 없음.** 캔버스, WebGL, 폰트 및 오디오 지문은 수집되지 않습니다. 일일 회전서버 해시는 지문 없이 고유 정보를 제공합니다.
- **원시 식별자는 저장되지 않습니다.** IP 와 User-Agent 는 한 번 읽히고, 서버 비밀과 일일 소금으로 해싱된 뒤 버려집니다.
- **프로젝트별 범위 설정.** 같은 브라우저가 두 프로젝트에서 사용되면 서로 다른 방문자 ID 가 생성되므로, Glossia 고객 간에는 방문자 추적이 불가능합니다.
