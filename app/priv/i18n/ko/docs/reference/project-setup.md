프로젝트 설정은 Glossia 를 위한 연결된 저장소를 준비합니다. 이는 사용자가 저장소와 최소 하나의 대상 언어를 선택한 에서 **새 프로젝트** 플로우.

## 전제조건

- 계정에 최소 하나의 구성된 모델이 있어야 합니다.
- Glossia GitHub 앱은 선택된 저장소에 접근할 수 있습니다.
- 사용자는 계정에 프로젝트를 생성할 수 있습니다.
- 최소 하나의 대상 언어가 선택되어 있습니다.

## 상태

| 상태 | 의미 | 사용 가능한 작업 |
|---|---|---|
| **대기 중** | 프로젝트가 승인되어 시작을 기다리고 있습니다. | 진행 상황을 확인하거나 페이지를 떠난 후 나중에 다시 방문할 수 있습니다. |
| **진행 중** | Glossia 는 저장소를 검사하고 업데이트 중입니다. | 실시간 작업을 확인하세요. |
| **완료됨** | 로케일라이제이션 기준선은 검토를 위해 준비되고 게시되었습니다. | 풀 리퀘스트를 열어 검토하고 병합하세요. |

프로젝트는 설정이 진행 중인 동안 임시적입니다. **대기 중** 또는 **진행 중**. 설정이 완료되지 않거나 사용할 수 있는 변경사항을 게시할 수 없는 경우, Glossia 는 설정 환경을 정리하고 임시 프로젝트를 삭제합니다. 저장소는 이제 **새 프로젝트** 흐름으로 설정을 다시 시도할 수 있습니다.

## 가시적인 진행 상황

설정 카드는 새 프로젝트 흐름이 프로젝트 개요 및 계속해서 표시됩니다. 이는 다음 사항을 포함합니다:

- 상태 배지와 진행 막대.
- 현재 상태에 대한 간략한 설명.
- 최근 저장소 준비, 검토, 파일 변경, 확인 및 완료 활동.
- 설치가 완료되지 않을 때 표시되는 명확한 실패 메시지.

임시 프로젝트가 존재하는 동안 진행 상황이 저장됩니다. 치명적인 실패는 프로젝트와 표시된 설치 진행 상황을 모두 제거합니다.

## 완료된 결과

성공적인 연결 설치 는 저장소 기본 브랜치에 대한 전용 브랜치와 풀 요청을 생성합니다. 풀 요청에는 생성된 로컬화 기준, 포함 `L10N.md` 컨텍스트 및 로컬화된 콘텐츠를 로드하는 데 필요한 최소한의 실용적인 변경 사항입니다.

설치는 헤더만 있는 대상 카탈로그를 게시하지 않습니다. 번역 전에 대상 카탈로그가 필요한 현지화 프레임워크의 경우 카탈로그에는 빈 번역 값이 있는 추출된 소스 메시지 항목이 포함되어 있습니다. 대상 카탈로그가 아직 필요 없는 경우 설치는 첫 번째 번역 실행을 위해 이를 남겨 둡니다.

Glossia 는 풀 요청 을 병합하지 않습니다. 저장소 관리자는 GitHub 의 일반적인 프로세스를 통해 이를 검토하고 병합합니다.

이 풀 요청이 열려 있는 동안 프로젝트 개요에는 설치 알림 이 표시됩니다. 풀 요청이 병합된 후 알림은 제거됩니다. 풀 요청이 병합되지 않고 닫힌 경우, 개요에서는 설치가 완료된 것으로 간주되기 전에 이를 다시 열어야 한다고 설명합니다.
