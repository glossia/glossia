프로젝트 설정은 Glossia 의 연결된 저장소를 준비합니다. 사용자가 저장소를 선택하고 최소 하나의 대상 언어를 선택한 후의 **새 프로젝트** 플로우.

## 선행 조건

- 계정에는 최소 하나의 설정된 모델이 있어야 합니다.
- Glossia GitHub 앱은 선택된 저장소에 접근할 수 있어야 합니다.
- 사용자는 계정 내에서 프로젝트를 생성할 수 있습니다.
- 최소 하나의 대상 언어가 선택되어 있어야 합니다.

## 상태

| 상태 | 의미 | 사용 가능한 작업 |
|---|---|---|
| **대기** | 프로젝트가 수락되어 시작을 기다리고 있습니다. | 진행 상황을 확인하거나 페이지를 떠난 후 다시 방문하세요. |
| **진행 중** | Glossia 는 저장소를 검토하고 업데이트하고 있습니다. | 실시간 실행 활동을 확인하세요. |
| **완료됨** | 검토를 위해 로컬라이제이션 베이스라인이 준비되어 게시되었습니다. | 풀 리퀘스트를 열어 검토하고 병합하세요. |

프로젝트는 설정 중일 경우 임시 상태입니다 **대기 중** 또는 **실행 중**. 만약 설치가 완료되지 않거나 사용 가능한 변경 사항을 게시할 수 없다면, Glossia 는 설치 환경을 정리하고 임시 프로젝트를 삭제합니다. 이후 저장소는 다음 **새 프로젝트** 프로세스에서 설치를 다시 시도할 수 있습니다.

## 가시적 진행 상황

설치 카드는 새 프로젝트 프로세스와 프로젝트 개요에서 계속 표시됩니다. 다음 항목을 포함합니다:

- 상태 배지 및 진행률 바.
- 현재 상태에 대한 짧은 설명.
- 최근 저장소 준비, 점검, 파일 변경, 검토 및 완료 활동.
- 설정이 완료되지 않을 경우 나타나는 명확한 실패 메시지.

임시 프로젝트가 존재하는 동안 진행 상태가 저장됩니다. 최종 실패 시 프로젝트와 가시적인 설정 진행 모두를 제거합니다.

## 완료 결과

성공적인 연결 설정은 저장소의 기본 브랜치에 대한 전용 브랜치 및 풀 리퀘스트를 생성합니다. 이 풀 리퀘스트에는 생성된 현지화 기준, 포함하여 `L10N.md` 컨텍스트 및 현지화된 콘텐츠를 로드하기 위해 필요한 최소한의 실질 변경 사항입니다.

설정은 헤더만 포함된 타겟 카탈로그를 발행하지 않습니다. 번역 전에 타겟 카탈로그가 필요한 현지화 프레임워크의 경우, 해당 카탈로그는 빈 번역 값을 가진 추출된 소스 메시지 항목을 포함합니다. 아직 타겟 카탈로그가 필요하지 않은 경우, 설정은 첫 번째 번역 실행을 위해 해당 항목을 남겨둡니다.

Glossia 는 풀 리퀘스트를 병합하지 않습니다. 저장소 관리자는 기존 GitHub 프로세스를 통해 이를 검토하고 병합합니다.

프로젝트 개요에는 이 풀 리퀘스트가 열려 있는 동안 설정 알림이 표시됩니다. 풀 리퀘스트가 병합된 후 알림이 제거됩니다. 풀 리퀘스트가 병합 없이 닫힌 경우, 개요에서는 설정이 완료되려면 다시 열어야 함을 설명합니다.
