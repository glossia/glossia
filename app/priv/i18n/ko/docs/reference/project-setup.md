프로젝트 설정은 Glossia 를 위한 연결된 리포지토리를 준비합니다. 사용자가 리포지토리를 선택하고 최소 하나의 대상 언어를 선택한 후 **새 프로젝트** 흐름.

## 선행 조건

- 계정에 최소 하나의 설정된 모델이 있습니다.
- Glossia GitHub 앱은 선택한 리포지토리에 접근할 수 있습니다.
- 사용자는 계정에 프로젝트를 생성할 수 있습니다.
- 최소 하나의 대상 언어가 선택되어 있습니다.

## 상태

| 상태 | 의미 | 사용 가능한 작업 |
|---|---|---|
| **대기 중** | 프로젝트가 수락되어 시작을 기다리고 있습니다. | 진행 상황을 확인하거나 페이지를 떠나 나중에 다시 방문하세요. |
| **진행 중** | Glossia 는 저장소를 검사하고 업데이트하고 있습니다. | 실시간 활동을 확인하세요. |
| **완료** | 현지화 기준이 검토를 위해 준비되어 게시되었습니다. | Pull request 를 열고 검토하고 병합하세요. |

프로젝트는 설정이 임시적입니다 **대기 중** 또는 **진행 중**. 설정이 완료되지 않거나 게시할 수 있는 변경 사항이 없는 경우, Glossia 는 설정 환경을 정리하고 임시 프로젝트를 삭제합니다. 저장소는 이후 이용 가능한 **새 프로젝트** 플로우에서 설정을 다시 시도할 수 있습니다.

## 가시적인 진행 상황

설정 카드는 새 프로젝트 플로우 및 프로젝트 개요에서 계속 사용 가능합니다. 포함되어 있는 항목은:

- 상태 배지 및 진행 막대.
- 현재 상태에 대한 간단한 설명.
- 최근 저장소 준비, 검사, 파일 변경, 확인 및 완료 활동.
- 설정을 완료할 수 없는 경우 명확한 실패 메시지가 표시됩니다.

잠정 프로젝트가 존재하는 동안 진행 사항은 저장됩니다. 최종 실패는 프로젝트와 가시적인 설정 진행 사항 모두를 폐기합니다.

## 완료 결과

성공적인 연결 설정은 전용 브랜치와 리포지토리의 기본 브랜치에 대한 풀 리퀘스트를 생성합니다. 이 풀 리퀘스트에는 생성된 현지화 베이스라인, 포함되어, `L10N.md` 맥락 및 로컬라이즈 콘텐츠를 로드하는 데 필요한 최소한의 실용적 변경 사항.

설정은 헤더만 포함된 대상 카탈로그를 게시하지 않습니다. 번역 전에 대상 카탈로그가 필요한 경우, 해당 카탈로그에는 빈 번역 값을 가진 추출된 소스 메시지 항목만 포함됩니다. 대상 카탈로그가 아직 필요하지 않은 경우, 설정은 이를 첫 번째 번역 실행에 남겨 둡니다.

Glossia 는 풀 리퀘스트를 병합하지 않습니다. 리포지토리 관리자는 통상적인 GitHub 워크플로우를 통해 이를 검토하고 병합합니다.

이 풀 리퀘스트가 열려 있는 동안 프로젝트 개요에는 설정 알림이 표시됩니다. 풀 리퀘스트가 병합된 후 알림은 제거됩니다. 풀 리퀘스트가 병합되지 않고 닫히는 경우, 개요는 설정 완료 판단 전에 해당 풀 리퀘스트를 다시 열어야 함을 설명합니다.
