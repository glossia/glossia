프로젝트 설정은 Glossia 에 연결된 저장소를 준비합니다. 사용자는 **새 프로젝트** 흐름에서 저장소를 선택한 후, 두 가지 설정 모드를 하나 선택합니다.

## 설정 모드

| 모드 | Glossia 가 수행하는 작업 | 선택 시기 |
|---|---|---|
| **자동 설정** | 저장소를 검사하고 선택한 대상 언어에 대한 생성된 `L10N.md` 구성으로 병합 요청을 엽니다. | 저장소는 아직 현지화 구성이 없습니다. |
| **수동 구성** | 프로젝트를 즉시 생성합니다. 저장소를 검사하거나 변경하거나 병합 요청을 엽니다. | 저장소는 이미 `L10N.md` 파일이 있거나, 관리자가 작성합니다. |

아래에 제시된 상태, 진행 정보 및 병합 요청은 자동 설정에만 적용됩니다.

## 수동 구성

수동으로 구성된 프로젝트는 설정 상태가 없습니다. 생성 직후 사용でき며, 실패한 설정에 의한 거절 대상이 되지 않습니다.

Glossia 는 저장소의 기본 브랜치로의 다음 푸시 시 번역 실행을 시작합니다. 해당 실행은 저장소의 [`L10N.md`](/docs/reference/l10n-md) 파일에 선언된 모든 대상 언어로 번역하며, **새 프로젝트** 흐름에서는 대상 언어가 선택하지 않았기 때문입니다.

첫 번째 번역 실행까지, 프로젝트 개요에서는 Glossia 가 `L10N.md` 파일을 포함한 푸시를 기다리고 있음을 설명하는 알림을 표시합니다.

## 선결 조건

- 계정에 최소 하나의 구성된 모델이 있습니다.
- Glossia GitHub App 은 선택된 저장소에 접근할 수 있습니다.
- 사용자는 해당 계정으로 프로젝트를 생성할 수 있습니다.
- 자동 설정의 경우, 최소 하나의 대상 언어가 선택됩니다.

## 상태

| 상태 | 의미 | 사용 가능한 작업 |
|---|---|---|
| **대기 중** | 프로젝트가 승인되어 시작을 기다리고 있습니다. | 진행 상황을 확인하거나 페이지를 떠난 후 나중에 다시 돌아옵니다. |
| **실행 중** | Glossia 가 저장소를 검사하고 업데이트하고 있습니다. | 실시간 활동을 확인하세요. |
| **완료됨** | 현지화 기준선이 준비되어 검토를 위해 게시되었습니다. | 병합 요청을 열고, 검토하고, 병합하세요. |

설정이 **대기 중** 이거나 **실행 중** 인 경우 프로젝트는 임시입니다. 설정이 완료되지 않거나 사용할 수 있는 변경 사항을 게시할 수 없는 경우, Glossia 는 설정 환경을 정리하고 임시 프로젝트를 삭제합니다. 저장소는 그 후 **새 프로젝트** 흐름에서 제공되므로 설정을 다시 시도할 수 있습니다.

## 가시적인 진행

설정 카드는 새 프로젝트 흐름 및 프로젝트 개요에서 계속 사용 가능합니다. 다음을 포함합니다:

- 상태 배지 및 진행 막대.
- 현재 상태에 대한 간단한 설명.
- 최신 저장소 준비, 검사, 파일 변경, 체크 및 완료 활동.
- 설정이 완료되지 않는 경우 명확한 실패 메시지.

진행 상태는 임시 프로젝트가 존재하는 동안 보존됩니다. 최종 실패의 경우 프로젝트와 가시적인 설정 진행 상황 모두 사후 처리됩니다.

## 완료 결과

성공적으로 연결된 설정은 저장소의 기본 브랜치에 대한 전용 브랜치와 병합 요청을 생성합니다. 병합 요청에는 생성된 현지화 기준선이 포함되어 있으며, `L10N.md` 컨텍스트와 현지화된 콘텐츠를 로드하는 데 필요한 최소한의 실질적인 변경 사항도 포함됩니다.

설정은 헤더 전용 대상 카탈로그를 게시하지 않습니다. 번역 전에 대상 카탈로그가 필요한 현지화 프레임워크의 경우, 카탈로그에는 빈 번역 값을 가진 추출된 소스 메시지 항목이 포함됩니다. 대상 카탈로그가 아직 필요하지 않은 경우, 설정은 첫 번째 번역 실행을 위해 그들을 남겨 둡니다.

Glossia 는 병합 요청을 병합하지 않습니다. 저장소 관리자는 일반적인 GitHub 워크플로우를 통해 검토하고 병합합니다.

프로젝트 개요는 이 병합 요청이 열려 있는 동안 설정 알림을 표시합니다. 병합 요청이 병합된 후 알림은 제거됩니다. 병합되지 않고 병합 요청이 닫히는 경우, 개요는 설정 완료로 간주되기 전에 다시 열어야 함을 설명합니다.
