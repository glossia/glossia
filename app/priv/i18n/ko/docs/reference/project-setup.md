프로젝트 설정은 Glossia 를 위한 연결된 저장소를 준비합니다. 사용자가 저장소 및 최소 하나의 대상 언어를 선택한 후 이어집니다. **새 프로젝트** 프로세스.

## 요구 사항

- 계정에는 최소 하나의 구성된 모델이 있어야 합니다.
- Glossia GitHub 앱은 선택한 저장소에 접근할 수 있습니다.
- 사용자는 계정에 프로젝트를 생성할 수 있습니다.
- 최소 하나의 대상 언어가 선택되었습니다.

## 상태

| 상태 | 의미 | 사용 가능한 작업 |
|---|---|---|
| **대기 중** | 프로젝트가 승인되어 시작을 기다리고 있습니다. | 진행 상황을 확인하거나 페이지를 떠난 후 나중에 다시 돌아오세요. |
| **실행 중** | Glossia 는 저장소를 검사하고 업데이트하고 있습니다. | 라이브 활동을 따라 주세요. |
| **완료됨** | 로케일라이제이션 기준이 검토를 위해 준비되어 제출되었습니다. | 풀 리퀘스트를 열어 리뷰하고 머지하세요. |

프로젝트는 설정이 진행 중인 동안 임시입니다. **대기 중** 또는 **실행 중**. 설정이 완료되거나 사용 가능한 변경 사항을 게시할 수 없는 경우, Glossia 는 설정 환경을 정리하고 임시 프로젝트를 삭제합니다. 저장소는 이제 이용 가능한 **새 프로젝트** 흐름에서 해당 설정을 다시 시도할 수 있습니다.

## 가시적인 진행 상황

설정 카드는 새 프로젝트 워크플로우 및 프로젝트 개요에서도 계속 사용 가능합니다. 여기에는 다음이 포함됩니다:

- 상태 배지와 진행 막대입니다.
- 현재 상태에 대한 간략한 설명.
- 최근 저장소 준비, 검토, 파일 변경, 확인 및 완료 활동.
- 설정이 완료하지 않을 경우 명확한 실패 메시지가 제공됩니다.

임시 프로젝트가 존재하는 동안 진행 상황이 저장됩니다. 치명적 실패가 발생하면 프로젝트와 가시적인 설정 진행 상황이 모두 삭제됩니다.

## 완료된 결과

성공적인 연결 설정은 전용 브랜치 및 저장소 기본 브랜치에 대한 pull request 를 생성합니다. 해당 pull request 에에는 생성된 현지화 기준, 다음 `L10N.md` 컨텍스트 및 현지화 콘텐츠를 로드하기 위해 필요한 가장 실질적이고 타협할 수 있는 변경 사항입니다.

설정은 헤더 전용 대상 카탈로그를 게시하지 않습니다. 현지화 프레임워크가 번역 전에 대상 카탈로그가 필요한 경우, 해당 카탈로그는 빈 번역 값을 가진 추출된 소스 메시지 항목을 포함합니다. 대상 카탈로그가 아직 필요하지 않은 경우 설정은 이를 첫 번째 번역 실행을 위해 남겨둡니다.

Glossia 는 pull request 를 병합하지 않습니다. 저장소 관리자는 정상적인 GitHub 프로세스를 통해 이를 검토하고 병합합니다.

이 pull request 가 열린 동안 프로젝트 개요에는 설정 알림이 표시됩니다. pull request 가 병합된 후 알림은 제거됩니다. pull request 가 병합 없이 닫힌 경우, 개요에서는 설정 완료 전 재개해야 함을 설명합니다.
