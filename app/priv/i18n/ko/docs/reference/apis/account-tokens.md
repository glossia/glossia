계정 토큰은 전체 OAuth 흐름을 거치지 않고 API 요청을 인증하는 간단한 방법입니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 로그인 후 계정 대시보드로 이동하세요.
2. 열기 **API** 사이드바의 섹션.
3. 클릭 **계정 토큰**", 그 다음 **새 토큰**.
4. 토큰에 설명 가능한 **이름** (예를 들어, \\"CI 배포\\" 또는 \\"CLI 접근").
5. 권한을 선택 **권한** 토큰이 필요한 것입니다. 최소 권한만 부여하세요.
6. 설정 **만료 날짜 를** 또은 만료되지 않는 토큰을 위해 비워두세요.
7. 클릭 **토큰 생성**.

생성 후 전체 토큰 값이 표시됩니다. **한 번만**. 즉시 복사하여 안전하게 보관하세요. 전체 값을 다시 볼 수 없습니다.

## 토큰 사용

토큰을 `Authorization` HTTP 요청 헤더에 포함하세요:

    Authorization: Bearer glsa_abc123def456...

예를 들어,: `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 마찬가지입니다 [권한 모델](/docs/reference/apis/authentication) OAuth 토큰으로 처리됩니다. 토큰의 스코프는 수행할 수 있는 최대 동작 집합을 정의하며, 계정의 관계에 기반한 리소스 수준의 정책은 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 다음으로 시작합니다. `glsa_` 접두어에 이어 난수 16 진수 문자열이 붙습니다. 이 접두어는 로그 및 기밀 스캐너에서 Glossia 토큰을 쉽게 식별하게 합니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 다음 [스코프 참조](/docs/reference/apis/authentication) 전체 목록입니다.

토큰을 생성할 때는 사용 사례에 필요한 범위만 선택하세요. 예를 들어 :

- 읽기 전용 통합은 필요합니다 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인은 필요합니다 `project:read` 및 `project:write`.
- 조직 구성원 관리를 위한 스크립트는 필요합니다 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 보기

이 **계정 토큰** 페이지는 이름, 스코프, 마지막 사용 날짜, 만료일을 포함한 모든 활성 토큰을 나열합니다. 사용된 적이 없는 토큰은 마지막 사용 열에 "사용되지 않음"을 표시합니다.

### 토큰 편집

토큰 이름을 클릭하여 **이름** 및 **설명**. 스코프와 만료 시간은 생성 후 변경할 수 없습니다. 다른 스코프가 필요한 경우 새 토큰을 생성하고 이전 토큰을 회수하세요.

### 토큰 회수

토큰을 회수하려면 클릭하세요 **회수** 토큰 목록에서 하거나 토큰의 편집 페이지를 열고 **회수 토큰** 위험 구역에 있는 버튼을 사용하십시오. 회수된 토큰은 즉시 작동 중지되며 복원할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 저장하세요.** 환경 변수 또는 비밀 관리 도구를 사용하세요. 토큰은 절대 소스 코드에 커밋하지 마십시오.
- **단기 유효 토큰을 사용하세요.** 가능할 때마다 만료 날짜를 지정하세요.
- **범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 오래된 토큰을 취소하세요.
- **사용량을 모니터링하세요.** 정기적으로 "마지막 사용" 날짜를 확인하세요. 더 이상 사용하지 않는 토큰을 취소하세요.
- **각 연동에 하나의 토큰을 사용하세요.** 이런 방식으로, 하나의 토큰을 회수하더라도 다른 워크플로우를 방해하지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰을 관리할 수도 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 그리고 `revoke_token` REST API 를 반영하는 도구.
