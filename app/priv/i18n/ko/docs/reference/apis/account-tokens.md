계정 토큰은 OAuth 절차를 거치지 않고 API 요청을 인증하는 간편한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하여 계정 대시보드로 이동하세요.
2. 사이드바의 **API** 섹션을 엽니다.
3. **계정 토큰**, **새 토큰**을 클릭합니다.
4. 토큰에 설명 있는 **이름**을 지정합니다 (예시: "CI deploy" 또는 "CLI access").
5. 토큰이 필요한 **범위**를 선택합니다. 필요한 최소한의 권한만 부여하세요.
6. **만료일**을 설정하거나 만료되지 않는 토큰을 위해 비워 두세요.
7. **토큰 생성**을 클릭합니다.

생성 후 전체 토큰 값이 **한 번** 표시됩니다. 즉시 복사하여 안전하게 저장하세요. 해당 값을 다시 볼 수 없습니다.

## 토큰 사용

HTTP 요청의 `Authorization` 헤더에 토큰을 포함하세요:

```
Authorization: Bearer glsa_abc123def456...
```

예를 들어 `curl` 를 사용하여:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰은 OAuth 토큰과 동일한 [권한 모델](/docs/reference/apis/authorization)을 따릅니다. 토큰의 범위는 실행할 수 있는 최대 작업 세트를 정의하며, 리소스 수준의 정책도 계정에 따라 적용됩니다.

## 토큰 형식

모든 계정 토큰은 `glsa_` 접두사 및 랜덤 16 진수 문자열로 시작합니다. 이 접두사를 사용하면 로그 및 시크릿 스캐너에서 Glossia 토큰을 식별하기가 쉽습니다.

## 범위

계정 토큰은 OAuth 토큰과 동일한 범위를 지원합니다. 전체 목록은 [범위 참조](/docs/reference/apis/authorization) 를 확인하세요.

토큰을 생성할 때 사용 사례에 필요한 범위만 선택합니다. 예를 들어:

- 읽기 전용 통합에는 `project:read` 와 `voice:read` 가 필요합니다.
- 프로젝트를 생성하는 CI 파이프라인에는 `project:read` 와 `project:write` 가 필요합니다.
- 조직 구성원을 관리하는 스크립트에는 `members:read` 와 `members:write` 가 필요합니다.

## 토큰 관리

### 토큰 보기

**계정 토큰** 페이지는 활성 토큰의 이름, 범위, 마지막 사용 날짜 및 만료 정보를 표시합니다. 이전에 사용되지 않은 토큰의 경우 마지막 사용 열에는 "Never"가 표시됩니다.

### 토큰 편집

토큰 이름을 클릭하여 **이름** 과 **설명**을 편집합니다. 범위와 만료일은 생성 후 변경할 수 없습니다. 다른 범위가 필요한 경우 새 토큰을 생성하고 기존 토큰을 철회하세요.

### 토큰 철회

토큰을 철회하려면 토큰 목록에서 **철회**를 클릭하거나 토큰의 편집 페이지를 열고 위험 영역의 **토큰 철회** 버튼을 사용하세요. 철회된 토큰은 즉시 작동이 멈추며 복구가 불가능합니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** 환경 변수 또는 시크릿 관리자를 사용하세요. 토큰을 소스 컨트롤에 절대 커밋하지 마세요.
- **짧은 유효기간의 토큰을 사용하세요.** 가능한 경우 만료일을 설정하세요.
- **범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 회전시키세요.** 일정별로 새 토큰을 생성하고 오래된 토큰을 철회하세요.
- **사용량을 모니터링하세요.** 주기적으로 "마지막 사용" 날짜를 확인하세요. 더 이상 사용하지 않는 토큰을 철회하세요.
- **각 통합마다 하나의 토큰을 사용하세요.** 이렇게 하면 하나의 토큰을 철회해도 다른 워크플로우에 영향을 주지 않습니다.

## API 관리

REST API 와 MCP 서버로도 계정 토큰을 관리할 수 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 철회 |

### MCP

MCP 서버는 REST API 를 반영하는 `list_tokens`, `create_token` 및 `revoke_token` 도구를 제공합니다.
