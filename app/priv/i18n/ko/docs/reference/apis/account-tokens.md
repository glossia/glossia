계정 토큰 은 전체 OAuth 플로우를 거치지 않고 API 요청을 인증할 수 있는 간단한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하고 계정 대시보드로 이동하세요.
2. 열려면 **API** 섹션을 사이드바에서.
3. 클릭 **계정 토큰**, 다음에 **새 토큰**.
4. 토큰에 설명적인 **이름** (예: "CI deploy" 또는 "CLI access").
5. 선택할 **스코프** 토큰이 필요한 것입니다. 최소한의 권한만 부여하세요.
6. 만료일을 **설정** 혹은 만료되지 않는 토큰을 위해 비워두세요.
7. 클릭 **토큰 생성**.

생성 후 전체 토큰 값이 표시됩니다. **한 번**. 즉시 복사하여 안전하게 보관하세요. 이후에는 전체 값을 다시 볼 수 없습니다.

## 토큰 사용

HTTP 요청 헤더에 토큰을 포함하여 `Authorization` HTTP 요청 헤더:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 사용 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일한 형식을 따릅니다 [인증 모델](/docs/reference/apis/authorization) OAuth 토큰과 마찬가지로. 토큰의 스코프는 수행할 수 있는 동작의 최대 집합을 정의하며, 계정 간 관계에 따라 리소스 수준의 정책 또한 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 해당 `glsa_` 접두사 뒤에는 랜덤 16 진수 문자열이 따릅니다. 이 접두사는 로그 및 기밀 스캐너에서 Glossia 토큰을 식별할 수 있습니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 보십시오. [스코프 참조](/docs/reference/apis/authorization) 전체 목록을 확인하세요.

토큰 생성 시, 사용 사례에 필요한 스코프만 선택하십시오. 예를 들어:

- 읽기 전용 통합에는 필요합니다 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인에는 필요합니다 `project:read` 및 `project:write`.
- 조직 구성원 관리를 담당하는 스크립트에는 `members:read` 와 `members:write`.

## 토큰 관리

### 토큰 보기

해당 **계정 토큰** 페이지에는 모든 활성 토큰의 이름, 스코프, 마지막 사용 날짜 및 만료일이 나열됩니다. 사용된 적이 없는 토큰은 마지막 사용 열에 "사용 안 됨"으로 표시됩니다.

### 토큰 편집

토큰의 이름을 클릭하여 편집할 수 있는 **이름** 및 **설명**. 생성 후 범위 및 유효기간은 변경할 수 없습니다. 다른 범위가 필요하면 새 토큰을 생성하고 기존 토큰을 회수하세요.

### 토큰 회수

토큰을 회수하려면 클릭하세요 **회수** 토큰 목록에서 또는 토큰의 편집 페이지를 열고 사용하는 **토큰 회수** 위험 영역의 버튼입니다. 회수된 토큰은 즉시 작동 중지되며 복구할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** 환경 변수 또는 비밀 관리자를 사용하세요. 토큰을 절대 소스 코드 제어에 커밋하지 마세요.
- **단기 토큰을 사용하세요.** 가능한 경우 만료 날짜를 설정하세요.
- **스코프를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 기존 토큰을 취소하세요.
- **사용량을 모니터링하세요.** 정기적으로 "최종 사용" 날짜를 확인하세요. 더 이상 사용하지 않는 토큰은 취소하세요.
- **각 연동마다 하나의 토큰만 사용하세요.** 이렇게 하면, 하나의 토큰을 취소하더라도 다른 워크플로우는 중단되지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰을 관리할 수도 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`"," 및 `revoke_token` REST API 를 반영하는 도구들입니다.
