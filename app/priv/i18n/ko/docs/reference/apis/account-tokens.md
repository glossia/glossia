계정 토큰은 전체 OAuth 흐름을 거치지 않고 API 요청을 인증하는 간단한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 이상적입니다.

## 토큰 생성

1. Glossia 에 로그인한 후, 계정 대시보드로 이동하세요.
2. 열으세요 **API** 사이드바 섹션에서.
3. 클릭 **계정 토큰**, 그리고 **새 토큰**.
4. . 토큰에 설명 가능한 **이름** (예를 들어, \\"CI deploy\\" 또는 \\"CLI access\\" ).
5. 선택할 **스코프** 토큰이 필요로 하는 최소 권한만 부여하
6. 설정 하 **만료일** 또는 만료되지 않는 토큰을 위해 빈칸을 남겨두세요.
7. 탭하기 **토큰을 생성**.

생성 후 전체 토큰 값이 표시됩니다. **한 번.**. 즉시 복사하여 안전하게 저장하세요. 전체 값을 다시 볼 수 없습니다.

## 토큰 사용

토큰을 다음에 포함하십시오 `Authorization` HTTP 요청 헤더:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 다음과 같이 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰은 동일한 규칙을 따릅니다. [권한 모델](/docs/reference/apis/authentication) OAuth 토큰과 같습니다. 토큰의 스코프는 해당 토큰이 실행할 수있는 최대 동작 세트를 정의하며, 계정 간의 관계에 따라 리소스 수준의 정책이 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 다음 `glsa_` 접두사 뒤에 랜덤 16 진수 문자열이 따릅니다. 이 접두사는 로그 및 시크릿 스캐너에서 Glossia 토큰을 식별하기 쉽게 합니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 다음의 [스코프 참조](/docs/reference/apis/authentication) 전체 목록 확인.

토큰을 생성할 때는 사용 사례에 필요한 스킵만 선택하세요. 예를 들어:

- 읽기 전용 통합은 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인은 `project:read` 및 `project:write`.
- 조직 구성원 관리 스크립트에는 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 확인

이 **계정 토큰** 페이지는 모든 활성 토큰의 이름, 스코프, 마지막 사용 날짜, 만료일을 표시합니다. 사용된 적이 없는 토큰은 마지막 사용 열에 "사용하지 않음"으로 표시됩니다.

### 토큰 편집

토큰 이름을 클릭하여 토큰의 **이름** 및 **설명**. 범위와 만료 시간은 생성 후 변경할 수 없습니다. 다른 범위가 필요하다면 새 토큰을 생성하고 기존 토큰을 취소하세요.

### 토큰 취소

토큰을 취소하려면 클릭 **회수** 토큰 목록에서, 또는 토큰 편집 페이지를 열고 **토큰 회수** 위험 구역의 버튼입니다. 회수된 토큰은 즉시 작동이 중단되며 복원할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** 환경 변수 또는 비밀 관리자를 사용하세요. 토큰을 소스 코드 관리 시스템에 절대 커밋하지 마세요.
- **유효 기간이 짧은 토큰을 사용하세요.** 가능하면 만료 날짜를 설정하세요.
- **범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 기존 토큰을 취소하세요.
- **사용량을 모니터링하세요.** "마지막 사용" 날짜를 정기적으로 확인하세요. 더 이상 사용하지 않는 토큰은 취소하세요.
- **하나의 통합당 하나의 토큰만 사용하세요.** 이렇게 하면 하나의 토큰을 취소하더라도 다른 워크플로는 영향을 받지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰도 관리할 수 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 그리고 `revoke_token` REST API 를 반영하는 도구들.
