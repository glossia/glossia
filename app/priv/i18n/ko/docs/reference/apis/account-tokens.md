계정 토큰은 전체 OAuth 플로우를 거치지 않고 API 요청을 인증할 수 있는 간단한 방법입니다. 스크립트, CI/CD 파이프라인, 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하고 계정 대시보드로 이동하세요.
2. 열기 **API** 사이드바의 섹션입니다.
3. 클릭 **계정 토큰**, 그다음 **새 토큰**.
4. 토큰에 설명적인 **이름** (예를 들어, \\"CI deploy\\" 또는 \\"CLI access\\").
5. 다음에 선택 **스코프** 토큰이 필요로 하는 권한입니다. 최소 필요한 권한만 부여하세요.
6. 설정 **만료일** 또는 만료되지 않는 토큰의 경우 빈칸으로 두세요.
7. 클릭 **토큰 생성**.

생성 후 전체 토큰 값이 표시됩니다. **한 번**. 즉시 복사하여 안전하게 저장하세요. 전체 값을 다시 볼 수 없습니다.

## 토큰 사용 시

토큰을 `Authorization` HTTP 요청 헤더에 포함해야 합니다:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 사용 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일합니다. [인증 모델](/docs/reference/apis/authentication) OAuth 토큰으로 사용됩니다. 토큰의 스코프는 해당 토큰이 수행할 수 있는 최대 동작 집합을 정의하며, 리소스 수준의 정책은 계정 관계에 따라 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 다음 으로 시작합니다. `glsa_` prefix 뒤에 무작위 16 진수 문자열이 이어집니다. 이 prefix 는 로그 및 비밀 감지기 에서 Glossia 토큰을 식별하기 쉽습니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 다음 [스코프 참조](/docs/reference/apis/authentication) 전체 목록을 확인하세요.

토큰을 생성할 때는 사용 사례에 필요한 스코프만 선택하세요. 예를 들어:

- 읽기 전용 통합에는 다음이 필요합니다 `project:read` 및 `voice:read`.
- 프로젝트 생성 CI 파이프라인에는 다음이 필요합니다 `project:read` 및 `project:write`.
- 조직 구성원을 관리하는 스크립트는 필요합니다 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 확인

해당 **계정 토큰** 페이지는 이름, 스코프, 마지막 사용 날짜, 만료일과 함께 모든 활성 토큰을 나열합니다. 아직 사용된 적 없는 토큰은 마지막 사용 열에 "사용 안함"을 표시합니다.

### 토큰 편집

토큰의 이름을 클릭하여 **이름** 및 **설명**. 스코프 및 만료 기간은 생성 후 변경할 수 없습니다. 다른 스코프가 필요한 경우 새 토큰을 생성하고 기존 토큰을 취소하세요.

### 토큰 취소

토큰을 취소하려면 **회수** 토큰 목록에서 또는 토큰의 편집 페이지를 열어 사용하여 **토큰 회수** 위험 구역의 버튼. 회수된 토큰은 즉시 사용 중지되며 복구할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하십시오.** 환경 변수 또는 비밀 관리자를 사용하십시오. 토큰을 소스 코드 관리에 절대 커밋하지 마십시오.
- **단기 토큰을 사용하십시오.** 가능하면 만료일을 설정하세요.
- **권한 범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 오래된 토큰을 취소하세요.
- **사용량을 모니터링하세요.** 정기적으로 "최종 사용일" 을 확인하세요. 더 이상 사용하지 않는 토큰은 취소하세요.
- **각 통합 당 하나의 토큰을 사용하세요.** 이렇게 하면 하나의 토큰을 취소해도 다른 워크플로우에 영향을 주지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰을 관리할 수도 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 그리고 `revoke_token` REST API 를 반영하는 도구.
