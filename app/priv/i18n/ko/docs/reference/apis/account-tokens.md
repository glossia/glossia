계정 토큰은 OAuth 를 거치지 않고 API 요청을 인증할 수 있는 간편한 방법입니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하여 계정 대시보드에 이동하세요.
2. 열고 **API** 섹션을 사이드바에서 엽니다.
3. 클릭하세요 **계정 토큰**, 그다음 **신규 토큰**.
4. 토큰에 설명 가능한 **이름** (for example, "CI deploy" or "CLI access").
5. 권한 **을 선택** 이 토큰이 필요한 최소한의 권한만 부여하세요.
6. 만료 날짜를 **설정하세요.** 또는 만료되지 않는 토큰을 위해 공란으로 두세요.
7. 클릭 **토큰 생성**.

생성 후에는 전체 토큰 값이 표시됩니다. **한 번**. 즉시 복사하여 안전하게 저장하세요. 전체 값을 다시 보실 수 없습니다.

## 토큰 사용 시

토큰을 `Authorization` HTTP 요청 헤더에 포함하세요:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 사용 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일하게 적용됩니다. [권한 모델](/docs/reference/apis/authentication) OAuth 토큰입니다. 토큰의 범위는 실행할 수 있는 최대 동작 세트를 정의하며, 계정 관계를 기반으로 리소스 수준의 정책 역시 적용됩니다.

## 토큰 형식

모든 계정 토큰은 `glsa_` 접두사 뒤에 랜덤 16 진수 문자열 이 이어집니다. 이 접두사 는 로그 및 비밀 스캐너 에서 Glossia 토큰 을 식별 하기 쉽게 만듭니다.

## 범위

계정 토큰 은 OAuth 토큰 과 동일한 범위를 지원합니다. 자세한 내용은 [범위 참조](/docs/reference/apis/authentication) 전체 목록을 보려면.

토큰을 생성할 때는 사용 사례에 필요한 스코프만 선택하세요. 예를 들어:

- 읽기 전용 통합에는 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인에는 `project:read` 및 `project:write`.
- 조직 구성원 관리를 담당하는 스크립트가 필요합니다 `members:read` 그리고 `members:write`.

## 토큰 관리

### 토큰 확인

이 **계정 토큰** 페이지는 모든 활성 토큰의 이름, 범위, 마지막 사용 날짜, 만료일을 나열합니다. 사용된 적이 없는 토큰은 마지막 사용 열에 "사용되지 않았습니다" 를 표시합니다.

### 토큰 편집

토큰의 이름을 클릭하여 **이름** 및 **설명**. 생성 후 권한 범위와 만료 시간은 변경할 수 없습니다. 다른 범위가 필요하면 새 토큰을 생성하고 기존 토큰을 취소하세요.

### 토큰 취소

토큰을 취소하려면 클릭하세요 **회수** 토큰 목록에서 또는 토큰의 수정 페이지를 열고 사용할 **토큰 회수** 위험 영역에 있는 버튼입니다. 회수된 토큰은 즉시 무효화되며 복구할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** 환경 변수 또는 비밀 관리 도구를 사용하세요. 소스 코드 관리 시스템에 토큰을 절대 커밋하지 마세요.
- **단기 토큰을 사용하세요.** 가능한 경우 만료 날짜를 설정하세요.
- **범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 정해진 일정에 따라 새 토큰을 생성하고 기존 토큰을 회수하세요.
- **사용량을 모니터링하세요.** "마지막 사용" 날짜를 주기적으로 확인하세요. 더 이상 사용하지 않는 토큰은 회수하세요.
- **각 연동에 하나의 토큰만 사용하세요.** 이를 통해 하나의 토큰을 취소하더라도 다른 워크플로우에는 영향을 미치지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰도 관리할 수 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 회수 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 그리고 `revoke_token` REST API 를 반영하는 도구.
