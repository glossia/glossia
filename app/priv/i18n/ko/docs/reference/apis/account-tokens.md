계정 토큰은 전체 OAuth 플로우를 거치지 않고 API 요청을 인증할 수 있는 간단한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 가장 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하고 계정 대시보드를 방문하세요.
2. 사이드바의 **API** 섹션을 여세요.
3. **계정 토큰**을 클릭한 후 **새 토큰**을 클릭하세요.
4. 토큰에 설명 가능한 **이름**을 지정하세요 (예: "CI 배포" 또는 "CLI 접근").
5. 토큰이 필요한 **범위**를 선택하세요. 필요한 최소한의 권한만 부여하세요.
6. **만료 날짜**를 설정하거나, 만료되지 않는 토큰을 위해 비워 두세요.
7. **토큰 생성**을 클릭하세요.

생성 후 전체 토큰 값이 **한 번** 표시됩니다. 즉시 복사하여 안전하게 저장하세요. 이후 다시 전체 값을 볼 수 없습니다.

## 토큰 사용

HTTP 요청의 `Authorization` 헤더에 토큰을 포함하세요.

```
Authorization: Bearer glsa_abc123def456...
```

예를 들어, `curl` 를 사용하는 경우:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰은 OAuth 토큰과 동일한 [권한 모델](/docs/reference/apis/authorization)을 따릅니다. 토큰의 범위는 수행할 수 있는 동작의 최대 세트를 정의하며, 계정 관계를 기준으로 리소스 수준 정책이 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 `glsa_` 접두사로 시작하며 다음으로 16 진수 랜덤 문자열이 계속됩니다.

## 범위

계정 토큰은 OAuth 토큰과 동일한 범위를 지원합니다. 전체 목록을 보려면 [범위 참조](/docs/reference/apis/authorization)를 확인하세요.

토큰을 생성할 때 사용 사례가 필요한 범위를만 선택하세요. 예를 들어:

- 읽 전용 통합에는 `project:read` 와 `voice:read` 가 필요합니다.
- 프로젝트를 생성하는 CI 파이프라인에는 `project:read` 와 `project:write` 가 필요합니다.
- 조직 멤버를 관리하는 스크립트에는 `members:read` 와 `members:write` 가 필요합니다.

## 토큰 관리

### 토큰 확인

**계정 토큰** 페이지는 이름, 범위, 마지막 사용 날짜, 만료일을 가진 모든 활성 토큰을 나열합니다. 아직 사용되지 않은 토큰은 마지막 사용 열에 "아직 없음"을 보여줍니다.

### 토큰 편집

토큰 이름을 클릭하여 **이름** 과 **설명** 을 편집할 수 있습니다. 준비 후 스키프와 만료 날짜를 변경할 수 없습니다. 다른 스키프가 필요하다면 새 토큰을 생성하고 기존 토큰을 취소할 수 있습니다.

### 토큰 해지

토큰을 해지하려면 토큰 목록에서 **해지**를 클릭하거나 토큰 편집 페이지를 열고 위험 영역 (**토큰 해지**) 을 사용하세요. 해지된 토큰은 즉시 작동하지 않으며 복구할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** environment 변수 를 사용하는 것이 좋습니다.
- **짧은 수명 토큰을 사용하세요.** 항상 가능한 경우 만료 날짜를 설정하세요.
- **스키프를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 오래된 토큰을 취소하세요.
- **사용을 확인하세요.** " laatste 사용" 날짜를 맞게 확인하세요. 더 이상 안쓰는 토큰을 취소하세요.
- **통합 당 1 토큰을 사용하세요.** (이 방법은 토큰 취소할 때 다른 워크의 압을 하지 않습니다.)

## API 관리

REST API 와 MCP 서 버를 통해 계정 토큰 을 관리 할 수도 있습니다.

### REST API

| Method | Endpoint | 설 명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 해지 |

### MCP

MCP 서버는 REST API 를 반영하는 `list_tokens`, `create_token`, 및 `revoke_token` 도구를 노출합니다.
