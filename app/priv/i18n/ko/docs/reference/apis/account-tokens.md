계정 토큰은 전체 OAuth 플로우를 거치지 않고 API 요청을 인증할 수 있는 간단한 방법입니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하고 계정 대시보드로 이동하세요.
2. 열기 **API** 사이드바의 섹션에서.
3. 클릭 **계정 토큰**, 그런 다음 **새 토큰**.
4. 해당 토큰에 설명 가능한 **이름** (예를 들어, \\"CI deploy\\" 또는 \\"CLI access\\").
5. 스코프 **선택할** 토큰이 필요합니다. 최소한 필요한 권한만 부여하세요.
6. 설정을 **만료일** 또는 비워두고 만료되지 않는 토큰을 생성하세요.
7. 클릭 **토큰 생성**.

생성 후에는 전체 토큰 값이 표시됩니다 **한 번**. 즉시 복사하여 안전하게 저장하세요. 다시는 전체 값을 볼 수 없습니다.

## 토큰 사용

토큰을 `Authorization` HTTP 요청 헤더에 포함하세요:

    Authorization: Bearer glsa_abc123def456...

예를 들어, `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일하게 따릅니다 [인증 모델](/docs/reference/apis/authentication) OAuth 토큰과 동일합니다. 토큰의 SCOPE 는 해당 토큰이 수행할 수 있는 동작의 최대 집합을 정의하며, 계정 간 관계에 따라 리소스 레벨 정책도 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 해당 `glsa_` prefix 이어지는 임의의 16 진수 문자열입니다. 이 prefix 는 로그 및 비밀 스캐너에서 Glossia 토큰을 식별하는 데 쉽습니다.

## SCOPE

계정 토큰은 OAuth 토큰과 동일한 SCOPE 를 지원합니다. 아래 [SCOPE 참조](/docs/reference/apis/authentication) 전체 목록을 보려면.

토큰 생성 시에는 사용 사례에 필요한 범위만 선택하세요. 예를 들어:

- 읽기 전용 통합에는 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인에는 `project:read` 및 `project:write`.
- 조직 구성원을 관리하는 스크립트가 필요합니다 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 보기

해당 **계정 토큰** 페이지는 모든 활성 토큰의 이름, 범위, 마지막 사용 날짜 및 만료일을 나열합니다. 사용된 적이 없는 토큰은 마지막 사용 열에 "Never"으로 표시됩니다.

### 토큰 편집

토큰 이름을 클릭하여 수정하려면 **이름** 및 **설명**. 생성 후 범위와 만료 시기는 변경할 수 없습니다. 다른 범위가 필요하면 새 토큰을 생성하고 기존 토큰을 회수하세요.

### 토큰 회수

토큰을 회수하려면 클릭하세요 **회수** 토큰 목록에서 또는 토큰의 편집 페이지를 열어서 **토큰 회수** 위험 구역에 있는 버튼. 회수된 토큰은 즉시 무효화되며 복구할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 저장하세요.** 환경 변수 또는 비밀 관리자를 사용하세요. 토큰을 버전 관리 시스템에 커밋하지 마세요.
- **짧은 유효기간의 토큰을 사용하세요.** 가능하면 만료일을 설정하세요.
- **스코프를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정에 따라 새 토큰을 생성하고 기존 토큰을 철회하세요.
- **사용량을 모니터링하세요.** 정기적으로 "마지막 사용" 날짜를 확인하세요. 더 이상 사용하지 않는 토큰은 철회하세요.
- **각 통합에 하나의 토큰만 사용하세요.** 이렇게 하면 하나의 토큰을 취소하더라도 다른 워크플로우에는 영향을 주지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰도 관리할 수 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 및 `revoke_token` REST API 를 반영하는 도구들.
