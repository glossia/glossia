계정 토큰은 전체 OAuth 인증 흐름을 거치지 않고 API 요청을 인증하는 간단한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 이상적입니다.

## 토큰 생성

1. Glossia 에 로그인하여 계정에 대시보드를 이동하세요.
2. 열기 **API** 사이드바의 섹션.
3. 클릭 **계정 토큰**, 그런 다음 **새 토큰**.
4. 토큰에 설명 가능한 **이름** (예를 들어, "CI deploy" 또는 "CLI access")
5. 선택할 **범위** 토큰이 필요한 권한입니다. 필요한 최소한의 권한만 허용하세요.
6. 설정 **만료일** 또는 만료되지 않는 토큰을 위해 공란으로 두세요.
7. 클릭 **토큰 생성**.

생성 후 전체 토큰 값이 표시됩니다. **한 번**. 즉시 복사하여 안전하게 보관하세요. 이후에는 전체 값을 다시 볼 수 없습니다.

## 토큰 사용 시

토큰을 포함하여 `Authorization` HTTP 요청 헤더에:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 사용하는 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일하게 따릅니다. [인가 모델](/docs/reference/apis/authentication) OAuth 토큰과 동일하게 작동합니다. 토큰의 스코프는 수행할 수 있는 동작의 최대 집합을 정의하며, 계정 관계에 따라 리소스 수준의 정책 또한 여전히 적용됩니다.

## 토큰 형식

모든 계정 토큰은 해당 `glsa_` 접두사 뒤로 난수 16 진수 문자열이 따릅니다. 이 접두사는 로그 및 기밀 스캐너에서 Glossia 토큰을 식별하기 쉽게 만듭니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 해당 [스코프 참조](/docs/reference/apis/authentication) 전체 목록을 보려면.

토큰 생성 시, 사용 사례에 필요한 스코프만 선택하세요. 예를 들어:

- 읽기 전용 통합은 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인은 `project:read` 및 `project:write`.
- 조직 구성원을 관리하는 스크립트의 필요 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 열람

해당 **계정 토큰** 페이지는 이름, 권한, 마지막 사용 날짜, 만료일을 포함한 모든 활성 토큰을 나열합니다. 사용되지 않은 토큰은 마지막 사용 열에서 \\"사용 안됨\\"으로 표시됩니다.

### 토큰 수정

토큰 이름을 클릭하여 수정할 수 있는 **이름** 그리고 **설명**. 생성 후 스코프 및 만료 시간은 변경할 수 없습니다. 다른 스코프가 필요할 경우 새 토큰을 생성하고 기존 토큰을 취소하세요.

### 토큰 취소

토큰을 취소하려면 클릭하세요 **취소** 토큰 목록에서 또는 토큰의 편집 페이지를 열고 **토큰 취소** 위험 구역의 버튼을 사용하세요. 취소된 토큰은 즉시 비활성화되며 복원할 수 없습니다.

## 보안 모범 사례

- **토큰을 안전하게 저장하세요.** 환경 변수 또는 비밀 관리 도구를 사용하세요. 토큰을 소스 컨트롤에 절대 커밋하지 마세요.
- **단기 유효 토큰을 사용하세요.** 가능할 때마다 만료 날짜를 설정하세요.
- **스코프를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 일정마다 새 토큰을 생성하고 이전 토큰을 회수하세요.
- **사용량을 모니터링하세요.** 정기적으로 "마지막 사용" 날짜를 확인하세요. 더 이상 사용하지 않는 토큰을 회수하세요.
- **각 통합마다 하나의 토큰만 사용하세요.** 이렇게 하면 하나의 토큰을 취소해도 다른 워크플로우에는 영향을 주지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰도 관리할 수 있습니다.

### REST API

| 방법 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버는 노출합니다 `list_tokens`, `create_token`, 그리고 `revoke_token` REST API 를 반영하는 도구들입니다.
