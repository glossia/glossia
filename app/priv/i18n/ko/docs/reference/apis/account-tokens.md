OAuth 플로우 전체를 거치지 않고 API 요청을 인증할 수 있는 간단한 방법을 제공합니다. 스크립트, CI/CD 파이프라인 및 개인 자동화에 적합합니다.

## 토큰 생성

1. Glossia 에 로그인하여 계정 대시보드에 이동하세요.
2. 열어서 **API** 섹션을 사이드바에서 엽니다.
3. 클릭 **계정 토큰**, 그런 다음 **새 토큰**.
4. 명확한 **이름** (예: \\"CI deploy\\" 또는 \\"CLI access\\" ).
5. 선택 **범위** 이 토큰이 필요로 하는 것입니다. 필요한 최소한의 권한만 허용하세요.
6. 설정할 **만료 날짜를** 하거나 비워두세요. 만료되지 않는 토큰을 위해.
7. 클릭하세요. **토큰 생성.**.

생성 후 전체 토큰 값이 표시됩니다. **한 번**바로 복사하여 안전하게 저장하세요. 이후에는 전체 값을 다시 보아하실 수 없습니다.

## 토큰 사용

토큰을 다음에 포함하세요 `Authorization` HTTP 요청의 헤더:

    Authorization: Bearer glsa_abc123def456...

예를 들어, 사용하는 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

계정 토큰도 동일합니다 [인증 모델](/docs/reference/apis/authentication) OAuth 토큰과 같습니다. 토큰의 스코프는 해당 토큰이 수행할 수 있는 최대 작업 집합을 정의하며, 계정의 관계에 따라 리소스 수준의 정책 역시 적용됩니다.

## 토큰 형식

모든 계정 토큰은 이 `glsa_` 접두사를 이어 랜덤 16 진수 문자열이 따릅니다. 이 접두사를 통해 로그 및 시크릿 스캐너에서 Glossia 토큰을 식별하기 쉽습니다.

## 스코프

계정 토큰은 OAuth 토큰과 동일한 스코프를 지원합니다. 다음 [스코프 참조](/docs/reference/apis/authentication) 전체 목록을 위해.

토큰을 생성할 때는 사용 사례에 필요한 권한 (scopes) 만 선택하세요. 예를 들어:

- 읽기 전용 통합은 필요합니다 `project:read` 및 `voice:read`.
- 프로젝트를 생성하는 CI 파이프라인은 필요합니다 `project:read` 및 `project:write`.
- 조직원을 관리하는 스크립트의 필요 `members:read` 및 `members:write`.

## 토큰 관리

### 토큰 확인

해당 **계정 토큰** 페이지는 모든 활성 토큰의 이름, 범위, 마지막 사용 날짜 및 만료일을 나열합니다. 한번도 사용된 적 없는 토큰은 마지막 사용 열에 "Never"을 표시합니다.

### 토큰 편집

토큰의 이름을 클릭하여 **name** 및 **description**를 편집하세요. 범위와 만료 날짜는 생성 후 변경할 수 없습니다. 다른 범위가 필요하면 새 토큰을 생성하고 기존 토큰을 취소하세요.

### 토큰 취소

토큰을 취소하려면 클릭 **회수** 토큰 목록에서나 해당 토큰의 편집 페이지를 열어 사용하는 **회수 토큰** 위험 구역의 버튼입니다. 회수된 토큰은 즉시 무효화되며 복원이 불가능합니다.

## 보안 모범 사례

- **토큰을 안전하게 보관하세요.** 환경 변수 또는 비밀 관리자를 사용하세요. 토큰은 소스 컨트롤에 절대 커밋하지 마세요.
- **단기 유효 토큰을 사용하세요.** 가능한 한 만료일을 설정하세요.
- **권한 범위를 최소화하세요.** 토큰이 실제로 필요한 권한만 부여하세요.
- **정기적으로 교체하세요.** 정해진 일정에 따라 새 토큰을 생성하고 기존 토큰을 취소하세요.
- **사용량을 모니터링하세요.** "마지막 사용" 날짜를 정기적으로 확인하세요. 더 이상 사용하지 않는 토큰은 취소하세요.
- **각 통합마다 하나의 토큰을 사용하세요.** 이렇게 하면 하나의 토큰을 취소해도 다른 워크플로우에는 영향을 주지 않습니다.

## API 관리

REST API 와 MCP 서버를 통해 계정 토큰을 관리할 수도 있습니다.

### REST API

| 메서드 | 엔드포인트 | 설명 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 활성 토큰 목록 |
| `POST` | `/api/tokens` | 새 토큰 생성 |
| `DELETE` | `/api/tokens/:id` | 토큰 취소 |

### MCP

MCP 서버가 노출합니다 `list_tokens`, `create_token`그리고 `revoke_token` REST API 를 반영하는 도구.
