Glossia 는 계정 및 프로젝트 애플리케이션 화면과 공개된 웹사이트 콘텐츠를 별도로 노출합니다.

## 데이터 표현

| 인터페이스 | 동작 방식 |
|---|---|
| 공개된 HTML URL | 브라우저의 표출 방식이며, 표준 메타데이터 및 마크다운 대안 `Link` 응답 헤더를 포함합니다. |
| 현재 URL 에서 `Accept: text/markdown` | 지정된 미디어 유형이 양수 품질을 가지며 `text/html` 보다 덜 선호되지 않을 때 마크다운 표출 방식입니다. |
| `.md` 를 첨부한 페이지 URL | 브라우저 언어 선호도와 독립적인 명시 마크다운 표현형입니다. |
| `/index.md` | 홈페이지 마크다운 개요. |
| `/docs.md`, `/blog.md`, `/features.md` | 공개 콘텐츠의 마크다운 인덱스입니다. |
| `/changelog.md` | 단 하나의 마크다운 문서에 포함된 공개 변경 로그 항목입니다. |
| `/terms.md`, `/privacy.md`, `/cookies.md` | 최신 공개된 법적 문서입니다. 날짜가 지정된 법적 URL 도 `.md` 을 지원합니다. |

`*/*` 만으로는 마크다운을 선택하지 않습니다. HTML 응답과 마크다운 응답은 `Vary: Accept` 를 공유하므로 캐시가 표출 형식을 혼합하지 않습니다.

각별한 문서, 블로그, 기능 및 법적 콘텐츠는 렌더링된 HTML 의 변환 대신 작성된 마크다운을 사용합니다. 인덱스 페이지는 게시된 인벤토리에서 생성되며, 홈페이지는 라운딩된 마크다운 개요를 제공합니다. 인터랙티브 REST 참조는 독자를 브라우저 전용 API 위젯을 포함하는 대신 OpenAPI 명세로 안내합니다.

## 언어 설정

영어는 접두사가 없습니다. 번역된 마케팅 URL 은 실제 접두사를 사용합니다: `/de`, `/es`, `/fr`, `/ja`, `/ko`, `/pt-br`, 및 `/zh-hans`. 예를 들어, `/es/docs/tutorials/getting-started.md` 는 게시될 때 스페인 버전이 됩니다.

URL 은 마크다운 콘텐츠의 언어를 선택합니다. `Accept-Language` 는 마크다운 요청을 리디렉션하지 않습니다. 누락된 콘텐츠 번역은 영어 소스로 복원됩니다. 홈페이지 개요는 현재 영어로 작성되었습니다.

## 검색

- `/robots.txt` 는 기본값으로 크롤링을 금지하며 유한한 공개 HTML 과 마크다운 인벤토리, 로컬라이즈 피드, `/assets/`, `/fonts/`, 와 `/images/` 하위에 있는 렌더링 자산, favicon, 및 `/og/marketing/` 하위에 있는 공개 마케팅 미리보기를 포함합니다. `/og/app/` 하위에 있는 계정 미리보기 이미지는 여전히 금지됩니다. 이는 협력 크롤러를 위한 안내이며 권한 부여 메커니즘이 아닙니다.
- `/sitemap.xml` 는 표준공개 내용과 로케일 대체본을 나열하며 마크다운 전용 페이지의 마크다운 URL 도 포함합니다. 변경 로그 조각은 별도의 URL 이 아닙니다.
- `/llms.txt` 는 Glossia 를 소개하며 공개 문서, 기능 가이드, 및 최근 게시글의 명시적 마크다운 링크를 포함합니다.
- `/llms-full.txt` 는 홈페이지 개요, 문서, 및 마크다운 전용 비교 콘텐츠를 하나의 마크다운 텍스트 문서로 내보냅니다.

비교 콘텐츠는 마크다운 전용으로 게시됩니다. HTML 문서, 내비게이션, 검색, 및 문서 인덱스에서 제외되지만 에이전트는 `/llms.txt` 와 시트맵을 통해 찾을 수 있습니다. 표준 URL 은 `.md` 로 끝나며, 이전 HTML URL 도 `Accept: text/markdown` 에 응답하지만 이제 더 이상 브라우저 페이지를 렌더링하지 않습니다.

인증, 계정 대시보드, API, 및 기타 애플리케이션 응답은 `noindex, nofollow` 로 표시됩니다. 게시된 성공 콘텐츠는 `index, follow` 로 표시됩니다. 오류는 여전히 인덱싱 불가 상태입니다. 검색 텍스트 파일 (`/robots.txt`, `/llms.txt`, 및 `/llms-full.txt`) 은 `noindex, follow` 을 사용합니다: 독자는 이를.FETCH 하고 링크를 따를 수 있지만, 검색 엔진은 중복 문서 덤프 대신 표준 페이지를 인덱싱해야 합니다.

## 캐싱 및 자원 사용

마크다운 및 검색 텍스트 응답에는 다음이 포함됩니다:

| 엔베어 | 값 또는 의미 |
|---|---|
| `Content-Type` | `text/markdown; charset=utf-8`, 또는 검색 텍스트의 경우 `text/plain; charset=utf-8`. |
| `Cache-Control` | `public, max-age=300, stale-while-revalidate=60`. |
| `ETag` | 표현 데이터에 대한 인용된 SHA-256 요약입니다. |
| `X-Markdown-Tokens` | 문자 수의 4 분 1 을 올림된 값이며 모델 특이 토크나이저 카운트가 아닙니다. |

`If-None-Match` 는 강하거나 약한 검증자 매칭과 여러 검증자 및 `*` 를 지원합니다. 매칭 시 `304`를 본체 없이 반환합니다. `HEAD` 는 표현 헤더를 본체 없이 반환합니다.

게시된 마크다운 인벤토리는 릴리스에 컴파일됩니다. 요청은 콘텐츠 번역 진행, 소스 파일 읽기, 인증 계정 로드, 또는 LiveView 렌더링을 수행하지 않습니다. 이 공개 표현에 액세스하려면 User-Agent impersonation 이 필요하지 않습니다.

## 운영 제한

마크다운 협상계정은 계정 또는 프로젝트 대시보드 접근을 제공하지 않습니다. 기존 계정 브라우징 속도 제한 및 Turnstile 확인은 별도의 보호 조치로 유지됩니다.

프로덕션 엣지 속도 제한은 `GET` 와 `HEAD` 모두에 적용됩니다. 검증된 크롤러도 속도 제한 받습니다. 초과 요청은 브라우저 챌린지가 아닌 속도 제한 응답을 받습니다. 독자는 속도를 재조정하여 나중에 재시도해야 합니다. 공유 캐싱 및 조건부 요청은 클라이언트에 속도 제한 면제를 제공하지 않습니다.

저장소의 크롤러 정책 변경은 애플리케이션 및 관련 인프라 설정이 배포될 때 효력이 발생합니다.
