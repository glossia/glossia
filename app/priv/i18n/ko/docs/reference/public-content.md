Glossia 는 계정 및 프로젝트 애플리케이션 표면과 분리하여 배포된 웹사이트 콘텐츠를 노출합니다.

## 표현

| 인터페이스 | 동작 |
|---|---|
| 배포된 HTML URL | 브라우저 표현으로, canonical 메타데이터와 Markdown 대안 `Link` 응답 헤더를 포함합니다. |
| 그 URL 에서 `Accept: text/markdown`입니다. | 명시적 미디어 유형이 양의 품질을 가지며 `text/html` 보다 선호도가 낮지 않을 때 마크다운 표현입니다. |
| `.md` 에 덧붙인 페이지 URL입니다. | 브라우저 언어 선호도와 독립적인 명시적 마크다운 표현입니다. |
| `/index.md` | 홈페이지의 마크다운 개요입니다. |
| `/docs.md`, `/blog.md`, `/features.md` | 배포된 콘텐츠의 마크다운 인덱스입니다. |
| `/changelog.md` | 하나의 마크다운 문서에 게시된 변경 로그 항목입니다. |
| `/terms.md`, `/privacy.md`, `/cookies.md` | 최신 게시된 법적 문서입니다. 날짜가 포함된 법적 URL 도 `.md`을 지원합니다. |

`*/*` 만으로는 마크다운을 활성화할 수 없습니다. HTML 응답과 마크다운 응답은 `Vary: Accept`를 공유하여 캐시에서 표현이 혼합되지 않습니다.

개별 문서, 블로그, 기능 및 법적 콘텐츠는 렌더된 HTML 의 변환이 아닌 작성된 마크다운을 사용합니다. 인덱스 페이지는 게시된 목록에서 생성되며, 홈페이지는 큐레이션된 마크다운 개요를 가집니다. 대화형 REST 참조는 독자를 브라우저 전용 API 위젯을 삽입하는 대신 OpenAPI 사양으로 안내합니다.

## 언어

영어는 접두사가 없습니다. 번역된 마케팅 URL 은 실제 접두사 `/de`, `/es`, `/fr`, `/ja`, `/ko`, `/pt-br`, 및 `/zh-hans`을 사용합니다. 예를 들어, `/es/docs/tutorials/getting-started.md` 은 발간될 때 스페인 버전을 제공합니다.

URL 은 마크다운 콘텐츠의 언어를 선택합니다. `Accept-Language` 은 마크다운 요청을 리디렉션하지 않습니다. 누락된 콘텐츠 번역은 영어 소식으로 대체됩니다. 홈페이지 개요는 현재 영어로 작성되었습니다.

## 검색

- `/robots.txt` 은 기본적으로 크롤링을 금지하며 제한된 게시 HTML 및 마크다운 목록, 지역별 피드, `/assets/`, `/fonts/`, 및 `/images/` 하위의 렌더링 자산, 사이드바 아이콘 및 `/og/marketing/` 하위의 공개 마케팅 예상을 포함하도록 옵트인합니다. `/og/app/` 하위의 계정 예상 이미지는 여전히 금지됩니다. 이는 협력적인 크롤러를 위한 지침일 뿐 인증 메커니즘이 아닙니다.
- `/sitemap.xml` 은 지역별 대번을 포함한 표준 공공 콘텐츠를 나열하며 마크다운 전용 페이지의 마크다운 URL 을 포함합니다. 변경 로그 조각은 별도의 URL 이 아닙니다.
- `/llms.txt` 은 Glossia 를 소개하고 공개 문서, 기능 가이드 및 최근 글을 포함하며 명시적인 마크다운 링크를 제공합니다.
- `/llms-full.txt` 은 마크다운이 포함된 하나의 텍스트 문서에 홈페이지 개요, 문서 및 마크다운 전용 비교 콘텐츠를 수출합니다.

비교 콘텐츠는 마크다운 전용으로 게시됩니다. 이는 HTML 문서, 탐색, 검색 및 문서 인덱스에 포함되지 않지만 에이전트는 `/llms.txt` 및 site map 을 통해 이를 발견할 수 있습니다. 표준 URL 은 `.md` 로 끝나며, 이전 HTML URL 도 `Accept: text/markdown`에 응답하지만 이제 브라우저 페이지를 렌더링하지 않습니다.

인증, 계정 대시보드, API 및 기타 애플리케이션 응답은 `noindex, nofollow`으로 표시됩니다. 성공적인 게시 콘텐츠는 `index, follow`로 표시됩니다; 오류는 비수색 상태로 유지됩니다. 검색 텍스트 파일 (`/robots.txt`, `/llms.txt`, 및 `/llms-full.txt`) 은 `noindex, follow`을 사용합니다: 독자는 이를 가져오고 링크를 따라갈 수 있지만, 검색 엔진은 표준 페이지 대신 중복 문서 덤프를 인덱싱해서는 안 됩니다.

## 캐싱 및 리소스 사용

마크다운 및 텍스트 검색 응답에는 다음이 포함됩니다:

| 헤더 | 값 또는 의미 |
|---|---|
| `Content-Type` | `text/markdown; charset=utf-8`, 또는 검색 텍스트용 `text/plain; charset=utf-8`입니다. |
| `Cache-Control` | `public, max-age=300, stale-while-revalidate=60`. |
| `ETag` | 표현의 인용된 SHA-256 요약입니다. |
| `X-Markdown-Tokens` | 문자 수의 4 로 나눈 대략적인 추정치, 올림; 모델별 토크나이저 개수가 아닙니다. |

`If-None-Match` 은 강력한 검증자, 약한 검증자, 다중 검증자 및 `*`을 지원합니다. 매칭은 본문 없이 `304`을 반환합니다. `HEAD` 은 본문 없이 표현 헤더를 반환합니다.

게시된 마크다운 목록은 릴리스에 컴파일됩니다. 요청은 콘텐츠 번역 수행, 소스 파일 읽기, 인증된 계정 로딩 또는 LiveView 렌더링을 수행하지 않습니다. 이러한 공개 표현에 액세스하려면 User-Agent 의 저동정을 필수로 하지 않습니다.

## 운영 경계

마크다운 협상 방식은 계정이나 프로젝트 대시보드에 대한 액세스를 제공하지 않습니다. 기존 계정 탐색 속도 제한 및 Turnstile 체크는 별도 보호 메커니즘으로 유지됩니다.

프로덕션 에지 속도 제한은 `GET` 및 `HEAD` 에 모두 적용됩니다. 검증된 크롤러도 여전히 속도 제한을 받습니다. 초과 요청은 브라우저 경고 대신 속도 제한 응답을 받습니다; 독자는 속도를 늦추고 나중에 다시 시도해야 합니다. 공유 캐싱 및 조건부 요청은 클라이언트가 속도 제한에서 제외되는 것을 방지합니다.

레포지토리의 크롤러 정책 변경 사항은 애플리케이션 및 관련 인프라 설정이 배포된 후에만 효과가 있습니다.
