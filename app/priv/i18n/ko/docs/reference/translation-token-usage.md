## 대시보드

열기 **설정 → 모델 → 토큰 사용량** 제공자가 보고한 생성형 번역 사용량을 확인하려면 여기를 클릭하세요. 모델 설정 읽기 권한이 필요합니다.

대시보드는 UTC 기준 오늘 포함 지난 7, 30 또는 90 일의 기간을 지원합니다. 모델, 프로젝트, 언어 필터는 총계, 일별 차트, 세부 정보에 적용됩니다. 검색은 세부 정보 행에만 적용됩니다. 선택한 기간, 차원, 필터, 검색, 정렬 및 페이지는 URL 에 유지됩니다.

## 지표

| 지표 | 의미 |
| --- | --- |
| 입력 토큰 | 제공자가 처리한 입력, 보고된 캐시 읽기 및 캐시 쓰기 포함. |
| 출력 토큰 | 제공자가 보고한 출력, 제공자가 이를 출력 수에 포함할 때 추론 포함. |
| 캐시 입력 토큰 | 캐시 읽기. 입력 토큰의 일부이며 총액에 추가 요금이 아님. |
| 전체 토큰 | 입력 토큰과 출력 토큰의 합. |
| 응답 | 입력 및 출력의 개수와 양수 토큰 합을 갖는 응답. 0 으로 처리된 누락 사용량 폴백은 무시됩니다. |

토큰 수는 금전 비용이 아닙니다. 제공자는 입력, 출력, 캐시 입력, 그리고 캐시 작기에 대해 다른 요금을 부과할 수 있습니다.

각 보고된 응답은 집계되며, 검증 재시도, 품질 교정 재시도, 및 출력 제한 도달로 거부된 응답도 포함됩니다. 모델 호출이 없는 체크포인트 히트와 제외된 파일은 사용량을 추가하지 않습니다. 사용량이 없는 실패한 요청은 집계되지 않습니다.

## 차원

- **프로젝트** 프로젝트별 사용량을 그룹화합니다. 모든 지표의 범위를 단일 프로젝트로 제한하려면 프로젝트 필터를 사용하세요.
- **언어** 목표 로케일별로 그룹화하며, 예를 들어 `es` 또는 `ja`, 현재 범위 내 프로젝트 전반에 걸쳐 있습니다.
- **파일** 소스 경로와 프로젝트를 기준으로 그룹화합니다. 여러 언어로 번역된 동일한 소스 파일은 한 번만 표시됩니다. 다른 프로젝트에 있는 동일한 이름의 파일은 별도로 유지됩니다.

**할당되지 않음** 프로젝트 또는 소스 경로 메타데이터가 없는 요청은 가시적으로 유지됩니다. 저장소 번역은 자동으로 두 가지를 제공합니다. 단일 콘텐츠 API 요청은 제공할 수 있습니다 `project_id` 그리고 `source_path` 출처 표기를 위해; 인증되지 않은 계정이 아닌 프로젝트 ID 는 할당되지 않은 것으로 간주됩니다. 유효하지 않거나 과도한 선택적 메타데이터는 토큰 수를 삭제하지 않고 할당되지 않은 것으로 처리됩니다.

## 범위

사용량은 ReqLLM API 키 및 OAuth 응답, Together 완성 결과 및 완료된 현지 Codex 턴에서 수집됩니다. 오직 공급자가 보고한 수량만이 영구적으로 저장됩니다. 현지 Pi 세션과 결정 모델 평가는 포함되지 않습니다. 과거 번역은 보충되거나 추정되지 않습니다. 따라서 합계는 기록된 사용량을 설명할 뿐 완전한 공급자 청구서가 아닙니다.

내역은 계정, 프로젝트, 모델 식별자 및 핸들, 목표 로케일, 소스 경로, 수량, 및 타임스탬프를 저장합니다. 이 내역은 프롬프트, 번역 콘텐츠, 자격 증명 또는 원본 공급자 응답을 저장하지 않습니다. 사용량 기록 실패는 번역을 중단하지 않고 로깅됩니다.
