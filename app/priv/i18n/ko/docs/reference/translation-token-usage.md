## 대시보드

생성 번역의 제공업체 보고 사용량을 보려면 **설정 → 모델 → 토큰 사용**을 엽니다. 액세스하려면 모델 설정을 읽을 수 있는 권한이 필요합니다.

대시보드는 UTC 기준 오늘의 포함 마지막 7, 30, 또는 90 개의 달력 일을 지원합니다. 모델, 프로젝트, 언어 필터는 총합, 일별 차트 및 세부 항목에 적용됩니다. 검색은 세부 항목 행에만 적용됩니다. 선택한 기간, 차원, 필터, 검색, 정렬 및 페이지는 URL 에서 보존됩니다.

## 계측 항목

| 계측 항목 | 의미 |
| --- | --- |
| 입력 토큰 | 제공업체에서 처리한 입력 값으로, 보고된 캐시 읽기 및 캐시 쓰기를 포함합니다. |
| 출력 토큰 | 제공업체 보고 출력 값으로, 제공업체가 출력 카운트에 포함할 때 추론을 포함합니다. |
| 캐싱된 입력 토큰 | 캐시 읽기. 입력 토큰의 하위 집합으로, 총합에 대한 추가 비용이 아님. |
| 총 토큰 | 입력 토큰과 출력 토큰의 합계. |
| 응답 | 입력과 출력 카운트 및 양수 토큰 합계를 갖는 응답. 사용량 누락 시 0 으로 설정된 대체값은 무시됩니다. |

토큰 수는 금전 비용이 아닙니다. 제공자는 입력, 출력, 캐싱된 입력 및 캐시 쓰기에 대해 상이한 요금을 매길 수 있습니다.

각 보고된 응답이 카운트에 포함되며, 검증 재시도, 품질 수정 재시도 및 출력 한계에 도달하여 거부된 응답이 포함됩니다. 모델 호출이 없는 스킵 파일 및 체크포인트 항목은 추가 사용량을 발생시키지 않습니다. 사용량 없는 실패 요청은 카운트될 수 없습니다.

## 차원

- **프로젝트** 는 프로젝트별로 사용량을 그룹화합니다. 프로젝트 필터를 사용하여 모든 계측 항목을 단일 프로젝트로 범위를 제한합니다.
- **언어** 는 대상 로케일로 그룹화하며, 예를 들어 `es` 또는 `ja`, 현재 범위 내의 모든 프로젝트를 대상으로 합니다.
- **파일** 는 출처 경로와 프로젝트별로 그룹화합니다. 동일한 출처 파일을 여러 언어로 번역하면 한 번만 표시됩니다. 서로 다른 프로젝트에서 동일한 이름의 파일은 분리됩니다.

**할당되지 않음** 은 프로젝트 또는 출처 경로 메타데이터가 없는 요청을 가시적도록 합니다. 저장소 번역은 양쪽을 자동으로 제공합니다. 단일 콘텐츠 API 요청은 귀속성을 위해 `project_id` 및 `source_path` 를 제공할 수 있습니다. 인증된 계정을 포함하지 않는 프로젝트 ID 는 할당되지 않음으로 취급됩니다. 무효하거나 과도한 선택적 메타데이터는 토큰 카운트를 포기하지 않고 할당되지 않습니다.

## 커버리지

사용량은 ReqLLM API 키 및 OAuth 응답, Together 완료, 완료된 현지 Codex 턴에서 수집됩니다. 제공업체 보고 카운터만이 지속됩니다. 로컬 Pi 세션 및 의사결정 모델 평가에는 포함되지 않습니다. 역사적 번역은 백필되거나 추정되지 않습니다. 따라서 합계는 기록된 사용량을 서술하며 완벽한 제공업체 청구서는 아닙니다.

장부에는 계정, 프로젝트, 모델 식별자 및 핸들, 대상 로케일, 출처 경로, 카운트 및 타임스탬프가 저장됩니다. 프롬프트, 번역된 콘텐츠, 자격 증명, 또는 공급업체 응답의 원본은 저장하지 않습니다. 사용량 기록 실패는 번역을 방해하지 않고 기록됩니다.
