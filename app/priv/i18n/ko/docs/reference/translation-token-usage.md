## 대시보드

생성 번역의 제공업체 사용량을 보려면 **설정 → 모델 → 토큰 사용량**을 엽니다. 모델 설정을 읽을 권한이 필요합니다.

대시보드는 UTC 기준 오늘을 포함하는 마지막 7, 30, 또는 90 일 동안의 데이터를 지원합니다. 모델, 프로젝트, 및 언어 필터는 집계, 일별 차트, 및 상세 분석에 적용됩니다. 검색은 상세 analysis 행에만 적용됩니다. 선택된 기간, 차원, 필터, 검색, 정렬, 및 페이지는 URL 에 저장됩니다.

## 메트릭

| 메트릭 | 의미 |
| --- | --- |
| 입력 토큰 | 제공업체에 의해 처리된 입력, 보고된 캐시 읽기 및 캐시 작성 포함. |
| 출력 토큰 | 제공업체 보고 출력, 제공업체가 이를 자체 출력 수에 포함하는 경우 추론 포함. |
| 캐시된 입력 토큰 | 캐시 읽기. 입력 토큰의 하위 집합이며 전체 비용에 추가 요금이 부과되지 않습니다. |
| 총 토큰 | 입력 토큰 및 출력 토큰의 합. |
| 응답 | 입력 및 출력 수와 양의 토큰 합을 모두 가진 응답. 제로화된 사용량 누락 폴백은 무시됩니다. |

토큰 수는 금전 비용이 아닙니다. 제공업체는 입력, 출력, 캐시 입력, 및 캐시 작성을 위한 다른 비율을 부과할 수 있습니다.

보고된 각 응답은 포함됩니다: 검증 재시도, 품질 수정 재시도, 및 출력 제한 도달로 거부된 응답. 모델 호출하지 않은 스킵 파일 및 체크포인트 히트는 사용량을 늘리지 않습니다. 사용량이 없는 실패된 요청은 포함되지 않습니다.

## 차원

- **프로젝트** 는 프로젝트별로 사용량을 그룹화합니다. 모든 메트릭의 범위를 하나의 프로젝트로 제한하려면 프로젝트 필터를 사용하세요.
- **언어** 는 현재 범위 내의 프로젝트간 대상 로케일, 예를 들어 `es` 또는 `ja`, 을 기준으로 그룹화합니다.
- **파일** 는 소스 경로와 프로젝트를 기준으로 그룹화합니다. 여러 언어로 번역된 동일한 소스 파일은 한 번만 표시되며, 다른 프로젝트에 있는 동일 이름 파일은 별개로 유지됩니다.

**지정되지 않음** 은 프로젝트 또는 소스 경로 메타데이터가 없는 요청을 가시적으로 유지합니다. 저장소 번역은 이를 자동으로 제공합니다. 단일 콘텐츠 API 요청은 귀속하려면 `project_id` 및 `source_path` 를 제공할 수 있습니다. 인증된 계정 밖의 프로젝트 ID 는 지정되지 않은 것으로 간주됩니다. 유효하지 않거나 과도한 선택적 메타데이터는 토큰 수를 제외하지 않은 채 지정되지 않은 것으로 간주됩니다.

## 범위

사용량은 ReqLLM API 키 및 OAuth 응답, Together 완료, 및 완료된 로컬 Codex 회에서 수집됩니다.只有 제공업체 보고된 숫자만 저장됩니다. 로컬 Pi 세션 및 결정 모델 평가는 포함되지 않습니다. 역사적 번역은 보충되거나 추정되지 않습니다. 따라서 총계는 기록된 사용량을 묘사하며, 전체 제공업체 송장에 해당하지 않습니다.

대장은 계정, 프로젝트, 모델 식별자 및 핸들, 대상 로케일, 소스 경로, 집계 수, 및 타임스탬프를 저장합니다. 프롬프트, 번역된 콘텐츠, 자격 증명, 또는 원시 제공업체 응답은 저장하지 않습니다. 사용량 기록 실패는 번역을 중단하지 않고 기록됩니다.
