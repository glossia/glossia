## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션에서 OAuth 제공자 구성을 선택적으로 만듭니다. GitHub/GitLab OAuth 자격 증수를 설정하지 않아도 앱이 시작되어야 합니다. 환경 변수가 있을 때만 제공자를 구성해야 합니다.
- 프로덕션 기본 포트를 4000 으로 설정하고 개발 환경은 4050 으로 유지하세요. 프로덕션 프록시는 앱이 포트 4000 에서 실행되기를 기대합니다. 그 `runtime.exs` 기본값은 4050 이었고, 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인을 포함한 Phoenix 앱 추가, 문서 및 UI 개선.
- 둠근 로고를 favicon 으로 사용합니다.
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드를 업데이트합니다.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 가로 넘침 방지합니다.
- 모바일에서 코드 스니펫에 올바른 오른쪽 여백 추가.
- 수평 넘침을 방지하기 위해 모바일 반응형 레이아웃 개선.
- Biome 포맷 적용.
- 릴리스 노트 템플릿에 그룹 제목 추가.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트.
- 게시글 본문을 히어로 레이아웃과 정렬하고 블로그 게시물 콘텐츠 개선.
- 블로그 게시글 내용을 수평으로 중앙 정렬.
- 멀티 바이트 UTF-8 도구 결과를 잘라낼 때 발생하는 panic 문제 수정.

#### 기능

- 제 1 사 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 제공.
- 진행 출력 단순화.
- 진행 라인 색감 적용.
- 번역 및 검증 활동 표시.
- 도구 라인 서식 지정.
- 모바일 메뉴 및 다중 브레이크포인트 레이아웃을 갖춘 웹사이트 반응형 지원.
- Bun/TypeScript 로 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 로 포맷 확인 추가.
- 홈페이지에 점진적 개선 섹션 추가.
- SEO 지원과 첫 블로그 포스트를 포함한 블로그 섹션 추가.
- 오른쪽 정렬 동사 형식으로 CLI 출력 통일.
- 더 풍부한 메시지 포맷팅으로 CLI 출력을 색상 처리.
- 정사각형 OG 이미지와 트위터 카드 메타 태그 추가.
- 도구 사용을 활용하여 coordinator 에이전트를 에이전틱(Agentic) 으로 만듭니다.
- 재작성 `glossia init` Agent 클라이언트 프로토콜 (ACP)을 사용하여.
- Gemini 지원, 자동 유효성 검사, 토큰 추적, 및 신뢰성 개선 추가.

#### 리팩토링

- CI 를 포맷, 타입검사, 테스트, 빌드 작업으로 분리합니다.
- CLI 를 TypeScript/Bun 에서 Rust 로 재작성합니다.
