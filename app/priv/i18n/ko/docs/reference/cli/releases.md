## 0.1.0

*2026-02-12*

#### 버그 수정
- 모바일 환경에서 코드 스니펫의 가로 오버플로우 방지.
- 모바일 환경에서 코드 스니펫에 올바른 오른쪽 여백 추가.
- 가로 오버플로우 방지를 위해 모바일 반응형 레이아웃 개선.
- Biome 포맷 적용.
- 릴리스 노트 템플릿에 그룹 제목 추가.
- 번역 워크플로우를 Bun 에서 Rust 로 변경합니다.
- 블로그 게시물 본문을 헤로 레이아웃과 정렬하고 블로그 게시물 내용 개선.
- 블로그 게시물 내용을 가로 중앙 정렬.
- 여러 바이트 UTF-8 도구 결과를 잘라낼 때 발생하는 panic 수정.

#### 기능
- 제 1 차 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 상황 출력 단순화.
- 진행 라인에 색상을 입힙니다.
- 번역 및 검증 중인 활동 표시.
- 도구 라인 포맷.
- 모바일 메뉴 및 멀티 브렉포인트 레이아웃을 갖춘 반응형 웹사이트 구현.
- Bun/TypeScript 로 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 를 사용한 포맷 검사 추가.
- 홈페이지에 Progressive Refinement 섹션 추가.
- SEO 지원 및 첫 번째 블로그 게시물 포함 블로그 섹션 추가.
- CLI 출력을 오른쪽 정렬된 동사 형식으로 통일합니다.
- 더 풍부한 메시지 포맷으로 CLI 출력 색상화.
- 정방형 OG 이미지 및 Twitter 카드 메타 태그 추가.
- 도구 사용을 통해 조율자 에이전트를 강화합니다.
- Agent Client Protocol (ACP) 로 `glossia init` 재작성합니다.
- Gemini 지원, 자동 검증, 토큰 추적 및 신뢰성 개선을 추가합니다.

#### 리팩터링
- CI 를 포맷, 타입 체크, 테스트, 빌드 작업별로 분리합니다.
- TypeScript/Bun 에서 Rust 로 CLI 를 재작성합니다.
