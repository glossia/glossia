## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 제공자 구성을 선택적으로 만듭니다. GitHub/GitLab OAuth 인증 자격 증명이 설정되어 있지 않아도 앱이 정상 부팅됩니다. 환경 변수가 존재할 때만 제공자를 구성합니다.
- 프로덕션 포트 기본값을 4000 으로 설정하고 개발 포트는 4050 으로 유지합니다. 프로덕션 프록시는 앱이 포트 4000 에서 실행되기를 예상합니다. 이 `runtime.exs` 기본값은 4050 이었으며 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인을 지원하는 Phoenix 앱 추가, 문서 개선 및 UI 향상.
- 둥근 로고를 fav 아이콘으로 사용.
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드 업데이트.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 가로 오버플로우 방지.
- 모바일 코드 스니펫에 적절한 오른쪽 여백 추가.
- 가로 오버플로우를 방지하기 위해 모바일 반응형 레이아웃 개선.
- biome 포맷팅 적용.
- 릴리스 노트 템플릿에 그룹 제목 추가.
- Bun 에서 Rust 로 번역 워크플로우 업데이트.
- 게시글 본문을 히어로 레이아웃과 정렬하고 블로그 글 내용 개선.
- 블로그 글 내용을 가로 중앙으로 정렬.
- 멀티바이트 UTF-8 도구 결과 잘라낼 때 panic 수정.

#### 기능

- 자체 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 상황 단순화.
- 진행 상태 줄 색상 지정.
- 번역 및 검증 작업 표시.
- 도구 줄 포맷.
- 모바일 메뉴와 다중 브레이크 포인트 레이아웃을 통한 반응형 웹사이트.
- CLI 를 Bun/TypeScript 로 재구현합니다.
- CI 워크플로우 및 테스트를 추가합니다.
- Biome 을 활용한 포맷 검사를 추가합니다.
- 홈페이지에 점진적 정교화 섹션을 추가합니다.
- SEO 지원 및 첫 번째 블로그 포스트를 포함한 블로그 섹션을 추가합니다.
- CLI 출력을 오른쪽 정렬 동사 형식으로 통일합니다.
- CLI 출력을 더 풍부한 메시지 형식으로 색상화합니다.
- 사각형 OG 이미지 및 트위터 카드 메타 태그를 추가합니다.
- 도구를 사용하여 조정 에이전트를 에이전트처럼 작동하게 합니다.
- 재작성 `glossia init` 에이전트 클라이언트 프로토콜 (ACP) 을 기반으로 합니다.
- Gemini 지원, 자동 유효성 검사, 토큰 추적 및 안정성 개선 추가.

#### 리팩토링

- CI 를 포맷, 타입 체크, 테스트, 빌드 작업으로 분리.
- CLI 를 TypeScript/Bun 에서 Rust 로 재작성.
