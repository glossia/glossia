## 0.2.0

*2026-02-14*

#### 버그 수정
- 프로덕션에서 OAuth 공급자 구성을 선택 사항으로 변경했습니다. GitHub/GitLab OAuth 자격 증명이 설정되지 않아도 앱이 시작됩니다. 환경 변수가 있는 경우에만 공급자를 구성합니다.
- 프로덕션 기본 포트를 4000으로 설정하고 개발 환경에서는 4050을 유지했습니다. 프로덕션 프록시는 앱이 포트 4000에서 실행될 것으로 예상합니다. `runtime.exs`의 기본값은 4050이었으며, 이로 인해 배포 중 상태 검사가 실패했습니다.

#### 기능
- OAuth 로그인, 문서 개선 사항, 사용자 인터페이스 개선 사항을 포함한 Phoenix 앱을 추가했습니다.
- 둥근 로고를 파비콘으로 사용했습니다.
- 명령줄 인터페이스를 Bun으로 마이그레이션하고 지속적 통합 실행 파일 빌드를 업데이트했습니다.

## 0.1.0

*2026-02-12*

#### 버그 수정
- 모바일에서 코드 조각이 가로로 넘치지 않도록 수정했습니다.
- 모바일의 코드 조각에 적절한 오른쪽 여백을 추가했습니다.
- 가로 넘침을 방지하도록 모바일 반응형 레이아웃을 개선했습니다.
- Biome 서식을 적용했습니다.
- 릴리스 노트 템플릿에 그룹 제목을 추가했습니다.
- 번역 워크플로를 Bun에서 Rust로 변경했습니다.
- 게시물 본문을 히어로 레이아웃에 맞추고 블로그 게시물 콘텐츠를 개선했습니다.
- 블로그 게시물 콘텐츠를 가로 방향 중앙에 배치했습니다.
- 다중 바이트 UTF-8 도구 결과를 자를 때 발생하는 패닉을 수정했습니다.

#### 기능
- 자사 도구 및 웹사이트 섹션을 추가했습니다.
- 도구 검증 단계를 표시했습니다.
- 진행 상황 출력을 간소화했습니다.
- 진행 상황 줄에 색조를 적용했습니다.
- 번역 및 검증 활동을 표시했습니다.
- 도구 출력 줄의 형식을 지정했습니다.
- 모바일 메뉴와 여러 중단점 레이아웃을 적용해 웹사이트가 반응형으로 동작하도록 개선했습니다.
- 명령줄 인터페이스를 Bun/TypeScript로 다시 구현했습니다.
- 지속적 통합 워크플로와 테스트를 추가했습니다.
- Biome을 사용한 서식 검사를 추가했습니다.
- 홈페이지에 점진적 개선 섹션을 추가했습니다.
- 검색 엔진 최적화 지원과 첫 번째 블로그 게시물을 포함한 블로그 섹션을 추가했습니다.
- 명령줄 인터페이스 출력을 동사가 오른쪽 정렬되는 형식으로 통일했습니다.
- 더 풍부한 메시지 서식을 적용해 명령줄 인터페이스 출력에 색상을 추가했습니다.
- 정사각형 Open Graph 이미지와 Twitter 카드 메타 태그를 추가했습니다.
- 코디네이터 에이전트가 도구를 사용해 자율적으로 작업하도록 개선했습니다.
- `glossia init`을 에이전트 클라이언트 프로토콜(ACP)로 다시 작성했습니다.
- Gemini 지원, 자동 검증, 토큰 추적, 안정성 개선 사항을 추가했습니다.

#### 리팩터링
- 지속적 통합을 서식, 유형 검사, 테스트, 빌드 작업으로 분리했습니다.
- 명령줄 인터페이스를 TypeScript/Bun에서 Rust로 다시 작성했습니다.
