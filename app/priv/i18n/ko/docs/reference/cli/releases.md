## 0.1.0

*2026-02-12*

#### 버그 수정
- 모바일에서 코드 스니펫 수평 오버플로우를 방지합니다.
- 모바일에서 코드 스니펫에 적절한 오른쪽 여백을 추가합니다.
- 수평 오버플로우 발생을 막기 위해 모바일 반응형 레이아웃을 개선합니다.
- Biome 포맷 적용합니다.
- 릴리스 노트 템플릿에 그룹 제목을 추가합니다.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트합니다.
- 히어로 레이아웃과 포스트 본문 정렬 및 블로그 게시물 콘텐츠를 개선합니다.
- 블로그 게시물 콘텐츠를 가로 중앙 정렬합니다.
- 여러 바이트 UTF-8 도구 결과를 자르는 과정에서 발생하는 Panic 오류를 수정합니다.

#### 기능
- 일차적 도구 및 웹 사이트 섹션을 추가합니다.
- 도구 검증 단계를 표출합니다.
- 진행 상황 출력을 단순화합니다.
- 진행 상황 줄에 색상을 입힙니다.
- 번역 및 검증 중인 활동을 표시합니다.
- 도구 줄 포맷을 적용합니다.
- 모바일 메뉴와 여러 단점 레이아웃으로 웹 사이트를 반응형으로 만듭니다.
- Bun/TypeScript 에서 CLI 를 재구현합니다.
- CI 워크플로우 및 테스트를 추가합니다.
- Biome 를 활용한 포맷 검사를 추가합니다.
- 홈페이지에 점진적 개선 섹션을 추가합니다.
- SEO 지원 및 첫 번째 블로그 게시물을 포함한 블로그 섹션을 추가합니다.
- 오른쪽 정렬 동사 형식을 통합하여 CLI 출력을 통일합니다.
- 풍부한 메시지 포맷으로 CLI 출력을 색상화합니다.
- 사각형 OG 이미지 및 twitter 카드 메타 태그를 추가합니다.
- 도구 사용 방식으로 조정자 에이전트를 에이전틱하게 만듭니다.
- Agent Client Protocol (ACP) 을 사용하여 `glossia init` 를 다시 작성합니다.
- Gemini 지원, 자동 검증, 토큰 추적 및 신뢰성 개선을 추가합니다.

#### 리팩토링
- CI 를 별도 포맷, 타입 검사, 테스트, 빌드 작업으로 분리합니다.
- TypeScript/Bun 에서 Rust 로 CLI 를 다시 작성합니다.
