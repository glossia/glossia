## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 공급자 구성을 선택 사항으로 만듭니다. GitHub/GitLab OAuth 자격 증명이 설정되어 있지 않아도 앱이 시작됩니다. 환경 변수가 설정되어 있을 때에만 공급자를 구성하십시오.
- 프로덕션은 포트 4000 으로 기본값 설정하고 개발은 포트 4050 으로 유지합니다. 프로덕션 프록시는 포트 4000 에서 앱 실행을 기대합니다. 그 `runtime.exs` 기본값은 4050 이었으며, 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인, 문서 개선 및 UI 개선이 포함된 Phoenix 앱 추가.
- 둥근 로고를 favicon 으로 사용.
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드 업데이트.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫의 수평 오버플로우 방지.
- 모바일에서 코드 스니펫에 올바른 오른쪽 여백을 추가합니다.
- 수평 오버플로우를 방지하기 위해 모바일 반응형 레이아웃을 개선합니다.
- biome 포맷 적용합니다.
- 릴리스 노트 템플릿에 그룹 헤더를 추가합니다.
- Bun 에서 Rust 로 번역 워크플로우를 업데이트합니다.
- 게시글 본문을 히어로 레이아웃과 정렬하고 블로그 게시물 콘텐츠를 개선합니다.
- 블로그 게시물 콘텐츠를 수평 중앙에 정렬합니다.
- 다중 바이트 UTF-8 도구 결과를 잘라낼 때 panic 을 수정합니다.

#### 기능

- 자사 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 상태 출력 간소화.
- 진행 라인 색상 설정.
- 번역 및 검증 중인 작업 표시.
- 도구 라인 형식 지정.
- 모바일 메뉴 및 다중 브레이크포인트 레이아웃으로 웹사이트 반응형 구축.
- Bun/TypeScript 로 CLI 를 재구현합니다.
- CI 워크플로우와 테스트를 추가합니다.
- Biome 를 활용한 형식 확인을 추가합니다.
- 홈페이지에 점진적 개선 섹션을 추가합니다.
- SEO 지원 및 첫 블로그 게시물을 포함한 블로그 섹션을 추가합니다.
- 오른쪽 정렬된 동사 포맷으로 CLI 출력을 통일합니다.
- 더 풍부한 메시지 포맷팅으로 CLI 출력을 색상 처리합니다.
- 정사각형 OG 이미지와 Twitter 카드 메타 태그를 추가합니다.
- 도구 사용을 통해 조정 에이전트를 에이전틱하게 만듭니다.
- 재작성 `glossia init` Agent Client Protocol (ACP) 를 통해.
- Gemini 지원, 자동 검증, 토큰 추적 및 안정성 개선 추가.

#### 리팩터링

- CI 를 포맷, 타입 체킹, 테스트, 빌드 작업으로 분리.
- TypeScript/Bun 에서 Rust 로 CLI 재작성.
