## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 제공자 설정은 선택 사항으로 만듭니다. GitHub/GitLab OAuth 인증 정보가 설정되지 않았더라도 앱은 정상적으로 시작되도록 합니다. 환경 변수가 있을 때만 제공자를 구성하세요.
- 프로덕션 환경에서는 기본 포트 4000 을 사용하고, 개발 환경에서는 4050 을 유지하세요. 프로덕션 프록시는 앱이 4000 포트에서 실행됨을 기대합니다. 그 `runtime.exs` 기본값이 4050 으로 설정되어 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인, 문서 및 UI 개선을 포함한 Phoenix 앱 추가.
- 둥근 로고를 파비콘으로 사용.
- CLI 를 Bun 으로 마이그레이션 및 CI 실행 파일 빌드 업데이트.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 가로 넘침 방지.
- 모바일에서 코드 스니펫에 올바른 오른쪽 여백 추가.
- 가로 오버플로우를 방지하기 위해 모바일 반응형 레이아웃 개선.
- biome 포맷 적용.
- 릴리스 노트 템플릿에 그룹 제목 추가.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트.
- 게시물 본문을 히어로 레이아웃과 정렬하고 블로그 게시물 내용 개선.
- 블로그 게시물 내용을 수평으로 중앙 정렬.
- 멀티바이트 UTF-8 도구 결과를 잘라낼 때 발생하는 패닉 수정.

#### 기능

- 제 1 차 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 상태 출력 간소화.
- 진행 라인 색상 처리.
- 번역 및 검증 활동 표시.
- 도구 라인 포맷팅.
- 모바일 메뉴 및 다중 브레이크포인트 레이아웃 기반 웹 사이트 반응형 구현.
- CLI 를 Bun/TypeScript 로 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 를 활용한 포맷 검증 추가.
- 홈페이지에 Progressive Refinement 섹션 추가.
- SEO 지원 및 첫 번째 블로그 게시물을 포함한 블로그 섹션 추가.
- CLI 출력을 우측 정렬 형식으로 통일.
- 더 풍부한 메시지 포맷팅을 적용하여 CLI 출력 색상화.
- 정사각형 OG 이미지 및 Twitter 카드 메타 태그 추가.
- 도구 사용을 통해 조정 에이전트를 에이전티브하게 만듭니다.
- 재작성 `glossia init` Agent Client Protocol (ACP) 를 통해.
- Gemini 지원, 자동 유효성 검사, 토큰 추적 및 안정성 개선 기능을 추가합니다.

#### 리팩터링

- CI 를 별도 포맷, 타입 체크, 테스트, 빌드 작업으로 분리합니다.
- CLI 를 TypeScript/Bun 에서 Rust 로 다시 작성합니다.
