## 0.1.0

*2026-02-12*

#### 버그 수정
- 모바일에서 코드 구문 수평 오버플로우 방지.
- 모바일에서 코드 구문에 적절한 오른쪽 여백 추가.
- 모바일 반응형 레이아웃 개선으로 수평 오버플로우 방지.
- Biome 포맷 적용.
- 릴리스 노트 템플릿에 그룹 헤더 추가.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트.
- 포스트 본문을 Hero 레이아웃과 정렬하고 블로그 내용 개선.
- 블로그 포스트 내용을 수평 중앙 정렬.
- 다중 바이트 UTF-8 도구 결과 절단 시 발생 가능한 Panic 수정.

#### 기능 추가
- 제 1 차 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 상황 출력 단순화.
- 진행 라인 색상 부여.
- 번역 및 검증 활동 표시.
- 도구 라인 포맷.
- 모바일 메뉴와 다중 Breakpoint 레이아웃으로 웹사이트 반응형 만들기.
- Bun/TypeScript 에서 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 로 포맷 확인 추가.
- 홈페이지에 점진적 다듬기 섹션 추가.
- SEO 지원 및 첫 블로그 포스트를 다룬 블로그 섹션 추가.
- CLI 출력을 오른쪽 정렬 동사 형식으로 통일.
- CLI 출력을 더 풍부한 메시지 포맷팅으로 색상화.
- 사각형 OG 이미지 및 Twitter 카드 메타 태그 추가.
- 도구 사용을 활용한 조정자 에이전트의 에이전트적 기능 강화.
- Agent Client Protocol (ACP) 를 사용하여 `glossia init` 재작성.
- Gemini 지원, 자동 검증, 토큰 추적 및 신뢰성 개선 추가.

#### 리팩토링
- CI 를 포맷, 타입 체크, 테스트, 빌드 작업으로 분할.
- CLI 를 TypeScript/Bun 에서 Rust 로 재작성.
