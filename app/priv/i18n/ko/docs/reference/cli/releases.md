## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경의 OAuth 공급자 구성을 선택 가능하게 합니다. GitHub/GitLab OAuth 인증정보가 설정되어 있지 않아도 앱은 부팅됩니다. 환경 변수가 있을 때만 공급자를 구성합니다.
- 프로덕션 환경의 기본 포트는 4000 으로 하고, 개발 환경은 4050 으로 유지합니다. 프로덕션 프록시는 앱이 4000 포트에서 실행되기를 기대합니다. 그 `runtime.exs` 기본값은 4050 으로 되어 있었으며, 이는 배포 중 헬스 체크 실패를 유발했습니다.

#### 기능

- OAuth 로그인을 지원한 Phoenix 애플리케이션 추가, 문서 및 UI 개선 사항
- 둥근 로고를 favicon 로 변경
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드 업데이트

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일 환경에서 코드 스니펫 수평 오버플로우 방지
- 모바일에서 코드 스니펫에 적절한 오른쪽 여백을 추가합니다.
- 가로 넘침을 방지하기 위해 모바일 반응형 레이아웃을 개선합니다.
- biome 포맷 적용.
- 릴리스 노트 템플릿에 그룹 제목을 추가합니다.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트합니다.
- 게시물 본문을 히어로 레이아웃과 정렬하고 블로그 게시물 콘텐츠를 개선합니다.
- 블로그 게시물 콘텐츠를 수평으로 중앙 정렬합니다.
- 멀티바이트 UTF-8 툴 결과 절단 시 발생하는 panic 을 수정합니다.

#### 기능

- 웹사이트 섹션과 제 1 차 도구를 추가합니다.
- 도구 검증 단계를 표시합니다.
- 진행 결과 출력을 단순화합니다.
- 진행 라인 색조 처리합니다.
- 번역 및 검증 활동을 표시합니다.
- 도구 라인 서식화합니다.
- 모바일 메뉴와 다중 브레이크포인트 레이아웃을 갖춘 반응형 웹사이트로 만듭니다.
- Bun/TypeScript 로 CLI 재구현.
- CI 워크플로우와 테스트 추가.
- Biome 를 활용한 형식 검사 추가.
- 홈페이지에 점진적 개선 섹션 추가.
- SEO 지원과 첫 번째 블로그 포스트를 포함한 블로그 섹션 추가.
- CLI 출력을 우 정렬 동사 형식으로 통합.
- CLI 출력을 더 풍부한 메시지 포맷팅과 함께 색상 처리.
- 정사각형 OG 이미지와 트위터 카드 메타 태그 추가.
- 도구를 사용하여 조정 에이전트를 에이전틱하게 만듦.
- 재작성 `glossia init` Agent Client Protocol (ACP) 을 기반으로.
- 지미니 지원, 자동 유효성 검사, 토큰 추적 및 신뢰성 개선 추가

#### 리팩토링

- CI 를 별도의 포맷, 타입체크, 테스트, 빌드 작업으로 분할
- TypeScript/Bun CLI 를 Rust 로 재작성
