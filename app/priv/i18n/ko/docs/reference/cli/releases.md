## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 수평 오버플로우 방지.
- 모바일에서 코드 스니펫에 올바른 오른쪽 여백 추가.
- 모바일 반응형 레이아웃을 개선하여 가로 오버플로우를 방지합니다.
- Biome 포맷 적용합니다.
- 릴리스 노트 템플릿에 그룹 제목을 추가합니다.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트합니다.
- 게시글 바디를 히어로 레이아웃과 정렬하고 게시글 내용을 개선합니다.
- 게시글 내용을 수평으로 중앙 정렬합니다.
- 다바이트 UTF-8 도구 결과 절단 시 발생하는 패닉을 수정합니다.

#### 기능

- 제 1 파티 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표출.
- 진행 출력 단순화.
- 진행 라인 색상 적용.
- 번역 및 검증 활동 표시.
- 도구 줄 정렬.
- 모바일 메뉴 및 다중 브레이크포인트 레이아웃으로 웹사이트 반응형 구현.
- Bun/TypeScript 기반 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 를 사용한 포맷 체크 추가.
- 홈페이지 점진적 정제 섹션 추가.
- SEO 지원 및 첫 블로그 포스트를 포함한 블로그 섹션 추가.
- CLI 출력을 오른쪽 정렬 동사 형식으로 통일.
- 더 풍부한 메시지 형식으로 CLI 출력 컬러화.
- 정사각형 OG 이미지 및 트위터 카드 메타 태그 추가.
- 도구 사용을 통해 코디네이터 에이전트를 에이제닉으로 만듦.
- 재작성 `glossia init` Agent Client Protocol (ACP)로.
- Gemini 지원, 자동 유효성 검사, 토큰 추적 및 신뢰성 개선 추가.

#### 리팩토링

- CI 를 별도의 format, typecheck, test, build 작업으로 분리.
- TypeScript/Bun 에서 CLI 를 Rust 로 재작성.
