## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 제공자 구성을 선택 사항으로 만듭니다. GitHub/GitLab OAuth 자격 증명 설정 없이도 애플리케이션이 실행됩니다. 환경 변수가 존재할 때만 제공자를 구성합니다.
- 프로덕션 환경의 기본 포트는 4000 으로, 개발 환경은 4050 으로 유지됩니다. 프로덕션 프록시는 애플리케이션이 4000 포트에서 실행됨을 예상합니다. 이 `runtime.exs` 기본값은 4050 이었으며, 이는 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인, 문서 개선 및 UI 개선이 포함된 Phoenix 앱 추가.
- 둥근 로고를 favicon 으로 사용합니다.
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 파일 빌드를 업데이트합니다.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫의 수평 오버플로우 방지.
- 모바일 환경에서 코드 스니펫에 올바른 오른쪽 여백 추가
- 가로 오버플로우를 방지하기 위한 모바일 반응형 레이아웃 개선
- biome 포맷 적용
- 릴리스 노트 템플릿에 그룹 제목 추가
- 번역 워크플로우를 Bun 에서 Rust 로 변경
- 게시글 본문을 히어로 레이아웃과 정렬하고 블로그 게시글 콘텐츠 개선
- 블로그 게시물 내용을 수평으로 중앙 정렬
- 다바이트 UTF-8 도구 결과를 잘라낼 때 발생하는 패닉 수정

#### 기능

- 제 1 파티 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표시.
- 진행 출력 단순화.
- 진행 라인 색상 적용.
- 번역 및 검증 작업 표시.
- 도구 라인 서식 지정.
- 모바일 메뉴와 다중 브레이크포인트 레이아웃을 갖춘 반응형 웹사이트 구현.
- Bun/TypeScript 로 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 으로 포맷 확인 추가.
- 홈페이지에 점진적 개선 섹션 추가.
- SEO 지원 및 첫 번째 블로그 게시글을 포함한 블로그 섹션 추가.
- 오른쪽 정렬 동사 형식으로 CLI 출력 통일.
- 더 풍부한 메시지 포맷팅으로 CLI 출력 색상 추가.
- 정사각형 OG 이미지 및 트위터 카드 메타 태그 추가.
- 도구 사용을 통해 코디네이터 에이전트의 에이전트적(agentic) 기능 구현합니다.
- 재작성 `glossia init` Agent Client Protocol (ACP) 를 활용하여.
- Gemini 지원, 자동 검증, 토큰 추적 및 신뢰성 개선 추가합니다.

#### 리팩토링

- CI 를 format, typecheck, test, build 개별 작업으로 분할합니다.
- CLI 를 TypeScript/Bun 에서 Rust 로 재작성합니다.
