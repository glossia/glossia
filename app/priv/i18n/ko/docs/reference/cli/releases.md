## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 공급자 구성을 선택 사항으로 설정합니다. GitHub/GitLab OAuth 자격 증명이 설정되어 있지 않아도 앱은 부팅됩니다. 환경 변수가 존재할 때만 제공자를 구성합니다.
- 프로덕션 기본 포트는 4000 으로 설정하고 개발 환경은 4050 으로 유지합니다. 프로덕션 프록시는 앱이 4000 포트에서 실행되길 기대합니다. 기존 `runtime.exs` 기본값은 4050 으로 되어 있어 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인을 지원한 Phoenix 앱 추가, 문서 및 UI 개선.
- 둥근 로고를 favicon 으로 사용.
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드 업데이트.

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 수평 오버플로우 방지.
- 모바일에서 코드 스니펫에 적절한 오른쪽 여백을 추가합니다.
- 가로 오버플로우를 방지하기 위해 모바일 반응형 레이아웃을 개선합니다.
- Biome 포맷팅을 적용합니다.
- 릴리스 노트 템플릿에 그룹 헤딩을 추가합니다.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트합니다.
- 게시글 본문을 히어로 레이아웃과 정렬하고 블로그 게시물 콘텐츠를 개선합니다.
- 블로그 게시물 콘텐츠를 가로로 중앙 정렬합니다.
- 다바이트 UTF-8 툴 결과를 잘라낼 때 발생하는 패닉을 수정합니다.

#### 기능

- 일정 당사 도구 및 웹사이트 섹션 추가.
- 도구 검증 단계 표출.
- 진행 상황 출력 간소화.
- 진행 줄 색상 적용.
- 번역 및 검증 활동 표시.
- 도구 줄 형식 지정.
- 모바일 메뉴와 다중 브레크포인트 레이아웃으로 웹사이트 반응형으로 전환.
- Bun/TypeScript 로 CLI 를 재구현합니다.
- CI 워크플로우 및 테스트를 추가합니다.
- Biome 를 활용한 포맷 검사를 추가합니다.
- 홈페이지에 점진적 개선 섹션을 추가합니다.
- SEO 지원 및 첫 번째 블로그 게시물을 포함한 블로그 섹션을 추가합니다.
- 오른쪽 정렬 동사 형식과 CLI 출력을 통합합니다.
- 더 풍부한 메시지 포맷팅으로 CLI 출력에 색상을 적용합니다.
- 정사각형 OG 이미지 및 트위터 카드 메타 태그를 추가합니다.
- 도구 사용을 활용한 조정 에이전트를 개체화합니다.
- 재작성 `glossia init` Agent Client Protocol (ACP) 을 사용하여.
- Gemini 지원, 자동 검증, 토큰 추적 및 신뢰성 개선을 추가합니다.

#### 리팩토링

- CI 를 포맷, 타입 체크, 테스트, 빌드 작업으로 분리합니다.
- CLI 를 TypeScript/Bun 에서 Rust 로 재작성합니다.
