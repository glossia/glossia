## 0.2.0

*2026-02-14*

#### 버그 수정

- 프로덕션 환경에서 OAuth 제공자 설정은 선택 사항입니다. GitHub/GitLab OAuth 자격 증명 설정 없이도 앱은 시작됩니다. 환경 변수가 설정되어 있을 때에만 제공자를 구성합니다.
- 프로덕션 기본 포트 4000 으로, 개발 4050 으로 유지합니다. 프로덕션 프록시는 앱이 포트 4000 에서 실행됨을 기대합니다. 그 `runtime.exs` 기본값은 4050 으로 되어 배포 중 헬스 체크가 실패했습니다.

#### 기능

- OAuth 로그인을 지원한 Phoenix 앱 추가, 문서 개선 및 UI 개선
- 둥근 로고를 favicon 으로 사용
- CLI 를 Bun 으로 마이그레이션하고 CI 실행 빌드 업데이트

## 0.1.0

*2026-02-12*

#### 버그 수정

- 모바일에서 코드 스니펫 가로 오버플로우 방지
- 모바일 환경에서 코드 스니펫에 적절한 오른쪽 여백을 추가합니다.
- 가로 오버플로우를 방지하기 위해 모바일 반응형 레이아웃을 개선합니다.
- biome 포맷을 적용합니다.
- 출시 노트 템플릿에 그룹 제목을 추가합니다.
- 번역 워크플로우를 Bun 에서 Rust 로 업데이트합니다.
- 게시글 본문을 Hero 레이아웃과 정렬하고 블로그 콘텐츠를 개선합니다.
- 블로그 게시글 내용을 수평으로 중앙 정렬합니다.
- 다바이트 UTF-8 도구 결과 잘라낼 때 발생하는 panic 오류를 수정합니다.

#### 기능

- 제 1 차 도구 및 웹사이트 섹션 추가
- 도구 검증 단계 강조
- 진행 출력 단순화
- 진행 라인 색상 조정
- 번역 및 검증 활동 표시
- 도구 라인 형식화
- 모바일 메뉴 및 다중 브레이크포인트 레이아웃을 포함한 반응형 웹사이트 구현
- Bun/TypeScript 로 CLI 재구현.
- CI 워크플로우 및 테스트 추가.
- Biome 를 사용한 형식 검사 추가.
- 홈페이지에 점진적 개선 섹션 추가.
- SEO 지원과 첫 번째 블로그 포스트가 포함된 블로그 섹션 추가.
- CLI 출력을 우측 정렬 동사 형식으로 통일.
- 더 풍부한 메시지 포맷팅과 함께 CLI 출력 색상화.
- 정사각형 OG 이미지 및 트위터 카드 메타 태그 추가.
- 도구를 사용하는 조정자 에이전트로 구현.
- 재작성 `glossia init` Agent Client Protocol (ACP) 을 기반으로.
- Gemini 지원, 자동 유효성 검사, 토큰 추적 및 신뢰성 개선 추가.

#### 리팩토링

- CI 를 포맷, 타입 체크, 테스트, 빌드 작업으로 분리.
- TypeScript/Bun 기반 CLI 를 Rust 로 재작성.
