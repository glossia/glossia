## `glossia init`

초안 생성 `L10N.md` 현재 저장소의 설정 파일입니다.

```bash
glossia init
```

이미 존재하는 경우. `L10N.md` 이미 존재합니다.

## 번역은 서버 기반입니다.

번역은 Glossia 서버에서 수행되며, 명령줄 인터페이스에서 수행되지 않습니다. 커밋이 완료될 때,
Glossia 는 귀하의 `L10N.md` 파일들로부터 계획하며, 각 파일을
계정에 설정된 모델을 사용하여 결과를 바탕으로 pull request 를 생성합니다. 사용자는
각 파일과 모델의 턴을 번역 세션 페이지에서 실시간으로 모니터링할 수 있습니다.

모델은 문서마다 선택됩니다: `L10N.md` `model:` 명명된 하나를
계정 모델 핸들이 이를 선택하며, 아니라면 기본 모델이 사용됩니다.

명령줄 인터페이스는 의도적으로 계획하지도, 번역하지도, 검증하지도 않으며,
검토하거나 생성된 번역을 삭제하지 않으며, 또한 서버의 것 을 읽지 않는
번역 로크파일입니다.

## `glossia revisit`

이후의 소스 언어 리비전 패스를 위해 예약됩니다. Rust 명령줄
인터페이스는 현재 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```

## 전역 플래그

| 플래그 | 설명 |
|---|---|
| `--path <PATH>` | 프로젝트 루트 디렉토리를 덮어 씁니다 |
| `--no-color` | 색상 출력 끄기 |
