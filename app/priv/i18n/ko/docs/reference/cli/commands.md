## `glossia init`

현재 저장소에 기본 `GLOSSIA.md` 구성 파일을 생성합니다.

```bash
glossia init
```

`GLOSSIA.md`이 이미 있으면 실패합니다.

## 번역은 서버에서 수행됩니다

번역은 명령줄 인터페이스가 아니라 Glossia 서버에서 실행됩니다. 커밋이 반영되면 Glossia는 `GLOSSIA.md` 파일을 기반으로 작업을 계획하고, 계정에 구성된 모델로 각 파일을 번역한 다음, 결과가 포함된 풀 리퀘스트를 생성합니다. 번역 세션 페이지에서 각 파일의 처리 과정과 모델의 각 처리 단계를 실시간으로 확인할 수 있습니다.

모델은 문서별로 선택됩니다. 계정 모델 핸들 중 하나를 지정하는 `GLOSSIA.md` `model:`이 있으면 해당 모델을 사용하고, 그렇지 않으면 계정의 기본 모델을 사용합니다.

명령줄 인터페이스는 의도적으로 생성된 번역을 계획, 번역, 검증, 검사 또는 삭제하지 않습니다. 또한 서버의 번역 잠금 파일을 읽지 않습니다.

## `glossia revisit`

향후 제공될 원문 언어 수정 단계용으로 예약되어 있습니다. 현재 Rust 명령줄 인터페이스는 이 명령에 대해 구현되지 않음 오류를 반환합니다.

```bash
glossia revisit
```

## 전역 플래그

| 플래그 | 설명 |
|---|---|
| `--path <PATH>` | 프로젝트 루트 디렉터리를 재정의합니다 |
| `--no-color` | 색상 출력을 비활성화합니다 |
