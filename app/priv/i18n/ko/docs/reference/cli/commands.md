## `glossia init`

시작 설정 생성 `L10N.md` 현재 리포지토리의 설정 파일입니다.

```bash
glossia init
```

이미 존재하는 경우 `L10N.md` 실패합니다.

## 번역은 서버 사이드입니다

번역은 Glossia 서버에서 처리되며, 명령줄 인터페이스가 아닙니다. 커밋이 등록되면,
Glossia 는 사용자의 `L10N.md` 파일을 기반으로 작업을 계획하고, 각 파일을 번역합니다.
귀하 계정의 설정된 모델을 사용하며, 결과를 포함하여 풀 리퀘스트를 엽니다. 사용자
각 파일과 모델의 턴을 번역 세션 페이지에서 실시간으로 확인하실 수 있습니다.

모델은 문서마다 선택됩니다: 한 `L10N.md` `model:` 지정하는 귀하의
계정 모델 핸들이 이를 선택합니다; 그렇지 않으면 귀하의 계정의 기본 모델이 사용됩니다.

커맨드라인 인터페이스는 의도적으로 계획하거나, 번역하거나, 검증하지 않습니다,
생성된 번역을 검사하거나 삭제하지도 합니다. 또한 읽지 않습니다. 서버의
번역 잠금 파일.

## `glossia revisit`

원어 버전의 향후 수정을 위해 예약됨. Rust 명령 줄
인터페이스는 현재 해당 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```

## 전역 플래그

| 플래그 | 설명 |
|---|---|
| `--path <PATH>` | 프로젝트 루트 디렉토리를 덮어쓰기 |
| `--no-color` | 색상 출력 비활성화 |
