## `glossia init`

현재 저장소에서 시작용 `L10N.md` 구성 파일을 생성합니다.

```bash
glossia init
```

`L10N.md` 가 이미 존재하는 경우 실패합니다.

## 번역은 서버에서 진행됩니다.

번역은 호스팅된 Glossia 서비스에서 수행되며, 명령줄 인터페이스가 아닌 곳에서 진행됩니다. 커밋이 완료되면 Glossia 는 당신의 `L10N.md` 파일을 기반으로 작업을 계획하고, 계정의 설정된 모델로 각 파일을 번역한 뒤 결과를 포함하여 풀 리퀘스트를 생성합니다. 번역 세션 페이지에서는 각 파일과 모델의 턴을 실시간으로 확인할 수 있습니다.

모델은 문서별마다 선택됩니다: `L10N.md` 에 `model:` 를 사용하여 당신의 계정 모델 핸들 중 하나를 지정한 경우 그것으로 선택되며; 그렇지 않으면 계정의 기본 모델이 사용됩니다.

명령줄 인터페이스는 고의로 생성된 번역을 계획하거나, 번역하거나, 검증하거나, 검사하거나, 삭제하지 않습니다. 또한 Glossia 가 발행한 번역 잠금 파일을 읽지도 않습니다.

## `glossia revisit`

향후 소스 언어 리비전 작업을 위해 보류됩니다. 현재 Rust 명령줄 인터페이스는 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```
