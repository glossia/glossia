## `glossia init`

현재 저장소에서 초기 `L10N.md` 구성 파일을 생성합니다.

```bash
glossia init
```

`L10N.md` 가 이미 존재하는 경우 실패합니다.

## 번역은 서버 측에서 수행됩니다.

번역은 호스팅된 Glossia 서비스에서 수행되며, 명령줄 인터페이스에서는 수행되지 않습니다. 커밋이 적용되면 Glossia 는 귀하의 `L10N.md` 파일에서 작업을 계획하고, 계정의 구성된 모델로 각 파일을 번역한 후 결과로 풀 리퀘스트를 엽니다. 번역 세션 페이지에서 각 파일 및 모델의 회차를 실시간으로 확인할 수 있습니다.

모델은 문서마다 선택됩니다. 계정 모델 핸들 중 하나를 명명한 `L10N.md` `model:` 가 있다면 이를 선택하고, 그렇지 않으면 계정의 기본 모델이 사용됩니다.

명령줄 인터페이스는 의도적으로 생성된 번역을 계획하거나, 번역하거나, 유효성 검사하거나, 검토하거나, 삭제하지 않습니다. 또한 Glossia 가 게시한 번역 잠금 파일도 읽지 않습니다.

## `glossia revisit`

미래의 소스 언어 수정 단계를 위해 예약되어 있습니다. Rust 명령줄 인터페이스는 현재 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```

## 전역 플래그

| 플래그 | 설명 |
|---|---|
| `--path <PATH>` | 프로젝트 루트 디렉토리를 덮어쓰기 |
| `--no-color` | 색상 출력 비활성화 |
