## `glossia init`

시작 템플릿`L10N.md` 구성 파일을 현재 저장소에 생성합니다.

```bash
glossia init
```

다음과 같은 경우 실패합니다.`L10N.md`가 이미 존재하는 경우.

## 번역은 서버 측에서 이루어집니다

번역은 Glossia 서버에서 진행되며, 명령행 인터페이스에서는 진행되지 않습니다. 커밋이 머지되면,
Glossia 는 귀하의 `L10N.md` 파일을 기반으로 작업을 계획하고, 각 파일을
귀하의 계정에서 설정한 모델로 번역한 후 결과를 포함하여 풀 리퀘스트를 엽니다. 귀하
는 각 파일과 모델의 회전을 번역 세션 페이지에서 실시간으로 모니터링할 수 있습니다.

모델은 문서마다 선택됩니다: `L10N.md` `model:` 을 통해 귀하의
계정 모델 핸들이 선택합니다. 그렇지 않으면 귀하의 계정의 기본 모델이 사용됩니다.

명령행 인터페이스는 계획, 번역, 유효성 검사,
검사하거나 생성된 번역을 삭제하지 않습니다. 또한 서버의
번역 잠금 파일을 읽지 않습니다.

## `glossia revisit`

향후 소스 언어 검토 패스를 위한
Rust 명령행 인터페이스는 현재 해당 명령에 대해 구현되지 않도록 하는 오류를 반환합니다.

```bash
glossia revisit
```

## 전역 플래그

| `--no-color` | 컬러 출력을 비활성화합니다 |
