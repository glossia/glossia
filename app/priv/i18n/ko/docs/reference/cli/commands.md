## `glossia init`

스타터 생성 `L10N.md` 현재 저장소의 구성 파일입니다.

```bash
glossia init
```

이미 존재하는 경우 `L10N.md` 이미 존재합니다.

## 번역은 서버 측에서 수행됩니다.

번역은 호스팅된 Glossia 서비스에서 실행되며 명령줄 인터페이스에서는 수행되지 않습니다. 커밋이 완료되면,
Glossia 는 귀하의 `L10N.md` 파일을 기반으로 각 파일을 번역합니다.
귀하 계정의 설정된 모델을 사용하여 결과를 바탕으로 풀 리퀘스트를 생성합니다. 귀하가
각 파일 및 모델의 턴을 번역 세션 페이지에서 실시간으로 확인하실 수 있습니다.

모델은 문서마다 선택됩니다: `L10N.md` `model:` 귀하의 모델 핸들러 중 하나를 지정한 경우
계정 모델 핸들러는 이를 선택하며, 그렇지 않으면 귀하의 계정의 기본 모델이 사용됩니다.

명령줄 인터페이스는 의도적으로 계획하거나, 번역하거나, 유효성을 검증하지 않습니다.
검사하거나 생성된 번역을 삭제하지 않습니다. 또한 Glossia 가 게시한 번역 잠금 파일을 읽지도 않습니다.

## `glossia revisit`

미래의 원어 수정 패스를 위해 비준됨. Rust 명령줄
인터페이스는 현재 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```
