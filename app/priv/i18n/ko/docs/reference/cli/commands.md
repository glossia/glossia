## `glossia init`

현재 저장소에서 시작 템플릿`GLOSSIA.md` 설정 파일을 생성합니다.

```bash
glossia init
```

다음과 같은 경우 실패합니다`GLOSSIA.md` 이미 이 이미 존재합니다.

## 번역은 서버 사이드에서 실행됩니다

번역은 명령어 인터페이스가 아닌 Glossia 서버에서 실행됩니다. 커밋이 성공적으로 적용될 때,
Glossia 는 여러분의`GLOSSIA.md` 파일을 기반으로 작업을 계획하며,
해당 계정에 구성된 모델을 사용하여 각 파일을 번역한 후 결과를 포함하는 풀 쌍을 제안합니다.
각 파일과 모델의 작업 흐름을 번역 세션 페이지에서 실시간으로 관찰할 수 있습니다.

모델은 문서당 선택되어`GLOSSIA.md` `model:` 형태로 하나 Select
계정의 모델 핸들러가 선택하지 않으면

명령어 인터페이스는 의도적으로 계획, 번역, 유효성 검사,
검토하거나 생성된 번역을 삭제하지 않습니다. 서버의
번역 잠금 파일을 읽지도 않습니다.

## `glossia revisit`

미래의 원어 재검토를 위해
Rust 명령어 인터페이스는 현재 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```
