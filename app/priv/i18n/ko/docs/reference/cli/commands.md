## `glossia init`

현재 리포지토리에 스타터 `L10N.md` 구성 파일을 생성합니다.

```bash
glossia init
```

`L10N.md` 이 이미 존재하는 경우 실패합니다.

## 번역은 서버 사이드에서 실행됩니다

번역은 호스팅된 Glossia 서비스에서 수행되며, 명령줄 인터페이스에서 수행되지 않습니다. 커밋이 저장될 때, Glossia 는您的 `L10N.md` 파일에서 작업을 계획하고 각 파일을 계정의 설정된 모델로 번역한 후 결과를 병합 요청으로 제출합니다. 각 파일과 모델의 작업 상태를 번역 세션 페이지에서 실시간으로 확인할 수 있습니다.

모델은 문서별로 선택됩니다: `L10N.md` `model:` 에서 계정의 모델 핸들 중 하나를 지정하면 해당 모델이 선택되며, 그렇지 않으면 계정의 기본 모델이 사용됩니다.

명령줄 인터페이스는 의도적으로 생성된 번역을 계획하거나, 번역하거나, 유효성을 검사하거나, 검사하거나, 삭제하지 않습니다. 또한 Glossia 가 공개한 번역 잠금 파일도 읽지 않습니다.

## `glossia revisit`

향후 출처 언어의 가제본 통과를 위한 것으로 여겨집니다. 현재 Rust 명령줄 인터페이스는 이 명령에 대해 구현되지 않은 오류를 반환합니다.

```bash
glossia revisit
```
