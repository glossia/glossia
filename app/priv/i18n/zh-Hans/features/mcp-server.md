## MCP 是什么？

The [模型上下文协议](https://modelcontextprotocol.io) 是将 AI 助手连接到外部工具和数据源的开源标准。无需为每个编程助手构建自定义集成，只需公开单个 MCP 服务器，任何兼容的客户端都可以使用它。

Glossia 的 MCP 服务器为智能体提供了对平台语言核心的直接访问：语音配置、术语表管理、组织管理和项目列出。

## 可用工具

MCP 服务器公开了 16 个工具，围绕您日常使用的资源组织。查看 [完整工具参考](/docs/reference/mcp/tools) 以获取参数和使用详情。

**账户和组织** -- 列出您的账户，创建和管理组织，邀请成员，并控制访问权限。智能体可以通过对话设置整个团队结构。

**语音配置** -- 阅读和更新控制 Glossia 生成和修订内容的语音设置。无需离开编辑器即可调整语气、正式程度、目标受众和区域覆盖。

**术语表管理** -- 在所有内容中维护术语表的一致性。添加、更新和版本化术语表条目，确保智能体始终使用正确的术语。

**项目** -- 列出并检查跨组织的项目。

## 工作原理

将您的 MCP 客户端指向 `https://your-glossia-instance/mcp`，并使用 OAuth 访问令牌进行身份验证。The [MCP 设置指南](/docs/reference/mcp/overview) 涵盖了完整的连接流程，包括动态客户端注册和 PKCE。服务器使用与 [REST API](/features/rest-api) 相同的身份验证和授权系统，因此任何可用于 API 的令牌也都适用于 MCP。

从那里开始，您的 AI 助手可以调用这 16 个工具中的任何一个。要求它"创建一个名为 Acme 的组织"或"将我的语音语气更新为专业"，智能体将您的意图转换为正确的工具调用。

## 专为智能工作流构建

MCP 不仅仅是一个便利层。它是将 Glossia 组合到更大型智能工作流程的基础。一个编程助手可以读取您的代码库、检测未本地化的内容、使用新术语更新术语表、为特定区域调整语音设置，并在单次对话中触发本地化运行。

由于协议已标准化，您不会被锁定在任何单一客户端上。可以在 Claude、Cursor 或您自己的自定义代理之间切换，无需修改任何一行配置文件。
