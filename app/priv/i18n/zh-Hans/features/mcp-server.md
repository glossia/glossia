## 什么是 MCP？

[模型上下文协议](https://modelcontextprotocol.io)（Model Context Protocol，MCP）是一项开放标准，用于将人工智能助手连接到外部工具和数据源。您无需为每个编程助手构建自定义集成，只需提供一个 MCP 服务器，任何兼容的客户端都可以使用它。

Glossia 的 MCP 服务器让智能体能够直接访问平台的语言核心功能，包括语言风格配置、术语管理、组织管理和项目列表。

## 可用工具

MCP 服务器提供 16 个工具，围绕您日常使用的资源进行组织。有关参数和使用详情，请参阅[完整工具参考](/docs/reference/mcp/tools)。

**账户和组织**：列出您的账户，创建和管理组织，邀请成员并控制访问权限。智能体可以通过对话完成整个团队结构的设置。

**语言风格配置**：读取和更新用于控制 Glossia 如何生成和修订内容的语言风格设置。无需离开编辑器，即可调整语调、正式程度、目标受众以及各语言区域的覆盖设置。

**术语管理**：在所有内容中保持术语一致性。添加、更新术语条目并对其进行版本管理，确保智能体始终使用正确的术语。

**项目**：列出并查看各组织中的项目。

## 工作原理

将您的 MCP 客户端指向 `https://your-glossia-instance/mcp`，并使用 OAuth 持有者令牌进行身份验证。[MCP 设置指南](/docs/reference/mcp/overview)介绍了完整的连接流程，包括动态客户端注册和证明密钥代码交换（Proof Key for Code Exchange，PKCE）。该服务器采用与 [REST API](/features/rest-api) 相同的身份验证和授权系统，因此任何适用于该应用程序编程接口的令牌也适用于 MCP。

完成连接后，您的人工智能助手即可调用这 16 个工具中的任意一个。您可以要求它“创建一个名为 Acme 的组织”或“将我的语言风格语调更新为专业”，智能体会将您的意图转换为正确的工具调用。

## 专为智能体工作流构建

MCP 不只是一个便捷层，更是将 Glossia 组合到大型智能体流程中的基础。编程助手可以读取您的代码库、检测未本地化的内容、使用新术语更新术语库、调整特定语言区域的语言风格设置，并触发本地化运行，所有操作都能在一次对话中完成。

由于该协议已标准化，您不会受限于任何单一客户端。您可以在 Claude、Cursor 或自己的自定义智能体之间切换，而无需更改任何配置。
