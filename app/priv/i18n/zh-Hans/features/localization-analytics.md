## 用数据决定您的下一个目标区域

大多数团队凭直觉选择目标语言。本地化分析用数据信号取代直觉。添加 Web SDK，Glossia 将显示访客浏览器请求的语言、他们来自的国家，以及最重要的是，显示这些与您已支持语言的重叠。

核心指标是 **本地化缺口**：访客首选语言暂无对应支持的翻译的百分比。按国家、来源和页面深入分析，以精确找出未满足需求集中的位置，并确定新增哪个目标区域能产生显著影响。

## 隐私无妥协

Glossia 分析不收集非必需数据，也不存储任何可识别信息。浏览器发送页面 URL、来源、首选语言、时区和屏幕尺寸。服务器基于 IP 与 User-Agent 的每日轮转哈希生成唯一访客标识，随后丢弃。不设置 Cookie，不会生成设备指纹，访客无法被跨天或跨站追踪。

最终结果是您可以无需同意横幅即可上线的分析功能，且完全符合国际访客既有的隐私预期。

## 几秒钟内安装

在您的网站上只需添加一行，Glossia 即刻开始测量：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更喜欢 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论哪种方式，页面浏览量、客户端导航和自定义事件都会汇聚至同一仪表板，该仪表板将为您优先级排序本地化机会。
