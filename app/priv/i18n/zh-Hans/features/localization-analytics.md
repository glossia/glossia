## 用数据决定您的下一个目标语言

大多数团队凭直觉选择目标语言。本地化分析用客观信号取代了直觉。添加 Web SDK，Glossia 将向您展示访客浏览器的请求语言、他们来自的国家，以及最关键的是与您已支持语言的重叠情况。

核心指标是 **本地化缺口**：指您访客中偏好语言尚无支持翻译的比例。按国家、来源和页面进行钻取，以准确查看未满足需求集中在何处，以及哪个新目标语言能产生显著影响。

## 隐私无妥协

Glossia 分析不收集任何不必要的信息，也不存储任何可识别的内容。浏览器会发送页面 URL、来源地址、偏好语言、时区和屏幕尺寸。服务器根据 IP 和用户代理生成每日轮换的唯一访客哈希值，随后丢弃这些信息。不会设置 Cookie，不会进行指纹识别，也无法跨天或跨网站追踪访客。

结果是您可以无需同意横幅即可发布此类分析，且与国际访客已有的隐私期望保持一致。

## 秒级安装

只需在您的站点中添加一行代码，Glossia 便开始测量：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更倾向于 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论哪种方式，页面浏览量、客户端导航和自定义事件都将汇入同一仪表板，该仪表板会为您评估本地化机会。
