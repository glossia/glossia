## 用数据决定您的下一个目标语种

大多数团队在挑选目标语种时凭直觉行事。本地化分析用信号取代直觉。添加 web SDK，Glossia 将展示访客浏览器请求的语言、他们来源的国家，以及至关重要的是，与已支持语言的重合。

关键指标是 **本地化缺口**：即首选语言无对译的访客占比。按国家、来源页或页面深入分析，查看需求未得到满足的集中点，以及哪个新目标语种能带来显著成效。

## 隐私无妥协

Glossia 分析仅收集所需信息，不存储任何可识别数据。浏览器仅发送页面 URL、回源地址、首选语言、时区和屏幕尺寸。服务器根据每日轮换的 IP 和 User-Agent 哈希值识别唯一访客，随后丢弃。不设置 Cookie，不生成指纹，无法跨天或跨站追踪访客。

结果是，您无需同意横幅即可上线分析，且符合国际访客已习惯的隐私预期。

## 秒级安装

向您的站点添加一行，Glossia 即刻开始统计：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更喜欢 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论采用何种方式，页面浏览量、客户端导航和自定义事件都会汇入同一仪表板，该仪表板会为您梳理本地化机会。
