## 使用数据决定您的下一个目标区域

大多数团队凭直觉选择目标语言。本地化分析用数据信号取而代之。添加 Web SDK，Glossia 将展示访客浏览器请求的语言、他们来自的国家，以及最关键的是，这些需求与您当前已支持语言的重叠部分。

核心指标是 **本地化缺口**：您的访客中首选语言未获支持的比例。按国家、来源和页面深入查看，以精确定位需求缺口集中处，以及选择哪个新语言区域能带来显著改变。

## 无需妥协的隐私

Glossia 分析仅收集所需内容，不存储任何可识别信息。浏览器发送页面 URL、推荐来源、首选语言、时区和屏幕尺寸。服务器从每日轮换的 IP 和用户代理哈希生成唯一访客，随后丢弃。不设置 Cookie，不进行指纹追踪，访客无法跨天或跨网站被跟踪。

最终，您无需同意横幅即可上线分析，且符合国际访客既有的隐私期望。

## 几秒钟即可安装

在你的网站中添加一行代码，Glossia 即刻开始测量：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更倾向 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论何种方式，浏览量、客户端导航和自定义事件都会流入同一仪表盘，该仪表盘可为您排序本地化机会。
