## 用数据决定你的下一个目标区域

大多数团队凭直觉选择目标语言。本地化分析用数据信号取而代之。添加 Web SDK，Glossia 将向您展示访客浏览器请求的语言、他们所在的国家，以及最关键的是，这些语言与您已支持语言的重叠情况。

核心指标是 **本地化缺口**：即首选语言无对应支持的访客百分比。按国家、来源及页面钻取，以精确查看未充分满足的需求集中地，以及新增哪个区域将带来实质影响。

## 隐私无妥协

Glossia 分析不收集任何不必要的信息，也不存储任何可识别数据。浏览器发送页面 URL、来源、首选语言、时区和屏幕尺寸。服务器根据 IP 和 User-Agent 的每日轮换哈希生成唯一访客标识，随后丢弃。未设置 Cookie，不进行指纹识别，且无访客能被跨天或跨站追踪。

结果是您可以无需同意横幅即可发布的分析，与您的国际访客既有的隐私期望相符。

## 几秒钟内安装

在您的站点中添加一行，Glossia 就会开始监测：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更倾向于 npm？安装 `@glossia/web` 并调用 `init({ domain })`. 无论哪种方式，页面浏览量、客户端导航和自定义事件都会汇入同一仪表盘，该仪表盘能为您梳理本地化机会的优先级。
