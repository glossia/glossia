## 用数据确定下一个区域设置

大多数团队凭直觉选择目标语言。本地化分析以数据洞察取代直觉。添加 Web 软件开发工具包后，Glossia 会显示访客浏览器请求的语言、访客所在的国家，以及最关键的部分：这些语言与您已支持语言之间的重叠情况。

核心指标是**本地化缺口**：首选语言尚无受支持翻译的访客所占百分比。您可以按国家、来源网站和页面深入分析，准确了解未满足的需求集中在哪里，以及新增哪个区域设置能带来最显著的改善。

## 隐私保护毫不妥协

Glossia 分析不会收集非必要信息，也不会存储任何可识别个人身份的信息。浏览器会发送页面 URL、来源网站、首选语言、时区和屏幕尺寸。服务器根据 IP 和 User-Agent 生成每日轮换的哈希值，以此识别独立访客，随后丢弃这些原始数据。系统不会设置 Cookie，不会采集浏览器指纹，也无法跨天或跨站点跟踪任何访客。

因此，您可以部署分析功能而无需显示同意横幅，同时满足国际访客已有的隐私期望。

## 数秒内完成安装

只需向网站添加一行代码，Glossia 即可开始统计：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更倾向于使用 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论采用哪种方式，页面浏览、客户端导航和自定义事件都会汇入同一仪表板，由其对您的本地化机会进行排序。
