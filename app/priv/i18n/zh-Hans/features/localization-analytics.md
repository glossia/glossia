## 基于数据选择您的下一个目标语言

大多数团队凭直觉选择目标语言。本地化分析用客观数据取代直觉。添加 Web SDK，Glossia 将向您展示访客浏览器请求的语言、他们所在的国家，以及至关重要的是，与现有支持语言的重合部分。

核心指标是 **本地化缺口**：您的访客中首选语言缺乏翻译支持的比例。您可以按国家、推荐来源或页面深入分析，以精准定位未满足的需求集中地，并决定新增哪个目标语言能产生显著影响。

## 隐私无妥协

Glossia 分析不收集不必要的数据，也不存储任何可识别的信息。浏览器会发送页面 URL、推荐来源、首选语言、时区和屏幕尺寸。服务器通过 IP 和用户代理的每日轮换哈希值生成唯一访客标识，随后即丢弃这些信息。不设置 Cookie，不进行指纹追踪，访客也无法在不同日期或网站之间被追踪。

这使您获得无需同意横幅即可上线的分析数据，且与您的国际访客已有的隐私预期保持一致。

## 数秒安装

在您的网站中添加一行，Glossia 即刻开始测量:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更倾向使用 npm？安装 `@glossia/web` 并调用 `init({ domain })`。无论采用何种方式，页面浏览量、客户端导航和自定义事件都会流入同一个仪表板，该仪表板会评估您的本地化机会。
