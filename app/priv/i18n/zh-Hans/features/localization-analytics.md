## 根据数据确定下一个目标地区

大多数团队选择目标语言往往凭直觉。本地化分析以数据信号取而代之。集成 Web SDK 后，Glossia 会向您展示访客浏览器请求的语言、来源国家，以及最关键的是，这些数据与您已支持语言的重叠部分。

关键指标是 **本地化缺口**：偏好语言暂无支持翻译的访客占比。通过国家、来源和页面深入查看，以精准定位需求不足集中点及能带来提升的新地区。

## 隐私无妥协

Glossia 分析仅收集所需信息，不存储任何可识别内容。浏览器发送页面 URL、来源、首选语言、时区和屏幕尺寸。服务器通过每日轮换的 IP 和用户代理哈希派生唯一访客标识，随后丢弃。不设置 Cookie，不生成指纹，也无法跨天或跨站追踪访客。

这意味着您可以无需同意横幅即可上线分析，同时符合您的国际访客已具备的隐私期望。

## 几秒钟内安装

向你的网站添加一行代码，Glossia 便开始测量：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

更喜欢 npm？安装 `@glossia/web` 并调用 `init({ domain })`. 无论采用哪种方式，页面浏览量、客户端导航和自定义事件都会流入同一个仪表盘，该仪表盘会为你梳理本地化机会。
