## 仪表板

打开 **设置 → 模型 → 令牌用量** 以查看生成式翻译的提供商报告用量。访问需拥有阅读模型设置的权限。

仪表板支持过去 7、30 或 90 个日历日，包括今天，以 UTC 时间计算。模型、项目和语言过滤器应用于总计、每日图表和分类明细。搜索仅应用于分类明细行。所选周期、维度、过滤器、搜索、排序和页面均保留在 URL 中。

## 指标

| 指标 | 含义 |
| --- | --- |
| 输入令牌 | 提供商处理的输入，包括报告的缓存读取和缓存写入。 |
| 输出令牌 | 提供商报告出的输出，包括提供商将其计入输出计数时的推理过程。 |
| 缓存输入令牌 | 缓存读取。输入令牌的子集，不计入总计的额外费用。 |
| 总令牌数 | 输入令牌加输出令牌。 |
| 响应 | 包含输入和输出计数且令牌总数为正数的响应。缺失用量回退值为零将被忽略。 |

令牌计数并非货币成本。提供商可以对输入、输出、缓存输入和缓存写入收取不同费率。

每个报告的响应都会被计数，包括验证重试、质量修正重试，以及因达到输出限制而被拒绝的响应。跳过 的文件和未调用模型的关键检查点命中不产生使用量。没有使用量的失败请求无法被计数。

## 维度

- **项目** 按项目对使用量进行分组。使用项目过滤器可将所有指标的範圍限制为单个项目。
- **语言** 按目标语言环境对使用量进行分组，例如 `es` 或 `ja`，涵盖当前范围内的各项目。
- **文件** 按源路径和项目对使用量进行分组。同一来源文件翻译成多种语言仅出现一次；不同项目中同名文件保持独立。

**未分配** 保持无前项目或源路径元数据请求的可见性。仓库转译自动提供两者。单次内容 API 请求可提供 `project_id` 和 `source_path` 用于归因；认证账户外部的项目 ID 被视为未分配。无效或过大的可选元数据不会丢弃令牌计数，仅被视为未分配。

## 覆盖范围

用量收集自 ReqLLM API 密钥和 OAuth 响应、Together 完成结果以及已完成的地方 Codex 回合。仅保存提供商报告次数。本地 Pi 会话和决策模型评估不包括在内。历史转译不会补全或估算。总计因此描述已记录的用量，而非完整的提供商发票。

账本存储账户、项目、模型标识符和句柄、目标语言环境、源路径、计数和时间戳。它不存储提示、转译内容、凭证或原始提供商响应。用量记录失败会记录日志，不会中断转译。
