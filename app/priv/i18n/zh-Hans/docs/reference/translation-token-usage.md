## 仪表盘

打开 **设置 → 模型 → Token 用量** 查看生成式翻译的提供商用量报告。访问需要读取模型设置的权限。

仪表盘支持过去 7、30 或 90 个日历日（含今天）的 UTC 时段。模型、项目和语言筛选器适用于总计、每日图表和细分。搜索仅适用于细分行。所选时段、维度、筛选器、搜索、排序和页面将保存在 URL 中。

## 指标

| 指标 | 含义 |
| --- | |
| 输入令牌 | 提供商处理的输入，包括所报告的缓存读取和缓存写入。|
| 输出令牌 | 提供商报告的输出，包括提供商将其纳入其输出计数时的推理。|
| 缓存输入令牌 | 缓存读取。输入令牌的一个子集，并非总计中的额外费用。|
| 总令牌数 | 输入令牌加输出令牌。|
| 响应 | 具有输入和输出计数且令牌总数为正的响应。归零的缺失用量回退将被忽略。|

令牌计数并非货币成本。提供商可为输入、输出、缓存输入和缓存写入收取不同费率。

每个报告的响应都会被计数，包括验证重试、质量修正重试，以及因达到输出限制而被拒绝的响应。跳过的文件和未调用模型的检查点命中不计入使用量。无使用数据的失败请求无法被计数。

## 维度

- **项目** 按项目分组展示使用情况。使用项目过滤器可将指标范围限定在单个项目内。
- **语言** 按目标语言分组，例如 `es` 或 `ja`，跨当前范围内所有项目。
- **文件** 按源路径和项目分组。同一源文件翻译成多种语言时仅显示一次；不同项目中同名文件保持独立。

**未分配** 保持缺少项目或源路径元数据的请求可见。仓库翻译会自动提供这两项信息。单次内容 API 请求可提供 `project_id` 并 `source_path` 用于归因；已认证账户之外的项目 ID 将被视为未分配。无效或过大的可选元数据将在不丢弃 token 计数的情况下保持未分配状态。

## 覆盖率

使用情况统计来源于 ReqLLM API 密钥和 OAuth 响应、Together 完成记录以及已完成的本地 Codex 调用。仅保留提供商报告的计数。本地 Pi 会话和决策模型评估不在统计范围内。历史翻译不会回填或估算。因此，总计描述的是实际记录的使用量，而非提供商的完整发票。

账本存储账户、项目、模型标识符和句柄、目标语言、源路径、计数和时间戳。它不存储提示词、翻译内容、凭证或原始提供商响应。使用量记录失败将记录日志，且不会中断翻译。
