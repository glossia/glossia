## 仪表板

打开**设置 → 模型 → Token 用量**查看由提供商报告的分类型转译用量。访问需要读取模型设置的权限。

仪表板支持 UTC 时区下最近 7、30 或 90 天（含今天）的数据。模型、项目和语言过滤器应用于总计、每日图表和细分。搜索仅应用于细分行。选定的时段、维度、过滤器、搜索、排序和页面将保留在 URL 中。

## 指标

| 指标 | 含义 |
| --- | --- |
| 输入 token | 由提供商处理的输入，包括报告的缓存读取和写入。 |
| 输出 token | 提供商报告的输出，包括提供商将其推理包含在输出计数中的推理。 |
| 缓存输入 token | 缓存读取。输入 token 的子集，不计入总计的额外费用。 |
| 总 token | 输入 token 加上输出 token。 |
| 响应 | 同时包含输入和输出计数且 token 总数为正的响应。缺失用量回退导致的零值将被忽略。 |

Token 计数并非货币成本。提供商可为输入、输出、缓存输入和缓存写入收取不同费用。

每个报告的响应都会计数，包括验证重试、质量修正重试，以及因达到输出限制而被拒绝的响应。被跳过的文件和未调用模型的检查点命中不会产生用量。无使用量的失败请求不计数。

## 维度

- **项目** 按项目汇总用量。使用项目过滤器将指标范围限定在单个项目内。
- **语言** 按目标区域（如`es`或`ja`）进行分组，涵盖当前范围内各个项目。
- **文件** 按源路径和项目分组。同一源文件被翻译成多种语言仅显示一次；不同项目中同名文件保持独立。

**未分配** 保留缺乏项目或源路径元数据的请求可见。仓库转译会自动提供这两项。单一内容 API 请求可提供`project_id`和`source_path`用于归因；不在已认证账户内的项目 ID 被视为未分配。无效或过大的可选元数据在不丢弃 token 计数的情况下被视为未分配。

## 覆盖范围

用量收集自 ReqLLM API 密钥和 OAuth 响应、Together 完成请求以及已完成的本地 Codex 轮次。仅保存提供商报告的计数。本地 Pi 会话和决策模型评估不计入。历史翻译不会回填或估算。因此，总计描述的是已记录的用量，而非提供商的完整发票。

账本存储账户、项目、模型标识符和句柄、目标区域、源路径、计数和时间戳。它不存储提示、译文内容、凭证或原始提供商响应。使用量记录失败将被记录而不会中断翻译。
