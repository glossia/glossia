账户令牌提供了一种简单的方式，用于在不经过完整的 OAuth 流程即可对 API 请求进行身份验证。它们非常适合脚本、CI/CD 管道和自动化操作。

## 创建令牌

1. 请登录 Glossia 并导航到您的账户仪表板。
2. 打开侧边栏中的 **API** 部分。
3. 点击 **账户令牌**，然后点击 **新令牌**。
4. 为该令牌指定一个描述性的 **名称**（例如 "CI 部署" 或 "CLI 访问"）。
5. 选择令牌所需的 **作用域**。仅授予所需的最小权限。
6. 设置 **过期日期** 或留空，用于永不过期的令牌。
7. 点击 **创建令牌**。

创建后，完整的令牌值将显示 **一次**。立即复制并安全存储。您将无法再次看到完整值。

## 使用令牌

将代币包含在 HTTP 请求的 `Authorization` 标头中：

```
Authorization: Bearer glsa_abc123def456...
```

例如，使用 `curl`：

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

账户令牌与 OAuth 令牌遵循相同的 [授权模型](/docs/reference/apis/authorization)。令牌的范围定义了它可以执行的最大操作集，资源级别的策略仍会根据您的账户关系适用。

## 令牌格式

所有账户令牌均以 `glsa_` 前缀开头，后跟随机十六进制字符串。此前缀可便于在日志和密钥扫描器中识别 Glossia 令牌。

## 范围

账户令牌支持的范围与 OAuth 令牌相同。有关完整列表，请参阅 [范围参考](/docs/reference/apis/authorization)。

创建令牌时，仅选择您用例所需的范围。例如：

- 只读集成需要 `project:read` 和 `voice:read`。
- 创建项目的 CI 流水线需要 `project:read` 和 `project:write`。
- 管理组织成员的脚本需要 `members:read` 和 `members:write`。

## 管理令牌

### 查看令牌

**账户令牌** 页面列出所有活动令牌及其名称、范围、最后使用时间到期日。从未使用过的令牌在最后使用时间列中显示 "未使用"。

### 编辑令牌

点击令牌名称以编辑其 **名称** 和 **描述**。创建后无法更改范围和到期日。如果需要不同的范围，请创建新令牌并撤销旧令牌。

### 撤销令牌

要撤销令牌，请在令牌列表上点击 **撤销**，或打开令牌编辑页面并在危险区域使用 **撤销令牌** 按钮。已撤销的令牌立即停止工作且无法恢复。

## 安全最佳实践

- **安全存储令牌。** 使用环境变量或密钥管理工具。切勿将令牌提交到源码控制。
- **使用短期令牌。** 在可能的情况下设置到期日期。
- **最小化范围。** 仅授予令牌实际需要的权限。
- **定期轮换。** 按照计划创建新令牌并撤销旧令牌。
- **监控使用情况。** 定期查看 "最后使用" 日期。撤销不再使用的令牌。
- **为每个集成使用一个令牌。** 这样，撤销一个令牌不会影响其他工作流。

## API 管理

您也可以通过 REST API 和 MCP 服务器管理账户令牌。

### REST API

| 方法 | 端点 | 描述 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 列出活动令牌 |
| `POST` | `/api/tokens` | 创建新令牌 |
| `DELETE` | `/api/tokens/:id` | 撤销令牌 |

### MCP

MCP 服务器提供 `list_tokens`、`create_token` 和 `revoke_token` 工具，它们镜像 REST API。
