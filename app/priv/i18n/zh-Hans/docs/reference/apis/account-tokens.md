账户令牌提供了一种简单的 API 请求认证方式，无需经过完整的 OAuth 流程。它们非常适合脚本、CI/CD 流水线和个人自动化。

## 创建令牌

1. 登录 Glossia 并导航到您的账户仪表板。
2. 从侧边栏打开 **API** 部分。
3. 点击 **账户令牌**，然后点击 **新建令牌**。
4. 为令牌指定一个描述性的 **名称**（例如，"CI 部署"或"CLI 访问"）。
5. 选择令牌所需的 **权限范围**。只需授予所需的最低权限。
6. 设置 **过期时间**，若要创建永不过期的令牌则留空。
7. 点击 **创建令牌**。

创建后，完整令牌值仅会显示 **一次**。请立即复制并安全存储。您将无法再次看到完整值。

## 使用令牌

将令牌包含在 HTTP 请求的 `Authorization` 标头中：

```
Authorization: Bearer glsa_abc123def456...
```

例如，使用 `curl`：

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

账户令牌遵循与 OAuth 令牌相同的 [授权模型](/docs/reference/apis/authorization)。令牌的权限范围定义了它可以执行的最大操作集，且基于您账户关系的资源级策略仍然适用。

## 令牌格式

所有账户令牌都以 `glsa_` 前缀开头，后跟一个随机十六进制字符串。该前缀使得在日志和密钥扫描器中轻松识别 Glossia 令牌变得简单。

## 权限范围

账户令牌支持与 OAuth 令牌相同的权限范围。查看完整的 [权限范围参考](/docs/reference/apis/authorization)。

创建令牌时，仅选择您的用例所需的权限范围。例如：

- 只读集成需要 `project:read` 和 `voice:read`。
- 创建项目的 CI 流水线需要 `project:read` 和 `project:write`。
- 管理组织成员的脚本需要 `members:read` 和 `members:write`。

## 管理令牌

### 查看令牌

**账户令牌** 页面列出了所有活动令牌及其名称、权限范围、最后使用日期和过期时间。从未使用过的令牌在“最后使用”列中显示“从不”。

### 编辑令牌

点击令牌名称以编辑其 **名称** 和 **描述**。创建后无法更改权限范围和过期时间。如果您需要不同的权限范围，请创建新令牌并撤销旧令牌。

### 撤销令牌

要撤销令牌，请在令牌列表中点击 **撤销**，或打开令牌编辑页面并使用危险区中的 **撤销令牌** 按钮。撤销的令牌会立即停止工作且无法恢复。

## 安全最佳实践

- **安全存储令牌。** 使用环境变量或秘密管理器。切勿将令牌提交到源代码控制中。
- **使用短期令牌。** 尽量设置过期日期。
- **最小化权限范围。** 仅授予令牌实际需要的权限。
- **定期轮换。** 按计划创建新令牌并撤销旧令牌。
- **监控使用情况。** 定期检查“最后使用”日期。撤销不再使用的令牌。
- **每个集成使用一个令牌。** 这样，撤销一个令牌不会影响其他工作流。

## API 管理

您也可通过 REST API 和 MCP 服务器管理账户令牌。

### REST API

| 方法 | 端点 | 描述 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 列出活动令牌 |
| `POST` | `/api/tokens` | 创建新令牌 |
| `DELETE` | `/api/tokens/:id` | 撤销令牌 |

### MCP

MCP 服务器提供 `list_tokens`、`create_token` 和 `revoke_token` 这些与 REST API 镜像的工具。
