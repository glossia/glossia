## `glossia init`

创建一个起始 `L10N.md` 当前仓库中的配置文件。

```bash
glossia init
```

如果 `L10N.md` 已存在。

## 翻译在服务端进行

翻译在 Glossia 服务器上运行，而非命令行界面。当提交合并时，
Glossia 根据您的 `L10N.md` 文件，并分别翻译每个文件使用
使用您账户配置的模型，并随结果创建一个拉取请求。您
可以在翻译会话页面上实时查看每个文件和模型的回合。

模型是按文档选择的：一 `L10N.md` `model:` 个您命名的
账户模型处理器选中它；否则使用您账户的默认模型。

命令行界面有意不执行规划、翻译、验证、
检查、或删除生成的翻译。它也不读取服务器的
翻译锁文件。

## `glossia revisit`

暂保留供未来源语言修订轮次。Rust 命令行
接口当前对此命令返回一个未实现错误。

```bash
glossia revisit
```
