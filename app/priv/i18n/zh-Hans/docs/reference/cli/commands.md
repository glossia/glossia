## `glossia init`

在当前仓库中创建一个初始 `L10N.md` 配置文件。

```bash
glossia init
```

如果 `L10N.md` 已存在，则失败。

## 翻译在服务器端进行

翻译在托管的 Glossia 服务中运行，不在命令行接口中。当提交到达时，Glossia 根据您的 `L10N.md` 文件规划工作，使用您账户配置好的模型翻译每个文件，并生成合并请求。您可以在翻译会话页面实时查看每个文件以及模型的各个轮次。

每个文档都会选择模型：通过 `L10N.md` `model:` 指定的一个账户模型管理器名称即可选中它；否则使用您账户的默认模型。

命令行接口故意不选择、翻译、验证、检查或删除生成的翻译。它也不会读取 Glossia 发布的翻译锁定文件。

## `glossia revisit`

保留给未来源语言修订版本。Rust 命令行接口当前对此命令返回未实现的错误。

```bash
glossia revisit
```
