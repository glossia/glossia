## `glossia init`

创建`L10N.md` 配置文件在当前仓库中。

```bash
glossia init
```

如果`L10N.md`已存在，则失败。

## 翻译是服务器端执行

翻译在 Glossia 服务器上运行，不在命令行界面中运行。当提交合并时，
Glossia 根据`L10N.md` 文件规划工作，使用您的
账户配置的模型进行翻译，并使用结果打开拉取请求。您
可以在翻译会话页面实时查看每个文件及模型的转译过程。

模型按文档选择：在`L10N.md` 中`model:` 命名您的
账户模型之一将予以选择；否则使用您的账户默认模型。

命令行界面有意不规划、翻译、验证、
检查或删除生成的翻译。它也不读取服务器的
翻译锁文件。

## `glossia revisit`

保留用于未来的源语言修订通过。Rust 命令行
界面当前为此命令返回未实现错误。

```bash
glossia revisit
```
