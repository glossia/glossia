## `glossia init`

在当前仓库中创建一个 `L10N.md` 初始配置文件。

```bash
glossia init
```

如果 `L10N.md` 已存在，则命令失败。

## 翻译在服务器端执行。

翻译在托管的 Glossia 服务中运行，而非在命令行界面中运行。当提交代码合并时，Glossia 会根据您的 `L10N.md` 文件规划工作，使用您账户配置的模型翻译每个文件，并打开拉取请求。您可以在翻译会话页面上实时查看每个文件及模型的交互过程。

模型按文档选择：通过 `L10N.md` `model:` 指定您的账户模型句柄之一将选择它；否则使用您账户的默认模型。

命令行界面故意不规划、翻译、验证、检查或删除生成的翻译。它也不读取 Glossia 发布的翻译锁文件。

## `glossia revisit`

保留用于未来的源语言修订阶段。Rust 命令行界面对此命令目前返回未实现错误。

```bash
glossia revisit
```
