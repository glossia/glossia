## `glossia init`

创建一个启动配置 `L10N.md` 当前仓库中的配置文件。

```bash
glossia init
```

失败，如果 `L10N.md` 已存在。

## 翻译是在服务端执行的。

翻译在 Glossia 服务器上运行，不在命令行界面中进行。当提交落地时，
Glossia 根据您的 `L10N.md` 文件，使用...翻译每个文件
您的账户配置的模型，并基于结果创建一个拉取请求。您
可以在翻译会话页面上实时查看每个文件及模型的交互轮次。

模型是按文档选择的：一 `L10N.md` `model:` 指定您的
账户模型句柄选择它；否则将使用您的账户的默认模型。

命令行界面故意不进行规划、翻译、验证，
检查或删除生成的翻译。它也不会读取服务器的
翻译锁文件。

## `glossia revisit`

预留用于未来的源语言修订轮次。Rust 命令行
接口当前为此命令返回未实现错误。

```bash
glossia revisit
```
