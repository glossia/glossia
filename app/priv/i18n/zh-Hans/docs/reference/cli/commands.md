## `glossia init`

在当前仓库中创建一个启动的`L10N.md`配置文件。

```bash
glossia init
```

如果`L10N.md`已存在则失败。

## 翻译在服务器上运行

翻译在 Glossia 服务器上运行，不在命令行界面中运行。当发生提交时，
Glossia 从您的`L10N.md`文件规划工作，
使用您的账户配置的模式翻译每个文件，并
打开使用结果的拉取请求。您可以在翻译会话页面上实时监视每个文件和模型的轮次。

模型是逐文档选择的: 一个`L10N.md` `model:`命名您的
账户模型将处理选择；否则使用您的账户默认模型。

命令行界面无意规划、翻译、验证、
检查或删除生成的翻译。它也不读取服务器的
翻译锁文件。

## `glossia revisit`

保留用于未来的源语言修订通过。Rust 命令行
接口当前针对此命令返回未实现错误。

```bash
glossia revisit
```
