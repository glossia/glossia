## `glossia init`

创建一个起始的`L10N.md`配置文件在当前仓库中。

```bash
glossia init
```

失败条件：如果`L10N.md`\` 已存在。

## 翻译在服务端进行

翻译在 Glossia 服务器上运行，而不是在命令行界面中。当提交完成时，
您的`L10N.md`文件，使用
账号配置的模型进行翻译，并生成拉取请求。您
可以在翻译会话页面上实时查看每个文件及模型的交互过程。

模型针对文档进行选择：一个`L10N.md` `model:` 命名为您的
账号模型处理选项指定了它；否则使用您账号的默认模型。

命令行界面故意不规划、不翻译、不验证，
检查或删除生成的翻译。它也不读取服务器的
翻译锁文件。

## `glossia revisit`

预留用于未来的源语言修订阶段。Rust 命令行
接口当前针对此命令返回一个未实现错误。

```bash
glossia revisit
```
