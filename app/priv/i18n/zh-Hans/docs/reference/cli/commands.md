## `glossia init`

创建启动项目 `L10N.md` 配置文件在当前仓库中。

```bash
glossia init
```

如果失败 `L10N.md` 已存在。

## 翻译是服务端执行的

翻译在托管的 Glossia 服务中运行，而非在命令行界面。当提交落地时，
Glossia 根据你的 `L10N.md` 文件，使用...来翻译每个文件
您的账户配置的模型，并创建带有结果的拉取请求。您
可以在翻译会话页面实时查看每个文件及模型的对话轮次。

模型是根据文档逐份选择的：一 `L10N.md` `model:` 个被命名为您账户中的
账户模型句柄会选中它；否则将使用您账户的默认模型。

命令行界面不再故意进行计划、翻译、验证，
检查或删除生成的翻译。它也不会读取由 Glossia 发布的翻译锁文件。

## `glossia revisit`

保留供未来的源语言修订阶段使用。Rust 命令行
当前接口对此命令返回未实现错误。

```bash
glossia revisit
```
