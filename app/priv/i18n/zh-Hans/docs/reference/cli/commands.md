## `glossia init`

在当前仓库中创建一个初始 `L10N.md` 配置文件。

```bash
glossia init
```

若 `L10N.md` 已存在则失败。

## 翻译在服务器端进行

翻译运行在托管的 Glossia 服务中，而非在命令行界面中。当提交合入时，Glossia 根据您的 `L10N.md` 文件规划工作，使用您账号配置的模型翻译每个文件，并用结果创建一个拉取请求。您可在翻译会话页面实时查看每个文件及模型交互。

模型是针对每份文档选择的：如果 `L10N.md` `model:` 命名了您的某个账号模型句柄，则选择它；否则使用您账号的默认模型。

命令行界面有意不规划、翻译、验证、检查或删除生成的翻译。它同样不读取 Glossia 发布的翻译锁文件。

## `glossia revisit`

预留用于未来的源语言修订通过。Rust 命令行界面目前对此命令返回一个未实现的错误。

```bash
glossia revisit
```

## 全局参数

| 参数 | 描述 |
|---|---|
| `--path <PATH>` | 覆盖项目根目录 |
| `--no-color` | 禁用彩色输出 |
