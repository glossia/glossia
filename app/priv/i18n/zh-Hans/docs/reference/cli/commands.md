## `glossia init`

创建初始 `L10N.md` 配置文件在当前仓库中。

```bash
glossia init
```

如果 `L10N.md` 文件已存在，则失败。

## 翻译是在服务端进行

翻译在 Glossia 服务器上运行，而不是在命令行接口中。当提交合入时，
Glossia 基于你的 `L10N.md` 文件规划工作，使用
您的账户配置的模型，并拉取包含结果的开发申请。您可以
在翻译会话页面实时查看所有文件和模型的回合。

模型是根据每个文档选择的：`L10N.md` `model:` 指定您的
账户模型处理的默认指令被选中；否则使用您账户的默认模型。

命令行接口故意不规划、翻译、验证、
检查或删除生成的翻译。它也不会读取服务器的
翻译锁文件。

## `glossia revisit`

预留用于未来的源语言修订轮次。Rust 命令行
接口当前对此命令返回未实现错误。

```bash
glossia revisit
```
