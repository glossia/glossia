## `glossia init`

创建一个起始的`L10N.md`配置文件在当前的仓库中。

```bash
glossia init
```

如果`L10N.md`已存在，则失败。

## 翻译在服务器端执行

翻译在 Glossia 服务器上运行，不在命令行界面中运行。当提交生效时，
Glossia 根据您的`L10N.md`文件规划工作，使用
您账户配置的模型翻译每个文件，并打开带有结果的拉取请求。您
可以随时在翻译会话页面上实时查看每个文件和模型的生成过程。

模型按文档选择：`L10N.md` `model:` 命名您
账户模型处理的选择项，否则使用您账户的默认模型。

命令行界面有意不规划、翻译、验证、
检查或删除生成的翻译。它也不读取服务器
的翻译锁文件。

## `glossia revisit`

保留用于将来源语言修订流程。Rust 命令行
界面对此命令当前返回未实现错误。

```bash
glossia revisit
```
