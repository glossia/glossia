## 0.2.0

*2026-02-14*

#### 错误修复

- 在生产环境中将 OAuth 提供商配置设为可选。即使未设置 GitHub/GitLab OAuth 凭据，应用程序也应正常启动。仅在环境变量存在时才配置提供商。
- 生产环境默认端口为 4000，开发保持 4050。生产代理期望应用程序运行在 4000 端口。该 `runtime.exs` 默认值为 4050，导致部署期间健康检查失败。

#### 功能

- 添加支持 OAuth 登录、文档增强和 UI 改进的 Phoenix 应用程序。
- 使用圆角 Logo 作为网站图标。
- 将 CLI 迁移至 Bun 并更新 CI 可执行构建。
