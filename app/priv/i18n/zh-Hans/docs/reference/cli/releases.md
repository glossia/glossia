## 0.2.0

*2026-02-14*

#### Bug 修复

- 在生产环境中将 OAuth 提供商配置设为可选。即使未设置 GitHub/GitLab OAuth 凭据，应用程序也应能启动。仅在环境变量存在时才配置提供商。
- 生产环境默认端口为 4000，开发环境保持 4050。生产代理期望应用程序运行在 4000 端口。该 `runtime.exs` 默认值曾为 4050，导致部署期间的健康检查失败。

#### 功能

- 添加支持 OAuth 登录的 Phoenix 应用，优化文档和界面。
- 使用圆形 Logo 作为浏览器标签页图标。
- 将 CLI 迁移至 Bun 并更新 CI 可执行构建。
