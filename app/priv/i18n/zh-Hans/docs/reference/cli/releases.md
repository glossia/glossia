## 0.2.0

*2026-02-14*

#### Bug 修复

- 将生产环境中的 OAuth 提供商配置设为可选。应用即使在未设置 GitHub/GitLab OAuth 凭据时也应启动。仅在环境变量存在时才配置提供商。
- 生产环境默认使用 4000 端口，开发环境保持 4050 端口。生产代理期望应用在 4000 端口上。该 `runtime.exs` 默认值为 4050，导致部署期间健康检查失败。

#### 功能

- 新增支持 OAuth 登录的 Phoenix 应用、文档增强及 UI 改进。
- 使用圆角 Logo 作为网站图标。
- 将 CLI 迁移至 Bun 并更新 CI 可执行构建。
