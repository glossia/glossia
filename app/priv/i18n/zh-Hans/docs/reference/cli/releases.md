## 0.2.0

*2026-02-14*

#### 缺陷修复

- 生产环境中使 OAuth 提供商配置可选。即使未设置 GitHub/GitLab OAuth 凭据，应用也应启动。仅在环境变量存在时配置提供商。
- 默认生产环境端口为 4000，开发环境保持 4050。生产代理期望应用在 4000 端口。该 `runtime.exs` 默认值为 4050，导致部署期间健康检查失败。

#### 功能

- 添加支持 OAuth 登录的 Phoenix 应用，增强文档与界面。
- 使用圆形 Logo 作为网站图标。
- 迁移 CLI 至 Bun 并更新 CI 可执行构建。
