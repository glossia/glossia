## 0.2.0

*2026-02-14*

#### Bug Fixes

- 使生产环境中的 OAuth 服务商配置为可选。即使未设置 GitHub/GitLab OAuth 凭证，应用程序也应正常启动。仅当环境变量存在时才配置服务商。
- 生产环境默认使用端口 4000，开发环境保持 4050。生产代理期望应用程序位于 4000 端口。`runtime.exs` 的默认值曾为 4050，导致部署期间健康检查失败。

#### Features

- 添加包含 OAuth 登录、文档增强和 UI 改进的 Phoenix 应用。
- 使用圆角徽标作为网站图标。
- 将 CLI 迁移到 Bun 并更新 CI 可执行文件构建。
