翻译记忆库通常记录以前翻译过的源 - 目标片段。匹配或相似的源片段可以复用之前的工作。这对重复性材料以及保留经过复审的翻译非常有价值。

Glossia 的语言记忆满足另一种需求：即使句子以前从未出现过，也能让新写作听起来像该组织风格的原则。

## 记住输出与记住意图

经过复审的翻译回答了“我们以前是如何翻译这个的？”语气指导和术语表回答了诸如以下的问题：

- 哪些产品术语应保持不变？
- 我们应该使用哪组术语以保持始终如一？
- 哪种语气适合此受众？
- 代理在起草新材料时应尊重哪些语言决定？

这些输入可帮助本地化和源语言的内容创作。它们不仅限于检索匹配的目标片段。

## 补充工具

翻译记忆库和语言指导解决的是重叠但不同的问题。团队可能从中受益。Glossia 不保证模型生成的文本可以取代每一个经过复审的片段，也不保证提示能保证语言正确性。

重要的架构选择不在于将专有记忆库作为公司语言的唯一权威。仓库内容、可重用的上下文、版本历史和复审都有助于构建团队能够理解和维护的流程。

## 上下文仍需复审

指导可能不完整或存在矛盾。某个术语在不同产品中可能有不同含义。人类仍负责决定结果是否准确和适当；验证可以发现结构故障，但不能证明每个句子都是正确的。
