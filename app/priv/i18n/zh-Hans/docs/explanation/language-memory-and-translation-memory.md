翻译记忆库通常会记录之前已翻译过的源目标片段。匹配的或相似的源片段可以复用之前的工作。这对重复性内容以及保留经过审核的译文很有价值。

Glossia 的语言记忆库解决了另一项需求：即使句子以前从未出现过，也要遵循让新写作听起来像该组织风格的原则。

## 记住输出结果与记住意图

经过审核的翻译回答了“我们之前是如何翻译这个的？”声音指引和术语表回答了诸如以下问题：

- 哪些产品术语应保持不变？
- 我们应该使用哪些术语保持一致？
- 什么语调适合这一受众？
- 在起草新材料时，代理人应尊重哪些语言决策？

这些输入内容可协助本地化和源语言的内容创作。它们不仅限于检索匹配的翻译目标片段。

## 互补工具

翻译记忆库和语言指引解决了重叠但不同的问题。团队可以从两者中受益。Glossia 不承诺模型生成的文本可以替换每个经过审核的片段，也不承诺提示能保证语言正确性。

重要的架构选择在于，不将专有记忆库作为公司语言的唯一权威。仓库拥有的内容、可重用的上下文、版本历史以及审核，均为团队可以理解和维护的流程做出了贡献。

## 上下文仍需审核

指引可能不完整或相互矛盾。一个术语在不同产品中可能有不同的含义。人类仍需负责决定结果是否准确和适当；验证可以发现结构性错误，但不能证明每句话都是对的。
