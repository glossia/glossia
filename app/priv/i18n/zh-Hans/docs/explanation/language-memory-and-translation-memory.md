翻译记忆通常记录先前翻译过的源文和目标文片段。匹配或相似的源文片段可以重用之前的工作。这对于处理重复性材料以及保存已审核的翻译很有价值。

Glossia 的语言记忆旨在满足另一种需求：使新撰写的文本听起来符合该组织的风格，即使该句子此前从未出现过。

## 记忆输出与记忆意图

已审核的翻译会回答，“我们以前是如何翻译这段内容的？”语音指导和术语表则回答如下问题：

- 哪些产品术语应保持原样？
- 哪些术语应当保持统一使用？
- 什么语气适合此受众？
- 代理人在起草新内容时应尊重哪些语言决策？

这些输入有助于本地化和源语言的内容创建。它们不仅限于检索匹配的目标片段。

## 互补工具

翻译记忆和语言指导解决的问题虽有重叠但各不相同。团队可能同时从中获益。Glossia 不保证模型生成的文本能取代每一个已审核的片段，也不保证提示词能确保语言正确性。

关键的架构决策在于不让专有记忆成为公司语言的唯一权威。仓库所属内容、可重用上下文、版本历史及审核过程均有助于构建一个团队能够理解并维护的流程。

## 上下文仍需审核

指导可能不完整或相互矛盾。术语在不同产品中可能有不同含义。人类仍需负责判断结果是否准确和恰当；验证可以捕捉结构缺陷，但无法证明每一句话都正确。
