翻译记忆库通常记录以前翻译过的源_目标片段。匹配的或相似的源片段可以重用先前的工作。这对于重复性内容和保存已审查的翻译很有价值。

Glossia 的语言记忆解决了另一种需求：即使句子此前从未出现过，也要让新写作听起来像该组织，即遵循相关的写作原则。

## 回顾输出与回顾意图

已审查的翻译回答了“我们之前是如何翻译这个的？”语气指导和术语表解决了诸如以下问题：

- 哪些产品术语应保持不变？
- 我们要一致使用哪些术语？
- 什么语调适合该受众？
- 代理人在起草新材料时应尊重哪些语言决策？

这些输入有助于本地化以及在源语言中创建内容。它们不仅限于检索匹配的目标准确片段。

## 补充工具

翻译记忆库和语言指导解决的是相互重叠但各自不同的问题。团队可能从中同时受益。Glossia 不承诺模型生成的文本能替换每个已审查的片段，也不承诺提示能保证语言的正确性。

关键的架构选择是不将专有记忆库作为公司语言的唯一权威。仓库所有内容、可重用上下文、版本历史和审查都有助于团队理解和维护的流程。

## 上下文仍需审查

指导可能不完整或相互矛盾。一个术语在不同产品中可能有不同含义。人类仍需负责决定结果是否准确和适当；验证发现结构故障，但不能证明每句话都是正确的。
