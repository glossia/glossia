翻译记忆通常记录以前翻译过的源目标片段。匹配或类似的源片段可以重用先前的工作。这对重复性材料以及保留经过审核的翻译非常有价值。

Glossia 的语言记忆解决了另一项需求：即使句子此前从未出现过，也能使新写作听起来符合组织的原则。

## 记忆输出与记忆意图

已审核的翻译回答，“我们之前是如何翻译这个的？”语音指导和词典解答诸如以下问题：

- 哪些产品术语应保持不变？
- 我们应该使用哪些术语保持一致？
- 什么样的语调适合此受众？
- 代理人在起草新材料时应尊重哪些语言决策？

这些输入有助于本地化及源语言的内容创作。它们不仅限于检索匹配的目标片段。

## 互补工具

翻译记忆和语言指导解决的是重叠但不同的问题。团队可能从中受益。Glossia 不承诺模型生成的文本可以替代每个已审核的片段，也不承诺提示能保证语言的正确性。

关键的架构选择是不要将专有记忆作为公司语言的唯一权威。仓库内容、可重用上下文、版本历史和审核都有助于团队理解与维护的流程。

## 上下文仍需审核

指导可能不完整或相互矛盾。术语在不同产品中可能有不同含义。人类仍负责决定结果是否准确和适当；验证可以捕捉结构失败，但无法证明每句话都是正确的。
