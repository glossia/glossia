%{
  title: "添加新语言",
  summary: "如何向现有 Glossia 设置添加目标语言。",
  category: "how-to",
  order: 1
}
---
如果您已配置 Glossia，并希望添加另一种目标语言，请按照以下步骤操作。

## 1. 更新 GLOSSIA.md

打开您的 `GLOSSIA.md`，并将新的语言代码添加到 `targets` 数组中：

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 添加语言特定的上下文（可选）

如果新语言需要特殊说明，例如正式程度或字符集注意事项，请创建上下文覆盖文件：

```
GLOSSIA/
  ja.md
```

在该文件中写入任何语言特定的指导说明。Glossia 会将其与日语翻译的基础上下文合并。

## 3. 发布配置更改

提交并推送更新后的配置。如果仓库已连接到
Glossia，服务器会检测到新的目标语言并启动翻译
会话。

如果其他语言翻译的输入和有效上下文未发生变化，
其现有翻译将保持不变。

## 4. 审核翻译拉取请求

在 Glossia 中跟踪翻译会话，然后审核服务器创建的拉取请求中
生成的语言文件。
