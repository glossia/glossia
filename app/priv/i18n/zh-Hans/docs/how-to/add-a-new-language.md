如果您已配置了 Glossia 并希望添加另一个目标语言，请按照以下步骤操作。

## 1. 更新 L10N.md

打开您的 `L10N.md` 并将新语言代码添加到 `targets` 数组中：

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 添加特定于语言的上下文（可选）

如果新语言需要特殊说明，例如正式程度或字符集考虑，请创建上下文覆盖文件：

```
L10N/
  ja.md
```

在该文件中编写任何特定于语言的指导。Glossia 会将其与日语翻译的基础上下文合并。

## 3. 发布配置更改

提交并推送更新的配置。如果仓库已连接到 Glossia，服务器将检测新的目标语言并启动翻译会话。

当其他语言的输入和有效上下文未发生变化时，其现有翻译保持不变。

## 4. 审查翻译拉取请求

在 Glossia 中跟踪翻译会话，然后在服务器创建的拉取请求中审查生成的语言文件。
