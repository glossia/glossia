%{title: "重试项目设置", summary: "设置报告失败后恢复项目。", category: "教程", order: 4}
---
使用 **重试配置** 在修复导致项目配置失败的问题后。

## 1\. 查看失败信息

打开项目概览。配置进度卡片会显示失败信息和最新的配置活动。

常见原因包括：

- 账户未配置模型。
- 提供商密钥缺失或已失效。
- Glossia GitHub 应用无法访问此仓库。
- 无法准备或检查此仓库。

## 2\. 修复前置条件

对于模型问题，打开 **设置** 与 **模型**。对于仓库访问问题，请更新 GitHub 上的 Glossia GitHub 应用安装，并授予其访问此仓库的权限。

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回至 **待处理**，然后 **运行中**, 并随着工作进展显示新活动。重试仅在项目处于 **失败** 状态，这防止了两次设置尝试同时运行。

## 4\. 审查完成

当状态变为 **完成**, 审查由此产生的 GitHub 拉取请求。如果再次失败，请使用卡片中的最新活动而非之前的尝试来确定下一步操作。
