%{title: "重试项目设置", summary: "在设置报告失败后恢复项目。", category: "教程", order: 4}
---
使用 **重试设置** 修复导致项目设置失败的条件后。

## 1\. 查看失败信息

打开项目概览。设置进度卡片显示失败信息和最新的设置活动。

常见原因包括：

- 该账户未配置模型。
- 提供商密钥缺失或已失效。
- Glossia GitHub 应用无法访问该仓库。
- 无法准备或检查该仓库。

## 2\. 修复先决条件

对于模型问题，打开 **设置** 和 **模型**。

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回至 **待处理**, 然后 **运行中**, 并随着工作进行显示新活动。重试仅在项目处于 **失败** 状态，这会阻止两次设置尝试同时运行。

## 4\. 完成审核

当状态变为 **已完成**, 在 GitHub 上审核生成的拉取请求。如果再次失败，请使用卡片中的新活动而非先前的尝试，以确定下一步操作。
