%{title: "重试项目设置", summary: "设置失败后恢复项目", category: "教程", order: 4}
---
使用 **重试设置** 修复导致项目设置失败的条件后。

## 1\. 查看失败

打开项目概览。设置进度卡显示失败信息和最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 提供者密钥缺失或已无效。
- Glossia GitHub App 无法访问该仓库。
- 仓库无法准备或检查。

## 2\. 修复前置条件

模型问题请打开 **设置** 和 **模型**。对于仓库访问问题，请更新 GitHub 上的 Glossia GitHub App 安装，并授权其访问该仓库。

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回至 **待处理**, 然后 **运行中**，并随着工作进展显示新的活动。重试仅在项目处于 **失败** ，状态，这阻止了两次设置尝试同时运行。

## 4\. 完成审查

当状态变更为 **完成**，请查阅 GitHub 上生成的拉取请求。如果再次失败，请使用卡片中的新活动而非上一次尝试来确定下一步操作。
