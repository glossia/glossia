%{title: "重试项目设置", summary: "设置报告失败后恢复项目。", category: "教程", order: 4}
---
在修复导致项目设置失败的条件后，使用 **重试设置**。

## 1\. 查看失败

打开项目概览。设置进度卡片显示失败信息和最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 提供商密钥缺失或不再有效。
- Glossia GitHub App 无法访问仓库。
- 仓库无法准备或无法检查。

## 2\. 修复前置条件

针对模型问题，打开 **设置** 和 **模型**。针对仓库访问问题，在 GitHub 上更新 Glossia GitHub App 安装并授予其对仓库的访问权限。

## 3\. 重试

返回项目概览并选择 **重试设置**。

卡片返回 **等待中**，然后 **运行中**，并显示新活动。重试仅在项目处于 **失败** 状态时可用，这防止了两个设置尝试同时运行。

## 4\. 审阅完成

当状态变为 **已完成** 时，在 GitHub 上审阅生成的拉取请求。如果它再次失败，请使用卡片中的新活动而非之前的尝试来确定下一步操作。
