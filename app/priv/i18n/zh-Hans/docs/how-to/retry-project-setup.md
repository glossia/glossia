在修复导致项目设置失败的条件后，使用 **重试设置**。

## 1\. 查看失败信息

打开项目概览。设置进度卡显示失败情况及最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 缺少提供程序密钥或其已无效。
- Glossia GitHub App 无法访问仓库。
- 仓库无法准备或检查。

## 2\. 修复先决条件

对于模型问题，打开 **设置** 和 **模型**。对于仓库访问问题，在 GitHub 中更新 Glossia GitHub App 的安装并允许其访问该仓库。

## 3\. 重试

返回项目概览并选择 **重试设置**。

卡片会回到 **待处理**，然后变为 **运行中**，并随工作进展显示新的活动。仅在项目处于 **失败** 状态时提供重试，这防止了两个设置尝试同时运行。

## 4\. 查看完成情况

当状态变为 **已完成** 时，在 GitHub 中查看生成的拉取请求。如果再次失败，请使用卡片中的新活动而非上次的尝试来确定下一步操作。
