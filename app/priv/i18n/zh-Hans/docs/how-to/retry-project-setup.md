---
使用 **重试设置** 在修复导致项目设置失败的条件后。

## 1\. 查看失败信息

打开项目概览。设置进度卡片显示失败信息和最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 提供商密钥缺失或已无效。
- Glossia GitHub App 无法访问仓库。
- 仓库无法准备或检查完成。

## 2\. 修复前置条件

针对模型问题，打开 **设置** 和 **模型**。若遇仓库访问问题，请在 GitHub 上更新 Glossia GitHub App 安装，并授权其访问该仓库。

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回至 **等待中**, 然后 **运行中**, 并随着工作进展显示新活动。仅在项目处于 **失败** 状态，防止同时运行两次设置尝试。

## 4\. 检查完成情况

当状态变为 **完成**, 审查 GitHub 生成的拉取请求。如果再次失败，请在卡片中的新活动而非上一次尝试中确定下一步操作。
