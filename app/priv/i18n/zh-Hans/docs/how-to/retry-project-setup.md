%{title: "重试项目设置", summary: "设置报告失败后，恢复项目。", category: "教程", order: 4}
---
使用 **重试设置** 在修复导致项目设置失败的条件后。

## 1\. 查看失败信息

打开项目概览。设置进度卡片显示失败情况和最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 提供商密钥缺失或已失效。
- Glossia GitHub 应用无法访问仓库。
- 无法准备或检查仓库。

## 2\. 修复前置条件

对于模型问题，打开 **设置** 和 **模型**.

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回到 **等待中**, 然后 **运行中**, 并随着工作推进显示新活动。重试仅在项目处于 **失败** 状态，防止两个设置尝试同时运行。

## 4\. 查看完成

当状态变为 **已完成**, 在 GitHub 上查看生成的拉取请求。如果再次失败，请使用卡片中的新活动而非之前的尝试以确定下一步操作。
