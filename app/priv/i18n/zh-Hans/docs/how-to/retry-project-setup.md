%{title: "重试项目设置", summary: "设置失败后恢复项目", category: "操作指南", section: "翻译", order: 4}
---
使用 **重试设置** 在修复导致项目设置失败的问题后。

## 1\. 查看失败

打开项目概览。设置进度卡片显示失败情况和最新的设置活动。

常见原因包括：

- 账户未配置模型。
- 提供商密钥缺失或已失效。
- Glossia GitHub App 无法访问该仓库。
- 该仓库无法准备或检查。

## 2\. 修复前置条件

对于模型问题，打开 **设置** 和 **模型**. 对于仓库访问问题，更新 GitHub 中的 Glossia GitHub App 安装并授予其访问该仓库的权限。

## 3\. 重试

返回项目概览并选择 **重试设置**.

卡片返回至 **待处理**，然后 **运行中**, 并随着工作推进显示新活动。重试仅在项目处于 **失败** , 状态，这会阻止两个设置尝试同时运行。

## 4\. 审查完成情况

当状态变为 **已完成**, 审查生成的 GitHub 拉取请求。如果再次失败，请使用卡片中的新活动而不是前一次尝试来帮助确定下一步操作。
