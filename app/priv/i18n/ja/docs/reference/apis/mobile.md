パブリックなネイティブ・アピアランス・カタログ以外のすべてのエンドポイントには、ビアラートークンを必要とします。[OpenAPI 仕様書](/api/openapi.json) に完全なスキーマが記載されています。既存の[OAuth PKCE フロー](/docs/reference/apis/authentication)を使用してトークンを取得してください。クライアントに推論プロバイダーキーを埋め込まないでください。

## 認可

| エンドポイント | トークンスコープ |
|---|---|
| `GET /api/native/themes` | なし（パブリックなアピアランスメタデータ） |
| `GET /api/me` | `user:read` |
| `GET /api/:handle/projects/:project/translations` | `translation:read` |
| `GET /api/:handle/projects/:project/translations/:id` | `translation:read` |
| `GET /api/:handle/projects/:project/analytics` | `analytics:read` |
| `GET /api/:handle/projects/:project/toki/conversations` | `toki:read` |
| `POST /api/:handle/projects/:project/toki/conversations` | `toki:write` |
| `GET /api/:handle/projects/:project/toki/conversations/:id` | `toki:read` |
| `POST /api/:handle/projects/:project/toki/conversations/:id/messages` | `toki:write` |

トークンスコープは上限であり、権限付与ではありません。各プロジェクトエンドポイントでは、ユーザーのプロジェクト読み取り権限も確認されます。`project:read` 第 2 の**トークン** スコープは必要ありませんが、明示的な権限を持つ組織メンバーシップは、プロジェクト読み取りと要求された機能の双方を許可する必要があります。新しいメンバーシップにはこれらのモバイル機能が含まれますが、既存の明示的なメンバーシップは自動的に拡張されません。

個人プロジェクトは、既存の個人・組織のメンバーシップルールに従います。アカウントの可視性が公衆プロジェクトの読み取りを制御していますが、必要なスコープを持つ認証された外部ユーザーは、公衆プロジェクトの翻訳アクティビティや分析を読むことができます。Toki の書き込みにはアカウントメンバーシップが必要であるため、公衆の可視性だけではアカウントの推論クレジットを使育しません。Toki の会話は、公衆アカウントであっても、プロジェクト内では作成ユーザーにのみプライバシーが保持されます。組織管理者やプラットフォーム管理者は、他のユーザーの会話を読むことはできません。会話 UUID を知っていること自体がアクセスを許可するものではありません。

## ネイティブ・アピアランス

`GET /api/native/themes` は、選択された Glossia サーバーからのインスタンス全体アピアランスメタデータを返し、認証やユーザー/プロジェクトデータは含まれません。レスポンスには`Cache-Control: public, max-age=300`が含まれます。これは、いずれかのプロジェクトエンドポイントの認証権限に変更を加えません。

レスポンスには 4 つの必須フィールドがあります:

| フィールド | 値 |
|---|---|
| `schema_version` | 整数`1` |
| `revision` | ブランクではないコンテンツリビジョン、最大 128 文字 |
| `default_theme_id` | `"glossia"` |
| `themes` | デフォルトの Glossia テーマを含む配列 |

デフォルトテーマは`id: "glossia"`、`name: "Glossia"`、ブランクでない`description`、`typography: "standard"`、`button_radius: 8`、`card_radius: 12`、`light`、および`dark`のカラーパレットを含んでいます。半径は数値論理ピクセルです。各パレットは以下のすべての 9 つのフィールドを含み、不透明`#RRGGBB`カラーとして表現されます:

| 顔色項目 | ライト | ダーク |
|---|---|---|
| `background` | `#FAF8F5` | `#1C1917` |
| `surface` | `#FFFFFF` | `#2A2621` |
| `subtle` | `#F2EFE9` | `#2A2621` |
| `text` | `#1C1917` | `#FAF8F5` |
| `secondary_text` | `#5C564E` | `#D1CDC5` |
| `border` | `#E4E0D9` | `#3D3833` |
| `accent` | `#6D3CC4` | `#D0BCFF` |
| `on_accent` | `#FFFFFF` | `#381E72` |
| `tint` | `#6D3CC4` | `#D0BCFF` |

カタログは、`app/priv/static/assets/styles.css`に含まれた規範的な`:root`カラーと半径トークンからコンパイルされます。ダークパレットはネイティブ専用セマンティックトークンを使用し、Web ランディングを変更しません。トークンの変更後のリビルドは、カタログとその決定論的改元を更新します。改元はカタログコンテンツをカバーし、関連しないスタイルシートの変更は含みません。ユーザーごとの設定や実行時のテーマ設定は含まれません。

## プロフィール

`GET /api/me` は認証ユーザーのプロフィールのみを返します:

```json
{
  "user": {
    "id": "30c92fe9-4477-4ba6-ae0a-0d874f9ff650",
    "name": "Alex Chen",
    "email": "alex@example.com",
    "handle": "alex"
  },
  "server_version": "0.1.0"
}
```

`name` は`null`であることがあります。ハンドルは選択された組織ではなく、ユーザーの個人アカウントに属しています。`server_version`は実行中のアプリケーションのバージョンです。

## ページネーション

翻訳と会話リストは`page`（デフォルト`1`、範囲`1–10000`）および`page_size`（デフォルト`20`、範囲`1–50`）を受け入れます。無効な値は`400`を返し、静かに制限する代わりに。メタデータは他の Glossia API リストと同じ形式を使用します:

```json
{
  "total_count": 23,
  "total_pages": 2,
  "current_page": 1,
  "page_size": 20,
  "has_next_page?": true,
  "has_previous_page?": false
}
```

リストはフローズンスナップショットではなく、現在のステータスを反映します。会話がソートされる順序は、最も最近更新されたものが最初の優先で、UUID は決定論的タイブレーカーとして使用されます。

## 翻訳アクティビティ

`GET /api/:handle/projects/:project/translations?page=1`は返します:

```json
{
  "sessions": [{
    "id": "e4183cef-2b43-42a8-a60f-78b4fbb02bbf",
    "status": "completed",
    "commit_message": "Update installation guide",
    "source_language": "en",
    "target_languages": ["es", "ja"],
    "translated_content_count": 8,
    "inserted_at": "2026-10-25T10:00:00Z",
    "summary": "Translated eight documents."
  }],
  "meta": {"total_count": 1, "total_pages": 1, "current_page": 1, "page_size": 20, "has_next_page?": false, "has_previous_page?": false}
}
```

ステータスは`pending`、`running`、`completed`、`failed`、または`cancelled`です。コミットメッセージ、ソース言語、および概要は、作業が待機中または利用できない間は`null`であることがあります。結果は最新優先で、指示されたプロジェクトにのみ制限されます。

`GET /api/:handle/projects/:project/translations/:id` は`{session: {...}}`を返し、リストセッションフィールドと オプション`commit_sha`を含みます。これは、指示されたプロジェクトとアカウント内での直接、正確な UUID ロックアップであり、ページネーションやセッションの年齢に依存しません。不正、不足、および外プロジェクト ID は`404`を返し、`error: "not_found"` を含む認証とプロジェクト認証が最初に行われます(`401`/`403`)。このリソースを開くことは、会話を決して作成せず、メッセージを決して送信せず、推論を決して開始しません。それは**セッションサマリーレベルの元データ**を提供しますが、翻訳されたセグメントテキストまたは翻訳出力のレビューではありません。

## 分析

`GET /api/:handle/projects/:project/analytics?days=30`は返します:

```json
{
  "summary": {
    "pageviews": 1350,
    "unique_visitors": 900,
    "locale_gap_visits": 180,
    "top_country": "DE",
    "top_browser_language": "de"
  },
  "top_pages": [{"pathname": "/docs", "pageviews": 420}],
  "days": 30
}
```

`days` は`30`がデフォルトであり、`1`から`365`までの整数でなければなりません。ローリング UTC レポートウィンドウはリクエスト時の時点で終了します。これらは、ダッシュボードのプロジェクトスコープ ClickHouse 集計と同じであり、日次回転の訪者識別子を含むものです。トップページリストは最多 10 件のエントリを含みます。空データセットはゼロ数を返し、空のトップ値文字列、および空ページリストを返し、スキャン失敗は`503`と`error: "analytics_unavailable"`を返し、決してゼロメトリクスの発明を行いません。

## Toki 会話

### 作成とリスト

`POST /api/:handle/projects/:project/toki/conversations` はクライアント生成 UUID を受け入れます:

```json
{"id": "52a3b55c-c2db-4b3f-a83f-d7d3542ae46b"}
```

`201` は`{conversation, messages: []}`を返し、空会話はタイトル`New conversation`とステータス`completed`（アイドル、生成中ではない）を持ちます。同じアクター、プロジェクト、およびソースでの同じ UUID を再生するのは、既存の詳細を返します。別のアクター、プロジェクト、またはソースでの再使用は`409`と`error: "id_conflict"`を返します。

`GET /api/:handle/projects/:project/toki/conversations` は`{conversations: [...], meta: {...}}`を返します。会話は`id`、`title`、`status`、`updated_at`、オプショナル`error`、およびオプショナル`translation_session_id`を含みます。タイトルは最初のユーザーメッセージから派生し、2 番目のモデルコールから派生するものではありません。

### 翻訳ースケ

作成はオプションで、同じプロジェクトの翻訳セッション UUID を受け入れます:

```json
{
  "id": "52a3b55c-c2db-4b3f-a83f-d7d3542ae46b",
  "translation_session_id": "e4183cef-2b43-42a8-a60f-78b4fbb02bbf"
}
```

元は不変であり、省略と`null` はどちらも元が存在しないことを意味します。再生は元を常に提供する必要があります。メッセージ送信後でも同様です。後で元を付加したり、再生で削除したりすることはできません。不正な元は`422` を返します。不足しているか外部プロジェクトのソースは`404` を返します。ソース連結作成には、`translation:read` トークン スコープと現在のポリシー権限、`toki:write` とプロジェクト読み取り権限が必要です。クライアントが提供するソースサマリー、メタデータ、ロール、および所有権は無視されます。UUID のみが保持され、サーバーは応答時にその認証コンテキストを解決します。

**Source-linked conversations fail closed**、したがって UUID をマスキングするだけでなく：現在の`translation:read` スコープまたはポリシー権限がない場合、詳細、一致する元作成再生、メッセージ送信、およびメッセージ再生は`403` を返します。不一致な元は`409` を返し、履歴やソースメタデータを返しません。リストは、タイトルとページネーションカウントへの貢献を含む、ソース連結の全会話を省略します。これにより、ソースを言及する可能性のある以前のアシスタントメッセージが保護されます。欠落スコープには通常の`WWW-Authenticate` チャレンジが含まれます。リンクされていない会話はその既存の Tokyo 専用認可スコープを維持します。

削除または移動されたソースも、失敗時に閉じます：ソース連結詳細、送信、および一致する作成再生は`404` を返し、リストは会話を省略します。不変の UUID はソース削除後に格納されるため、再生が静かにリンク解除になることはありません。参照はカスケード的外鍵を持たず、すべての使用ケースは現在のソース存在とその正確なプロジェクト/アカウントをチェックします。ソース参照はアクセス権を与えたり、ボイス、用語集、または共有コンテキストを変更したりすることはできません。

ソース連携会話の作成または開始は、メッセージの送信または推論のキュー入行を**しない**。ネイティブナビゲーションは翻訳詳細を最初に取得し、明示的なユーザー操作のみが会話を作成し、明示的なメッセージ提出がターンを開始する。提案公開や共有ディスカッションレビュー、エージェントライティングツールの提供はありません。

### 送信とポーリング

`POST /api/:handle/projects/:project/toki/conversations/:id/messages` は独立したクライアント生成 **メッセージ** UUID を受け入れます:

```json
{"id": "17c3b189-80f0-4382-b7bb-1305b1db70ad", "content": "Which translations have completed?"}
```

リクエストはユーザーメッセージと Oban ジョブを単一のデータベーストランザクションに保持します。モデルを呼び出さないか。返り値は`202` インターコンネクション状態`queued` と現在のメッセージを meliputi。状態が `queued` または`running` ときはポーリング `GET /api/:handle/projects/:project/toki/conversations/:id` を；`completed` または`failed` で停止。

詳細レスポンスは次の形状を有します:

```json
{
  "conversation": {
    "id": "52a3b55c-c2db-4b3f-a83f-d7d3542ae46b",
    "translation_session_id": null,
    "title": "Which translations have completed?",
    "status": "queued",
    "updated_at": "2026-10-25T10:00:00Z",
    "error": null
  },
  "messages": [{
    "id": "17c3b189-80f0-4382-b7bb-1305b1db70ad",
    "role": "user",
    "content": "Which translations have completed?",
    "inserted_at": "2026-10-25T10:00:00Z"
  }]
}
```

メッセージはロール `user` または`assistant` を有し、時系列です。会話は最多 100 メッセージを保持するため、詳細エンドポイントは追加ページリクエストなしでその全有界履歴を返します。

同じ内容のメッセージ UUID 再生は、完了または失敗後を含む他の推論を最新のキューに入れません。確定再生は`200` を返します；待機中再生は`202` を返します。異なる内容または別の会話で UUID を再利用すると`409` を返します。ターンアクティブ中に別のメッセージ提出は`409` に`error: "conversation_busy"` を返します。

### モデル動作と制限

- 各ユーザーメッセージは空白でないテキストで、最多 8,000 キャラクターおよび 32,000 UTF-8 バイトです。無効 UUID、タイプ、または内容が定義されると`422` が返ります。
- 各ユーザーはプロジェクトあたり最多 100 会話、プロジェクト全体で 5 つのキュー中/実行中会話を持ち得ます。5 つ以上の待機ターンは`429` を返し、会話/履歴制限は`422` を返します。
- 新しいメッセージはサーバーあたりユーザーあたり 1 時間 30 件に制限されます、通常の API レート制限に加え再生は推論クォータを消費しません。
- 専用 Oban キューはサーバーあたり 2 個対二次同時に実行されます。各ターンは最大 1 つプロバイダー HTTP リクエストを生成します：ReqLLM がプロバイダーリクエストを準備し、Oban ワーカーはプロバイダー接続後に HTTP リトライとリダイレクト無効化で同期実行します。Condukt セッション、着いた推論タスク、ツール、サブエージェント、またはファイルシステム指示読み込みは関与しません。プロバイダーは 2,048 出力トークンの天井を受信します；アシスタントレスポンスも主なが 8,000 キャラクターおよび 32,000 バイトに制限されます。
- HTTP 接続およびプール待機は 5 秒に制限され、ソケット受信待機は 60 秒に制限されます。Oban ワーカーは 90 秒間の硬壁クロック期限を含み、滴下レスポンスも込めます。ワーカー終了はローカル推論実行も終了します。断線は既にリモートプロバイダーに受け入れられた計算のキャンセルを保証できません、なので曖昧な失敗は決して自動で再試行されません。
- モデルは有界プロジェクトメタデータと、両方最大の 3 直近翻訳サマリーを受信します、トークンと現在のメンバーシップが`translation:read` を許可する場合。最後の 10 会話切り取りは独立して有界されます。書き込み機能または一般的なリポジトリアクセスはなく、分析モデルには提供されません。
- ソース連結会話の場合、モデルは正確に保持されたソースをさらに受信します、たとえ最新ではない：UUID、ステータス、コミットメタデータ、言語、カウント、および最多 1,000 サマリー文字。コンテキストは `provenance: "session_summary"` でラベル付けられ、プロンプトはサマリーレベル制限を報告します。セグメントテキスト、リポジトリファイル、またはクライアント提供ソースコンテキストは読み込まれません。
- クレデンシャルはアカウントの既存生成モデルおよびサーバー推論構成を解き明かします。インタラクティブ CLI/OAuth セッションは Toki に使用されません。欠落またはサポート外クレデンシャルは `failed` のステータスで`error: "provider_unavailable"` を生成します。
- プロバイダー失敗は`inference_failed` を生成します；空またはサイズオーバー出力は`invalid_provider_response` を生成します。生プロバイダーエラーおよびシークレットは返しません。失敗には合成アシスタントレスポンスは挿入されません。
- アカウント/プロジェクトアクセスおよびソース存在、プロジェクト/アカウント関連、および翻訳認証は推論前と後に再度チェックされます。撤回されたアクセスまたは不足キュー済みスコープはターンを `not_authorized` で失败します；削除または移動されたソースは`source_unavailable` で失敗します。いずれの失敗にもアシスタントレスポンスは保存されません。
- リカバリージョブは毎分実行され、2 分以上経過している実行中の作業、または 15 分以上経過しているキューされた作業を `failed` のステータスおよび `inference_interrupted` としてマークします。これにより、タイムアウト、終了、および孤立したジョブは、推論の再試行なしに解決されます。遅延されたジョブは、失効したメッセージを処理することも、新しいターンを上書きすることもできません。ユーザーは失敗後に意図的に **new** メッセージ UUID を送信することができます。

## エラー

`401` は認証失敗を意味します。`403` はスコープまたはリソースポリシーによるアクセス拒否を意味します；不足スコープには `WWW-Authenticate` チャレンジが含まれます。不明なプロジェクトと外部/プライベート会話 UUID は `404` を返します。バリデーションは `422` を使用し、ページネーションは `400` を使用し、UUID/バジー衝突は `409` を使用し、クォータ枯渇は `429` を使用します。
