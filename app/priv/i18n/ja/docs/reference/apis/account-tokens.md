アカウント トークンは、完全な OAuth フローを経由せずに API リクエストを認証するための簡単な方法を提供します。スクリプト、CI/CD パイプライン、および個人用の自動化に最適です。

## トークンの作成

1. Glossia にサインインし、アカウントダッシュボードへ移動します。
2. 「を開く **API** サイドバーのセクションを。
3. クリック **アカウント トークン**, 次に **新しいトークン**.
4. トークンに説明的な **名前** (例「CI deploy」または「CLI access」)。
5. スコープを **指定** トークンに必要な最小限の権限のみ付与してください。
6. 設定する **有効期限** または永続的なトークンの場合は空白のままにしておきます。
7. クリック **トークンを作成**。

作成後、トークンの完全な値が表示されます。 **一度**. コピーし、直ちに安全に保存してください。その後、完全な値を再度表示することはできません。

## トークンの使用

トークンを `Authorization` HTTP リクエストのヘッダーに含める：

    Authorization: Bearer glsa_abc123def456...

例えば、使用する `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

アカウントトークンは同様です。 [認可モデル](/docs/reference/apis/authentication) OAuth トークンと同様です。トークンのスコープは実行可能なアクションの最大セットを定義し、アカウントの関係に基づいてリソースレベルのポリシーも引き続き適用されます。

## トークン形式

すべてのアカウントトークンは `glsa_` プレフィックスにランダムな十六進数文字列が続きます。このプレフィックスにより、ログやシークレット スキャナーで Glossia トークンを識別するのが容易になります。

## スコープ

アカウントトークンは OAuth トークンと同じスコープをサポートします。詳細を [スコープ リファレンス](/docs/reference/apis/authentication) 完全なリストについては。

トークンの作成時に、利用ケースに応じて必要なスコープのみを選択してください。例えば：

- 読み取り専用の連携には、 `project:read` および `voice:read`。
- プロジェクトを作成する CI パイプラインには、 `project:read` および `project:write`。
- 組織メンバーを管理するスクリプトは必要です `members:read` および `members:write`、

## トークンの管理

### トークンの表示

本 **アカウント トークン** ページにはアクティブなトークンの名前、スコープ、最終使用日、および有効期限が表示されます。一度も使用されなかったトークンは、最終使用列に "Never" と表示されます。

### トークンの編集

トークンの名前をクリックして、その **名前** および **説明**。スコープと有効期限は作成後に変更できません。異なるスコープが必要な場合は、新しいトークンを作成し、古いものを無効化してください。

### トークンの無効化

トークンを無効化するには、クリック **無効化** トークンリスト上に表示されている、またはトークンの編集ページを開き、 **トークンの無効化** ボタンです。無効化されたトークンは直ちに機能しなくなり、元に戻すことはできません。

## セキュリティベストプラクティス

- **トークンを安全に保管してください。** 環境変数またはシークレットマネージャーを使用してください。トークンをソース管理に決してコミットしないでください。
- **短期間有効のトークンを使用してください。** 可能であれば有効期限を設定してください。
- **スコープを最小限にしてください。** トークンが実際に必要な権限のみを付与してください。
- **定期的にローテーションを行ってください。** スケジュールに従って新しいトークンを作成し、古いトークンを消去してください。
- **使用状況を監視してください。** 「最後に使用された」日付を定期的に確認してください。使用されていないトークンを消去してください。
- **各統合ごとに 1 つのトークンを使用してください。** この方法では、1 つのトークンを取り消しても他のワークフローには影響しません。

## API 管理

アカウントトークンには、REST API および MCP サーバーを通じて管理することもできます。

### REST API

| メソッド | エンドポイント | 説明 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | アクティブなトークンの一覧 |
| `POST` | `/api/tokens` | トークンの作成 |
| `DELETE` | `/api/tokens/:id` | トークンの失効 |

### MCP

MCP サーバーは公開しています `list_tokens`, `create_token`、かつ `revoke_token` REST API を反映するツール。
