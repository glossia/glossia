アカウントトークンは、フルの OAuth フローを介さずに API リクエストを認証するためのシンプルな方法を提供します。スクリプトや CI/CD パイプライン、個人の自動化にも適しています。

## トークンの作成

1. Glossia にサインインし、アカウントダッシュボードに移動してください。
2. 開く **API** サイドバーのセクション。
3. クリック **アカウントトークン**", 次に **新しいトークン**.
4. トークンに分かりやすい **名前** （例："CI deploy" または "CLI access"。）
5. 指定する **スコープ** トークンに必要なものです。最低限必要な権限のみ付与してください。
6. 設定 **有効期限** または期限切れしないトークンのために空のままにしてください。
7. クリック **トークンを作成**.

作成後、完全なトークン値が表示されます **一度**. 即座にコピーし、安全に保管してください。その後、完全な値は再度表示されません。

## トークンの使用

トークンを `Authorization` HTTP リクエストのヘッダーに:

    Authorization: Bearer glsa_abc123def456...

例えば、 `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

アカウントトークンは同じ [認証モデル](/docs/reference/apis/authentication) OAuth トークンとして。トークンのスコープは、実行可能なアクションの最大セットを定義し、アカウントの関係に基づくリソースレベルのポリシーも引き続き適用されます。

## トークン形式

すべてのアカウントトークンは `glsa_` プレフィックスに続いてランダムな 16 進文字列が続きます。このプレフィックスは、ログやシークレットスキャナーで Glossia トークンを識別しやすくします。

## スコープ

アカウントトークンは OAuth トークンと同様のスコープをサポートします。詳細は [スコープの参照](/docs/reference/apis/authentication) 完全な一覧については。

トークンを作成する際は、ユースケースに必要なスコープのみを選択してください。例:

- 読み取り専用インテグレーションには `project:read` と `voice:read`.
- プロジェクトを作成する CI パイプラインには `project:read` と `project:write`.
- 組織メンバーを管理するスクリプトは必要です `members:read` および `members:write`。

## トークンの管理

### トークンの表示

この **アカウントトークン** ページはすべての有効なトークンの名前、スコープ、最終使用日付、および有効期限をリストします。一度も使用されたことのないトークンは、最終使用列に"未使用"を表示します。

### トークンの編集

トークンの名前をクリックして、その **名前** と **説明**。スコープと有効期限は作成後に変更できません。異なるスコープが必要な場合は、新しいトークンを作成し、古いトークンを取消してください。

### トークンの取消

トークンを取消するには、クリック **リボーク** トークン一覧から、またはトークンの編集ページを開いて **リボーク** のボタンを使用してください。リボークされたトークンは直ちに機能停止し、復元できません。

## セキュリティのベストプラクティス

- **トークンを安全に保管してください。** 環境変数またはシークレットマネージャーを使用してください。トークンはソース管理にコミットしないでください。
- **短期有効のトークンを使用してください。** 可能であれば、有効期限を設定してください。
- **スコープを最小限にしてください。** トークンに実際に必要な権限のみを付与してください。
- **定期的に更新してください。** スケジュールに従って新しいトークンを作成し、古いトークンを無効化してください。
- **使用状況を監視してください。** 「最終使用日」を定期的に確認し、使用していないトークンを無効化してください。
- **各連携には、1 つのトークンを使用してください。** このようにして、1 つのトークンを無効化しても他のワークフローは壊されません。

## API 管理

また、REST API および MCP サーバーを通じて、アカウントトークンの管理も行うことができます。

### REST API

| メソッド | エンドポイント | 説明 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | アクティブなトークンの一覧を表示 |
| `POST` | `/api/tokens` | 新しいトークンを作成する |
| `DELETE` | `/api/tokens/:id` | トークンを無効化する |

### MCP

MCP サーバーは公開しています、 `list_tokens`、 `create_token`および `revoke_token` REST API を鏡像化するツールです。
