アカウントトークンは、完全な OAuth フローを経由せずに API リクエストを認証する簡単な方法を提供します。スクリプト、CI/CD パイプライン、および個人的な自動化に最適です。

## トークンの作成

1. Glossia にサインインし、アカウントダッシュボードに移動します。
2. 開く **API** サイドバーのセクション。
3. クリック **アカウントトークン**、次に **新しいトークン**.
4. トークンに説明的な **名前** （例えば、"CI deploy" または "CLI access"）。
5. スコープを **選択** トークンに必要なものです。必要最小限の権限のみ付与してください。
6. 有効期限を **指定** また、永続トークン用の場合は空欄のままにしてください。
7. クリック **トークンの作成**。

作成後、完全なトークン値が表示されます。 **一度**. すぐにコピーして安全に保存してください。その後、完全な値はもう表示されなくなります。

## トークンの使用

トークンを `Authorization` HTTP リクエストのヘッダーに含める:

    Authorization: Bearer glsa_abc123def456...

例えば、次のように `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

アカウントトークンは同様の [認証モデル](/docs/reference/apis/authentication) OAuth トークンとして機能します。トークンのスコープは、そのトークンが実行できるアクションの最大セットを定義し、リソースレベルのポリシーは引き続きあなたのアカウント関係に基づいて適用されます。

## トークン形式

すべてのアカウントトークンは `glsa_` プレフィックスにランダムな 16 進数文字列が続きます。このプレフィックスにより、ログやシークレットスキャナーで Glossia トークンを識別しやすくします。

## スコープ

アカウントトークンは OAuth トークンと同じスコープをサポートします。以下の [スコープ リファレンス](/docs/reference/apis/authentication) 完全なリストについては。

トークンを作成する際は、ユースケースに必要なスコープのみを選択してください。例えば：

- 読み取り専用連携には `project:read` と `voice:read`。
- プロジェクトを作成する CI パイプラインには `project:read` と `project:write`.
- 組織メンバーを管理するスクリプトには `members:read` および `members:write`。

## トークンの管理

### トークンの表示

この **アカウント トークン** ページには、アクティブなすべてのトークンの名前、スコープ、最終使用日、有効期限が表示されます。未使用のトークンは、最終使用日カラムに「Never」を表示します。

### トークンの編集

トークンの名前をクリックして、その **名前に** と **説明**. スコープと有効期限は、作成後に変更できません。異なるスコープが必要な場合は、新しいトークンを作成し、古いトークンを無効化してください。

### トークンの無効化

トークンを無効化するには、クリック **取消** トークン一覧上、またはトケンの編集ページを開いて **トークンの取消** 危険領域のボタンです。取消されたトークンは直ちに停止し、復元できません。

## セキュリティベストプラクティス

- **トークンを安全に保管** 環境変数またはシークレットマネージャーを使用してください。トークンはソースコントールにコミットしないでください。
- **有効期限が短いトークンを使用** 可能な限り有効期限を設定してください。
- **スコープを最小限に抑えてください。** トークンに必要な権限のみを付与してください。
- **定期的に更新してください。** スケジュールに基づいて新規トークンを作成し、古いトークンを無効化してください。
- **利用状況を確認してください。** "最終使用日"を定期的に確認し、使用されていないトークンを無効化してください。
- **各統合に 1 つのトークンを使用してください。** このように、1 つのトークンを無効化しても他のワークフローには影響しません。

## API 管理

さらに、REST API および MCP サーバーを通じてアカウントトークンを管理することも可能です。

### REST API

| メソッド | エンドポイント | 説明 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | 有効なトークンの一覧 |
| `POST` | `/api/tokens` | 新しいトークンを作成 |
| `DELETE` | `/api/tokens/:id` | トークンを無効化する |

### MCP

MCP サーバーは公開しています `list_tokens`, `create_token`, および `revoke_token` REST API と同様の機能を備えたツール。
