アカウントトークンは、完全な OAuth フローを介さずに API リクエストを認証する簡単な方法を提供します。スクリプト、CI/CD パイプライン、および個人の自動化に最適です。

## トークンの作成

1. Glossia にサインインし、アカウントダッシュボードに移動します。
2. 開く **API** サイドバーにあるセクション。
3. クリック **アカウントトークン**、次に **新しいトークン**。
4. トークンに説明可能な **名前** (例：\\"CI deploy\\" または \\"CLI access\\")。
5. スコープを選択 **スコープ** トークンに必要です。必要な最小限の権限のみ付与してください。
6. 設定 **有効期限** または、有効期限のないトークンのため、空欄のままにしてください。
7. クリック **トークン作成**。

作成後、完全なトークン値が表示されます。 **一度**。すぐにコピーし、安全に保管してください。その後、完全な値は再度表示されなくなります。

## トークンを使用

トークンを `Authorization` HTTP リクエストヘッダーに含めてください:

    Authorization: Bearer glsa_abc123def456...

例えば、使用する `curl`:

```bash
curl -H "Authorization: Bearer glsa_abc123def456..." \
  https://glossia.ai/api/projects
```

アカウントトークンも同様です [認可モデル](/docs/reference/apis/authentication) OAuth トークンとして。トークンのスコープは実行可能なアクションの最大セットを定義し、アカウントの関係に基づいてリソースレベルのポリシーも引き続き適用されます。

## トークン形式

すべてのアカウントトークンは `glsa_` プレフィックスに続くランダムな 16 進文字列。このプレフィックスは、ログや機密スキャナーでの Glossia トークンの識別を容易にします。

## スコープ

アカウントトークンは OAuth トークンと同じスコープをサポートしています。詳細は [スコープの参照](/docs/reference/apis/authentication) 詳細一覧について。

トークンを作成する際は、必要なスコープのみを選択してください。 例えば:

- 読み取り専用の統合は `project:read` および `voice:read`。
- プロジェクトを作成する CI パイプラインは `project:read` および `project:write`。
- 組織メンバーを管理するスクリプトは を必要とします `members:read` と `members:write`。

## トークン管理

### トークン表示

の **アカウントトークン** ページはすべての有効なトークンの名前、スコープ、最終使用日、および有効期限を一覧表示します。使用されていないトークンは最終使用日列に「未使用」を表示します。

### トークンの編集

トークンの名前をクリックして、その **名前** と **説明**。スコープと有効期限は作成後に変更できません。異なるスコープが必要であれば、新しいトークンを作成して古いものを無効化してください。

### トークンの無効化

トークンを無効化するには、クリック **無効化** トークンリストから、またはトークンの編集ページを開いて、 **トークンを無効化する** 「危険領域」のボタンです。無効化されたトークンは即座に機能しなくなり、復元できません。

## セキュリティベストプラクティス

- **トークンを安全に保管してください。** 環境変数またはシークレットマネージャーを使用してください。トークンをソース管理にコミットしないでください。
- **短期間有効なトークンを使用してください。** 可能な限り有効期限を設定してください。
- **スコープを最小限に抑えてください。** トークンが実際に必要とする権限のみを付与してください。
- **定期的にローテーションを行ってください。** スケジュールに従って新しいトークンを作成し、古いトークンを無効にしてください。
- **利用状況を確認してください。** 「最終使用日」を定期的に確認してください。使用されていないトークンは無効にしてください。
- **各統合に 1 つのトークンを使用してください。** この方法では、1 つのトークンを取り消しても他のワークフローには影響しません。

## API 管理

REST API と MCP サーバーを介して、アカウント トークンも管理できます。

### REST API

| メソッド | エンドポイント | 説明 |
|--------|----------|-------------|
| `GET` | `/api/tokens` | アクティブなトークン一覧 |
| `POST` | `/api/tokens` | トークンを新規作成 |
| `DELETE` | `/api/tokens/:id` | トークンを無効化 |

### MCP

MCP サーバーは公開し、 `list_tokens`, `create_token`, および `revoke_token` REST API と同様のツールを公開します。
