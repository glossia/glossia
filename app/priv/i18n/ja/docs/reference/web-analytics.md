## # イベント エンドポイント

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` は引き続き、互換性の維持のために利用可能です。ホストスクリプトは、自身のオリジンから`/v1/collect` を導出します。パッケージ統合は`endpoint` を明示的に設定する必要があります。

`@glossia/web` SDK から JSON イベントを受け入れます。不明なドメインや適切なペイロードの欠損を含む場合でも`202 Accepted`を応答します。これにより SDK がどのプロジェクトが分析データを収集しているか漏らすことはありません。

プロジェクトはスニペットが宣言するサイトドメインによって解決されます。`d`が権威的であり、それが不足している場合サーバーは`u` (ページ URL) のホストにフォールバックし、次にリクエスト`Origin`/`Referer`へとフォールバックします。

### リクエストボディ

| フィールド | タイプ   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトドメイン (例：`example.com`)。ブラウザライブラリによって送信され、フォールバック解決は上記の説明通りです。 |
| `n`   | 文字列 | イベント名。`pageview`がデフォルトです。                          |
| `u`   | 文字列 | ページ URL (`location.href`)。                                  |
| `r`   | 文字列 | リファラ (`document.referrer`)。                              |
| `l`   | 文字列 | ブラウザの言語 (`navigator.languages.join(",")`)。         |
| `sl`  | 文字列 | 実際のページ言語 (`document.documentElement.lang`)。未採用の場合に空白。 |
| `al`  | 文字列 | Comma-separated translation languages from `link[rel="alternate"][hreflang]`, excluding `x-default`. |
| `cl`  | 文字列 | 明示的に選択された言語または、選択された者が観察されなかった場合に空白。SDK は BCP 47 タグをカノニカル化し、入力は 64 文字に制限されます。 |
| `tz`  | 文字列 | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | 文字列 | CSS ピクセルでの画面幅。                                  |
| `sid` | 文字列 | タブごとのセッション ID (sessionStorage, 閉じられたときに消去)。       |

CORS は`Access-Control-Allow-Origin: *`がオープンです。

## 明示的な言語選択

`selectLanguage(language)` は名祖出関数として、デフォルト SDK エクスポート、およびホストされたスクリプトの`glossia` グローバルとして利用可能です。初期化後、ユーザーアクションハンドラから呼び出し、ナビゲーション前に呼び出してください。無効な言語タグおよび初期化前の呼び出しは無視されます。

このメソッドは`language_selection`イベントを即座に送信します。その`sl`は引き続き現在のページを説明し、目的地ではありません。継続するイベントは `cl` における選択を含み、別の明示的な選択で置換されるまで続きます。観察されていない選択の場合、`cl`は空白です。選択は同原点の、タブごとの`sessionStorage`において`__glossia_selected_language`として保存されます。ストレージが失敗した場合、それは記憶されているまでロードされません。

リンクの場合、`data-glossia-language="zh-Hans"` は信頼されている、変更なしの主なクリック、キーボードアクティベーションを含む委任された追尾を有効にします。スクリプトされたクリック、すでにキャンセルされたクリック、ダウンロード、クロスオリジンリンク、および別のタブまたはフレームをターゲットとしたリンクは無視されます。リスナーはナビゲーション前にキャプチャフェーズで実行され、ナビゲーションを止めず、動的に挿入されたリンクも処理します。アクションには注釈または API のどちらかを使用してはいけません。両方を使用しないでください。

これはクライアント報告の意図シグナルであり、ナビゲーションが成功したという証拠ではありません。URL の変更、再方向付け、および HTML 言語の変化は選択として解釈されません。選択は`l` または`sl`を上書きせず、または`has_locale_gap`またはダッシュボードバッジの現在の変化に影響しません。

## サーバー由来のフィールド

これらは収集時に計算され、サーバーサイドに保存されます。生の IP アドレスとユーザーエージェントは決して保存されません。

| フィールド             | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + ユーザーエージェント + プロジェクトの組み合わせの、毎日更新されるハッシュです。日を超えて連結できません。  |
| `country_code`    | Cloudflare / GeoIP | 信頼されている `CF-IPCountry` ヘッダーから得た ISO 3166-1 alpha-2 コード、または設定されている IP 地理位置アダプタから。どちらも国を解決しない場合は空です。 |
| `device`          | ユーザーエージェント    | `desktop`, `mobile`, `tablet`, `bot` または `unknown`.                 |
| `browser`         | ユーザーエージェント    | `chrome`, `safari`, `firefox`, `edge`, `opera` および `unknown`.       |
| `os`              | ユーザーエージェント    | `windows`, `macos`, `ios`, `android`, `linux` または `unknown`.        |
| `hostname`        | ページ URL      | 小文字のホスト。                                                    |
| `pathname`        | ページ URL      | パスコンポーネント。                                                     |
| `referrer_source` | リファラー      | リファラーホスト。先頭の `www.`/`m.` は取り除かれます。                        |
| `browser_language`| 言語     | 最も優先された正規化されたロケール（例：`pt-BR`）。                    |
| `served_locale`   | ページ言語 | 収集されていなかった場合は空です。 정규化された `sl`. ページ言語が空の行はブラウザ言語の分析から除外されます。 |
| `selected_locale` | 明示的な選択 | 正規化された `cl`. 欠落、誤作動、または外部入力の場合は空です。 ブラウザの好まし訳およびページ言語とは独立して保存されます。 |
| `has_locale_gap`  | 計算済み      | 訪問者の優先言語がプロジェクトターゲット、公表された翻訳 (`al`)、またはページ言語 (`sl`) のどれとも一致しない場合に `1`. 欠落した好みはギャップとして数えられません。 |

### クライアント IP 解決

プライベートなイングレスペアからのリクエストの場合、Glossia は `X-Forwarded-For` の呼び出し制御された最初のエントリではなく、nginx のオーバーライトされた `X-Real-IP` ヘッダーを使用します。直接の公開接続はソケットアドレスを使用します。Hetzer については、ロードバランサーと nginx の両方が PROXY プロトコルを有効にする必要があります。そうしないと、nginx はロードバランサーアドレスではなく訪問者アドレスを受け取ります。他の逆プロキシは、認証されたソースを使用して `X-Real-IP` もオーバーライトし、無制限の受信 `X-Forwarded-For` ヘッダーを使用する必要があります。汎用的なチャートの転送ヘッダーポリシーのみではこれを保証しません。プライベートペアは信頼されたインフラストラクチャであるため、直接のポッドアクセスを制限します。

`GLOSSIA_TRUST_CLOUDFLARE_CLIENT_IP_HEADER=true` は、プライベートなイングレスペアからのリクエストの公式的なアドレスを `CF-Connecting-IP` で上書きする機能を有します。それは国ヘッダーの信頼性に関わらず **デフォルトでは無効** です。Cloudflare を認証するまで、または Cloudflare をバイパスするリクエストの偽装ヘッダーを取り去るまで有効にしないでください。DNS みのデプロイメントはそれを無効なままにしてください。このアドレスは、IP レート制限と日毎の訪問者ハッシュのキーとしても機能します。

### 国 解決

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` は `CF-IPCountry` の高速パイプを有効にします。それは **デフォルトでは無効** です。オリジンが Cloudflare を認証するか、Cloudflare をバイパスするリクエストを拒否するか、またはイングレスがヘッダーの信頼されないコピーを銅になりますまで有効にする必要があります。Cloudflare の IP Geolocation 設定もゾーンで有効にする必要があります。`CF-Connecting-IP`, `CF-Ray`、および nginx の`use-forwarded-headers` はリクエストを自身のobservations で認証しません。

ヘッダーの信頼性が有効になると、単一の有効な ISO 国 コードは、IP アドレスの検索またはキャッシュへのアクセスなしで即座に使用されます。現在のエッジ値は常にキャッシュされた検索よりも優先されます。Pages の欠落、重複、誤作動、または不明なコード、Cloudflare の `XX`（不明）および `T1`（Tor）の値を含むもの、信頼された地理位置アダプタに戻ります。

MaxMind データベースが設定されていない場合、フォールバック検索は `api.ipapi.is` を使用し、主要なリクエストが失敗または認識された国を返さない場合、`api.country.is` を使用します。各リクエストには、再試行が無効な 1 秒後の接続とレスポンスタイムアウトがあります。両方のプロバイダから得られた成功結果は、Cachex によって 24 時間キャッシュされます。100,000 エントリのスケジューリングサイズ制限と自動的な有効期限のリコウションがあります。`Cachex.fetch/3` は、コヒーレントなミスを同じ IP 一つに解消します。失敗はキャッシュされません。プライベートおよび予約されたアドレスは両方のプロバイダに送信されません。

### 欠落したページ言語

ブラウザ言語の分析は、`sl` のないイベントを省略します。これには、古いトラッカーバージョンで収集されたイベントと HTML `lang` 属性のないページが含まれます。これらのイベントは総トラフィックにさらに貢献します。ページ言語はブラウザの好まし訳または URL から推測されません。履歴イベントはそれまでに収集したメタデータを維持しており、新しいトラッカーバージョンはそれらをバックフィルしません。

## プライバシーモデル

- **永続的なクロスセッション識別子はありません。** SDK はクッキーを設定せず、ブラウザが閉じるときにクリアされる `sessionStorage` にて、ラベルごとのセッション ID と明示的に選択された言語のみを保存します。
- **フィンガープリンティングはありません。** Canvas、WebGL、フォント、および音声のフィンガープリンティングは収集されません。daily-rotated サーバーハッシュはそれらなしでユニークを提供します。
- **生データ識別子は保持されません。** IP とユーザーエージェントは一度読み取られ、サーバーの秘密と日毎のソルトでハッシュ化され、その後破棄されます。
- **プロジェクトごとのスコーピング。** 同じブラウザが 2 つのプロジェクトで関連付けられない訪問者 ID を生成するため、訪問者は Glossia カスタマーを跨いで追跡されません。
