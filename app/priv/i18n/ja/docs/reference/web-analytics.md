## events エンドポイント

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` は互換性のために引き続き利用可能です。ホストスクリプトは、自身のオリジンから `/v1/collect` を導き出します。パッケージ統合では `endpoint` を明示的に設定する必要があります。

`@glossia/web` SDK から JSON イベントを受けます。常に `202 Accepted` を返します。不明なドメインまたは不正なペイロードの場合も同様であり、SDK はどのプロジェクトが分析データを収集しているかを漏洩することはありません。

プロジェクトは、スニペットが宣言するサイトドメインで解決されます。`d` が優先されます。不在の場合、サーバーは、`u` のホスト（ページ URL）に、さらに、リクエスト `Origin`/`Referer` にフォールバックします。

### Request

| フィールド | タイプ   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトのドメイン（例： `example.com` ）。ブラウザライブラリから送信され、フォールバックの解決方法は上記に記載されています。 |
| `n`   | 文字列 | イベント名。デフォルトは `pageview` です。                          |
| `u`   | 文字列 | ページ URL（ `location.href` ）                                  |
| `r`   | 文字列 | 参照元（ `document.referrer` ）                              |
| `l`   | 文字列 | ブラウザの言語（ `navigator.languages.join(",")` ）         |
| `sl`  | 文字列 | 実際のページの言語（ `document.documentElement.lang` ）。宣言されていない場合は空。 |
| `al`  | 文字列 | `link[rel="alternate"][hreflang]` から取得したカンマ区切りの翻訳言語リスト。 `x-default` を除く。 |
| `tz`  | 文字列 | IANA タイムゾーン（ `Intl.DateTimeFormat().resolvedOptions().timeZone` ） |
| `sw`  | 数値 | CSS ピクセル単位の画面幅                                  |
| `sid` | 文字列 | 各タブのセッション ID（ sessionStorage 使用、クローズ時にクリア）       |

CORS は`Access-Control-Allow-Origin: *` として開かれており、エンドポイントが認証情報を許可しないためです。

## サーバーで生成されたフィールド

これらは取り込み時に計算され、サーバー側に保存されます。生 IP アドレスおよび User-Agent は保存されません。

| フィールド             | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + User-Agent + プロジェクトから生成された日付ごとのハッシュ。日付を超えて関連付けられません。  |
| `country_code`    | Cloudflare / GeoIP | 信頼できる `CF-IPCountry` ヘッダーまたは設定された IP ギオロケーションアダプターから取得した ISO 3166-1 alpha-2 コード。どちらも国を特定できない場合は空。 |
| `device`          | User-Agent    | `desktop`、`mobile`、`tablet`、`bot`、または`unknown`                 |
| `browser`         | User-Agent    | `chrome`、`safari`、`firefox`、`edge`、`opera`、または `unknown`。       |
| `os`              | User-Agent    | `windows`、`macos`、`ios`、`android`、`linux`、または`unknown`。        |
| `hostname`        | ページ URL      | 小文字のホスト名。                                                    |
| `pathname`        | ページ URL      | パス成分。                                                     |
| `referrer_source` | 参照元      | 先頭の `www.`/`m.` が削除された参照元ホスト。                        |
| `browser_language`| 言語     | 最も優先される正規化されたロケール（例：`pt-BR`）。                    |
| `served_locale`   | ページの言語 | `sl` の正規化値、または収集されていない場合は空（Not reported と表示）。 |
| `has_locale_gap`  | 計算      | `1` は訪問者の優先言語が、プロジェクトのターゲット、表示翻訳 (`al`), またはページ言語 (`sl`) と一致しない場合、優先設定の不足はギャップとしてカウントされません。 |

### 国コードの判定

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` は `CF-IPCountry` の高速パスを有効にします。デフォルトでは **デフォルトで無効** です。有効にするには（Cloudflare の認証を行い、Cloudflare を迂回するリクエストを拒否するか、および ingress が信頼できないヘッダーコピーを削除した後）、Cloudflare の IP ギオロケーション設定もゾーンで有効にする必要があります。`CF-Connecting-IP`、`CF-Ray`、および nginx の `use-forwarded-headers` は、独自ではリクエストを検証できません。

ヘッダー信頼が有効な場合、単一の有効な ISO 国コードを直ちに使用し、IP 照会またはキャッシュへのアクセスなしで行います。現在のエッジ値は常にキャッシュされた照会を優先します。欠落、重複、不正、または不明なコード（Cloudflare の `XX` (不明) および `T1` (Tor) 値を含む）は、設定されたギオロケーションアダプターにフォールバックします。

MaxMind データベースが設定されていない場合、フォールバック照会では `api.ipapi.is` を使用し、プライマリリクエストが失敗したり、認識された国を返さない場合は `api.country.is` です。各リクエストに対しては 1 秒の接続と応答タイムアウトがあり、リトライは無効です。両方のプロバイダから得た成功した結果は、Cachex によって 24 時間キャッシュされ、10 万エントリのスケジューリングされたサイズ制限と自動失効処理があります。`Cachex.fetch/3` は同一の IP からの同時ミスを 1 つの解決器に共通化します。失敗はキャッシュされません。プライベートおよび予約アドレスはどちらのプロバイダにも送信されません。

### ページ言語の欠落

ダッシュボードは、イベントに `sl` が含まれていない場合、**未報告** を表示します。これは旧バージョンのトラッカーで収集されたイベントおよび HTML `lang` 属性を持たないページに含まれます。ページ言語はブラウザの好実または URL から推測されません。歴史的イベントは当時の収集メタデータを維持し、新しいトラッカーバージョンはそれらを補填しません。

## プライバシーモデル

- **永続的なクロスセッション識別子は存在しません。** SDK はクッキーを設定せず、`sessionStorage` にのみタブごとのセッション ID を保存し、クローズ時にブラウザがクリアします。
- **指紋化は行われません。** Canvas、WebGL、フォント、およびオーディオの指紋は収集されません。日付ごとのサーバーハッシュはそれらなしで一意性を提供します。
- **生識別子は永続化されません。** IP および User-Agent は一度読み取り、サーバーシークレットと日付別のソルトでハッシュ化され、その後破棄されます。
- **プロジェクトごとのスコープ。** 同じブラウザが 2 つのプロジェクトで使用されると、関連性の持たないビジター ID が生成され、Glossia の顧客間でビジターを追跡することはできません。
