## イベントエンドポイント

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` 互換性を保つために引き続き利用可能です。ホストスクリプトは `/v1/collect` 独自の起源から導出されます。パッケージ統合は `endpoint` 明示する必要があります。

から JSON イベントを受け入れる `@glossia/web` SDK です。常に対応する `202 Accepted`, 不明なドメインや形式が誤っているペイロードを含め、SDK がどのプロジェクトが分析データを収集しているか漏洩しません。

プロジェクトはスニペットが宣言するサイトのドメインによって解決されます。 `d` 権威性があります。存在しない場合、サーバーはホストへフォールバックします `u` （ページの URL）およびその後リクエスト `Origin`/`Referer`.

### リクエスト本体

| 項目 | 型   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトドメイン (例え `example.com`). ブラウザライブラリによって送信されます。フォールバック解決については上記で説明されています。 |
| `n`   | string | イベント名。デフォルトは `pageview`.                          |
| `u`   | string | ページ URL (`location.href`).                                  |
| `r`   | string | リファラ (`document.referrer`).                              |
| `l`   | string | ブラウザの言語 (`navigator.languages.join(",")`).         |
| `sl`  | string | 実際のページ言語 (\[`document.documentElement.lang`)。宣言されていない場合は空にする。 |
| `al`  | string | カンマ区切りの翻訳言語、の `link[rel="alternate"][hreflang]`， 除く `x-default`。 |
| `tz`  | string | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`）。 |
| `sw`  | number | 画面幅の CSS ピクセル数。                                  |
| `sid` | string | タブ単位のセッション ID（sessionStorage 使用、閉じ時にクリア）。       |

CORS は許可されており、(`Access-Control-Allow-Origin: *`) エンドポイントが認証情報を許可しないため。

### 国ごとの解決

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` 有効にします `CF-IPCountry` 高速パス。それは **デフォルトでは無効です**. オリジンが Cloudflare を認証し、Cloudflare を迂回するリクエストを拒否するか、エングレスが信頼できないヘッダーコピーを除去した場合のみ有効にしてください。Cloudflare の IP 位置情報設定もそのゾーンで有効にする必要があります。 `CF-Connecting-IP`、 `CF-Ray`、および nginx の `use-forwarded-headers` 独自にリクエストを認証しません。

信頼ヘッダーが有効な場合、有効な単一の ISO 国コードが直ちに使用され、IP 照合やキャッシュへのアクセスは行われません。現在のエッジ値は常にすべてのキャッシュ照合に優先されます。欠落、重複、不正な形式、または不明なコード（Cloudflare のを含む `XX` (不明) と `T1` (Tor) 値の場合は、設定済みの位置情報アダプターにフォールバックします。

MaxMind データベースの設定がない場合、フォールバック検索は `api.ipapi.is`、次に `api.country.is` プライマリリクエストが失敗した場合、または認識された国が返されていない場合。各リクエストは接続およびレスポンスの 1 秒間のタイムアウトを持ち、リトライは無効です。いずれかのプロバイダーからの成功した結果は、Cachex によって 24 時間キャッシュされ、100,000 エントリのスケジュール化されたサイズ制限および自動失効回収が適用されます。 `Cachex.fetch/3` 同じ IP に対する並行ミスを一つの解決者へ集約します。失敗はキャッシュされません。プライベートおよび予約アドレスはどちらのプロバイダーにも送信されません。

### ページ言語なし

ダッシュボードに表示します **報告されません** イベントに該当がない場合は、 `sl`. これは、旧バージョンのトラッカーで収集されたイベントや、HTML `lang` 属性です。ページ言語はブラウザの設定や URL から推測されません。過去のイベントは当時のメタデータを保持しますが、新しいトラッカーバージョンはそれらを後から補完しません。

## プライバシーモデル

- **永続的なクロスセッション識別子はありません。** SDK はクッキーを設定せず、タブごとのセッション ID を 内部に `sessionStorage`, ブラウザが終了時にクリアします。
- **指紋化は行いません。** キャンバス、WebGL、フォント、および音声の指紋は一切収集されません。日替わりサーバーハッシュにより、それらなしで一意な識別子が提供されます。
- **生の識別子は保持されていません。** IP と User-Agent は一度だけ読み取られ、サーバーシークレットと日替わりソルトを用いてハッシュ化され、その後破棄されます。
- **プロジェクトごとのスコープ設定。** 同じブラウザを使用して 2 つのプロジェクトを訪れた場合、無関係な訪問者 ID が生成されるため、Glossia の顧客間で訪問者が追跡されません。
