## イベント エンドポイント

`POST /api/analytics/events`

SDK からの JSON イベントを受け取る `@glossia/web` SDK です。常にレスポンスを返します。 `202 Accepted`, 未知のドメインまたは不正なペイロードの場合も含め、SDK が分析対象のプロジェクト名を漏らすことはありません。

スニペットが宣言するサイトドメインによってプロジェクトが解決されます。 `d` は権威的です。欠落時、サーバーはホストの `u` （ ページ の URL）そしてリクエスト `Origin`/`Referer`.

### リクエストボディ

| フィールド | タイプ   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | string | プロジェクトを特定するサイトドメイン (例：") `example.com`必須。 |
| `n`   | string | イベント名。デフォルトは `pageview`。                          |
| `u`   | string | ページ URL (`location.href`).                                  |
| `r`   | string | リファラー (`document.referrer`).                              |
| `l`   | 文字列 | ブラウザの言語 (`navigator.languages.join(",")`".         |
| `tz`  | 文字列 | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | 数値 | CSS ピクセル単位の画面幅。                                  |
| `sid` | string | 各タブのセッション ID (sessionStorage で、閉じると消去される)。       |

CORS は開いています (`Access-Control-Allow-Origin: *`- エンドポイントが認証情報を受け取らないためです。

## サーバー由来のフィールド

これらは取り込み時に計算され、サーバー側に保存されます。生の IP アドレスと User-Agent は保存されません。

| フィールド              | ソース          | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + UA + プロジェクトの日替わりハッシュ。日を超えて関連付けられない。  |
| `country_code`    | GeoIP         | ISO 3166-1 alpha-2 コード。GeoIP が構成されていない場合は空。        |
| `device`          | ユーザーエージェント    | `desktop`, `mobile`, `tablet`以前、再構成されたドキュメントは検証に失敗しました：Markdown テキストリテラル回復は、一致する長さの JSON 文字列配列を返す必要があります。 `bot`, または `unknown`|
| `browser`         | ユーザーエージェント    | `chrome`, `safari`, `firefox`, `edge`以前に再構成されたドキュメントは検証に失敗しました：マークダウンテキストリテラルの復元は、一致する長さの JSON 文字列配列を返す必要があります `opera`この提供されたセグメントのみに対する修正翻訳を返してください。このセグメントに含まれるすべての必要なトークンを保持してください。 `unknown`.       |
| `os`              | ユーザーエージェント    | `windows`, `macos`, `ios`, `android`, `linux`, または `unknown`.        |
| `hostname`        | ページ URL      | 小文字のホスト名。                                                    |
| `pathname`        | ページ URL      | パス要素。                                                     |
| `referrer_source` | リファラー      | リファラー ホスト，先頭 `www.`/`m.` 削除。                        |
| `browser_language`| 言語                   | 最も優先される正規化されたローケール（例えば `pt-BR`)。                    |
| `served_locale`   | 計算                     | 優先言語に一致する最初のサポート対象、そうでない場合は空。   |
| `has_locale_gap`  | 計算済み      | `1` プロジェクトが提供しない言語を訪問者が選択した場合。 |

## プライバシーモデル

- **クライアントサイドでの保存なし。** SDK はクッキーを設定せず、タブごとにセッション ID を `sessionStorage`、 ブラウザが閉じるとクリアされます。
- **指紋化は行われません。** Canvas、WebGL、フォント、および音声指紋は収集されません。日次更新サーバーハッシュは、それらなしで一意性を提供します。
- **生識別子是保持されません。** IP および User-Agent は一度読み取られ、サーバーの秘密と日次塩を用いてハッシュ化され、その後破棄されます。
- **プロジェクトごとのスコープ。** 2 つのプロジェクトで同一ブラウザを使用しても、関連しない訪問者 ID が生成されるため、訪問者は Glossia の顧客間で追跡されません。
