## イベントエンドポイント

`POST /api/analytics/events`

SDK の JSON イベントを受け付け、 `@glossia/web` SDK は常に応答します。 `202 Accepted`, 不明なドメインやフォーマット不良のペイロードを含む場合でも、SDK がどのプロジェクトが分析データを収集しているか漏洩しないようにするため。

スニペットが宣言するサイトドメインによってプロジェクトが解決されます。 `d` は権威的ですが、欠落している場合、サーバーはホストのフォールバックします `u` （ページの URL）なら、その後リクエスト `Origin`/`Referer`.

### リクエストボディ

| フィールド | タイプ   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトドメイン (例. `example.com`). 必須。 |
| `n`   | 文字列 | イベント名。デフォルト値は `pageview`.                          |
| `u`   | 文字列 | ページ URL (`location.href`.                                  |
| `r`   | 文字列 | リフェラ (`document.referrer`.                              |
| `l`   | 文字列 | ブラウザ言語 (`navigator.languages.join(",")`).         |
| `tz`  | 文字列 | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | number | 画面幅（CSS ピクセル）。                                  |
f `sid` | string | タブごとのセッション ID（sessionStorage、閉じた時にクリア）。       |

CORS は有効（`Access-Control-Allow-Origin: *`）エンドポイントは認証情報を許可しないためです。

## サーバー由来のフィールド

これらは取り込み時に計算され、サーバー側に保存されます。生 IP アドレスおよび User-Agent は決して保存されません。

| フィールド             | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + ユーザーエージェント + プロジェクトの毎日回転するハッシュ。日をまたいでリンクできません。  |
| `country_code`    | GeoIP         | ISO 3166-1 alpha-2 コード。GeoIP の設定がされていない場合は空です。        |
| `device`          | User-Agent    | `desktop`, `mobile`, `tablet`, `bot`, または, `unknown`.                 |
| `browser`         | ユーザーエージェント    | `chrome`, `safari`再構成されたドキュメントは以前バリデーションに失敗しました。Markdown テキストリテラルの復元には、長さが一致する JSON 文字列配列を返す必要があります。 `firefox`再構成ドキュメントは以前検証に失敗しました：Markdown テキストリテラルの復元で無効な JSON が返されました `edge`、 `opera`または `unknown`.       |
| `os`              | ユーザーエージェント    | `windows`, `macos`, `ios`再構成されたドキュメントは以前検証に失敗しました：Markdown テキストノード復元により空の翻訳が生成されました `android`, `linux`, or `unknown`.        |
| `hostname`        | ページ URL      | 小文字化したホスト。                                                    |
| `pathname`        | ページ URL      | パス成分。                                                     |
| `referrer_source` | リファラー      | リファラー送信元ホスト、先頭 `www.`/`m.` 削除。                        |
| `browser_language`| 言語     | 最も優先度の高い正規化されたロケール（例 `pt-BR`）.                    |
| `served_locale`   | 計算    | 優先言語に一致する最初のターゲット、それ以外は空。   |
| `has_locale_gap`  | 計算済み      | `1` プロジェクトが提供しない言語を訪問者が優先する場合です。 |

## プライバシーモデル

- **クライアントサイドストレージはありません。** SDK はクッキーを設定せず、タブごとのセッション ID を `sessionStorage`, ブラウザが閉じた時点でクリアされます。
- **フィンガープリンティングは行いません。** キャンバス、WebGL、フォント、およびオーディオのフィンガープリントは収集されません。毎日回転するサーバーハッシュはそれらを使わずに一意の識別子を提供します。
- **生識別子は保持されません。** IP アドレスと User-Agent は一度だけ読み取られ、サーバー秘密鍵と日次ソルトでハッシュ化されたのち破棄されます。
- **プロジェクトごとのスコープ。** 2 つのプロジェクト上の同じブラウザは関連のない訪問者 ID を生成するため、Glossia の顧客間で訪問者は追跡されません。
