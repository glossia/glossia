## イベント エンドポイント

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` は互換性のために引き続き利用可能です。ホストスクリプトは自らのオリジンから`/v1/collect` を導き出します。パッケージ統合は`endpoint` を明示的に設定する必要があります。

`@glossia/web` SDK から JSON イベントを受け取ります。常に`202 Accepted` を返します（不明なドメインや不正なペイロードを含む場合を含む）。これにより、SDK はどのプロジェクトが分析データを収集しているかが漏れることはありません。

公開スニペットで宣言されるサイトドメインによってプロジェクトが解決されます。`d` が権威的です；欠落している場合、サーバーは`u`（ページの URL）のホストに戻り、その後リクエスト`Origin`/`Referer` にフォールバックします。

### リクエスト本体

| フィールド名 | 型   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトドメイン（例：`example.com`）。ブラウザライブラリによって送信され、フォールバックの解決は上記にあります。 |
| `n`   | 文字列 | ページ URL (`pageview`)。                          |
| `u`   | 文字列 | ブラウザの言語 (`location.href`)。                                  |
| `r`   | 文字列 | 転送元ヘッダー (`document.referrer`).                              |
| `l`   | 明示的に選択された言語。選択が検出されなかった場合は空です。SDK は BCP 47 タグを正規化し、入力制限を 64 キャラクタに適用します。 | IANA タイムゾーン (`navigator.languages.join(",")`)。         |
| `sl`  | CSS ピクセル単位での画面幅。 | 実際のページの言語 (`document.documentElement.lang`). 未宣言の場合、空。 |
| `al`  | 文字列 | `link[rel="alternate"][hreflang]` から Derived、`x-default` を除く、コンマ区切りの翻訳言語。 |
| `cl`  | 文字列 | 明示的に選択された言語、または選択がされていない case 該当 field。SDK は BCP 47 タグを正規化し、入力は 64 文字まで制限します。 |
| `tz`  | 文字列 | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | 数字 | 欠落、不正な、または大きすぎる選択はブラウザの優先順位にフォールバックします。選択もブラウザの優先順位も不明な場合、ギャップはありません。ダッシュボードの合計とバッジは保存されたイベントごとのフラグを読み取ります。ギャップ計算に影響を与える前の選択で収集された履歴フラグを含め、再計算されません：履歴の告知翻訳と完全なブラウザの優先順位は保存されません。                                  |
| `sid` | サーバーから導出されたフィールド | これらは取り込み時に計算され、サーバーサイドに保存されます。生 IP と User-Agent は決して保存されません。       |

CORS は公開 (`Access-Control-Allow-Origin: *`)。エンドポイントはいくつかの認証を受け入れるため。

## 明示的な言語選択

`selectLanguage(language)` は名前付きエクスポート、デフォルト SDK エクスポート、およびホストスクリプトの `glossia` グローバルとして利用可能です。初期化後、ユーザー操作ハンドラから、ナビゲーション前に呼び出します。無効な言語タグと初期化前の呼び出しは無視されます。

メソッドは `language_selection` イベントを即座に送ります。その `sl` はまだ現在のページを記述し、宛先ではありません。連続するイベントは `cl` に選択を含めます、until another explicit choice replaces it. 観察された選択なしの場合、`cl` は空。選択は `__glossia_selected_language` として、same-origin、per-tab `sessionStorage` に保存されます。保存が失敗する場合は、unload までメモリにのみ保持されます。

リンクには、`data-glossia-language="zh-Hans"` は信頼された、変更しない、主要クリックの委任追跡を可能にします、including keyboard activation. スクリプトクリック、already cancelled clicks、ダウンロード、cross-origin links、および別の tab または frame をターゲット化するリンクは無視されます。リスナーはルーターがナビゲーションする前にキャプチャーフェーズで実行され、ナビゲーションを阻止せず、動的に挿入されたリンクも処理します。アクションのためには、注釈または API のどちらかを示す使用、両方ではなく。

これはクライアント報告された意向シグナルだけであり、ナビゲーションが成功したという証拠ではありません。URL 変更、リダイレクト、および HTML 言語変更は選択として解釈されません。選択は `l` または `sl` を上書きしません。有効な選択は `has_locale_gap` を計算する際にのみブラウザ設定に優先されます：選択された言語はプロジェクトターゲット、広告された翻訳 (`al`)、または実際のページ言語 (`sl`) のいずれかに一致する必要があります。選択自体は利用可能性の証拠ではありません。マッチングは正規化された正確または基本言語一致を使用します、ブラウザ設定とどのようにも。

例えば、日本の言語を選択した訪問者が、直接利用可能な英語の翻訳を選択した場合、ギャップはありません。英語を優先する訪問者が利用できない日本語を選択する場合、まだギャップがあり、英語のページであっても。ナビゲーション前に実施された選択イベントは、現在のページの `sl` を保持します。宛先言語はプロジェクトターゲットや `al` によって認識され、ナビゲーションが成功したと仮定せずに。

不足している、無効な、またはüberの選択はブラウザ設定にフォールバックします。選択とブラウザ設定の両方が不明の場合、ギャップはありません。ダッシュボード合計とバッジはイベントごとの保存されたフラグを読み取ります。履歴フラグ、choices がギャップ計算に影響した前のを含む、は再計算されません：历史的にある翻訳と完全なブラウザ設定は保存されません。

## サーバー導出されたフィールド

これらの場はインGESTION で計算され、サーバーサイドに保存されます。生 IP とユーザーエージェントは保存されません。

| フィールド             | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + UA + プロジェクトの日次回転ハッシュです。日々を通してリンクできません。  |
| `country_code`    | Cloudflare / GeoIP | 信頼できる `CF-IPCountry` ヘッダーから取得した ISO 3166-1 alpha-2 コード、または設定された IP Geolocation アダプター。いずれも国を解決できない場合、空です。 |
| `device`          | User-Agent    | `desktop`, `mobile`, `tablet`, `bot`, または `unknown`。                 |
| `browser`         | User-Agent    | `chrome`, `safari`, `firefox`, `edge`, `opera`, または `unknown`。       |
| `os`              | User-Agent    | `windows`, `macos`, `ios`, `android`, `linux`, または `unknown`。        |
| `hostname`        | ページ URL      | 小文字化されたホスト。                                                    |
| `pathname`        | ページ URL      | パスコンポーネント。                                                     |
| `referrer_source` | Referrer      | Referrer ホスト、先頭の `www.`/`m.` は削除されています。                        |
| `browser_language`| 言語     | 最も優先される正規化されたロケール (例: `pt-BR`)。                    |
| `served_locale`   | ページ言語 | 正規化された `sl`。収集されていない場合は空。ページ言語が空の行は、ブラウザ言語の分解から除外されます。 |
| `selected_locale` | 明示的な選択 | 正規化された `cl`。不足、不良、またはサイズが大きい場合は空。ブラウザ設定とページ言語とは別に保存されます。 |
| `has_locale_gap`  | 計算      | 有効な明示的な選択がプロジェクトターゲット、広告された翻訳 (`al`)、またはページ言語 (`sl`) に一致しない場合 `1`。有効な選択がない場合、ブラウザ設定が空でないと一致しない場合のみ `1`。 |

### クライアント IP の解決

プライベート インゲスピアからのリクエストに対して、Glossia は nginx が上書きした `X-Real-IP` ヘッダーを使用し、`X-Forwarded-For` の呼び出し者制御の最初のエントリーからではありません。直接的なパブリック接続はソケットアドレスを使用します。Hetzner では、ロードバランサーと nginx の両方が PROXY プロトコルを有効にして、nginx がロードバランサーアドレスではなく訪問者アドレスを受け取る必要があります。他のリバースプロキシは、認証されたソースを使用して `X-Real-IP` を上書きし、無制限の入行い `X-Forwarded-For` ヘッダーを使用してはいけません。一般的なグラフの転送ヘッダーポリシーはこれを保証しません。プライベートピアは信頼されたインフラストラクチャなので、直接のポッドアクセスを制限します。

`GLOSSIA_TRUST_CLOUDFLARE_CLIENT_IP_HEADER=true` は `CF-Connecting-IP` がプライベート インゲスピアからのリクエストに対する公式住所を上書きすることを可能にします。それは **デフォルトで無効** で、国ヘッダー信頼とは独立しています。有効にするには、エッジが Cloudflare を認証するか、Cloudflare をバイパスするリクエストで偽造ヘッダーを削除してからのみ有効にしてください。DNS みの展開はこのままとすべきです。このアドレスは IP レート制限と日々の訪問者ハッシュのキーとしても機能します。

### 国の解決

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` は `CF-IPCountry` の迅速パスを有効にします。それは **デフォルトで無効** です。有効にするには、オリジンが Cloudflare を認証し、Cloudflare をバイパスするリクエストを拒絶するか、インゲスピアがヘッダーの信頼できないコピーを削除した後にのみ有効にします。Cloudflare の IP Geolocation 設定もゾーンで有効にする必要があります。 `CF-Connecting-IP`, `CF-Ray`, および nginx の `use-forwarded-headers` は単独でリクエストを検証しません。

ヘッダー信頼が有効化されると、単一の有効な ISO 国コードがすぐに使用され、IP 確認やキャッシュアクセスなしです。現在のエッジ値はいつでもキャッシュされた確認よりも優先されます。欠落、重複、不良、または不明なコード、Cloudflare の `XX` (不明) および `T1` (Tor) 値を含むものは、セットアップされた Geolocation アダプターにフォールバックします。

MaxMind データベースが設定されていない場合、フォールバック検索は `api.ipapi.is` を使用し、主要リクエストが失敗または認識される国が返されない場合は `api.country.is` を使用します。各リクエストは再試行を無効にした 1 秒の接続およびレスポンス タイムアウトがあります。どちらのサービス提供元からの成功結果は Cachex で 24 時間キャッシュされます。100,000 エントリのスケジュールされたサイズ制限と自動期限切れ回復と共に。`Cachex.fetch/3` は同一 IP の同時ミスを 1 つの解決手段に収束させます。失敗はキャッシュされません。プライベートおよび予約済みアドレスは両方のサービス提供元至送信されません。

### 欠落したページ言語

ブラウザ言語の分解は `sl` のないイベントを除外します。これには古トラッカーによる収集されたイベントと HTML `lang` 属性なしのページが含まれます。これらのイベントは全体トラフィックに貢献します。ページ言語はブラウザ設定または URL から推測されません。歴史的事情イベントはその時点で収集されたメタデータを保持します；新トラッカーバージョンはそれらを埋め戻しません。

## プライバシーモデル

- **永続的なクロスセッション識別子がありません。** SDK はクッキーを設定せず、`sessionStorage` にタブごとのセッション ID と明示的に選択された言語のみを保存し、ブラウザは閉じてもクリアされます。
- **フィンガープリンティングはありません。** キャンバス、WebGL、フォント、およびオーディオフィンガープリントは収集されません。日次回転サーバー ハッシュはそれらなしでユニークを提供します。
- **生の識別子は保存されません。** IP と User-Agent は一度読み取られ、サーバー秘密と日次ソルトでハッシュ化され、その後棄却されます。
- **プロジェクトごとのスコープ。** 同じブラウザが 2 つのプロジェクトで使用されると、無関係な訪問者 ID が生成されるため、Glossia の顧客間で追跡されません。
