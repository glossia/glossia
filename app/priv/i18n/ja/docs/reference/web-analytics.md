## イベントエンドポイント

`POST https://glossia.ai/v1/collect`

`POST /api/analytics/events` は互換性のために引き続き利用可能です。ホストされたスクリプトは自身のオリジンから `/v1/collect` を導出します。パッケージ統合では、`endpoint` を明示的に設定する必要があります。

`@glossia/web` SDK から JSON イベントを受け入れます。常に `202 Accepted` を返しますが、不明なドメインまたは破損したペイロードの場合でも同様です。これにより、どのプロジェクトが分析データを収集しているかなどの情報が SDK から漏洩することはありません。

プロジェクトはスニペットで宣言されたサイトドメインによって解決されます。`d` が権威性を持ちます。それが欠落している場合、サーバーは `u`（ページ URL）のホストにフォールバックし、次にリクエストの `Origin`/`Referer` にフォールバックします。

### リクエスト本文

| フィールド | タイプ   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | 文字列 | プロジェクトを識別するサイトドメイン（例：`example.com`）。ブラウザライブラリから送信されます。フォールバック解決は上記に記述されています。 |
| `n`   | 文字列 | イベント名。`pageview` になります。                          |
| `u`   | 文字列 | ページ URL（`location.href`）。                                  |
| `r`   | 文字列 | リファラー（`document.referrer`）。                              |
| `l`   | 文字列 | ブラウザ言語（`navigator.languages.join(",")`）。         |
| `sl`  | 文字列 | 実在のページ言語（`document.documentElement.lang`）。宣言されていない場合は空になります。 |
| `al`  | 文字列 | `link[rel="alternate"][hreflang]` から取得する翻訳言語（カンマ区切り）、`x-default` を除く。 |
| `tz`  | 文字列 | IANA タイムゾーン（`Intl.DateTimeFormat().resolvedOptions().timeZone`）。 |
| `sw`  | 数値 | CSS ピクセルでの画面幅。                                  |
| `sid` | 文字列 | 各タブ固有のセッション ID（sessionStorage、クローズ時にクリア）。       |

CORS は `Access-Control-Allow-Origin: *` で開放されています。エンドポイントが認証情報を許可しないため。

## サーバー固有フィールド

これらはインテイク時に計算され、サーバー上に保存されます。生の IP アドレスと User-Agent は決して保存されません。

| フィールド             | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP、UA、プロジェクトの組み合わせから算出される、毎日回転するハッシュです。日を超えて関連付けられません。  |
| `country_code`    | Cloudflare / GeoIP | 信頼された `CF-IPCountry` ヘッダーまたは設定された IP ジオロケーションアダプターから取得する ISO 3166-1 alpha-2 コード。どちらも国を解決できない場合は空になります。 |
| `device`          | User-Agent    | `desktop`、`mobile`、`tablet`、`bot`、または`unknown`。                 |
| `browser`         | User-Agent    | `chrome`、`safari`、`firefox`、`edge`、`opera`、または`unknown`。”       |
| `os`              | User-Agent    | `windows`、`macos`、`ios`、`android`、`linux`、または`unknown`。”        |
| `hostname`        | ページ URL      | 小文字化されたホスト。”                                                    |
| `pathname`        | ページ URL      | パス成分。”                                                     |
| `referrer_source` | リファラー      | リファラーホスト、先頭の`www.`/`m.`を削った。”                        |
| `browser_language`| 言語     | 最も優先された正規化ロケール（例：`pt-BR`）。”                    |
| `served_locale`   | ページ言語 | 正規化された`sl`、または収集されなかった場合は空（Not reported と表示）。” |
| `has_locale_gap`  | 計算      | `1` 訪問者の優先言語がプロジェクトターゲット、宣伝された翻訳（`al`）、またはページ言語（`sl`）に一致しない場合。優先するものが欠落している場合はギャップとみなされません。” |

### クライアント IP 解決

プライベート接続接続リージョンからのリクエストに対して、Glossia は nginx の書き換えられた`X-Real-IP`ヘッダーを使用し、`X-Forwarded-For`内の呼び出し側制御最初のエントリを使用しません。直接の公開接続ではソケットアドレスを使用します。Hetzner では、ロードバランサーと nginx の両方が PROXY プロトコルを有効にし、nginx がロードバランサーアドレスではなく訪問者アドレスを受け取るようにする必要があります。他のリバースプロキシも認証されたソースを使用して`X-Real-IP`を書き換え、制限のないインバウンド`X-Forwarded-For`ヘッダーでは不行きません。一般的なチャートの転送ヘッダーポリシーだけではこれを保証できません。プライベートピアは信頼されたインフラなので、直接のポッドアクセスを制限します。”

`GLOSSIA_TRUST_CLOUDFLARE_CLIENT_IP_HEADER=true` は `CF-Connecting-IP` を使用することで、プライベート・イングレス ピアからのリクエストのキャノニカルアドレスを上書きできます。これは国ヘッダーの信頼設定とは独立しており、**デフォルトで無効** です。エッジが Cloudflare を認証するか、Cloudflare を迂回するリクエストで偽造将己されたヘッダーを削除した後にのみ有効にしてください。DNS 専用のデプロイメントでは、無効のままにしてください。このアドレスは、IP レート制限と日次訪問者ハッシュの鍵としても機能します。

### 国解決

`GLOSSIA_TRUST_CLOUDFLARE_COUNTRY_HEADER=true` は `CF-IPCountry` の高速パスの有効化を行います。それは **デフォルトで無効** です。オリジンが Cloudflare を認証するか、Cloudflare を迂回するリクエストを拒否するか、または ingress が信頼できないヘッダーのコピーを削除した後にのみ有効にしてください。Cloudflare の IP ジオロケーション設定も、ゾーンでは有効にする必要があります。`CF-Connecting-IP`, `CF-Ray` および nginx の `use-forwarded-headers` は、それぞれその単独でリクエストを認証することはできません。

ヘッダー信頼が有効化されると、単一有効な ISO 国コードが即座に使用されます。IP 検索やキャッシュアクセスなし。現在の edge 値は常にキャッシュされた検索よりも優先されます。欠落、複製、フォーマット不良、または不明なコードには、Cloudflare の`XX`（不明）および`T1`（Tor）値も含まれ、設定されたジオロケーションアダプターにフォールバックします。”

MaxMind データベースが設定されていない場合、フォールバック検索は`api.ipapi.is`を使用し、主要リクエストが失敗または認識された国が返された場合は`api.country.is`を使用します。各リクエストには、再開無効の 1 秒接続および返信タイムアウトがあります。両方からの成功結果は、Cachex によって 24 時間キャッシュされ、100,000 件エントリーのscheduled サイズ制限と自動期限切れ回収があります。`Cachex.fetch/3` は同じ IP の同時欠落を単一の解決者に結合します。失敗はキャッシュされません。プライベートおよび予約アドレスは両方のプロバイダーに送信されません。”

### 欠落ページ言語

ダッシュボードはイベントに`sl`がないとき**Not reported**を表示します。これには、古いトラッカーバージョンで収集されたイベントと HTML `lang` 属性がないページが含まれます。ページ言語はブラウザ環境または URL から推測されません。履歴イベントはその時収集したメタデータを保持します；新しいトラッカーバージョンはこれらにバックアップします。”

## プライバシーモデル

- **永続的なクロスセッション識別子はありません。** SDK はクッキーを設定せず、`sessionStorage`, クローズでブラウザがクリアするタブごとのセッション ID のみを保存します。
- **フィンガープリントはありません。** キャンバス、WebGL、フォント、および音声フィンガープリントは収集されません。日次ローテーションサーバーハッシュがそれらを含まずユニークを提供します。”
- **生の識別子は永続化されません。** IP と User-Agent は一度読みが取られ、サーバー秘密鍵と日次塩分ハッシュされ、その後破棄します。”
- **プロジェクトごとのスコーピング。** 同じブラウザが2つのプロジェクトで使用すると関連のない訪問者 ID が生成されるため、訪問者はGlossia の顧客間では追跡できません。
