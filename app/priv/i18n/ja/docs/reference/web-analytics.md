## イベントエンドポイント

`POST /api/analytics/events`

SDK の JSON イベントを受け取る `@glossia/web` SDK です。常に応答します。 `202 Accepted`、不明なドメインや不正なペイロードの場合も含め、SDK がどのプロジェクトで分析データを収集するかを漏洩することはありません。

スニペットで宣言されたサイトドメインによってプロジェクトが解決されます。 `d` 権威を持ちます；それが不在の時はサーバーはホストの `u` （ページの URL）およびその後リクエスト `Origin`/`Referer`.

### リクエストボディ

| フェールド | 型   | 説明                                                  |
|-------|--------|--------------------------------------------------------------|
| `d`   | string | プロジェクトを識別するサイトドメイン (例 `example.com`).必須。|
| `n`   | string | イベント名。デフォルト値： `pageview`.                          |
| `u`   | string | ページ URL (`location.href`)                                  |
| `r`   | string | リファラー (`document.referrer`)                              |
| `l`   | 文字列 | ブラウザの言語 (`navigator.languages.join(",")`).         |
| `tz`  | 文字列 | IANA タイムゾーン (`Intl.DateTimeFormat().resolvedOptions().timeZone`). |
| `sw`  | 数値 | CSS ピクセルの画面幅.                                  |
| `sid` | 文字列 | タブごとのセッション ID (sessionStorage、クローズ時にクリアされる)。       |

CORS は公開されており (`Access-Control-Allow-Origin: *`) エンドポイントが認証情報を受け付けないため。

## サーバー由来のフィールド

これらは取り込み時に計算され、サーバー側に保存されます。生の IP アドレスと User-Agent は決して保存されません。

| フィールド            | ソース        | 説明                                                         |
|-------------------|---------------|---------------------------------------------------------------------|
| `visitor_id`      | HMAC          | IP + UA + プロジェクトの日次ローテーションハッシュ。跨日での関連付け不可。|
| `country_code`    | GeoIP         | ISO 3166-1 alpha-2 コード。GeoIP 未設定の場合は空。|
| `device`          | ユーザーエージェント    | `desktop`, `mobile`, `tablet`再構築ドキュメントは以前検証に失敗しました：Markdown text-node の回復で空の翻訳が生成されました。 `bot`, または `unknown`.                 |
| `browser`         | User-Agent    | `chrome`, `safari`再構成された文書は以前検証に失敗しました：Markdown テキストリテラルの復元は、長さが一致する JSON 文字列配列を返す必要があります `firefox`再構成ドキュメントが以前検証に失敗しました：マークダウンテキストリテラルの回復は一致する長さの JSON 文字列配列を返す必要があります。 `edge`、 `opera`, または `unknown`.       |
| `os`              | ユーザーエージェント    | `windows`, `macos`, `ios`, `android`, `linux`, or `unknown`.        |
| `hostname`        | Page URL      | Lowercased host.                                                    |
| `pathname`        | Page URL      | Path component.                                                     |
| `referrer_source` | リファラー      | リファラー ホスト、先行 `www.`/`m.` 削り落とし。                        |
| `browser_language`| 言語     | 最も優先される正規化されたロケール（例えば `pt-BR`)。              |
| `served_locale`   | 計算済み | 優先言語に合致する最初のサポートターゲット、そうでない場合は空。|
| `has_locale_gap`  | 自動判定      | `1` プロジェクトで対応していない言語を好む場合 |

## プライバシーモデル

- **クライアント側での保存はありません。** SDK はクッキーを設定せず、タブごとのセッション ID を `sessionStorage`, ブラウザはそのタブを閉じるとクリアします。
- **フィンガープリンティングは行われません。** キャンバス、WebGL、フォント、およびオーディオ指紋は収集されません。毎日変更されるサーバーハッシュがそれらなしで一意の ID を提供します。
- **生の識別子は永続化されません。** IP アドレスとユーザーエージェントは一度読み取られ、サーバーシークレットと日替わりソルトでハッシュ化され、その後破棄されます。
- **プロジェクト別スコープ。** 2 つのプロジェクトで同じブラウザを使用すると、無関係な訪問者 ID が生成されるため、Glossia の顧客間で訪問者を追跡することはできません。
