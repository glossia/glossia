## `glossia init`

起動用の`GLOSSIA.md`現在のリポジトリ内の設定ファイルを作成します。

```bash
glossia init
```

失敗します。`GLOSSIA.md`既に存在しています。

## 翻訳はサーバーサイドで行われます

翻訳は Glossia サーバー上で執行され、コマンドラインインターフェース内ではありません。コミットが適用されると、
GLOSSIA はあなたの`GLOSSIA.md` ファイルを翻訳します。
アカウントで設定されたモデルを使用し、結果を包含してプルリクエストを開きます。
翻訳セッションページで各ファイルとモデルのターンをライブ表示することができます。

ドキュメントごとにモデルが選択されます。`GLOSSIA.md`  `model:`あなたのアカウントのモデルが選択され、
それがない場合はデフォルトのモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証、
確認または削除された結果を試行していません。また、サーバーの 
翻訳ロックファイルも読んでいません。

## `glossia revisit`

将来のソース言語リビジョンのパスのために予約されています。
Rust コマンドラインインターフェースは現在、このコマンドに対して実装されていないエラーを返します。

```bash
glossia revisit
```

## グローバルフラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを上書きする |
| `--no-color` | 文字色の出力を無効化します |
