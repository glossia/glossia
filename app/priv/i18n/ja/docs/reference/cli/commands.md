## `glossia init`

初期構成を作成 `L10N.md` 現在のリポジトリ内の設定ファイル。

```bash
glossia init
```

既に存在する場合 `L10N.md` すでに存在しています。

## 翻訳はサーバーサイド処理です

翻訳は Glossia サーバー上で行われ、コマンドラインインターフェース上では行われません。コミットが完了すると、
Glossia はあなたの `L10N.md` ファイルそれぞれを翻訳し、
あなたのアカウントに設定されたモデルを使用して、結果をプルリクエストに開きます。あなた
は各ファイルとモデルのターンを、翻訳セッションページでリアルタイムで観察できます。

モデルはドキュメントごとに選択されます：a `L10N.md` `model:` naming one of your account のモデルハンドラを指定する
アカウントのモデルハンドラが選択された場合、それ以外の場合はアカウントのデフォルトのモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証を、
確認、または生成翻訳の削除も行いません。サーバーの
翻訳ロックファイルを読み取ることもありません。

## `glossia revisit`

将来のソース言語リビジョンパスのため予約されています。Rust コマンドライン
インターフェースは現在、このコマンドに対して未実装エラーを返します。

```bash
glossia revisit
```

## グローバルフラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを上書きする |
| `--no-color` | カラー出力を無効化する |
