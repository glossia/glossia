## `glossia init`

現在のリポジトリに初期の `L10N.md` 設定ファイルを作成します。

```bash
glossia init
```

`L10N.md` が既に存在する場合、失敗します。

## 翻訳はサーバーサイドで行われます。

翻訳はホスティングされた Glossia サービス内で、コマンドライン インターフェース内では行われません。コミットが受け取られ、Glossia はあなたの `L10N.md` ファイルの作業を計画し、アカウントで設定されたモデルを使って各ファイルを翻訳し、結果を含むプルリクエストを開きます。各ファイルとモデルのターンの推移は翻訳セッションページでリアルタイムで確認できます。

モデルはドキュメントごとに選択されます。アカウントのモデル ハンドルのいずれかを指定する `L10N.md` `model:` 節がある場合、それを選択します。指定がない場合は、アカウントのデフォルト モデルが使用されます。

コマンドライン インターフェースは意図的に生成された翻訳の計画、翻訳、検証、点検、または削除を行いません。また、Glossia によって公開された翻訳 ロックファイルも読みません。

## `glossia revisit`

将来のソース言語のリビジョン パス用に予約されています。Rust のコマンドライン インターフェースは現在、このコマンドに対して未実装のエラーを返します。

```bash
glossia revisit
```

## グローバル フラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルート ディレクトリを上書きします |
| `--no-color` | カラー付き出力を無効にします |
