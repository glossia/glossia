## `glossia init`

初期の`L10N.md`現在のリポジトリ内の設定ファイルを作成します。

```bash
glossia init
```

Fails if `L10N.md` already exists.

## Translation is server-side

翻訳は Glossia サーバー上で実行され、コマンドラインインターフェース内では実行されません。コミットがマージされた場合、
Glossia は、あなたの `L10N.md` ファイルから作業を計画し、
アカウントの構成されたモデルを使用して各ファイルを翻訳し、結果を含む プルリクエストを開きます。 
翻訳セッションページ上で各ファイルとモデルのターンをライブで監視できます。

ドキュメントごとにモデルが選択されます： `L10N.md` `model:`アカウントのモデル用として命名する場合は、
アカウントのモデルが選択されます; それ以外の場合はアカウントのデフォルトモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証、
検査、または生成された翻訳を削除しません。サーバーの
翻訳ロックファイルも読み取らない。 

## `glossia revisit`

将来のソース言語の再編集に対して予約されています。Rust コマンドライン
インターフェースは現在、このコマンドに対して未実装エラーを返しています。

```bash
glossia revisit
```

## Global flags

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを強制する |
| `--no-color` | 色付きの出力をオフに |
