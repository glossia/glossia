## `glossia init`

起動設定を作成する `L10N.md` 現在のリポジトリ内の設定ファイル。

```bash
glossia init
```

失敗します `L10N.md` 既に存在する場合。

## 翻訳はサーバーサイドです。

翻訳はコマンドラインインターフェースではなく、ホストされた Glossia サービス内で実行されます。コミットが到着すると、
Glossia はあなたの `L10N.md` ファイルに基づきタスクを計画し、各ファイルを翻訳し
あなたのアカウントで設定されたモデルを使用し、結果をプルリクエストとして開きます。あなた
翻訳セッションページ上で各ファイルとモデルのターンをリアルタイムで確認できます。

モデルはドキュメントごとに選択されます：ある `L10N.md` `model:` 指定するあなたの一つを
アカウントモデルはそれを選択します。それ以外の場合は、あなたのアカウントのデフォルトモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証を行いません、
検査、または生成された翻訳の削除も行いません。また、Glossia が公開する翻訳ロックファイルも読み込みません。

## `glossia revisit`

将来のソース言語の改訂パスのため予備です。Rust のコマンドライン
インターフェースは現在、このコマンドに対して未実装エラーを返します。

```bash
glossia revisit
```

## グローバル フラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを上書きする |
| `--no-color` | 色付きの出力を無効にする |
