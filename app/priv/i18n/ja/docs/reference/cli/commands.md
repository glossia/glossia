## `glossia init`

初期化用 `L10N.md` 現在のリポジトリ内の構成ファイルを作成します。

```bash
glossia init
```

エラーが発生する場合 `L10N.md` すでに存在しています

## 翻訳はサーバーサイドです

翻訳は Glossia サーバー上で実行され、コマンドラインインターフェース内では行われません。コミットが合致すると、
Glossia はあなたの `L10N.md` ファイルに基づき、各ファイルで
あなたのアカウントで設定されたモデルを使用して処理を実行し、結果と共にプルリクエストを開きます。あなたは
各ファイルとモデルのターンを翻訳セッションページでリアルタイムで確認できます。

モデルはドキュメントごとに選択されます：a `L10N.md` `model:` アカウントのモデルハンドラーのいずれかを指定し
ハンドラーが選択されます。そうでなければ、アカウントのデフォルトのモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証を行いません、
生成された翻訳の検査や削除も行いません。また、サーバーの
翻訳ロックファイルを読みません。

## `glossia revisit`

将来的なソース言語改訂パスのため予約されています。Rust コマンドライン
インターフェースは現在、このコマンドに対して未実装のエラーを返しています。

```bash
glossia revisit
```

## グローバルフラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを上書きする |
| `--no-color` | カラー出力を無効にする |
