## `glossia init`

初期用の`L10N.md`現在のリポジトリに設定ファイルを作成します

```bash
glossia init
```

## 翻訳はサーバーサイド

翻訳は Glossia サーバー上で実行され、コマンドラインインターフェースでは実行されません。コミットが適用されると、
Glossia はあなたの `L10N.md` ファイルから作業を計画し、
アカウントの指定されたモデルを使用して各ファイルを翻訳し、結果をプルリクエストとして開きます。
各ファイルとモデルのターンを翻訳セッションページのリアルタイムで監視できます。

モデルはドキュメントごとに選択されます。`L10N.md` `model:` でアカウントのモデルハンドラのうち一つを指定した場合、
それのモデルハンドラが選択され、それ以外の場合はアカウントのデフォルトモデルが使用されます。

コマンドラインインターフェースは意図的に計画、翻訳、検証、
確認、または生成された翻訳の削除を行いません。また、サーバーの
翻訳ロックファイルも読み取らない。

## `glossia revisit`

将来的なソース・ラングージ改訂パスのために予約されている。Rust コマンドライン
インターフェースは現在、このコマンドに対して未実装エラーを返します。

```bash
glossia revisit
```

## グローバルフラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトルートディレクトリを上書きする |
| `--no-color` | カラー出力を無効化 |
