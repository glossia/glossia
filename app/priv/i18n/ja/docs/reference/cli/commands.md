## `glossia init`

現在のリポジトリにスタート用 `L10N.md` 設定ファイルを作成します。

```bash
glossia init
```

`L10N.md` が既に存在する場合、失敗します。

## 翻訳はサーバーサイドで実行されます

翻訳はホスティングされている Glossia サービス内で行われ、コマンドラインインタフェース内ではありません。コミットが着地すると、Glossia は `L10N.md` ファイルから作業を計画し、アカウントで設定済みのモデルを使用して各ファイルを翻訳し、結果をプルリクエストとして開きます。各ファイルとモデルのターンを、翻訳セッションページでリアルタイムで確認できます。

モデルは文書ごとに選択されます：`L10N.md` `model:` でアカウントのモデルハンドルを指定することで選択され、それ以外の場合はアカウントのデフォルトモデルが使用されます。

コマンドラインインターフェースは意図的に、生成された翻訳の計画、翻訳、検証、検査、または削除を行いません。また、Glossia による公開された翻訳ロックファイルも読み取りません。

## `glossia revisit`

将来のソース言語改訂パスのために予約されています。Rust コマンドラインインタフェースは現在、このコマンドに対して未実装エラーを返します。

```bash
glossia revisit
```

## グローバルフラグ

| フラグ | 説明 |
|---|---|
| `--path <PATH>` | プロジェクトのルートディレクトリを上書きする |
| `--no-color` | 色のついた出力を無効にする |
