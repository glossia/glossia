## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では、OAuth 提供元の構成をオプションにしました。GitHub/GitLab の OAuth 認証情報が設定されていなくてもアプリは起動します。環境変数が存在する場合のみ提供元の構成を行います。
- 本番環境ではポート 4000 をデフォルトとし、開発環境では 4050 を維持します。本番プロキシはアプリがポート 4000 で動作することを前提としています。これ `runtime.exs` デフォルトは 4050 でしたが、それはデプロイ中のヘルスチェックの失敗を引き起こしました。

#### 機能

- Phoenix アプリの追加、OAuth ログイン、ドキュメント強化、および UI 改善。
- ファビコンに丸いロゴを使用する。
- CLI を Bun に移行し、CI の実行ビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコードスニペットの横はみ出しを防ぐ。
- モバイルでのコードスニペットに適切な右マージンを追加する。
- 水平方向のオーバーフローを防ぐためにモバイル対応レイアウトを改善する。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループの見出しを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 投稿本文をヒーローレイアウトに合わせて揃え、ブログ投稿の内容を改善する。
- ブログ投稿コンテンツを水平に中央揃えする。
- マルチバイト UTF-8 ツール結果を切り詰める際に発生するパニックを修正する。

#### 機能

- ファーストパーティーツールとウェブサイトセクションを追加。
- ツール検証ステップを可視化する。
- 進捗出力を簡略化する。
- 進捗行に着色する。
- 翻訳および検証アクティビティを表示する。
- ツール行を整形する。
- モバイルメニューとマルチブレイクポイントレイアウトでウェブサイトをレスポンシブ化する。
- Bun/TypeScript で CLI を再実装する。
- CI workflow とテストを追加する。
- Biome を用いたフォーマットチェックを追加する。
- トップページに Progressive Refinement セクションを追加する。
- SEO 対応と最初のブログ投稿を含むブログセクションを追加する。
- 右揃え動詞形式で CLI 出力を統一する。
- より充実したメッセージフォーマットで CLI 出力をカラー化する。
- 正方形の OG 画像と Twitter カードのメタタグを追加する。
- コーディネーターエージェントにツール使用による代理能力を付与し、エージェント化を実現。
- 書き換え `glossia init` Agent Client Protocol (ACP) で。
- Gemini 対応、自動検証、トークントラッキング、および信頼性向上を追加。

#### リファクタリング

- CI を format、typecheck、test、build の個別ジョブに分割。
- CLI を TypeScript/Bun から Rust に書き換え。
