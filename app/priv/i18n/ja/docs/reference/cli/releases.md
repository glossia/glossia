## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では OAuth プロバイダー構成をオプション化します。GitHub/GitLab の OAuth 認証情報が設定されていなくてもアプリケーションは起動します。環境変数が存在するときにのみプロバイダーを設定します。
- 本番環境のデフォルトポートを 4000 にし、開発環境では引き続き 4050 を維持します。本番プロキシはアプリケーションがポート 4000 で動作することを前提としているため、 `runtime.exs` デフォルトが 4050 だったため、デプロイ時のヘルスチェックが失敗していました。

#### 機能一覧

- OAuth 認証付き Phoenix アプリの追加、ドキュメント強化、UI 改善。
- 丸いロゴをファビコンとして使用。
- CLI を Bun に移行し、CI 実行可能ファイルのビルドを更新。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでコードスニペットの横方向オーバーフローを防ぐ。
- モバイル上でコードスニペットに適切な右余白を追加する。
- 水平方向のオーバーフローを防ぐためにモバイルレスポンシブレイアウトを改善する。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- Bun から Rust へ翻訳ワークフローを更新する。
- ヒーローレイアウトに合わせて投稿本文を整え、ブログ投稿のコンテンツを改善する。
- ブログ投稿のコンテンツを水平に中央揃えにする。
- 多バイト UTF-8 ツール結果を切り詰めた際に発生するパニックを修正する。

#### 機能

- ファーストパーティーツールおよびウェブサイトセクションの追加
- ツール検証手順の表示
- 進捗出力の簡素化
- 進捗ラインの着色
- 翻訳および検証活動の表示
- ツールラインのフォーマット
- モバイルメニューとマルチブレイクポイントレイアウトによるレスポンシブ対応
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome を用いてフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO サポートと最初のブログ投稿を含むブログセクションを追加する。
- CLI 出力を右揃えの動詞フォーマットに統合する。
- より豊富なメッセージフォーマットで CLI 出力を色付けする。
- 正方形の OG 画像と Twitter カードのミタタグを追加する。
- コーディネーターエージェントにツールの使用による自律性を持たせます。
- 書き換え `glossia init` アージェント・クライアント・プロトコル (ACP) を使用した。
- ジェマイニ対応、自動検証、トークン追跡、および信頼性向上を追加。

#### 改修

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割。
- CLI を TypeScript/Bun から Rust に書き換え。
