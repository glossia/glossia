## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では OAuth プロバイダー設定をオプション化します。GitHub/GitLab OAuth 認証情報が設定されていなくても、アプリは起動します。環境変数が設定されている場合のみプロバイダーを設定してください。
- 本番環境ではポート 4000 をデフォルトとし、開発環境では 4050 を維持します。本番プロキシはアプリがポート 4000 で動作することを想定しています。その `runtime.exs` デフォルトは 4050 でした。これにより、デプロイ中にヘルスチェックが失敗しました。

#### 新機能

- Phoenix アプリの追加、OAuth ログイン、ドキュメント強化、UI 改善
- 丸いロゴをファビコンとして使用する
- CLI を Bun に移行し、CI 実行ビルドを更新

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイル表示でのコードスニペットの横方向オーバーフローを防ぐ
- モバイルのコードスニペットに適切な右マージンを追加する。
- モバイルレスポンシブレイアウトを改善し、水平方向のオーバーフローを防ぐ。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループヘッダーを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 投稿本文をヒーローレイアウトと整合させ、ブログ投稿内容を改善する。
- ブログ投稿内容を水平方向に中央揃えにする。
- マルチバイト UTF-8 ツール結果を切り捨てた際に発生するパニックを修正する。

#### 機能

- ファーストパーティのツールとウェブサイトセクションを追加。
- ツール検証手順を表示する。
- 進捗出力を簡素化する。
- 進捗ラインを着色する。
- 翻訳および検証中のアクティビティを表示。
- ツール行を整形する。
- モバイルメニューとマルチブレイクポイントレイアウトにより、ウェブサイトをレスポンシブ対応にする。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome を用いたフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO 対応と最初のブログ投稿を含むブログセクションを追加する。
- CLI 出力を右揃えの動詞形式に統一する。
- より詳細なメッセージフォーマットで CLI 出力をカラー化する。
- 正方形の OG 画像と Twitter カードメタタグを追加する。
- コーディネーターエージェントをツール使用機能付きの agentic なエージェントとして機能させる。
- 書き換え `glossia init` Agent クライアントプロトコル (ACP) を採用。
- Gemini 対応、自動検証、トークン追跡、および信頼性向上を追加。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割。
- CLI を TypeScript/Bun から Rust に書き換え。
