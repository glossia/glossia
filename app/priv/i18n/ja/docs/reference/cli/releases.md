## 0.2.0

*2026-02-14*

#### バグ修正

- プロダクション環境では OAuth プロバイダー設定をオプションとします。GitHub/GitLab の OAuth クレデンシャルが設定されていなくても、アプリは起動します。環境変数が存在する場合のみプロバイダーを設定します。
- プロダクションではデフォルトをポート 4000 にし、開発では 4050 を維持します。プロダクションプロキシはアプリがポート 4000 で動作することを期待しています。この `runtime.exs` デフォルトは 4050 だったため、デプロイ中にヘルスチェックが失敗しました。

#### 機能

- OAuth ログイン、ドキュメントの改善、UI 改善を備えた Phoenix アプリを追加する。
- 角丸のロゴをファビコンとして使用します。
- CLI を Bun に移行し、CI 実行可能ビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコードスニペットの横方向オーバーフローを防止する。
- モバイル上のコードスニペットに適正な右側余白を追加する。
- 水平方向のオーバーフローを防ぐためにモバイルレスポンシブレイアウトを改善する。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 投稿本文をヒーローレイアウトと揃え、ブログ記事の内容を改善する。
- ブログ記事の内容を水平に中央揃えにする。
- マルチバイト UTF-8 ツール結果の切断時に発生するパニックを修正する。

#### 機能

- ファーストパーティツールとウェブサイトセクションを追加。
- ツール検証ステップを明示する。
- 進行状況の出力を簡略化する。
- 進行状況の行を着色する。
- 翻訳および検証のアクティビティを表示。
- ツール行を整形する。
- モバイルメニューとマルチブレイクポイントレイアウトでウェブサイトをレスポンシブにする。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome を使ってフォーマットチェックを追加する。
- ホームページに漸進型精査セクションを追加する。
- SEO サポートと最初のブログ投稿を含むブログセクションを追加する。
- CLI 出力を右揃えの動詞形式に統一する。
- CLI 出力を、より詳細なメッセージフォーマットと共に色付ける。
- 正方形の OG イメージと Twitter カード用のメタタグを追加する。
- コーディネーターエージェントをツール使用を伴うエージェントとして機能させます。
- リライト `glossia init` エージェントクライアントプロトコル（ACP）により。
- ジェミニ対応、自動検証、トークン追跡、および信頼性の向上を追加します。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割します。
- TypeScript/Bun の CLI を Rust にリライトします。
