## 0.14.1

*2026-02-14*

#### バグ修正

- リリースアーカイブ内のバイナリをプラットフォーム固有の名前から単に `glossia`。
- パッケージ化前にバイナリから macOS のクアルレンティン xattr を削除する。

## 0.14.0

*2026-02-14*

#### 機能

- ローカルリリーススクリプトと手動管理チェンジログワークフローを追加

## 0.2.0

*2026-02-14*

#### バグ修正

- ホスティングされたログインプロバイダーの設定処理を修正
- ホスティングされたサービスのヘルスチェックを修正

#### 機能

- OAuth ログイン、ドキュメント改善、および UI 改善を備えた Phoenix アプリを追加。
- 丸いロゴをファビコンとして使用。
- CLI を Bun に移行し、CI 実行可能ビルドを更新。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイル端末でのコードスニペットの横溢れを防ぐ。
- モバイルでのコードスニペットに適切な右余白を追加。
- モバイルレスポンシブレイアウトを改善し、横方向のオーバーフローを防ぐ。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- Bun から Rust への翻訳ワークフローを更新する。
- 記事本文をヒーローレイアウトに合わせ、ブログ記事コンテンツを改善する。
- ブログ記事の内容を水平に中央揃えにする。
- 多バイト UTF-8 ツール結果を切り詰める際のパニックを修正する。

#### 機能

- ファーストパーティのツールとウェブサイトのセクションを追加する。
- ツールの検証ステップを明示する。
- 進捗出力を簡素化する。
- 進捗行を着色する。
- 翻訳および検証のアクティビティを表示する。
- ツール行をフォーマットする。
- モバイルメニューとマルチブレイクポイントレイアウトに対応したレスポンシブウェブサイトにする。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加。
- Biome を用いた形式チェックを追加。
- ホームページに Progressive Refinement セクションを追加。
- SEO 対応と初投稿を含むブログセクションを追加。
- 右揃え動詞形式で CLI 出力を統一する。
- より豊富なメッセージフォーマットで CLI 出力を色付けする。
- 正方形の OG 画像と Twitter カードメタタグを追加。
- ツール使用によりコーディネーターエージェントを agentic にする。
- 書き換え `glossia init` Agent Client Protocol（ACP）を使用して。
- ジェミニ対応、自動検証、トークン追跡、および信頼性の向上を追加。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの別々のジョブに分割。
- TypeScript/Bun から Rust に CLI を書き換える。
