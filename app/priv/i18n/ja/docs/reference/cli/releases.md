## 0.14.1

*2026-02-14*

#### バグ修正
- リリースアーカイブ内のバイナリをプラットフォーム固有の名前から単に `glossia` に変更。
- パッケージ化前にバイナリから macOS 隔離属性 xattr を削除。

## 0.14.0

*2026-02-14*

#### 新機能
- ローカルのリリーススクリプトと手動で管理する変更履歴ワークフローを追加。

## 0.2.0

*2026-02-14*

#### バグ修正
- ホストされたログインプロバイダーの構成処理を修正。
- ホストされたサービスの健全性チェックを修正。

#### 新機能
- OAuth ログイン、ドキュメント強化、UI 改善を備えた Phoenix アプリを追加。
- 丸形ロゴをファビコンとして使用。
- CLI を Bun に移行し、CI の実行可能ビルドを更新。

## 0.1.0

*2026-02-12*

#### バグ修正
- モバイルでのコードスニペットの横方向の溢れを防ぐ。
- モバイルでのコードスニペットに適切な右余白を追加。
- 横方向の溢れを防ぐためにモバイルのレスポンシブレイアウトを改善。
- Biome 書式を適用。
- リリースノートテンプレートにグループヘッダーを追加。
- 翻訳ワークフローを Bun から Rust に更新。
- ヒーローレイアウトと投稿本文を一致させ、ブログ投稿内容を改善。
- ブログ投稿内容を水平に中央揃え。
- マルチバイト UTF-8 ツール結果の切り捨て時にパニックを修正。

#### 新機能
- ファーストパーティのツールとウェブサイトセクションを追加。
- ツール検証ステップを表示。
- 進行状況の出力を簡素化。
- 進行状況ラインを着色する。
- 翻訳および検証中のアクティビティを表示。
- ツール行の書式設定。
- モバイルメニューとマルチブレイクポイントレイアウトを備えてウェブサイトをレスポンシブにする。
- Bun/TypeScript で CLI を再実装。
- CI ワークフローとテストを追加。
- Biome を使用してフォーマットチェックを追加。
- ホームページに段階的洗練セクションを追加。
- SEO 支援と pertama ブログ投稿を備えたブログセクションを追加。
- 右揃えの動詞形式で CLI 出力を統一。
- より豊かなメッセージフォーマットで CLI 出力を色付け。
- 正方形の OG イメージと Twitter カードメタタグを追加。
- ツール使用によりコーディネーターエージェントをエージェント化する。
- Agent Client Protocol (ACP) で `glossia init` を再構築。
- Gemini 対応、自動検証、トークン追跡、および信頼性改善を追加。

#### リファクタリング
- CI を個別のフォーマット、型チェック、テスト、ビルドジョブに分割。
- CLI を TypeScript/Bun から Rust に再構築。
