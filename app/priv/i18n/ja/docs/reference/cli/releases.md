## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境で OAuth プロバイダー設定をオプションとする。GitHub/GitLab の OAuth 認証が設定されていなくてもアプリは起動する。環境変数が存在する時にのみプロバイダーを設定する。
- 本番環境ではポート 4000 をデフォルトとし、開発環境では 4050 を維持する。本番の代理サーバーはアプリをポート 4000 で期待している。`runtime.exs`のデフォルトは 4050 だったため、デプロイ中のヘルスチェックが失敗した。

#### 機能

- OAuth ログイン、ドキュメントの改善、および UI の向上を含む Phoenix アプリを追加する。
- 丸いロゴをファビコンとして使用する。
- CLI を Bun へ移行し、CI の実行ファイルビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコードスニペットの横溢れを防止する。
- モバイルでのコードスニケットに適切な右 tantos 余白を追加する。
- 水平な溢れ防止のためにモバイルのレスポンシブレイアウトを改善する。
- Biome によるフォーマットを適用する。
- リリースノートテンプレートにグループヘッディングを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- ブログ記事の内容をヒーローレイアウトと一致させたら。
- ブログ記事の内容を水平に中央揃えする。
- マルチバイト UTF-8 ツール結果を切断する際のパニックを修正する。

#### 機能

- ファーストパーティツールとウェブサイトセクションを追加する。
- ツール検証手順を\_surface Zwar する。
- 進捗出力を簡略化する。
- 進捗線の着色を行う。
- 翻訳および検証のアクティビティを表示する。
- ツール行をフォーマットする。
- モバイルメニューとマルチブレイクポイントレイアウトを使用してレスポンシブなウェブサイトを構築する。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome によるフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO サポートと最初のブログ記事を含むブログセクションを追加する。
- 右揃えた動詞フォーマットを使用して CLI 出力を統一する。
- R رہνηcher における CLI 出力を色付けする。
- 正方形 OG イメージと Twitter カード meta タグを追加する。
- ツール使用でコーディネーターエージェントをエージェント化する。
- Agent Client Protocol (ACP) `glossia init` with 再実装する。
- Gemini サポート、自動検証、トークントラッキング、および信頼性の向上を追加する。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割する。
- TypeScript/Bun から Rust に CLI を書き直す。
