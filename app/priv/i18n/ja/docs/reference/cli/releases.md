## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では OAuth プロバイダー設定をオプションにしました。GitHub/GitLab OAuth 認証情報が設定されていなくてもアプリケーションは起動します。環境変数が存在する場合のみプロバイダーを設定してください。
- 本番環境のデフォルトをポート 4000 にし、開発環境では 4050 を維持します。本番プロキシはポート 4000 のアプリを想定しています。その `runtime.exs` デフォルトが 4050 であったため、デプロイ時のヘルスチェックが失敗する原因となりました。

#### 新機能

- OAuth ログイン対応の Phoenix アプリを追加。ドキュメント機能の改善および UI の向上。
- ファビコンとして丸いロゴを使用。
- CLI を Bun に移行し、CI の実行可能ビルドを更新。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイル端末でのコードスニケットの横方向のオーバーフローを防止。
- モバイルのコードスニペットに適切な右端余白を追加します。
- 横方向のオーバーフローを防ぐため、モバイル レスポンシブ レイアウトを改善します。
- biome フォーマットを適用します。
- リリース ノーツ テンプレートにグループ見出しを追加します。
- 翻訳ワークフローを Bun から Rust へ更新します。
- 投稿本文をヒーロー レイアウトに合わせて揃え、ブログ投稿の内容を改善します。
- ブログ投稿の内容を水平方向に中央揃えします。
- マルチバイト UTF-8 ツール結果を截る際のパニックを修正します。

#### 機能

- ファーストパーティツールとウェブサイトセクションを追加
- ツール検証手順を目立たせる
- 進捗表示を簡素化する
- 進捗ラインに着色する
- 翻訳および検証アクティビティを表示する
- ツール行を整形する
- モバイルメニューとマルチブレイクポイントレイアウトでレスポンシブウェブサイトを構築する
- Bun/TypeScript に CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome を使用したフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO 対応のブログセクションと最初の投稿を追加する。
- 右揃え動詞形式で CLI の出力を統一する。
- より豊かなメッセージフォーマットで CLI の出力を色付ける。
- 正方形の OG 画像と Twitter カードのメタタグを追加する。
- コーディネーターエージェントをツール使用に対応したエージェントにする。
- 書き換え。 `glossia init` エージェントクライアントプロトコル (ACP) で。
- ジェミニ対応、自動検証、トークン追跡、および信頼性向上を追加。

#### リファクタ。

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割。
- TypeScript/Bun から Rust への CLI の書き換え。
