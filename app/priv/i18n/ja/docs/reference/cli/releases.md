## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では OAuth プロバイダー設定をオプションとしました。GitHub/GitLab の OAuth 認証情報が設定されていなくても、アプリケーションは起動します。環境変数が存在する場合のみ、プロバイダーを構成します。
- 本番環境のデフォルトポートを 4000 に、開発環境では 4050 を維持します。本番プロキシはアプリがポート 4000 で動作することを前提としています。その `runtime.exs` デフォルトは 4050 でした。これにより、デプロイ中のヘルスチェックに失敗しました。

#### 機能

- OAuth ログイン機能、ドキュメント改修、および UI 改善を含む Phoenix アプリの追加
- 丸いロゴを favicon として使用する
- CLI を Bun に移行し、CI の実行可能ビルドを更新

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイル表示でのコードスニペットの横方向のはみ出しを防ぐ
- モバイルでコードスニペットに適切な右余白を追加する。
- 水平方向の溢れを防止するためにモバイル対応レスポンシブレイアウトを改善する。
- Biome 書式設定を適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 記事本文をヒーローレイアウトに合わせ、ブログ投稿の内容を改善する。
- ブログ投稿の内容を水平方向に中央揃えする。
- 多バイト UTF-8 ツール結果を切断する際のパニックを修正する。

#### 機能

- ファーストパーティ製ツールおよびウェブサイトのセクションを追加する。
- ツールの検証手順を表示する。
- プログレス出力を簡素化する。
- プログレス行に色を付ける。
- 翻訳中および検証中のアクティビティを表示する。
- ツールの行をフォーマットする。
- モバイルメニューとマルチブレイクポイントレイアウトでウェブサイトをレスポンシブにする。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome によるフォーマットチェックの追加。
- ホームページに Progressive Refinement セクションを追加する。
- SEO 対応と最初の投稿付きのブログセクションを追加する。
- 右揃え動詞フォーマットで CLI 出力を統一する。
- より充実したメッセージフォーマットで CLI 出力をカラー化。
- 正方形の OG 画像と Twitter カードメタタグを追加する。
- ツール使用による能動性を備えたコーディネーターエージェントにする。
- 書き直し `glossia init` Agent Client Protocol (ACP) を用いて。
- Gemini 対応、自動検証、トークン追跡、および信頼性の向上を追加。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの各ジョブに分割。
- CLI を TypeScript/Bun から Rust に書き換える。
