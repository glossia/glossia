## 0.14.1

*2026-02-14*

#### バグ修正
- リリースアーカイブ内のバイナリをプラットフォーム固有の名前から単に `glossia` に変更する。
- パッケージ化前に macOS quarantine xattr をバイナリから除去する。

## 0.14.0

*2026-02-14*

#### 機能
- ローカルリリーススクリプトと手動管理の更新履歴ワークフローを追加する。

## 0.2.0

*2026-02-14*

#### バグ修正
- ホストログインプロバイダーの構成処理を修正する。
- ホストサービスのヘルスチェックを修正する。

#### 機能
- OAuth ログイン、ドキュメント強化、および UI 改善を備えた Phoenix アプリを追加する。
- 丸みを帯びたロゴをファビコンとして使用する。
- CLI を Bun に移行し、CI の実行可能ビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正
- モバイル環境でのコードスニペットの横方向オーバーフローを防ぐ。
- モバイルでのコードスニペットに適切な右マージンを追加する。
- 横方向オーバーフローを防ぐためのモバイルレスポンシブレイアウトを改善する。
- Biome フォーマットを適用する。
- リリースノートテンプレートにグループタイトルを追加する。
- Translate ワークフローを Bun から Rust に更新する。
- 投稿本文をヒーローレイアウトに合わせて配置し、ブログ投稿内容を改善する。
- ブログ投稿内容を横方向に中央揃えにする。
- マルチバイト UTF-8 ツール結果を切断した際のパニックを修正する。

#### 機能
- ファーストパーティツールとウェブサイトセクションを追加する。
- ツール検証手順を明確化する。
- 進行状況の出力を簡素化する。
- 進行状況ラインに着色を施す。
- 翻訳および検証活動を表示する。
- ツールラインをフォーマットする。
- モバイルメニューとマルチブレイクポイントレイアウトで Web サイトをレスポンシブにする。
- CLI を Bun/TypeScript で再実装する。
- CI ワークフローとテストを追加する。
- Biome を使用してフォーマットチェックを導入する。
- ホームページにプログレッシブリファインメントセクションを追加する。
- SEO サポート付きのブログセクションと最初のブログ投稿を追加する。
- CLI 出力を右揃え動詞形式で統一する。
- メッセージフォーマットを強化し CLI 出力をカラー化する。
- 四角形の OG 画像と Twitter カード meta タグを追加する。
- ツール使用機能を持たせてコーディネーターエージェントを代理操作化する。
- Agent Client Protocol (ACP) で `glossia init` を再実装する。
- Gemini 対応、自動検証、トークン追跡、および信頼性の向上を追加する。

#### リファクタリング
- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割する。
- CLI を TypeScript/Bun から Rust に再実装する。
