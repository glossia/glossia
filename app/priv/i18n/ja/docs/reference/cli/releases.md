## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境で OAuth プロバイダー設定をオプションにします。GitHub/GitLab の認証情報が設定されていなくてもアプリは起動します。環境変数が存在する場合のみプロバイダーを設定します。
- 本番環境のデフォルトポートを 4000 にし、開発環境には 4050 を維持します。本番プロキシは 4000 ポートのアプリを期待しています。デ `runtime.exs` フォルトは 4050 だったため、これによりデプロイ中のヘルスチェックに失敗しました。

#### 機能

- OAuth ログインを備えた Phoenix アプリの追加、ドキュメントの改善、および UI の向上。
- 丸いロゴをファビコンとして使用する。
- CLI を Bun に移行し、CI の実行可能ビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコードスニペットの横はみ出しを防ぐ。
- モバイルでのコードスニペットに適切な右余白を追加する。
- モバイルレスポンシブレイアウトを改善して、水平方向のオーバーフローを防ぐ。
- biome のフォーマットを適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 記事本文をヒーローレイアウトに合わせて配置し、ブログ投稿の内容を改善する。
- ブログ投稿コンテンツを水平に中央揃えする。
- 多バイト UTF-8 ツール結果の切り詰め時に発生するパニックを修正する。

#### 機能

- ファーストパーティツールとウェブサイトセクションを追加。
- ツール検証手順を明示する。
- 進捗出力を簡素化する。
- 進捗ラインに色を付ける。
- 翻訳および検証中のアクティビティを表示する。
- ツール行を整形する。
- モバイルメニューと多段ブレイクポイントレイアウトを備えたレスポンシブなウェブサイトにする。
- CLI を Bun/TypeScript で再実装する。
- CI ワークフローとテストを追加する。
- Biome を用いたフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO サポートおよび最初の投稿を含んだブログセクションを追加する。
- CLI 出力を右揃えの動詞形式に統一する。
- CLI 出力を、より豊かなメッセージフォーマットでカラー化する。
- 正方形の OG 画像と Twitter カード用メタタグを追加する。
- 協調エージェントにツール利用による代理動作（agentic）を実装する。
- 書き換え `glossia init` Agent Client Protocol (ACP) を使用して。
- Gemini 対応、自動検証、トークン追跡、および信頼性強化を追加。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割。
- TypeScript/Bun から Rust への CLI 書き換え。
