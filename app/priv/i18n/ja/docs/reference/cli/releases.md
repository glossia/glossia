## 0.2.0

*2026-02-14*

#### 修正

- 本番環境では OAuth プロバイダー設定をオプションにしました。GitHub/GitLab OAuth の認証情報が設定されていなくても アプリは起動します。環境変数が設定されている場合のみ、プロバイダーを設定してください。
- 本番環境のデフォルトポートを 4000 にし、開発環境では 4050 を維持します。本番プロキシはポート 4000 のアプリを想定しています。デフォルトは `runtime.exs` 4050 でした。これにより、デプロイ中のヘルスチェックが失敗しました。

#### 機能

- OAuth ログイン、ドキュメント強化、UI 改善を備えた Phoenix アプリを追加。
- 丸いロゴをファビコンとして使用する。
- CLI を Bun に移行し、CI 実行可能ビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコードスニペットの横幅オーバーフローを防止。
- モバイルでコードスニペットに適切な右マージンを追加する。
- 横方向の溢れを防ぐためにモバイルレスポンシブレイアウトを改善する。
- Biome フォーマットを適用する。
- リリースノートテンプレートにグループ見出しを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 記事本文をヒーローレイアウトに合わせて整え、ブログ記事内容を改善する。
- ブログ記事の内容を水平方向に中央揃えする。
- 多バイト UTF-8 ツールの結果を切り詰めた際のパニックを修正する。

#### 機能

- ファーストパーティのツールとウェブサイトセクションを追加する。
- ツール検証の手順を明確にする。
- 進捗出力を簡素化する。
- 進捗ラインを着色する。
- 翻訳および検証中のアクティビティを表示する。
- ツール行を整形する。
- モバイルメニューとマルチブレイクポイントレイアウトを持つレスポンシブウェブサイトにする。
- Bun/TypeScript で CLI を再実装。
- CI ワークフローとテストを追加。
- Biome でフォーマットチェックを追加。
- ホームページに Progressive Refinement セクションを追加。
- SEO 対応と最初のブログ投稿を含むブログセクションを追加。
- CLI 出力を右揃え動詞形式で統一。
- CLI 出力をより豊かなメッセージフォーマットで着色。
- 正方形の OG 画像と Twitter カードメタタグを追加。
- コーディネーターエージェントをツール使用に対応させたエージェントにする。
- 書き換え `glossia init` エージェントクライアントプロトコル (ACP) により。
- Gemini 対応、自動検証、トークン追跡、および信頼性向上を追加。

#### リファクタリング

- CI をフォーマット、型チェック、テスト、ビルドの個別ジョブに分割。
- CLI を TypeScript/Bun から Rust に書き換える。
