## 0.2.0

*2026-02-14*

#### バグ修正

- 本番環境では OAuth プロバイダー設定をオプション化しました。GitHub/GitLab OAuth 認証情報が設定されていなくても、アプリは起動します。環境変数が設定されている場合のみプロバイダーを設定します。
- 本番環境ではポート 4000 をデフォルトとし、開発環境では 4050 を維持します。プロダクションプロキシはアプリをポート 4000 で期待しています。その `runtime.exs` デフォルトは 4050 であり、デプロイ中のヘルスチェックによって失敗しました。

#### 機能

- OAuth ログイン、ドキュメント改善、UI 改善を含む Phoenix アプリの追加。
- 丸いロゴをファビコンとして使用する。
- CLI を Bun に移行し、CI 実行ファイルのビルドを更新する。

## 0.1.0

*2026-02-12*

#### バグ修正

- モバイルでのコード スニペットの水平オーバーフローを防ぐ。
- モバイルのコードスニペットに適切な右マージンを追加する。
- 横スクロールを防ぐモバイルレスポンシブレイアウトを改善する。
- biome フォーマットを適用する。
- リリースノートテンプレートにグループヘッダーを追加する。
- 翻訳ワークフローを Bun から Rust に更新する。
- 投稿本文をヒーローレイアウトに合わせて配置し、ブログ投稿の内容を改善する。
- ブログ投稿の内容を水平中央揃えにする。
- 多バイト UTF-8 ツール結果の切断時に発生するパニックを修正する。

#### 機能

- ファーストパーティのツールとウェブサイトセクションを追加。
- ツールの検証ステップを目立たせる。
- 進捗出力を簡素化する。
- 進捗ラインを着色する。
- 翻訳および検証中のアクティビティを表示。
- ツール行を整形する。
- モバイルメニューとマルチブレイクポイントレイアウトによるレスポンシブ対応。
- Bun/TypeScript で CLI を再実装する。
- CI ワークフローとテストを追加する。
- Biome を用いてフォーマットチェックを追加する。
- ホームページに Progressive Refinement セクションを追加する。
- SEO 対応と最初のブログ投稿を含むブログセクションを追加する。
- CLI 出力を右揃えの動詞形式に統一する。
- より豊かなメッセージフォーマットで CLI 出力をカラー化する。
- 正方形の OG イメージと Twitter カードメタタグを追加する。
- ツール使用による自律性を持つコーディネーターエージェントに変更しました。
- 書き直し `glossia init` Agent Client Protocol (ACP) を使用して。
- Gemini 対応、自動検証、トークン追跡、および信頼性向上を追加しました。

#### 改修

- CI をフォーマット、型チェック、テスト、ビルドの個別のジョブに分割しました。
- CLI を TypeScript/Bun から Rust に書き直しました。
