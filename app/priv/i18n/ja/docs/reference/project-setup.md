プロジェクトセットアップは、Glossia を連携させるリポジトリの準備を行います。ユーザーが**新規プロジェクト** フローでリポジトリを選択した後、2 つのセットアップモードの 1 つを選択します。

## セットアップモード

| モード | Glossia が行うこと | 選択タイミング |
|---|---|---|
| **自動設定** | 選択したターゲット言語向けの生成された`L10N.md`設定を使用して、リポジトリを検査し、プルリクエストを開きます。 | まだリポジトリにはローカライズ設定がありません。 |
| **手動設定** | プロジェクトを即座に作成します。リポジトリの検査や変更、またはプルリクエストの作成を行いません。 | リポジトリにはすでに`L10N.md`ファイルが存在するか、あるいはメンテナーが作成する予定です。 |

以下のステータス、進捗情報、およびプルリクエストは、自動設定用にのみ適用されます。

## 手動設定

手動設定されたプロジェクトにはセットアップ状態がありません。作成直後に使用可能であり、設定失敗によって破棄されることはありません。

Glossia は、リポジトリのデフォルトブランチへの次のプッシュで翻訳ランを開始します。そのランは、**新規プロジェクト** フローでターゲット言語が選択されていないため、リポジトリの[`L10N.md`](/docs/reference/l10n-md)ファイルに宣言されたすべてのターゲットに翻訳されます。

最初の翻訳ランまで、プロジェクトの概要には`L10N.md`ファイルを含むプッシュを待機中であることを説明する通知が表示されます。

## 前提条件

- アカウントには設定済みのモデルが少なくとも 1 つあります。
- Glossia GitHub アップは選択されたリポジトリにアクセスできます。
- ユーザーはアカウント内でプロジェクトを作成できます。
- 自動設定の場合、少なくとも 1 つのターゲット言語が選択されています。

## ステータス

| ステータス | 意味 | 利用可能な操作 |
|---|---|---|
| **保留中** | プロジェクトは承認され、開始を待機しています。 | 進捗を確認するか、ページを離れて後に戻ってください。 |
| **実行中** | Glossia はリポジトリを検査・更新中です。 | リアルタイムの活動を確認してください。 |
| **完了** | ローカライズの基準は準備され、レビュー用に公開されました。 | プルリクエストを開き、レビューしてマージしてください。 |

セットアップが**保留中**または**実行中**の間、プロジェクトは一時的なステータスです。セットアップが完了不能または利用可能な変更の公開に失敗した場合、Glossia はセットアップ環境をクリーンアップし、一時的なプロジェクトを削除します。その後、リポジトリは**新規プロジェクト**フローで利用可能となり、再度セットアップが可能になります。

## 表示される進捗

セットアップカードは、新規プロジェクト フローおよびプロジェクトの概要において引き続き利用可能です。含まれる内容：

- ステータスバッジと進捗バー。
- 現在のステータスを短く説明します。
- リポジトリの準備、検査、ファイル変更、チェック、完了に関する直近の活動。
- セットアップの完了に失敗した場合に表示される明確な失敗メッセージ。

一時的なプロジェクトが存在する間、進捗は保存されます。致命的な失敗が発生した場合、プロジェクトと表示されるセットアップ進捗が両方とも破棄されます。

## 完了結果

正常に接続されたセットアップがリポジトリのデフォルトブランチに対する専用ブランチとプルリクエストを作成します。このプルリクエストには、生成されたローカリゼーションの基準、`L10N.md` コンテキスト、およびローカリゼーションコンテンツを読み込むために必要な最小限の実用的な変更が含まれています。

セットアップはヘッダーだけのターゲットカタログを公開しません。精密化フレームワークが翻訳前にターゲットカタログを必要とする場合、カタログには翻訳値の空の抽出ソースメッセージエントリのみが含まれます。ターゲットカタログはまだ必須ではない場合、セットアップはそれらを最初の翻訳ランのために留めます。

Glossia はプルリクエストをマージしません。リポジトリのメンテナは通常の GitHub プロセスを通じて、レビューとマージを行います。

このプルリクエストが開いている間、プロジェクトの概要にはセットアップ通知が表示されます。このプルリクエストがマージされた後、通知は削除されます。このプルリクエストがマージされずに閉じられた場合、概要はセットアップが完了とみなされる前に再オープンする必要がありますと説明します。
