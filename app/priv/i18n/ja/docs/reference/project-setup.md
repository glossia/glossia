プロジェクト設定は、Glossia と連携されたリポジトリを準備します。ユーザーが**新規プロジェクト**フローでリポジトリを選択した後、2 つのセットアップモードのいずれかを選択します。

## セットアップモード

| モード | Glossia が行う処理 | 選択するべき時 |
|---|---|---|
| **自動設定** | リポジトリを検査し、選択したターゲット言語向けの生成された`L10N.md`設定に対するプルリクエストを開きます。 | リポジトリにはまだローカライズ設定สรえません。 |
| **手動設定** | プロジェクトを直ちに作成します。リポジトリを検査したり、変更したり、プルリクエストを開いたりしません。 | リポジトリには`L10N.md`ファイルがすでに存在するか、メンテナンス者がそのファイルを作成します。 |

以下で説明する状態、進捗情報、およびプルリクエストは、自動設定のみ適用されます。

## 手動設定

手動設定されたプロジェクトには設定状態がありません。作成直後に使用可能となり、失敗したセットアップによって廃棄されることはありません。

Glossia は、リポジトリのデフォルトブランチへの次のプッシュで翻訳ジョブを開始します。このジョブは、リポジトリの[`L10N.md`](/docs/reference/l10n-md)ファイルにあるすべてのターゲット言語に翻訳します。これは、**新規プロジェクト**フローでターゲット言語が選択されていないためです。

最初の翻訳ジョブまで、プロジェクト概要では、Glossia が`L10N.md`ファイルを含むプッシュを待機していることを説明するお知らせが表示されます。

## 前提条件

- アカウントには少なくとも 1 つの構成済みのモデルが必要です。
- Glossia GitHub App は選択されたリポジトリへのアクセス権限が必要です。
- ユーザーはアカウント内でプロジェクトを作成できます。
- 自動設定の場合、少なくとも 1 つのターゲット言語が選択されています。

## 状態

| 状態 | 意味 | 利用可能なアクション |
|---|---|---|
| **保留中** | プロジェクトは承認され、開始を待機しています。 | 進行状況を確認するか、ページを出て後で戻ってください。 |
| **実行中** | Glossia はリポジトリを検査し、更新しています。 | ライブアクティビティを確認します。 |
| **完了** | ローカライズの基盤線が準備され、レビューのために公開されました。 | プルリクエストを開き、レビューしてマージします。 |

セットアップが**保留中**または**実行中**の間、プロジェクトは暫定的です。セットアップを完了できず、使用可能な変更を公開できない場合、Glossia はセットアップ環境をクリーンアップし、暫定的なプロジェクトを削除します。その後、リポジトリは**新規プロジェクト**フローで利用可能となり、セットアップをもう一度試すことができます。

## 表示される進捗

セットアップカードは、新規プロジェクトフローとプロジェクト概要でも利用可能です。含まれる項目は以下の通りです:

- 状態バッジと進捗バー。
- 現在の状態の短い説明。
- 最近のリポジトリ準備、検査、ファイル変更、チェック、完了に関するアクティビティ。
- セットアップが完了できない場合、明確な失敗メッセージが表示されます。

暫定的なプロジェクトが存在する間は進捗情報が保存されます。致命的なエラーにより、プロジェクトとその表示されるセットアップの進捗がともに破棄されます。

## 完了結果

成功した接続されたセットアップは、リポジトリのデフォルトブランチに対する専用ブランチとプルリクエストを作成します。プルリクエストには、生成されたローカライズの基盤線、`L10N.md` コンテキスト、およびローカライズされたコンテンツを読み込むために必要な最小限の実用的な変更が含まれます。

セットアップはヘッダーのみを含むターゲットカタログを公開しません。ローカライゼーションフレームワークが翻訳前にターゲットカタログを必要とする場合、カタログには抽出されたソースメッセージエントリと空の翻訳値が含まれています。ターゲットカタログがまだ必要とされない場合、セットアップはそれらを最初の翻訳ジョブのために残しておきます。

Glossia はプルリクエストをマージしません。リポジトリ管理者は、そのプルリクエストについて通常行われる GitHub プロセスでレビューおよびマージを行います。

このプルリクエストが開いている間は、プロジェクト概要にセットアップのお知らせが表示されます。プルリクエストがマージされた後、お知らせは削除されます。プルリクエストがマージされずに閉じられた場合、概要では、セットアップが完了とみなされる前に再度開く必要があることが説明されます。
