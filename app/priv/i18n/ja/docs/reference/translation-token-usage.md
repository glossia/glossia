## ダッシュボード

**設定 → モデル → トークン使用量** を開いて、生成翻訳のプロバイダー報告分の使用量を表示します。アクセスにはモデル設定の読み取り権限が必要です。

このダッシュボードでは、今日を含む直近 7、30、または 90 カレンダー日がサポートされ、すべて UTC です。モデル、プロジェクト、および言語のフィルターは合計数、日次チャート、および分割に適用されます。検索は分割行のみに対して動作します。選択された periode、次元、フィルター、検索、ソート、およびページは URL に保存されます。

## 指標

| 指標名 | 意味 |
| --- | --- |
| 入力トークン | プロバイダーによって処理された入力。報告されたキャッシュ読み取りおよびキャッシュ書き込みを含む。 |
| 出力トークン | プロバイダーから報告された出力。プロバイダーが出力カウントにそれを含める場合、論理推論を含む。 |
| キャッシュ入力トークン | キャッシュ読み取り。入力トークンのサブセットであり、合計への追加課金ではありません。 |
| 合計トークン | 入力トークンと出力トークンの合計。 |
| レスポンス | 入力と出力のカウント数ともに正のトークン合計を有するレスポンスです。ゼロ化された使用量欠損のフォールバックは無視されます。 |

トークンの数値は金銭的なコストではありません。プロバイダーは入力、出力、キャッシュ入力、およびキャッシュ書き込みに対して異なる料金を設定できます。

各報告されたレスポンスはカウントされます。バリデーション再試行、品質修正再試行、および出力制限に達して拒否されたレスポンスを含む。スキップされたファイルとモデルを呼び出さなかったチェックポイントヒットは使用量を増加させません。使用量がない失敗リクエストはカウントできません。

## 区分

- **プロジェクト** ごとに使用量がグループ化されます。すべての指標を単一のプロジェクトに限定するには、プロジェクトフィルターを使用します。
- **言語** は現在のスコープ内のプロジェクト間でターゲットのロケールごとにグループ化されます。`es` または `ja` のような。
- **ファイル** はソースパスおよびプロジェクトごとにグループ化されます。複数の言語に翻訳された同一のソースファイルは一度に現れます。異なるプロジェクトの同名ファイルは分離されたままです。

**未割り当て** はプロジェクトまたはソースパスのメタデータがないリクエストを可視化します。リポジトリ翻訳は双方を 자동으로 供給します。単一コンテンツ API リクエストは帰属のために`project_id` と`source_path` を提供できます。認証用のアカウントの外部にあるプロジェクト ID は未割り当てとして扱われます。無効またはが大きすぎるオプションメタデータは、トークン数を捨てることなく未割り当てされます。

## カバレッジ

使用量は ReqLLM API キーおよび OAuth 応答、Together 全成完、ならびに完了したローカル Codex ターンから収集されます。プロバイダー報告のカウントのみが永続化されます。ローカル Pi セッションまたは意思決定モデルの評価は含まれません。履歴翻訳はバックフィルまたは推定されません。したがって、合計は記録された使用を示すのみであり、完全なプロバイダー請求書ではありません。

、リーダーはアカウント、プロジェクト、モデルの識別子とハンドル、ターゲットロケール、ソースパス、カウント、およびタイムスタンプを保存します。プロンプト、翻訳内容、認証情報、または生プロバイダー応答は保存されません。使用量記録の失敗は翻訳を中断せずにログに記録されます。
