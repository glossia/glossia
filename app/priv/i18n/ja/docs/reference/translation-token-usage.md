## ダッシュボード

Open **設定 → モデル → トークン使用量** を表示します。 generating translation のサービス報告された使用状況を確認するには、モデル設定の読み取り権限が必要です。

ダッシュボードは、UTC 時間 기준の今日を含む過去 7 日、30 日、または 90 日のデータをサポートします。モデル、プロジェクト、言語フィルターは総計、日別グラフ、および詳細に適用されます。検索は詳細行のみを対象とします。選択された期間、ディメンション、フィルター、検索、ソート、およびページは URL に保持されます。

## 指標

| 指標項目 | 意味 |
| --- | --- |
| 入力トークン | プロバイダーによって処理された入力データ、報告されたキャッシュ読み取りとキャッシュ書き込みを含む。 |
| 出力トークン | プロバイダー報告の出力データ、プロバイダーが出力カウントに含ます場合の推論を含む。 |
| キャッシュ入力トークン | キャッシュ読み込み。入力トークンの一部であり、総計への追加請求ではありません。 |
| 総計トークン | 入力トークンと出力トークンの合計。 |
| 応答 | 入力と出力の両方のカウントと正のトークン合計を持つ応答。ゼロ化された未使用フォールバックは無視されます。 |

トークンカウントは料金ではありません。プロバイダーは入力、出力、キャッシュ入力、およびキャッシュ書き込み对不同费率を課金できます。

各報告された応答はカウントされます（検証リトライ、品質修正リトライ、出力制限に達して拒否された応答を含む）。スキップされたファイルやモデルを呼び出さないチェックポイントヒットは使用数に追加されません。使用数のない失敗リクエストはカウントされません。

## ディメンション

- **プロジェクト**ごとの使用量を集計します。すべての指標を単一のプロジェクトに制限するには、プロジェクトフィルターを使用します。
- **言語**は、現在の範囲内のプロジェクト全体でターゲット言語（例：`es` または `ja`）ごとにグループ化されます。
- **ファイル**は、ソースパスとプロジェクトごとにグループ化されます。同一のソースファイルを複数の言語に翻訳した場合は一度だけ表示され、異なるプロジェクトで同名のファイルは別々に保持されます。

**未割り当て**は、プロジェクトまたはソースパスのメタデータのないリクエストを可視化します。リポジトリ翻訳はこれらを自動的に提供します。単一コンテンツ API リクエストはアトリビューションのために `project_id` と `source_path` を提供できます。認証済みアカウント外のプロジェクト ID は未割り当てとして扱われます。無効または過大なオプションメタデータは、トークン数を破棄せずに未割り当てとして扱われます。

## カバレッジ

使用状況は、ReqLLM API クレジットおよび OAuth 応答、Together コンプリション、完了したローカル Codex ターンから収集されます。プロバイダーによる報告データのみが保存されます。ローカル Pi セッションと意思決定モデルの評価は含まれません。履歴翻訳は補填または推定されません。合計は記録された使用状況を記述し、提供される請求書全体の状況ではありません。

帳簿はアカウント、プロジェクト、モデル識別子とハンドル、ターゲットローカライゼーション、ソースパス、カウント、およびタイムスタンプを保管します。プロンプト、翻訳済みコンテンツ、認証情報、または生のプロバイダー応答は保存されません。使用状況記録の失敗は翻訳を中断しないようログに記録されます。
