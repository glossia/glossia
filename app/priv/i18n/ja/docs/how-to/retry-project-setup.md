条件を修正**設定の再試行** 後。

## 失敗の内容を確認

プロジェクト概要を開きます。設定進捗カードには失敗と最新の活動が表示されます。

原因としては、次のことが考えられます:

- アカウントに設定済みのモデルがありません。
- プロバイダーキーが欠落しているか無効になっています。
- Glossia GitHub アプリがリポジトリにアクセスできません。
- リポジトリの準備や確認ができませんでした。

## 必須条件を修正

モデルに関する問題の場合、**設定** と **モデル**を開きます。リポジトリへのアクセス問題の場合、Glossia GitHub アプリのインストールを更新し、リポジトリへのアクセス権を付与します。

## 再試行

プロジェクト概要に戻り、**設定の再試行**を選択します。

カードの状態は **保留**になり、**実行中**に変更され、処理が進行するに従って新しい活動が表示されます。再試行はプロジェクトが **失敗**状態にある間のみ可能であり、これは同時に 2 つのセットアップ試行の実行を防ぎます。

## 完了を確認

状態が **完了**に変更されたら、GitHub で生成されたプルリクエストを確認します。再度失敗する場合、カード内の新しい活動を使用して、以前のアテンプトとは異なる次のアクションを確認します。
