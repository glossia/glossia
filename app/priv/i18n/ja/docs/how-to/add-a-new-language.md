}
---
Glossia の設定が完了していて、別のターゲット言語を追加する場合は、以下の手順に従ってください。

## 1. GLOSSIA.md を更新する

`GLOSSIA.md` を開き、`targets` 配列に新しい言語コードを追加します。

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 言語固有のコンテキストを追加する（任意）

新しい言語に、敬体のレベルや文字セットに関する考慮事項などの特別な指示が必要な場合は、コンテキストのオーバーライドファイルを作成します。

```
GLOSSIA/
  ja.md
```

そのファイルに言語固有のガイダンスを記述します。Glossia は、日本語翻訳用の基本コンテキストにその内容を統合します。

## 3. 設定変更を公開する

更新した設定をコミットしてプッシュします。リポジトリが Glossia に接続されている場合、サーバーが新しいターゲット言語を検出し、翻訳セッションを開始します。

他の言語の既存翻訳は、その入力と実効コンテキストが変更されていない限り、変更されません。

## 4. 翻訳プルリクエストをレビューする

Glossia で翻訳セッションを確認し、サーバーが作成したプルリクエスト内の生成済み言語ファイルをレビューします。
