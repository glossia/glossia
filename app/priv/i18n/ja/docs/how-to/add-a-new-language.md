%{title: "新しい言語を追加する", summary: "既存の Glossia セットアップにターゲット言語を追加する方法。", category: "操作ガイド", order: 1}
---
Glossia が既に設定済みであり、別のターゲット言語を追加したい場合は、以下の手順に従ってください。

## 1\. L10N.md を更新

開いて、あなたの `L10N.md` と 新しい言語コードを末尾に `targets` 配列:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2\. 言語固有のコンテキストを追加（オプション）

新しい言語に特別な指示（例：丁寧さの度合いや文字セットの考慮事項など）が必要な場合は、コンテキスト オーバーライド ファイルを作成してください:

    L10N/
      ja.md

そのファイルに言語固有のガイダンスを記述してください。Glossia はそれを日本語翻訳用のベースコンテキストとマージします。

## 3\. 設定の変更を公開する

更新された設定をコミットしプッシュしてください。リポジトリが接続されている場合、
Glossia のサーバーは新しいターゲット言語を検知し、翻訳
セッションを開始します。

他の言語の既存の翻訳は、その入力が
有効なコンテキストに変更がない場合に不変です。

## 4\. 翻訳プルリクエストをレビューする

Glossia の翻訳セッションを進め、生成された言語をレビューしてください。
サーバーが作成したプルリクエスト内のファイル。
