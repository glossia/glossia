Glossia がすでに設定されており、別のターゲット言語を追加したい場合は、以下の手順に従ってください。

## 1. L10N.md を更新

`L10N.md` を開き、新しい言語コードを `targets` 配列に追加してください：

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 言語固有のコンテキストを追加（オプション）

新しい言語に特別な指示、例えば形式レベルや文字セットの考慮事項が必要であれば、コンテキストオーバーライドファイルを作成してください：

```
L10N/
  ja.md
```

そのファイルに言語固有のガイダンスを記述します。Glossia はこれを日本語翻訳の基本コンテキストと統合します。

## 3. 設定の変更を公開

更新された設定をコミットし、プッシュします。リポジトリが Glossia に接続されている場合、サーバーは新しいターゲット言語を検知し、翻訳セッションを開始します。

他の言語の既存の翻訳は、入力と有効なコンテキストに変更がない限り変更されません。

## 4. 翻訳プルリクエストをレビュー

Glossia 内の翻訳セッションを確認し、次にサーバーによって開かれたプルリクエスト内の生成された言語ファイルをレビューします。
