既に Glossia を設定しており、他のターゲット言語を追加したい場合は、これらの手順に従ってください。

## ## 1. L10N.md を更新

`L10N.md` を開いて、新しい言語コードを `targets` 配列に追加してください：

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## ## 2. 言語固有のコンテキストの追加（オプション）

新しい言語に特別な指示が必要ですが、敬語レベルや文字セットの考慮事項などについては、コンテキストオーバーライドファイルを作成してください：

```
L10N/
  ja.md
```

そのファイルに言語固有のガイダンスを記述してください。Glossia はそれを日本語翻訳用の基準コンテキストとマージします。

## ## 3. 設定変更を公開

更新された設定をコミットしてプッシュしてください。リポジトリが Glossia に接続されている場合、サーバーは新しいターゲット言語を検知し、翻訳セッションを開始します。

入力と効果的なコンテキストが変更されていない場合、他の言語の既存翻訳は変更されません。

## ## 4. 翻訳プルリクエストのレビュー

Glossia で翻訳セッションを追跡し、サーバーによって開かれたプルリクエスト内の生成された言語ファイルをレビューしてください。
