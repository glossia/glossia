すでに Glossia を設定しており、他のターゲット言語を追加したい場合は、以下の手順に従ってください。

## 1. L10N.md を更新

`L10N.md` を開き、新しい言語コードを `targets` アレイに追加してください:

```yaml
targets:
  - es
  - fr
  - de
  - ja
```

## 2. 言語固有のコンテキストを追加（オプション）

新しい言語に特別な指示が必要（例：丁寧さレベルや文字セットの考慮）の場合は、コンテキスト オーバーライド ファイルを作成してください:

```
L10N/
  ja.md
```

そのファイルに言語固有のガイダンスを記述してください。Glossia はこれを日本語翻訳におけるベースコンテキストとマージします。

## 3. 設定の変更を公開

更新された設定をコミットし、プッシュしてください。リポジトリが Glossia に接続されている場合、サーバーは新しいターゲット言語を検知し、翻訳セッションを開始します。

他の言語の既存の翻訳は、それぞれの入力と有効なコンテキストに変更がない限り不変のままです。

## 4. 翻訳のプルリクエストを確認

Glossia で翻訳セッションを確認し、サーバーによって開かれたプルリクエストに生成された言語ファイルを確認してください。
