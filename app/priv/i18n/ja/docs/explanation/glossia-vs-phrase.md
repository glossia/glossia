製品のパブリッシングシステムに従って言語作業を行いたい場合、**並行する翻訳管理プロセスを構築するのではなく Glossia を選択してください。** Git でコンテンツを保持し、独自資格情報で対応モデルを選択し、リポジトリが既に信頼しているチェックで結果を検証します。

[Phrase](https://phrase.com/) はローカライズスイートを提供し、ソフトウェアローカライズと管理翻訳の異なるニーズに対応するために Phrase Strings と Phrase TMS を含む。Glossia は焦点を合わせたアプローチを取ります：ソフトウェアチームに、彼らが既存のレビューおよび配送ループに合う言語 OS を取り付ける。

## Glossia を選ぶ理由

| 優先事項 | Glossia の優位性 |
|---|---|
| ソフトウェアと一緒に言語変更を配信 | リポジトリの更新はローカライズを駆動し、出力はレビュー可能な変更として返されます。 |
| 処理を監視し、自ら権限を持ちます | パブリックソースはアプリケーションとデプロイの実装を公開し、ライセンス条項の下での改変とセルフホスティングを許可します。 |
| 独自のトークンを導入 | 対応するモデルプロバイダーの資格を構成し、リポジトリ設定でアカウントハンドルを通じてモデルを選択します。 |
| 検証パイプラインを再利用 | 翻訳候補に対してリポジトリ固有のチェックを実行し、ファイルがビルドすることを言語の承認として証明するのではなく。 |
| 永続的な所有権を維持 | 公開されたファイル、構成、およびプルリクエスト履歴はリポジトリに保持されます。 |

## ローカライズを継続的配送の一部にする

Glossia の変更検出は、変更しない入力に対する翻訳作業の繰返しを防ぎます。そのリポジトリのスコープはプロジェクトごとに 1 つのオープン翻訳プルリクエストを保持し、バッチで進捗を公開するため、高速化ソースリポジトリは小さな変更ごとに新しい翻訳プロセスを必要としません。

目的はレビューがない状態での生産競争ではありません。チームが既に利用しているパイプラインを通じて言語作業を継続的にお見直し可能かつ配送可能にすることです。

Phrase は API、統合、自動化も提供します。Glossia が強調する優位性はアーキテクチャの整合性です：リポジトリはコンテンツ権威および配送境界であり、他のワークスペースの結果を同期するだけの場所としてではなく。

## モデル選択と資格を自らの管理下で保持

Glossia は対応するモデルのプロバイダー API トークンを受け入れます。資格はアカウント設定に留まり、リポジトリは安定したハンドルを選択します。チームはトークンをローテーションするかハンドルの背後にあるモデルを変更してもリポジトリの指示を書き換えることはありません。

異なるコンテンツの範囲とターゲット言語は異なる設定モデルを使用できます。オプションの決定モデルは翻訳を評価し修正をリクエストできますが、言語的判断の責任は人間に留まります。現在の動作と制限について [アカウントモデル](./account-models) を参照してください。

## リポジトリはすでに有効コンテンツの意味を知っています

翻訳管理システムの文字列の見解は、必然的にアプリケーションのファイルの見解ではありません。リポジトリには独自のパーサー、コンパイラ、コンポーネントルール、ドキュメントビルド、プレースホルダーチェックがある可能性があります。

Glossia は `L10N.md` 検証コマンドでそれらのチェックを再利用できます。それは検証のために候補を一時的に実際ターゲットパスに書き込み、有効にされるまで必要なチェックが通過するまで受容しません。コマンドとその依存項は実行環境に利用可能である必要があります。

これにより、チームは翻訳ワークスペースの内部でのみに「有効」の定義を維持するのではなく、既存の品質境界を拡大できます。[L10N.md](/docs/reference/l10n-md) を参照してください。

## パブリック実装、ブラックボックスではない

Glossia のアプリケーション、CLI、SDK、インフラのソースは公開されています。コアは [Apache-2.0](https://github.com/glossia/glossia/blob/main/LICENSE-APACHE) に基づき、その条件の下で商用利用、変更、配布、セルフホスティング、競合するホスト型サービスの提供が可能です。`ee/` のコードには別の [Enterprise ライセンス](https://github.com/glossia/glossia/blob/main/ee/LICENSE.md) が適用され、本番環境での利用には書面による商用契約が必要です。

より広い翻訳スイートは、専門家の翻訳操作と複雑な連携に意味があります。あなたの優先順位が **独自のトークンとリポジトリチェックでソフトウェア配送速度と一致する** ロウコンのラベル、Glossia はワークフローを直接的に保つように設計されています。

確立された翻訳プログラムを移動する場合は、そのメモリ、用語、および歴史の計画が必要です。このページは Phrase インポーターの自動またはフルスイートパラリティを保証せず、Phrase が同等のすべての統合を欠いていると日常的に述べません。特定製品の現在の機能については [Phrase のドキュメント](https://support.phrase.com/)、ご参照ください。
