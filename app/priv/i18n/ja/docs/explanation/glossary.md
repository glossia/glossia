グロッサリは、翻訳が一貫性のある方法でレンダリングされる必要がある用語の厳選されたセットです。バージョン制御の文脈における "Commit" はそのまま残ります。 `commit` スペイン語では、これになります。 `提交` 簡体中国語では、かつ、 `コミット` 日本語です。各言語ごとに 1 つの決定、すべてで強制されます。

## グロッサリが置ける 2 つの場所

Glossia は 2 つの場所から用語を検索し、翻訳時にそれらをマージします：

- **あなたのリポジトリ**, 既に翻訳設定で使用しているファイルにあります。 `L10N.md` 用語を宣言し、各言語の `L10N/<locale>.md` 翻訳を宣言する。これは開発者主導の用語辞書です：変更はプルリクエストを通じて進み、各言語のレビュアーは独自のファイルを管理し、ネストされたファイルはリポジトリの一部でこれを洗練させることができます。
- **サーバー**, あなたのアカウントに保存されています。これは言語専門家主導の用語辞書です：レビューアやローカライズ貢献者はコードに触れることなく、ダッシュボード、 [REST API](/docs/reference/apis), または [MCP サーバー](/docs/reference/mcp)。これはアカウントが翻訳するすべてのリポジトリに適用されます。

どちらも役立ちますが、互いに代替できません。

## どちらを使用すべきか

用語を **サーバー上で** 条件：

- **複数のリポジトリに適用されます。** 製品名、ブランド用語、および企業用語は一度に定義され、すべての場所で使用されます。
- **それを決定する担当者はリポジトリ内で勤務していません。** リンガリスト、レビューワーカー、および外部のコントリビューターは、リポジトリがクローズドソースである場合でも、書き込み権限がない場合でも、用語集を改善できます。
- **コード変更なしで用語を修正したい場合。** 修正された翻訳は、コードベースへのプルリクエストを伴わず、次の実行時に適用されます。
- **変更はレビューと履歴を必要とします。** 各編集は変更ノート付きの新しいバージョンを作成し、コントリビューターは承認待ちの提案として変更を提案でき、以前作成されたバージョンも引き続き利用可能です。
- **他のツールもこれが必要です。** エージェントや統合機能は、REST API および MCP サーバーを介して用語集を読み取り、承認済みの用語を使用する新しいコンテンツの作成などを行えます。

用語を定義する場所で **あなたのリポジトリ** 条件：

- **これはこのコードベースに属します。** 特定のプロジェクトのみに意味を特化した用語、例えばバージョン管理のアクションを意味する「コミット」は、それを使用中のコードの隣に置かれます。
- **ソーステキストと共に変化する必要があります。** 用語とその導入コピーは同じプルリクエストにまとめられ、共同レビューされます。
- **リポジトリ全体ではなく、一部だけで良い場合があります。** ネストされた `L10N.md` または `L10N/<locale>.md` 特定のディレクトリ（マーケティングページなど）のエントリを追加または上書きできます。
- **サーバー設定を上書きします。** 同一用語について、それを翻訳する言語では、リポジトリのエントリはサーバーのエントリよりも優先されます。

## それらの組み合わせ方

各ファイルとターゲット言語に対し、Glossia は 2 つの用語集を 1 つの有効なセットに統合します：

1. ターゲット言語のサーバー用語集のエントリから始めます。
2. その言語のリポジトリ用語集のエントリを重ねます：ファイルの用語を `L10N.md` その中に翻訳を持つチェーン `L10N/<locale>.md` チェーンです。レポジトリ項目がサーバー項目と同じ源用語を持つ場合、レポジトリ項目が優先されます。
3. レポジトリ用語が特定の言語で翻訳がない場合、その言語のサーバー項目は引き続き適用されます。レポジトリは翻訳していない言語をブロックすることは決してありません。

マージは **ターゲット言語ごとに**, 項目ごとではありません。"commit"のスペイン語翻訳が `L10N/es.md` "commit"のサーバー上のスペイン語項目を置き換えますが、同じ用語のスペイン語サーバー項目には触れません。レビュアーはどのサーバー項目が置き換えられたかを確認できます：翻訳セッションのサマリーは上書きされた数を示し、各ファイルのロックファイルはそれらを以下にリストします `glossary.shadowed`.

## 用語集が変更されると、ファイルを再翻訳します

辞書項目を編集すると、Glossia は、その有効な用語集が *変更されたファイルを再翻訳します。*. ファイルのソーステキストに一致する文字がない場合、その翻訳は変更されません。用語を使用するファイルの次の翻訳パスには、更新された指示が含まれます。

逆も同様です。一部のファイルでだけ使用される用語を追加しても、完全な再実行が強制されません。

## 用語集とは何ではない

- 機械翻訳用の辞書ではありません。Glossia のモデルは周囲のコンテキストを読み取り、文の要件によって用語を異なる方法で出力できます。用語集は代替ではなく、ガイダンスです。
- 全体のスタイルガイドではありません。声、トーン、フォーマル性、および対象読者は、あなたのアカウントの声設定と `L10N.md`. 個別の用語とその承認済みの翻訳のみを対象とする用語集です。
- 静粛ではありません。すべての適用された用語はファイルのロックファイルに記録され、レビュアーはどの用語集エントリがモデルに到達したかを正確に追跡できます。
