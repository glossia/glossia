**言語自動化をソフトウェアデリバリの他の部分と同じように動作させたい場合は Glossia を選択してください：** ソース管理された指示、ご自身のモデルトークン、リポジトリネイティブチェック、およびレビュー用のプルリクエストです。

[Weblate](https://weblate.org/) は、ウェブ翻訳インターフェース、バージョン管理統合、そしてセルフホスティングオプションを備えたオープンソースのローカリゼーションシステムです。公開コードと Git 統合は Glossia だけで独占されているわけではありません。Glossia を選ぶ理由は、リポジトリ中心の配信、モデル駆動の変換、そして人間とエージェントの両方に再利用可能な言語文脈の組み合わせにあります。

## Glossia を選ぶ理由

| あなたの優先事項 | Glossia の利点 |
|---|---|
| 製品ワークフローにレビューを維持する | リポジトリ変更とプルリクエストを通じて、実際のソース管理された出力をレビューします。 |
| 高速なソースリポジトリに対応する | 変更検出とバッチ公開は、変更のないインプットを繰り返し翻訳することなしに継続的なローカリゼーションループをサポートします。 |
| ご自身でモデルトークンを導入する | アカウントスコーププロバイダ資格情報でサポートされているモデルを設定し、リポジトリ所有のハンドルで選択できます。 |
| ネイティブ検証を再利用する | 実際のターゲットパスにおいて候補に対してリポジトリ固有の検証コマンドを実行します。 |
| 翻訳を超えたコンテキストを再利用する | 共有されたトーンと用語は、MCP と REST インターフェースを通じて新規コンテンツとエージェント統合を指し示すことができます。 |

## リポジトリをレビュー対象に据え続ける

Glossia は、Git を使用して出荷できるものを既に決めるチームを対象に設計されています。そのローカリゼーション設定はコンテンツの隣に置かれ、提案された出力は製品のリリースと同じプロセスを通じてレビューできます。

Weblate もバージョン管理と統合されます。そのブラウザベースの翻訳インターフェースはコントリビューターコミュニティのニーズに完璧に合うかもしれません。Glossia の重点は異なります：チームの作業を別の編集インタフェースの中心にするのではなく、リポジトリのレビュー境界を維持し、言語自動化をそこに導入してください。

## 独自のトークンを導入し、モデルの選択を明確化します

Glossia は、プロバイダ API トークンで構成されたサポートされているモデルを使用します。リポジトリ構成は安定したモデルハンドルを指しており、機密情報はアカウント設定内に残留します。コンテンツスコープまたはターゲットロケールによって異なる構成されたモデルを選択でき、すべてのリポジトリを変更せずに資格情報をローテーションできます。

そのコンテンツを書き込むモデルを選択する明確な場所を与えます。それはどのトークンやモデルがサポートされるのか、あるいは生成が人間のレビューの必要性を排除するのかを約束するものではありません。参照：[モデルプロバイダーの設定](/docs/how-to/configure-a-model-provider)。

## 納品変更を検証するチェックを再利用する

Glossia の組み込み構造的チェックは品質の境界の一部に過ぎません。`L10N.md` を通じて、その実際のターゲットパスでの候補に対し、リポジトリ固有の検証スクリプト、パーサー、コンパイラー、またはドキュメントチェックを実行できます。

翻訳されたコンテンツが単なる文字列を超える場合、これは便利です：アプリケーション固有の形式、Markdown コンポーネント、構造化されたメタデータ、そしてプロジェクトが既に検証する方法を知る制約です。

実行環境は依然としてバリデータの詳細が必要であり、構造的検証は言語の正確さを確立しません。参照：[L10N.md](/docs/reference/l10n-md) と [翻訳の回復](./translation-recovery)。

## 公開ソースは基準であり、完全な比較ではありません

Glossia の実装は公開されており、[O'Saasy](https://github.com/glossia/glossia/blob/main/LICENSE.md) 下で検査、変更、およびセルフホスティングが可能です。ライセンスは競合するホスティングサービスに制限され、Weblate の GPL ベースのオープンソースライセンスとは異なります。

完全な制限のないオープンソースライセンスと確立されたウェブ翻訳インターフェースがあなたの主要な基準であれば、Weblate には検討の価値があります。目的が**ご自身のモデル資格情報、既存のリポジトリチェック、およびソフトウェア取引に従う言語作業**であれば、Glossia はそれらの選択を言語 OS に集約します。

この比較は、Weblate が自動化、検証機能、またはプロバイダ統合を欠いていることを断じておりません、かつ自動移行機能や機能同等性を約束するものではありません。最新の機能を参照：[Weblate のドキュメント](https://docs.weblate.org/)。
