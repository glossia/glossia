**Glossia を選ぶことは、言語自動販売をソフトウェアデリバリーの他の部分のように働きたい時に:** ソース制御された指示、あなた自身のモデルトークン、リポジトリネイティブチェック、およびレビューコードのプルリクエストなど。

[Weblate](https://weblate.org/) は Web で翻訳インターフェースを楽しめるオープンソースのローカライゼーションシステムです。バージョン管理統合およびセルフホスティングオプションもあります。公開されたコードと Git の統合は Glossia に专有ではありません。Glossia を選ぶ理由は、リポジトリ指向の移行、モデル駆動の変換、そして人間とエージェントのために再利用可能な言語コンテキストの組み合わせです。

## Why choose Glossia

| Your priority | Glossia's advantage |
|---|---|
| 製品のワークフローの中でレビューを保つ | リポジトリの変更とプルリクエストを通じて、実際ソースコードの構造化された出力を確認する。 |
| 高速なソースリポジトリと対になるようにする | 変更検知とバッチ発行は、常にローカライズループを支援し、変更された入力又没有翻訳することを入れます。 |
| あなた自身のモデルトークンを導入する | アカウントスコープのプロバイダ認証と、リポジトリ所有のハンドルでモデルを構成し、選定する。 |
| ネイティブバリデーションを再利用する | 実ターゲットパスのオブジェクトに対してリポジトリ自身のバリデーションコマンドを実行する。 |
| 翻訳以上の言語コンテキストを活用する | 共有の音声と用語は、MCP と REST インターフェースを通じて新しいコンテンツとエージェント統合を導きます。 |

## Keep the repository as the review surface

Glossia は、すでに Git を用いて何が届行に用意されているかを判断しているチームのために設計されています。そのローカライズ設定はコンテンツの隣にあります。提案された出力は、製品変更と同じプロセスでレビューするために通過できます。

Weblate もバージョン制御と統合されます。ブラウザベースの翻訳インターフェースは、コントリビューターコミュニティの必要に一致するかもしれません。Glossia の重点は異なります：別の編集インターフェースをチームの作業の中心にすることではなく、リポジトリのレビュー境界を維持し、そこに言語自動化を導入することです。

## Bring your own tokens and make model choices explicit

Glossia は、プロバイダの API トークンで構成されたサポートされたモデルを使用します。リポジトリ設定は安定したモデルハンドルを指しますが、機密情報はアカウント設定に保存されます。コンテンツスコープまたはターゲットロケールによって異なる構成されたモデルを選択し、すべてのリポジトリを変更せずに認証情報を回転させることができます。

これにより、あなたのチームにはコンテンツを生成するモデルを選択する明らかな場所が得られます。すべてのトークンやモデルがサポートされていることを保証するものでもなく、生成によって人間のレビューの必要性が無くなることを約束するものでもありません。[モデルプロバイダーを設定する](/docs/how-to/configure-a-model-provider) を参照してください。

## Reuse the checks that define a deliverable change

Glossia に組み込まれた構造的チェックは品質の境界の一部にすぎません。`L10N.md` を通じて、リポジトリ固有の検証スクリプト、パーサー、コンパイラ、またはドキュメント チェックを実行し、実際のターゲットパスにある候補に対して行うことができます。

これは翻訳されたコンテンツが単純な文字列を超える場合に便利です：アプリケーション固有のフォーマット、Markdown コンポーネント、構造化されたメタデータ、そしてプロジェクトがすでに検証する方法を知っている制約などです。検証と回復は、パイプラインが公開する実際のファイルとまま接続されます。

実行環境は検証者の依存関係を必要とし、構造検証は言語正確性を確立しません。 [L10N.md](/docs/reference/l10n-md) と [Translation recovery](./translation-recovery) を参照してください。

## Public source is a baseline, not the whole comparison

[Glossia の実装は公開されており、O'Saasy](https://github.com/glossia/glossia/blob/main/LICENSE.md) 下に検査、改定、およびセルフホスティングを行うことができます。ライセンスは競合するホスティングサービスに制限されています。Weblate の GPL ベースのオープンソースライセンスとは同じではありません。

無制限のオープンソースライセンスと確立された Web 翻訳インターフェースを主要な基準とするなら、Weblate を検討する価値があります。 もしあなたが **your own model credentials, existing repository checks, and language work that follows software delivery** を目指すなら、Glossia は言語 OS でそれらの選択肢を一つにまとめてくれます。

この比較は Weblate に自動化機能や検証機能、プロバイダ統合が欠けていることを主張はおclusiveではありません。また自動移行や機能同等性を約束するものではありません。現在の機能については [Weblate's documentation](https://docs.weblate.org/) を参照してください。
