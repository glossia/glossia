翻訳メモリは通常、以前翻訳されたソースからターゲットへのセグメントを記録します。一致するまたは類似するソース・セグメントは以前の仕事の再利用を可能にします。これは反復的な材料や、審査された翻訳の保持にとって価値があります。

Glossia の言語記憶は別のニーズに対応します：かつてその文が使用されたこともない場合でさえ、新しい文章が組織のトーンに従うようにする原則です。

## 出力の記憶と意図の記憶

審査された翻訳は「以前どのように翻訳したか」と答えます。トーンガイドと用語集は以下のような質問に対して答えます:

- どの製品用語は変更せず保つべきか？
- どの用語を一貫して使用するべきか？
- この聴衆にどのようなトーンが適しているか？
- 新規資料の起草時にエージェントが尊重すべき言語判断はどれか？

これらの入力はローカライゼーションとソース言語でのコンテンツ作成を支援します。一致するターゲット・セグメントの検索には限定されません。

## 相補的なツール

翻訳メモリと言語ガイドは重複するが異なる問題を解決します。チームの双方から利益を得る可能性があります。Glossia は、モデル生成テキストがすべての審査済みのセグメントを代替できることを保証せず、プロンプトによる記述が言語学的正確さを保証することを約束しません。

重要なアーキテクチャ的な判断は、独占的な記憶を会社の言語の唯一の権威にしないことです。リポジトリ所有のコンテンツ、再利用可能なコンテキスト、バージョン履歴、そしてレビューはすべて、チームが理解し維持できるプロセスに貢献します。

## 文脈にはまだレビューが求められます

ガイドは不完全または矛盾している可能性があります。用語は異なる製品で異なる意味を持つことがあります。人間は結果が正確か適切か判断する責任を負います。検証は構造的な失敗を検出できますが、すべての文が正しいことを証明することはできません。
