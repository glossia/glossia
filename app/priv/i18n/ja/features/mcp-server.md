## MCP は何ですか？

MEN[モデルコンテキストプロトコル](https://modelcontextprotocol.io) は、AI アシスタントを外部ツールやデータソースに接続するためのオープンな規格です。すべてのコードアシスタントにカスタム統合を構築する代わりに、単一の MCP サーバーを公開すれば、いかなる互換性のあるクライアントもそれを利用できます。

Glossia の MCP サーバーは、エージェントがプラットフォームの言語コアに直接アクセスすることを可能にします：音声設定、用語集管理、組織管理、プロジェクト一覧。

## 利用可能なツール

MCP サーバーは、毎日使うリソースを軸に 16 つのツールを提供します。パラメータや使用詳細については、[ツールの完全なリファレンス](/docs/reference/mcp/tools) を参照してください。

**アカウントと組織** -- アカウントを一覧表示し、組織を作成・管理、メンバーを招待し、アクセスを制御します。エージェントは会話を通じてチーム全体の設定を行えます。

**音声設定** -- Glossia がコンテンツを生成・改訂する方法を制御する音声設定を読み取り更新します。トーン、フォーマルさ、ターゲットオーディエンス、および各ロケールのオーバーライドを、エディターを離れずに調整できます。

**用語集管理** -- すべてのコンテンツにわたって用語集の整合性を維持します。正しい用語を常に使用するよう、エージェントに対して用語集エントリを追加、更新、バージョン管理していただけます。

**プロジェクト** -- 組織全体でプロジェクトを一覧表示し、確認します。

## 仕組み

MCP クライアントを `https://your-glossia-instance/mcp` に設定し、OAuth ビアラー トークンで認証してください。[MCP セットアップガイド](/docs/reference/mcp/overview) は、動的クライアント登録および PKCE を含む完全な接続フローを説明しています。サーバーは [REST API](/features/rest-api) と同じ認証・認証システムを使用するため、API で動作する任意のトークンは MCP でも動作します。

それ以降、AI アシスタントは 16 つのツールのいずれかを呼び出せます。「Acme という組織を作成する」や「私の音声トーンをプロフェッショナルに更新する」など指示し、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェント型ワークフロー向けに構築

MCP は単なる便利さのためのレイヤーではありません。 Glossia をより大きなエージェント型パイプラインに組み立てるための土台です。コードアシスタントは、コードベースを読み、未ローカライズコンテンツを検出し、新用語を含む用語集を更新、特定のロケール用の音声設定を調整、局域化実行をトリガーし、これらすべてを一度の会話で扱うことができます。

プロトコルが標準化されているため、特定のクライアントにロックインされるわけではありません。Claude、Cursor、または独自のカスタムエージェント間を切り替えることも可能です。設定の一行を変更する必要はありません。
