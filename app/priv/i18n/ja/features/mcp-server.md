## MCP とは何ですか？

の [モデルコンテキストプロトコル](https://modelcontextprotocol.io) は、外部ツールやデータソースに AI アシスタントを接続するためのオープンスタンダードです。各コーディングアシスタントでカスタム連携を構築する必要はなく、単一の MCP サーバーを公開するだけで、互換性のあるどのクライアントも使用できます。

Glossia の MCP サーバーは、エージェントにプラットフォームの言語機能コアへのアクセスを提供し、音声設定、用語管理、組織管理、プロジェクト一覧にアクセスできます。

## 利用可能なツール

MCP サーバーは、日常で使用するリソースを中心に整理された 16 つのツールを公開しています。詳細 [全ツールのリファレンス](/docs/reference/mcp/tools) パラメータと使用詳細について。

**アカウントと組織** -- あなたのアカウント一覧を確認、組織を作成・管理し、メンバーを招待してアクセスを制御できます。エージェントは会話を通じて、チーム全体の構造を設定できます。

**音声設定** -- Glossia がコンテンツの生成および修正内容を制御する音声設定を表示・更新できます。トーン、フォーマル度、ターゲットオーディエンス、および各ロケールのオーバーライドを、エディタから離れることなく調整できます。

**用語管理** -- すべてのコンテンツにおける用語の整合性を維持できます。用語エントリを追加・更新・バージョン管理し、エージェントが常に適切な用語を使用できるようにします。

**プロジェクト** -- 組織全体にわたるプロジェクトを表示し、確認します。

## 動作方法

MCP クライアントを、 `https://your-glossia-instance/mcp` OAuth ベアラー トークンで認証します。その [MCP セットアップガイド](/docs/reference/mcp/overview) は、動的クライアント登録および PKCE を含む完全な接続フローを詳説します。サーバーは、同様の認証および認可システムを使用し、 [REST API](/features/rest-api)、したがって、API で機能するトークンは MCP でも機能します。

そこから、AI アシスタントは 16 つのツールのいずれかを呼び出すことができます。「Acme という組織を作成する」や「ボイストーンをプロフェッショナルなトーンに更新する」と指示すれば、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築

MCP は単なる便利機能ではなく、Glossia を大規模なエージェント型パイプラインに組み込むための基盤です。コーディングアシスタントはコードベースを読み取り、未翻訳コンテンツを検出し、新用語で用語を更新し、特定のローカール向けのボイス設定を調整し、翻訳実行をトリガーできます。これらすべては 1 つの会話で完了します。

プロトコルが標準化されているため、特定のクライアントに限定されるわけではありません。Claude、Cursor、または自社のカスタムエージェント間を切り替える際も、設定の 1 行も変更する必要はありません。
