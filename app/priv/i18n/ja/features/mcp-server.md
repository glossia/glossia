## MCP とは何ですか？

「” [Model Context Protocol](https://modelcontextprotocol.io) は、AI アシスタントを外部ツールおよびデータソースに接続するオープンな標準です。各コーディングアシスタント向けのカスタム統合を構築するのではなく、単一の MCP サーバーを公開し、互換性のあるクライアントがこれを使用できるようにします。

Glossia の MCP サーバーは、エージェントにプラットフォームの言語的中核への直接アクセスを提供します：音声構成、用語管理、組織管理、およびプロジェクトリスト。

## 利用可能なツール

MCP サーバーは、毎日使用するリソースを中心に 16 つのツールを公開しています。次の [完全なツールリファレンス](/docs/reference/mcp/tools) パラメータと使用方法の詳細について。

**アカウントと組織** -- アカウントを一覧表示し、組織を作成・管理、メンバーを招待し、アクセスを制御します。エージェントは会話を通じて、チーム構造全体を設定できます。

**ボイス設定** -- コンテンツの生成と改訂を制御するボイス設定を読み込み、更新できます。トーン、形式、対象読者、および各ローカルのオーバーライドは、エディタから離れずに調整できます。

**用語管理** -- すべてのコンテンツにおける用語の一貫性を維持します。用語項目を追加、更新、およびバージョン管理し、エージェントが常に適切な用語を使用できるようにします。

**プロジェクト** -- 組織間のプロジェクトを一覧し、確認する。

## 仕組みについて

MCP クライアントを向けて、 `https://your-glossia-instance/mcp` さらに、OAuth Bearer トークンで認証し。その [MCP セットアップガイド](/docs/reference/mcp/overview) 接続フロー全体を、動的クライアント登録および PKCE を含めて説明します。サーバーは同じ認証および認可システムを [REST API](/features/rest-api)、したがって API で動作するトークンは MCP でも動作します。

その後、AI アシスタントは 16 種類のツールのいずれを呼び出すこともできます。"Acme という組織を作成する" または "ボイストーンをプロフェッショナルに更新する" と指示すると、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに設計されています。

MCP は単なる利便性層ではなく、Glossia をより大規模なエージェントパイプラインに統合するための基盤です。コーディングアシスタントはコードベースを確認し、未ローカリゼーションコンテンツを検出し、新しい用語で用語表を更新し、特定のロケール向けのボイス設定を調整し、ローカリゼーション実行をトリガーします。これらすべては単一の会話で完了できます。

このプロトコルが標準化されているため、特定のクライアントに限定されることはありません。Claude、Cursor、またはユーザー固有のカスタムエージェントを切り替えるには、設定を一切変更する必要はありません。
