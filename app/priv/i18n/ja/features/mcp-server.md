## MCP とは何か？

[モデルコンテキストプロトコル](https://modelcontextprotocol.io) は、AI アシスタントを外部ツールやデータソースに接続するためのオープンな標準です。コーディング アシスタントごとにカスタム統合を構築するのではなく、単一の MCP サーバーを提供するだけですと、互換性のあるクライアントはすべてそれを使用できます。

Glossia の MCP サーバーは、エージェントにプラットフォームの言語学的コアへの直接アクセスを提供します：音声設定、用語集管理、組織管理、およびプロジェクトリスト。

## 利用可能なツール

MCP サーバーは、あなたが毎日扱うリソースを中心に配置された 16 つのツールを公開しています。パラメータと使用詳細については、[全ツールの参照](/docs/reference/mcp/tools)を参照してください。

**アカウントと組織** -- あなたのアカウントをリスト表示し、組織を作成して管理し、メンバーを招待してアクセスを制御します。エージェントは会話を通じてチーム全体の構造を設定できます。

**ボイス設定** -- Glossia がコンテンツを生成および修正する方法を制御する音声設定を読み取って更新します。トーン、フォーマリティ、ターゲットオーディエンス、および各ローカルのオーバーライドを調整するにはエディタから離れる必要はありません。

**用語集管理** -- すべてのコンテンツ全体にわたる用語集の一貫性を維持します。エージェントが常に正しい用語を使用できるように、用語集のエントリを追加、更新し、バージョン管理を行います。

**プロジェクト** -- 組織全体に跨るプロジェクトをリスト表示し、確認します。

## 動作方法

MCP クライアントを `https://your-glossia-instance/mcp` に向け、OAuth ベアラートークンで認証します。[MCP 設定ガイド](/docs/reference/mcp/overview) は、動的クライアント登録や PKCE を含む完全な接続フローを説明します。サーバーは [REST API](/features/rest-api) と同じ認証および認可システムを使用するため、API で機能するトークンは MCP でも機能します。

そこから、あなたの AI アシスタントは 16 つのツールのどれでも呼び出すことができます。「Acme と呼ばれる組織を作成」または「私のボイストーンをプロフェッショナルに更新」と頼んでください。エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築され

MCP は単なる利便性レイヤーではありません。Glossia をより大きなエージェントパイプラインに構成するための基盤です。コーディングアシスタントは、コードベースを読み込み、未ローカライズのコンテンツを検出し、新用語で用語集を更新し、特定のローカルの音声設定を調整し、ローカライズ実行をトリガーし、すべて 1 つの会話の中で完了できます。

プロトコルが標準化されているため、特定のクライアントに縛られることはありません。Claude、Cursor、または独自のカスタムエージェント間で切り替えることもできます。設定の一行も変更する必要はありません。
