## MCP とはなにか？

その [モデルコンテキストプロトコル](https://modelcontextprotocol.io) は、オープン標準で、AI アシスタントを外部ツールやデータソースに接続します。すべてのコーディングアシスタント向けのカスタム統合を開発する代わりに、単一の MCP サーバーを公開すれば、互換性のクライアントはすべてそれを利用できます。

Glossia の MCP サーバーは、プラットフォームの言語コアにエージェントが直接アクセスできるようにします：ボイス設定、用語管理、組織管理、およびプロジェクト一覧。

## 利用可能なツール

MCP サーバーは、日常で扱うリソースを中心に 16 つのツールを公開しています。ご参照 [完全なツール参照](/docs/reference/mcp/tools) パラメータと使用方法の詳細については。

**アカウントと組織** -- アカウント一覧の表示、組織の作成・管理、メンバーの招待、アクセス制御が可能です。エージェントは会話を通じてチーム構造全体を設定できます。

**音声設定** -- Glossia がコンテンツを生成・修正する方法を制御する音声設定を読み込み更新できます。エディタを離れることなく、トーン、形式、ターゲットオーディエンス、および各ローカルのオーバーライドを調整できます。

**用語管理** -- すべてのコンテンツで用語の一貫性を維持します。用語エントリを追加、更新、バージョン管理し、エージェントが常に適切な用語を使用できるようにします。

**プロジェクト** -- 組織を超えたプロジェクトを一覧表示および詳細を確認します。

## 仕組み

MCP クライアントを `https://your-glossia-instance/mcp` および OAuth ベアラートークンで認証します。、 [MCP イントロガイド](/docs/reference/mcp/overview) 完全な接続フロー、動的クライアント登録と PKCE を含む、サーバーによる認証と認可システムと同様として [REST API](/features/rest-api)、 および API で動作するトークンは MCP でも動作します。

そこから、あなたの AI アシスタントは 16 つのツールのいずれかを呼び出すことができます。"Acme という組織を作成" または"ボイストーンをプロフェッショナルに更新" と依頼すると、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築

MCP は単なる利便性レイヤーではありません。Glossia を大規模なエージェント型パイプラインに統合するための基盤です。コーディングアシスタントはコードベースを読み、未ローカライズコンテンツを検出し、用語を新たな用語で更新し、特定のロケール向けにボイス設定を調整し、現地化実行をトリガーできます。これらはすべて単一の会話で完結します。

プロトコルが標準化されているため、特定のクライアントにロックインされることはありません。Claude、Cursor、あるいは独自のカスタムエージェントへ切り替えても、設定を一切変更する必要はありません。
