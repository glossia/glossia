## MCP とは何ですか？

その [モデルコンテキストプロトコル](https://modelcontextprotocol.io) AI アシスタントを外部ツールやデータソースに接続するためのオープンな標準規格です。すべてのコーディングアシスタントにカスタム統合を構築する代わりに、単一の MCP サーバーを公開するだけで、互換性のあるクライアントがすべて利用できます。

Glossia の MCP サーバーは、エージェントにプラットフォームの言語的コア機能（音声設定、用語管理、組織管理、プロジェクト一覧）への直接アクセスを提供します。

## 利用可能なツール

MCP サーバーは、日常で扱うリソースを軸に 16 つのツールを公開しています。ご参照 [完全なツールリファレンス](/docs/reference/mcp/tools) パラメータと使用方法の詳細については。

**アカウントと組織** -- アカウントを一覧表示し、組織を作成・管理、メンバーを招待してアクセス制御を行います。エージェントは会話を通じてチーム構造のすべてを設定できます。

**音声設定** -- Glossia のコンテンツ生成と修正方法を制御する音声設定を表示し更新できます。トーン、フォーマルさ、ターゲット読者、およびロケール別上書き設定を、エディタを離さずに調整できます。

**用語管理** -- すべてのコンテンツの用語の一貫性を維持します。用語項目を追加、更新、バージョン化することで、エージェントが常に適切な用語を使用できるようにします。

**プロジェクト** -- 組織全体でプロジェクトの一覧表示および確認を行います｡

## 仕組みについて

MCP クライアントを以下へ設定し `https://your-glossia-instance/mcp` および OAuth ベアラートークンで認証し、その [MCP セットアップガイド](/docs/reference/mcp/overview) 完全な接続フローを解説し、ダイナミック・クライアント登録および PKCE を含む。サーバーは認証および認可システムを [REST API](/features/rest-api)したがって、API で動作するトークンは MCP でも動作します。

そこから、AI アシスタントは 16 つのツールのいずれでも呼び出すことができます。「Acme という組織を作成する」や、「自分のボイスのトーンをプロフェッショナルに更新する」のように指示すると、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェンティックワークフロー向けに構築

MCP は単なる利便性レイヤーではありません。より大きなエージェンティックパイプラインに Glossia を組み込むための基盤です。コーディングアシスタントはコードベースを読み、未ローカライズコンテンツを検出し、新しい用語で用語を更新し、特定のロケール向けの音声設定を調整し、ローカライズ実行を開始できます。これら全ては 1 回の会話ですべて完了します。

プロトコルが標準化されているため、特定のクライアントに固定されることはありません。Claude、Cursor、または独自のカスタムエージェントと切り替えても、設定の 1 行も変更せずに済みます。
