## MCP とは何か？

その [モデルコンテキストプロトコル](https://modelcontextprotocol.io) AI アシスタントを外部ツールやデータソースに接続するためのオープンな標準です。すべてのコーディングアシスタント向けのカスタム統合を構築するのではなく、単一の MCP サーバーを公開し、互換性のあるクライアントは誰でもそれを使用できます。

Glossia の MCP サーバーは、エージェントにプラットフォームの言語コアへの直接アクセスを提供します：音声設定、用語管理、組織管理、およびプロジェクト一覧。

## 利用可能なツール

MCP サーバーは、日常で使用しているリソースを基に 16 つのツールを公開しています。詳細は [全ツールのリファレンス](/docs/reference/mcp/tools) パラメータと使用方法の詳細については。

**アカウントと組織** -- アカウントをリストし、組織を作成・管理、メンバーを招待し、アクセスを制御できます。エージェントは会話を通じてチーム全体を構築できます。

**音声設定** -- Glossia がコンテンツを生成し改定する方法を制御する音声設定を読み取り、更新してください。トーン、形式、ターゲットオーディエンス、および各ローカルのオーバーライドをエディタから離れることなく調整できます。

**用語管理** -- すべてのコンテンツ全体で用語の整合性を保ちます。エージェントが常に適切な用語を使用できるよう、用語エントリを追加、更新、およびバージョン化します。

**プロジェクト** -- 組織を超えてプロジェクトをリストし、確認します。

## 仕組み

MCP クライアントを `https://your-glossia-instance/mcp` そして OAuth ベアラー トークンで認証します。その [MCP 設定ガイド](/docs/reference/mcp/overview) は完全な接続フロー（動的クライアント登録および PKCE を含む）全体を解説します。サーバーは認証および認可システムを、 [REST API](/features/rest-api)、したがって API で動作するトークンは MCP でも動作します。

そこから、あなたの AI アシスタントは 16 つのツールのいずれも呼び出すことができます。「Acme という組織を作成する」や「ボイストーンをプロフェッショナルな設定に更新する」といった指示を与えると、エージェントはその意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築されています

MCP は単なる利便性レイヤーではありません。Glossia をより大きなエージェントパイプラインに組み込むための基盤です。コーディングアシスタントはコードベースを読み込み、未ローカライズのコンテンツを検出し、新しい用語で用語を変更し、特定のロケール向けのボイス設定を調整し、ローカライズ実行をトリガーします。これらはすべて単一の会話で実行されます。

プロトコルが標準化されているため、特定のクライアントに縛られることはありません。Claude、Cursor、または独自のカスタムエージェント間で切り替える際、設定を一行も変えずに行えます。
