## MCP とは何ですか？

その [モデルコンテキストプロトコル](https://modelcontextprotocol.io) は AI アシスタントを外部ツールやデータソースに接続するためのオープンな標準です。すべてのコーディング アシスタントにカスタム統合を構築させるのではなく、単一の MCP サーバーを公開すれば、互換性のある任意のクライアントがこれを利用できます。

Glossia の MCP サーバーは、エージェントがプラットフォームの言語学的コアに直接アクセスできるようにします：音声設定、用語管理、組織管理、およびプロジェクトリストです。

## 利用可能なツール

MCP サーバーは、あなたが毎日扱うリソースを中心に構成された 16 つのツールを公開しています。以下の [完全なツール リファレンス](/docs/reference/mcp/tools) パラメータおよび使用方法の詳細については。

**アカウントと組織** -- アカウントを一覧表示し、組織を作成・管理、メンバーを招待してアクセスを制御できます。エージェントは会話を通じてチーム構造全体を設定できます。

**音声設定** -- コンテンツの生成・改訂方法を制御する音声設定を確認・更新できます。トーン、格式、対象読者、および言語別のオーバーライドを、エディタを離さずに調整可能です。

**用語管理** -- すべてのコンテンツにおける用語の整合性を維持します。用語エントリを追加・更新し、バージョン化することで、エージェントが常に適切な用語を使用できるようになります。

**プロジェクト** -- 組織を跨いでプロジェクトを一覧表示し、確認します。

## 仕組み

MCP クライアントを設定し `https://your-glossia-instance/mcp` OAuth ベアアクセストークンで認証し、本 [MCP セットアップ ガイド](/docs/reference/mcp/overview) は完全な接続フロー、動的クライアント登録および PKCE を詳述します。 サーバーは認証および認可システムとして [REST API](/features/rest-api)、API で機能するトークンは MCP でも機能します。

そこから、お使いの AI アシスタントは 16 つのツールのいずれでも呼び出すことができます。「Acme という組織を作成する」または「プロフェッショナルなボイストーンに更新する」と指示し、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築されています

MCP は単なる利便性のレイヤーではありません。Glossia をより大きなエージェント パイプラインに統合するための基盤です。コーディングアシスタントはコードベースを読み、未翻訳コンテンツを検出し、新用語で用語を更新し、特定のローカライゼーション用に音声設定を調整し、ローカライゼーション実行をトリガーします。すべては単一の会話の中で完了します。

プロトコルが標準化されているため、特定のクライアントに縛られることはありません。Claude、Cursor、またはご自身のカスタムエージェント間で切り替えることもでき、設定の一行も変更する必要はありません。
