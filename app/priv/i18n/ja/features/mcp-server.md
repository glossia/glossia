## MCP とは何ですか？

この [モデルコンテキストプロトコル](https://modelcontextprotocol.io) は AI アシスタントを外部ツールやデータソースに接続するためのオープンな標準です。各コーディングアシスタント専用の統合を構築する代わりに、単一の MCP サーバーを公開することで、互換性のあるクライアントがすべて利用できます。

Glossia の MCP サーバーは、エージェントがプラットフォームの言語の中核（ボイス設定、用語集管理、組織管理、プロジェクト一覧）への直接アクセスを提供します。

## 利用可能なツール

毎日扱うリソースを中心に構成された 16 つのツールを公開しています。詳細は、 [全ツールのリファレンス](/docs/reference/mcp/tools) パラメータと使用方法の詳細については。

**アカウントと組織** -- アカウントを一覧表示し、組織を作成・管理し、メンバーを招待し、アクセスを制御できます。エージェントは会話を通じてチーム構造全体を設定できます。

**音声設定** -- Glossia がコンテンツの生成および改訂を制御する音声設定を確認し更新できます。エディタを離れずに、トーン、形式、ターゲット、および各ローカルのオーバーライドを調整できます。

**用語集管理** -- すべてのコンテンツで用語集の一貫性を維持します。エージェントが常に適切な用語を使用できるよう、用語集のエントリを追加・更新し、バージョン管理します。

**プロジェクト** -- 組織間でプロジェクトをリストし、確認します。

## 仕組みについて

MCP クライアントを `https://your-glossia-instance/mcp` および OAuth ベアラー トークンで認証します。その [MCP セットアップガイド](/docs/reference/mcp/overview) 完全な接続フロー、動的クライアント登録および PKCE を含む一連の流れを案内します。その [REST API](/features/rest-api), API で動作するトークンは MCP でも動作します。

そこから、AI アシスタントは 16 つのツールのいずれでも呼び出せます。「"Acme という組織を作成する"」や「"ボイストーンをプロフェッショナルに更新する"」と指示すると、エージェントはあなたの意図を適切なツール呼び出しに変換します。

## エージェントワークフロー向けに構築

MCP は単なる利便性レイヤーではありません。それは、Glossia をより大規模なエージェントパイプラインに統合するための基盤です。コーディングアシスタントはコードベースを読み取り、未ローカリゼーションコンテンツを検出し、新しい用語で用語集を更新し、特定のローカルのボイス設定を調整し、単一の会話でローカリゼーション実行をトリガーできます。

プロトコルが標準化されているため、特定のクライアントに縛られることはありません。Claude や Cursor、あるいはあなた独自のカスタムエージェントとの切り替えも、設定の一行すら変更することなく行うことができます。
