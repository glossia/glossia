## データに基づいて次の言語を選択

多くのチームはターゲット言語を選定する際感覚や勘を頼ります。ローカライゼーション分析はその感覚に代わり、シグナルを提供します。web SDK を追加すると、Glossia は訪問者のブラウザが要求する言語、訪問元の国、ならびに、より重要なのは、すでにサポートしている言語との重なりを表示します。

主要指標は **ローカライゼーションギャップ**: 訪問者の希望言語がサポートされていない割合です。国、リファラー、ページごとに掘り下げることで、需要がどこに集中しているのか、どの新しい言語を追加すれば効果が出せるかが分かります。

## 妥協のないプライバシー

Glossia analytics は必要なもの以外は一切収集せず、識別可能なデータは一切保存しません。ブラウザはページ URL、リファラー、希望言語、タイムゾーン、および画面サイズを送信します。サーバーは IP アドレスと User-Agent から、毎日更新されるハッシュを用いて一意の訪問者を導出し、その後破棄します。クッキーは一切設定されず、フィンガープリント化もされず、どの訪問者も日単位またはサイト間を超えて追跡されることはありません。

その結果、同意バナーなしで提供できる分析となり、国際訪問者が既に持っているプライバシーの期待と整合します。

## 数秒でインストール

サイトに 1 行追加し、Glossia は計測を開始します:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を使いますか？インストール `@glossia/web` と呼び出します `init({ domain })`". どちらの場合でも、ページビュー、クライアント側のナビゲーション、およびカスタムイベントは、ローカライズの機会をランク付けする同じダッシュボードに集まります。
