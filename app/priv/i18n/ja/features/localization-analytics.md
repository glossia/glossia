## データに基づき、次のターゲット言語を選択

多くのチームは直感だけでターゲット言語を選択します。ローカライゼーション分析は、その感覚をデータ（シグナル）に置き換えます。Web SDK を追加すると、Glossia は訪問者のブラウザから要求された言語、出身国、そして最も重要なのは、すでにサポートしている言語とのオーバーラップを示します。

主要な指標は **ローカライゼーションギャップ**：訪問者の優先言語に翻訳が提供されていない割合です。国、リファラー、ページごとに詳しく見ることで、満たされていない需要がどの程度集中しているか、またどの新しいローカライゼーションが効果的かを把握できます。

## 妥協しないプライバシー

Glossia 分析は必要なもの以外を収集せず、特定可能な情報を保存しません。ブラウザはページ URL、リファラー、推奨言語、タイムゾーン、および画面サイズを送信します。サーバーは IP アドレスと User-Agent のハッシュ（毎日更新）から一意の訪問者を導き出し、その後削除します。クッキーは設定されず、フィンガープリント化も行われず、訪問者は日またぎやサイト間での追跡されることはありません。

その結果、同意バナーなしで公開可能な分析が可能となり、すでにあなたの国際訪問者のプライバシー期待と合致しています。

## 数秒でインストール

サイトに一行追加するだけで Glossia が計測を開始します:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を好む？インストール `@glossia/web` そして呼び出します `init({ domain })`。どちらの場合も、ページビュー、クライアントサイドナビゲーション、カスタムイベントは、ローカライズの機会を順位付ける同じダッシュボードに集約されます.
