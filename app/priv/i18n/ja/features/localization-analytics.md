## データで次のローカライゼーション先を選択

多くのチームはターゲット言語を直感で選びます。ローカライゼーション分析は、その直感にシグナルを代えます。Web SDK を追加すると、Glossia は訪問者のブラウザが要求する言語、訪問者が来ている国、そして何より既に支援している言語との重なりを提示します。

メインの指標は **ローカライゼーションギャップ** です。これは、優先言語に対してサポート翻訳がない訪問者の割合です。国別、リフェラー別、ページ別に詳細を確認し、需要が不足している場所を見つけ、どの新しいローカライゼーション先が最も変化をもたらすか判断できます。

## 妥協のないプライバシー

Glossia アナリティクスは必要なもの以外は収集せず、個人を特定できる情報は保存しません。ブラウザはページ URL、リフェラー、優先言語、タイムゾーン、画面サイズを送信します。サーバーは IP と User-Agent を使用して、毎日轮换するハッシュから一意の訪問者を生成し、その後破棄します。クッキーは設定されませんし、指紋化も行われず、訪問者は日を超えて、またはサイトを超えて追跡されることはありません。

その結果、同意バナーなしで提供できる分析は、国際訪問者が既に持っているプライバシーへの期待とも合致します。

## 数秒でインストール

サイトに一行を追加するだけで、Glossia が測定を開始します:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を好む場合は、`@glossia/web` をインストールして `init({ domain })` を呼び出してください。どちらの場合でも、ページビュー、クライアントサイドのナビゲーション、そしてカスタムイベントは、ローカライゼーションの機会を順位付ける同じダッシュボードに集約されます。
