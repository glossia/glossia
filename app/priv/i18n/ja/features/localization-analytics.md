## データに基づいて次のターゲット言語を選択

多くのチームは直感に基づいてターゲット言語を選びます。ローカライゼーション分析は、それの代わりにデータにより正確な指標を提供します。ウェブ SDK を追加すると、Glossia は訪問者のブラウザがリクエストする言語、訪問者が訪れた国、そして特にすでにサポートしている言語との重複を表示します。

最重要指標は **ローカライゼーションギャップ** です：訪問者の間で、優先言語にサポートされない翻訳の割合です。国、リファラ、ページごとに詳細を確認し、不満な需要がどこに集中しているか、どの新しいターゲット言語が変化をもたらすかを確認できます。

## 妥協のないプライバシー

Glossia 分析サービスは不要なものを収集せず、特定可能な情報も保持しません。ブラウザはページ URL、リファラ、優先言語、タイムゾーン、画面サイズを送信します。サーバーは IP アドレスと User-Agent から日次ローテーションハッシュで一意の訪問者を導き出し、破棄します。クッキーは設定されず、フィンガープリントされず、訪問者は日次間やサイト間を追跡されることはありません。

その結果、同意バナーなしで提供できる分析となり、国際訪問者がすでに持つプライバシーの期待に沿っています。

## 数秒でインストール

サイトに一行を追加すると、Glossia が測定を開始します：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を使用したい場合は、`@glossia/web` をインストールして `init({ domain })` を呼び出します。どちらの方法でも、ページビュー、クライアントサイドナビゲーション、カスタムイベントが、ローカライゼーション機会をランク付けする同じダッシュボードに流入します。
