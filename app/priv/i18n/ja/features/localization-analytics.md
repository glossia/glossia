## データに基づき次なるロケールを決定する

多くのチームはターゲット言語を選択する際、感覚や独断に頼ります。翻訳はそれを具体的なデータに置き換えます。Web SDK を追加するだけで、Glossia は訪問者のブラウザが要求する言語や、訪問者がいる国、そして重要なのは既にサポートしている言語との重複を表示します。

メイン指標は**ローカライズギャップ**です。これは、好みの言語にサポートされた翻訳がない訪問者の割合のことです。国、リファラー、ページごと詳細を深掘りして、不足した需要が集中している箇所や、どの新しいロケールが需要を満たせるかを明確に判断できます。

## 妥協のないプライバシー

Glossia 分析は不要なものしか収集せず、特定可能な情報は保存しません。ブラウザはページ URL、リファラー、希望言語、タイムゾーン、画面サイズを送信します。サーバーは IP と User-Agent から生成される日次回転ハッシュから一意の訪問者を導き出し、その後破棄します。クッキーは設定されず、指紋化もされず、訪問者は日を超え、サイトを超えても追跡されません。

その結果、同意バナーなしで配布できる分析となります。それは、あなたの国際訪問者が既に持っているプライバシーへの期待に合致しています。

## 数秒でインストール

サイトに一行を追加するだけで、Glossia の計測が開始します：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を優先しますか？`@glossia/web` をインストールし、`init({ domain })` を呼び出します。どちらのいずれであっても、ページビュー、クライアントサイドのナビゲーション、カスタムイベントは、あなたのローカライズ機会をランクする同じダッシュボードに流入します。
