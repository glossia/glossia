## データで次のロケールを決定

多くのチームはターゲット言語を選定する際は素感を頼りますが、ローカライゼーション分析はこれをシグナルで置き換えてくれます。ウェブ SDK を追加し、Glossia は訪問者のブラウザがリクエストする言語や、訪問者の出身国、そして最も重要なのは、すでにサポートしている言語との重なりを表示します。

主要指標は **ローカライゼーションギャップ**: 希望言語に未対応の訪問者の割合です。国、リファラー、ページそれぞれで詳細を掘り下げ、未対応の需要がどこに集中しているか、どの新しいロケールが効果をもたらすかを確認できます。

## 妥協しないプライバシー

Glossia analytics は必要ないものは収集せず、特定可能な情報は保存しません。ブラウザはページ URL、リファラー、希望言語、タイムゾーン、画面サイズを送信します。サーバーは IP と User-Agent の毎日更新されるハッシュ値から一意の訪問者を導き出し、その後破棄します。クッキーは設定されず、指紋化も行われず、訪問者は日付やサイトを超えて追跡されません。

その結果、同意バナーなしで公開できるアナリティクスとなり、あなたの国際的な訪問者が既に持っているプライバシーへの期待と合致します。

## 数秒でインストール

サイトに 1 行を追加し、Glossia が計測を開始します：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm が手軽なら？インストール `@glossia/web` そして呼び出す `init({ domain })`どちらの場合も、ページビュー、クライアントサイドナビゲーション、カスタムイベントは、ローカリゼーションの機会をランク付けする同じダッシュボードに集約されます。
