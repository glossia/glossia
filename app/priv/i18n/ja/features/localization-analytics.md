## データに基づいて次のローカライズ先言語を選んでください。

多くのチームはターゲット言語を選定する際、感覚に頼っています。ロケライゼーション分析は、その直感をデータシグナルに置き換えます。ウェブ SDK を追加すれば、Glossia は訪問者のブラウザが要求する言語、それらの訪問者がアクセスしてきた国、そして何より重要なのは、あなたが既にサポートしている言語との共通点をお示しします。

主要指標は「 **ローカライズギャップ**：訪問者の好みの言語に翻訳が用意されていない者の割合を指します。国、リファラ、ページ単位で詳細に分析することで、不足している需要がどこに集中しており、どの新しいローケールを追加すれば効果が出るかがわかります。

## 妥協しないプライバシー保護

Glossia 分析は必要な情報以外は一切収集せず、識別可能なデータは保存しません。ブラウザはページ URL、リファラ、好みの言語、タイムゾーン、および画面サイズを送信します。サーバーは IP アドレスと User-Agent から日次でハッシュを回転させ、これに基いて一意の訪問者を特定して直ちに破棄します。クッキーは設定されず、指紋化もされず、訪問者は日次やサイト間で追跡されることはありません。

その結果、同意バナーなしで公開できる分析データを確保し、あなたの国際的な訪問者が既に抱いているプライバシーの期待に整合します。

## 数秒でインストール

サイトに 1 行を追加すると、Glossia が計測を開始します:

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を使いますか？インストール `@glossia/web` そして呼び出す `init({ domain })`。どちらの場合でも、ページビュー、クライアントサイドナビゲーション、カスタムイベントは、ローカリゼーション機会の優先順位を決定する同じダッシュボードに集約されます。
