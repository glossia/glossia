## データに基づいて次のロケールを決定

多くのチームはターゲット言語を直感で選定します。ローカライゼーション分析はこれを信頼できるデータに置き換えます。Web SDK を追加すると、Glossia は訪問者のブラウザがリクエストする言語、出身国、そして最も重要なのは、既にサポートしている言語との重なりを表示します。

主要指標は「 **ローカライゼーションギャップ**: 訪問者の推奨言語がサポートされていない割合を表します。国、リファラー、ページ別に詳細分析を行うことで、未滿足の需要が具体的にどこに集中しているか、どの新しいロケールが効果をもたらすかを把握できます。

## 妥協のないプライバシー

Glossia アナリティクスは必要な情報以外は一切収集せず、識別可能な情報は保存しません。ブラウザはページ URL、リファラー、推奨言語、タイムゾーン、および画面サイズを送信します。サーバーは IP アドレスと User-Agent を日替わりハッシュ化して一意の訪問者を導出し、その後破棄します。クッキーも設定されず、フィンガープリンティングも行われず、訪問者は日付やサイトを超えて追跡されません。

その結果、国際訪問者のすでに抱くプライバシーの期待に沿った、同意バナーなしで配布可能なアナリティクスが提供されます。

## 数秒でインストール

サイトに一行追加すれば、Glossia が計測を開始します：

```html
<script defer data-domain="example.com" src="https://cdn.glossia.ai/web.js"></script>
```

npm を好むなら、インストール `@glossia/web` そして呼び出す `init({ domain })`. いずれの方法でも、ページビュー、クライアントサイドのナビゲーション、およびカスタムイベントは、ローカライズの機会をランク付けする同じダッシュボードへ集約されます。
