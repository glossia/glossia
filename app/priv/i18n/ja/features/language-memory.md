## 言語メモリとは何ですか？

言語メモリは、Glossia のエージェントが貴社組織がどのようにコミュニケーションを行うかを示す蓄積されたコンテキストです。以下、あなたが時間をかけて作成し、洗練させていく 2 つの基本的な構成要素で構成されています：

**トーン** は、コンテンツがどのように聞こえるべきかを定義します。トーン、礼儀 jednifier, ターゲットオーディエンス、およびフリーフォーマのガイドラインはすべてここに格納されます。アカウントに対して基底トーンを設定し、特定のロケール向けにフィールドを上書きする機能を備えており、日本語のコピーをより正式にし、英語は対話的なトーンを維持することができます。

**用語** は用語の意味とそれらがどのようにローカライズされるべきかを定義します。各エントリは定義とロケールごとの翻訳を帯びます。エージェントがソースコンテンツで "workspace" を遭遇する際、用語はローカライズ、音訳、またはそのまま残すかを指示し、ターゲット言語に対して正確にどの単語を使用すべきかを教えています。

トーンおよび用語は、エージェントが各実行時に参照するコンテキスト層を形成します。この層への投資が大きいほど、出力に対するレビューの必要量は減ります。

## 不変のバージョン管理

言語メモリは追記専用です。トーンまたは用語を更新すると、Glossia はそれ以前のバージョンを上書きするのではなく、新しいバージョンを作成します。各バージョンは、作成者、作成日時、および何が進化したかを示すオプションの変更ノートを記録します。

これにより、常に完全な監査証跡が維持されます。第 3 のバージョンと第 7 のバージョンを比較することで、トーンが四半期間でどのように変化するかを理解できます。最近の変更が一貫性の欠如を招いた場合は、以前のバージョンへロールバックして作業を続けます。

バージョン管理は協業の安全性を向上させます。複数チームメンバーがトーンの変更を提案しても、各変更が個別で追跡可能なイベントとして管理されるため、競合を気にする必要がありません。

## ロケール対応の解決

エージェントが特定のロケール向けのワークフローを実行すると、Glossia は該当コンテキストの言語メモリを解決します。アカウントの基底トーン設定から始まり、ひいてはロケール固有の上書きを適用します。用語についても同様です：ターゲットロケールにローカライズされた用語を持つエントリのみが含まれます。

この解決ステップにより、エージェントは常に最も関連性のあるコンテキストで処理を行います。言語ごとに別々の設定を維持する必要はありません。デフォルトを一度定義し、必要に応じて上書きし、残りの処理を解決システムに任せるだけです。

## どの場所でも利用可能です

言語メモリはローカライズのために設計されていますが、テキストを作成する場所ならどこでも役立ちます。コンテキストが [REST API](/features/rest-api) または [MCP server](/features/mcp-server) を介してアクセス可能であるため、ローカライズの枠組みを超えたワークフローへの統合が可能です：

**マーケティングおよび SNS コンテンツ** -- 組織のトーンを、SNS ポスト、メールキャンペーン、またはランディングページの作成を担うコンテンツエージェントに活用します。用語がブランド用語の一貫性を保ち、トーン設定がブランドのトーンを反映するのを保証します。

**ドキュメンテーション** -- 言語メモリをドキュメンテーションパイプラインに Howard し、技術ライティングが残りのコンテンツとスタイルルールに従うようにします。用語エントリは、ドキュメント、ヘルプ記事、および製品内コピーにわたる逸脱を防ぎます。

**コードレビュー** -- 貴社のトーンおよび用語に照らしてプルリクエストの copied（エラーメッセージ、UI ラベル、オンボーディングテキスト）をレビューするエージェントを構築してください。リリース前に一貫性の欠如を Flags します。

**カスタムエージェント** -- どの MCP 互換クライアントも言語メモリを読み書きできます。コーディングエージェントに「新しいプロダクト名での用語を更新」または「ドイツロケール向けにトーンを設定されたトーンに設定」を指示し、就是最好的に API 呼び出しを行います。

## 段階的な改良

言語メモリは使用されるにつれて改善します。レビューヤーがエージェントの出力を修正するたびに、その修正は次バージョンのトーンまたは用語にフィードバックされます。時間の経過とともに、初稿と最終出力の間のギャップは縮まり、レビューステップはより高速になります。

これが Glossia の核にあるフィードバックのループです：生成、レビュー、コンテキストの改善、再度生成。エージェントは単に指示に従うだけではありません。各サイクルで洗練されるコンテキストを用いて動作します。
