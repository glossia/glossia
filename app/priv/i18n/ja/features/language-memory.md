## 言語メモとは何ですか？

言語メモは、Glossia のエージェントが、組織がどのようにコミュニケーションをとるかを伝える積まれたコンテキストです。これは、作成し、時間の経過に合わせて洗練させる 2 つの主要なプリミティブで構成されています。

**ボイス** はコンテンツがどのように聞こえるべきかを定義します。トーン、形式、ターゲットオーディエンス、および自由形式のガイドラインはすべてここに存在します。アカウント全体に基本のボイスを設定し、個別のローカルの特定のフィールドを上書きできるようにすると、日本語のコピーはより形式的になり、一方、英語は会話がメインのままで済みます。

**用語集** は用語の意味とどのようにローカライズすべきかを定義します。各エントリーは定義とローカルな翻訳を持っています。エージェントがソースコンテンツで "workspace" に遭遇すると、用語集はそれをローカライズするか、音似させるか、そのままにするか、また各ターゲット言語でどの単語を使用すべきかを正確に伝えます。

ボイスと用語集は、エージェントが各実行時に参照するコンテキスト層を形成します。この層に投入するほど、出力へのレビューは少なくなるでしょう。

## 不変なバージョン管理

言語メモは追加のみです。ボイスや用語集を更新すると、Glossia は古いものを上書きするのではなく、新しいバージョンを作成します。各バージョンは誰が作成したか、いつ作成したか、そして何が進化したかを示すオプションの変更ノート记录了します。

つまり、常に完全な監査証跡があります。バージョン 3 とバージョン 7 を比較し、トーンが四半期でどのようにシフトしたかを理解できます。最近の変更が不一致を導入した場合、以前の実行状態に戻り、継続できます。

バージョン管理は協力も安全にします。複数のチームメンバーがボイスの変更を提案し、競合について心配する必要はありません。なぜなら各変更は分離し、追跡可能なイベントだからです。

## ロケール対応の解決

エージェントが特定のロケールのワークフローを処理すると、Glossia はそのコンテキストの言語メモを解決します。それはまずあなたの基本のボイス設定を開始し、その上网格员へ適用します。同じことが用語集にも当てはまります: ターゲットのロケールにローカライズされた用語があるエントリーのみが含められます。

この解決ステップは、エージェントは常に最も関連するコンテキストで作業することを意味します。言語ごとに別々の構成を維持する必要はありません。デフォルトを一度定義し、必要な場所を上書きし、残りの部分を解決システムに任せてください。

## どこでも活用

言語メモはローカライ化用として設計されていますが、テキストを生成する場所ならどこでも役立ちます。コンテキストは [REST API](/features/rest-api) と [MCP サーバー](/features/mcp-server) を通してアクセス可能なので、ローカライ化以外のワークフローに統合できます:

**マーケティングおよび SNS コンテンツ** - 組織のボイスを、SNS 投稿、メールキャンペーン、またはランディングページのコピーを作成するコンテンツエージェントに引き込みます。用語集はブランド用語の整合性を維持し、ボイス設定はトーンがブランドと一致していることを保証します。

**ドキュメンテーション** - 言語メモをドキュメンテーションパイプラインに供給し、テクニカルライティングが他のコンテンツと同じスタイル規則に従うようにします。用語集のエントリーはドキュメント、ヘルプ記事、および製品内を通じてのドリフトを防ぎます。

**コードレビュー** - ボイスと用語集に対してプルリクエストのコピー（エラーメッセージ、UI ラベル、オンボーディングテキスト）をレビューするエージェントを作成します。出荷前に不一致をマークします。

**カスタムエージェント** - どの MCP 互換クライアントも言語メモを読み書きできます。コーディングアシスタントに "新しい製品名で用語集を更新する" または "ドイツのロケールのボイストーンをプロフェッショナルに設定する" と指示し、それはあなたの意図を適切な API 呼び出しに変換します。

## 漸進的な洗練

言語メモは使用されるほど良くなります。レビュアーがエージェントの出力を修正するたびに、その修正はボイスまたは用語集の次のバージョンにフィードバックされます。時間の経過とともに、第一次案と最終出力のギャップは縮まり、レビューステップは速くなります。

これが Glossia の心にあるフィードバックループです：生成、レビュー、コンテキスト洗練、再度生成。エージェントは単に指示に従うだけではありません。彼らは循環するごとに良くなるコンテキストと共に作業します。
