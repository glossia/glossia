## 言語メモリとは何ですか？

言語メモリは、貴社の組織のコミュニケーション方法を Glossia エージェントに伝える蓄積されたコンテキストです。時間の経過と共にあなたが作成し、改善する 2 つの中核的な要素から構成されています。

**トーン＆マナー** コンテンツがどのようなトーンであるべきかを定義します。トーン、格式、ターゲット・オーディエンス、および自由形式のガイドラインがここにあります。アカウントレベルでベースのトーンを設定し、各ロケール向けの特定のフィールドを上書きすることができるため、日本語の文章はより公式になり、英語は会話しやすい調子でそのまま保つことができます。

**用語集** 用語の意味とローカライズ方法を定義します。各エントリには定義と、各ロケール向けの翻訳が含まれています。エージェントがソースコンテンツで "workspace" を検出した際、用語集はローカライズ、音写、またはそのまま残すいずれにするか、および各ターゲット言語で正確にどの単語を使用するかを指示します。

トーン＆マナーと用語集は、エージェントが各実行で参照するコンテキスト層を形成します。この層への投資が大きいほど、出力のレビューは少なくなります。

## 不変バージョン管理

言語メモリは追記専用です。ボイスまたは用語を更新すると、Glossia は既存の上書きではなく、新版本を作成します。各バージョンは作成者、時刻、および進化した内容を説明するオプションの変更ノートを含みます。

これにより常に完全な監査証跡があります。バージョン 3 とバージョン 7 を比較することで、四半期にわたってトーンがどのように変化したかを理解できます。直近の変更で不一致が発生した場合、以前のバージョンにロールバックして継続できます。

バージョン管理によりコラボレーションがより安全になります。複数のチームメンバーがボイス変更を提案しても、衝突を心配する必要はありません。なぜなら、各変更は個別の追跡可能なイベントだからです。

## ロケール固有の解決

エージェントが特定のロケールに対してワークフローを実行すると、Glossia はそのコンテキスト用の言語メモリを解決します。基本ボイス設定から始まり、その後、任意のロケール固有の上書きを適用します。用語についても同様です：対象ロケールに対してローカライズ用語を持つエントリのみが含まれます。

この解決ステップによって、エージェントは常に最も関連性のあるコンテキストで作業します。言語ごとに別々の設定を維持する必要はありません。一度デフォルトを定義し、必要な箇所を上書きし、残りを解決システムに任せてください。

## あらゆる場所で使用

言語メモリはローカライゼーションのために設計されていますが、テキストを生成するあらゆる場所でも有用です。コンテキストは以下の通りアクセス可能で [REST API](/features/rest-api) と [MCP サーバー](/features/mcp-server), ローカライゼーション以外のワークフローに統合することもできます：

**マーケティングおよびソーシャルコンテンツ** -- 組織のトーンをコンテンツエージェントに反映させ、SNS 投稿やメールキャンペーン、ランディングページのコピーを作成します。用語集はブランド用語の一貫性を保ち、トーン設定はブランドのトーンに合わせます。

**ドキュメント** -- 言語の知識をドキュメントパイプラインに投入し、技術文書が他のコンテンツと同じスタイルルールに従うようにします。用語集の項目はドキュメント、ヘルプ記事、製品内コピーにおけるスタイルのズレを防止します。

**コードレビュー** -- あなたのボイスと用語に従い、プルリクエストの文言（エラーメッセージ、UI ラベル、オンボーディングテキスト）を検証するエージェントを作成します。公開前に不整合を特定します。

**カスタムエージェント** -- MCP 互換クライアントは言語メモリを読み書きできます。コーディングアシスタントに "新しい製品名で用語を更新" または "ドイツのロケールに向けたプロフェッショナルなボイストーンを設定" と指示し、意図を適切な API 呼び出しに変換します。

## 漸進的な改善

言語メモリは使用によって向上します。レビュアーがエージェントの出力を修正するたびに、その修正はあなたのボイスまたは用語の次のバージョンに反映されます。時間の経過とともに、初稿と最終出力の間の距離は縮まり、レビューステップも速くなります。

Glossia の核心にあるのはフィードバックループです：生成、レビュー、コンテキストの改善、そして再生成。エージェントは単に指示に従うだけではありません。彼らは、各サイクルでより良くなるコンテキストを活用します。
