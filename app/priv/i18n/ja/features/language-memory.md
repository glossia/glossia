## 言語メモリとは何ですか？

言語メモリは、Glossia のエージェントがあなたの組織のコミュニケーション方法を伝えるために示す蓄積されたコンテキストです。あなたは時間をかけて作成し改善していく 2 つの中核的なプリミティブで構成されています：

**トーン** コンテンツが必要とされる音、トーン、フォーマルさ、ターゲットオーディエンス、および自由形式のガイドラインはすべてここに含まれます。アカウントにベーストーンを設定し、個々のローカライズ先で特定のフィールドを上書きできます。これにより、日本語のテキストはよりフォーマルに設定し、英語のテキストは対話的なままにし続けることができます。

**用語** 用語は、各用語の意味とローカライズ方法を定義します。各エントリには定義と各ローカルの翻訳が含まれています。エージェントがソースコンテンツで "workspace" を邂逅した際、用語はその用語をローカライズするか、音写するか、またはそれをそのまま残すか、および各ターゲット言語に使用する正確な単語を指示します。

トーンと用語は、エージェントが各実行ごとに参照するコンテキスト層を形成します。この層に対する投資ほど、あなたの出力のレビュー量は少なくなります。

## 不変のバージョン管理

言語メモリは追記専用です。文体や用語を更新すると、古いものを上書きするのではなく、Glossia は新しいバージョンを作成します。各バージョンは作成者、作成時刻、および変更の内容を説明するオプションの変更ノートを記録します。

これにより常に完全な監査証跡があります。バージョン 3 と バージョン 7 を比較することで、四半期間文体がどのようにシフトしたかを理解できます。最近の変更で不整合が生じた場合は、以前のバージョンにロールバックして続行できます。

バージョニングも協働をより安全にします。複数のチームメンバーが文体の変更を提案しても、競合を気にする必要はありません。各変更は個別で追跡可能なイベントとなっているためです。

## ロケール対応の解決

エージェントが特定のロケール向けのワークフローを実行すると、Glossia はそのコンテキストの言語メモリを解決します。ベースの文体設定から始め、その上からロケール固有の上書きを適用します。用語についても同様です：目的のロケールにローカライズされた用語を持つエントリのみが含まれます。

この解決ステップにより、エージェントは常に最も関連性の高いコンテキストで作業します。言語ごとに個別の設定を維持する必要はありません。一度デフォルトを定義し、必要な点では上書きし、残りは解決システムにお任せください。

## どこでもご使用ください

言語メモリはローカライズ用に設計されていますが、テキストを作成する場所はどこでも役立ちます。コンテキストは以下を通じてアクセス可能です。 [REST API](/features/rest-api) と [MCP サーバー](/features/mcp-server), ロカライゼーションを超えたワークフローに統合できます：

**マーケティングおよびソーシャルコンテンツ** -- 組織の声を文章作成エージェントに統合し、SNS 投稿、メールキャンペーン、またはランディングページの文章を作成します。用語表はブランド用語の整合性を維持し、声設定はトーンがブランドに一致するのを保証します。

**ドキュメント** -- 言語記憶をドキュメントパイプラインに供給し、技術ライティングが他のコンテンツと同じスタイルルールに従うようにします。用語表のエントリはドキュメント、ヘルプ記事、および製品内コピー全体にわたる乖離を防ぎます。

**コードレビュー** -- プルリクエストのコピー（エラーメッセージ、UI ラベル、オンボーディングテキスト）を、あなたのトーンと用語に照らしてレビューするエージェントを構築できます。公開前に不整合を指摘します。

**カスタムエージェント** -- 任意の MCP 互換クライアントは言語メモリを読み書きできます。コーディングアシスタントに"新しい製品名で用語を更新"や"ドイツ語ローカルのトーンを専門的なトーンに設定"といった指示を出し、その意図を適切な API 呼び出しに変換します。

## 段階的な洗練

言語メモリは使用を重ねるほど向上します。レビューヤーがエージェントの出力を修正するたびに、その修正はあなたの次のトーンまたは用語のバージョンに反映されます。時間とともに、初稿と最終出力との間のギャップが狭まり、レビューのステップも速くなります。

これが Glossia の中心にあるフィードバックループです：生成、レビュー、コンテキストの洗練、再度生成。エージェントは単に指示に従うだけではありません。彼らは、各サイクルでより良くなるコンテキストを活用して作業します。
