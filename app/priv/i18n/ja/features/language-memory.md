## 言語メモリとは何ですか？

言語メモリは、Glossia のエージェントが組織のコミュニケーション方法を示す蓄積されたコンテキストです。これは、時間とともに作成し洗練させる 2 つの主要なプリミティブによって構成されています：

**ボイス** ボイスはコンテンツの響き方を定義します。トーン、フォーマルさ、ターゲットオーディエンス、およびフリーフォームのガイドラインはすべてここに含まれます。アカウントのベースボイスを設定し、個別のロケールの特定のフィールドを上書きすることで、日本語のコピーはよりフォーマルになり、英語のコピーは対話的なまま保てます。

**用語** 用語は意味とローカライズ方法を定義します。各エントリには定義と各種ローカライズの翻訳が含まれます。エージェントがソースコンテンツで "workspace" を検出した場合、用語はそれをローカライズするか、音訳するか、またはそのまま残すか、そして各ターゲット言語で具体的にどの単語を使用すべきか指示します。

ボイスと用語は、エージェントが各実行で参照するコンテキストレイヤーを形成します。このレイヤーへの投資が増えれば、出力に必要なレビュー量は少なくなります。

## 不変のバージョン管理

言語メモリーは追加専用です。音声または用語を更新すると、Glossia は古いものを上書きするのではなく新しいバージョンを作成します。各バージョンには作成者、作成日時、および何が進化したかの説明を明記したオプションの変更注釈が記録されています。

これにより常に完全な監査証跡があります。バージョン 3 とバージョン 7 を比較することで、四半期間にわたってトーンがどのように変化していたかを理解できます。最近の変更が不整合を引き起こした場合、前のバージョンにロールバックして継続できます。

バージョニングによりコラボレーションをより安全にします。複数のチームメンバーが競合を心配することなく音声の変更を提案できます。なぜなら、各変更は個別で追跡可能なイベントとして扱われるためです。

## ロケール認識型解決

エージェントが特定のロケール向けのワークフローを実行する際、Glossia はそのコンテキストに対して言語メモリーを解決します。基本音声設定から始め、次にそのロケール固有のオーバーライドを適用します。用語に対しても同様です：ターゲットロケール向けのローカライズされた用語を有するエントリのみが含まれます。

この解決ステップにより、エージェントは常に最も関連性のあるコンテキストで作業します。言語ごとに別々の設定を維持する必要はありません。デフォルトを一度定義し、必要な場所のみでオーバーライドし、残りは解決システムに任せてください。

## どこでも活用

言語メモリーはローカライゼーション用に設計されていますが、テキストを作成するあらゆる場所で役立ちます。そのためコンテキストはこれを通じてアクセス可能です。 [REST API](/features/rest-api) と [MCP サーバー](/features/mcp-server)、ロカライゼーションの枠を超えたワークフローに統合可能です：

**マーケティングおよびソーシャルコンテンツ** -- あなたの組織のトーンをコンテンツエージェントに反映させ、ソーシャルメディア投稿、メールキャンペーン、ランディングページの文章を起草します。用語集はブランド用語の一貫性を保ち、トーン設定はブランドのトーンに一致させます。

**ドキュメント** -- 言語知識をドキュメントパイプラインに投入し、テクニカルライティングがコンテンツ全体のスタイルルールに従うようにします。用語集の項目はドキュメント、ヘルプ記事、および製品内コピーにわたるばらつきを防ぎます。

**コードレビュー** -- あなたのボイスおよび用語に対して、プルリクエストのコピー（エラーメッセージ、UI ラベル、オンボーディングテキスト）をレビューするエージェントを作成します。リリース前に不整合を指摘できます。

**カスタムエージェント** -- 任意の MCP 互換クライアントは言語メモリを読み書きできます。コーディングアシスタントに「新しい製品名で用語を更新」または「ドイツ語のロケールに対してボイスのトーンをプロフェッショナルにする」と依頼すると、意図が適切な API 呼び出しに変換されます。

## 段階的改善

使用にともなって言語メモリは改善します。レビュアーがエージェントの出力を修正するたびに、その修正は次のバージョンのボイスまたは用語にフィードバックされます。時間の経過とともに、ファーストライティングと最終出力とのギャップは縮まり、レビューステップはより速くなります。

これが Glossia の核心にあるフィードバックループです：生成、レビュー、文脈の最適化、再度生成。エージェントは、指示を単に追従するだけではありません。彼らは、各サイクルごとに改善されていく文脈と連携して作業します。
