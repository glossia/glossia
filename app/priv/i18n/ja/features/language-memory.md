## 言語の記憶とは何ですか？

言語の記憶とは、Glossia のエージェントがあなたの組織がどのようにコミュニケーションを取るべきかを示す蓄積されたコンテキストです。これはあなたが時間の経過とともに作成し、洗練させていく 2 つの主要な基盤から構成されています:

**ボイス** コンテンツがどのような調子で表すべきかを定義します。トーン、形式、ターゲット読者、および自由記述のガイドラインはすべてここにあります。アカウントのベースのボイスを設定し、個々のローカライズの特定のフィールドを上書きできるため、日本語のテキストはより公式になり、英語は対話的のままと保つことができます。

**用語集** 用語の意味とローカライズ方法を定義します。各エントリには定義とローカライズの翻訳が含まれています。エージェントがソースコンテンツ内の "workspace" に遭遇した際、用語集はそれをローカライズするか、音訳するか、またはそのまま残すか、そして各ターゲット言語で使用する正確な単語を指示します。

ボイスと用語集は、エージェントが毎回の実行で参照するコンテキスト層を形成します。この層への投入を増やすほど、出力に必要なレビュー作業は少なくなります。

## 不変バージョン管理

言語メモリは追記専用です。ボイスまたは用語集を更新すると、Glossia は旧バージョンを上書きせず、新しいバージョンを作成します。各バージョンには作成者、作成日時、および変更内容を示すオプションの変更ノートが記録されています。

これにより、常に完全な監査証跡が可能になります。バージョン 3 とバージョン 7 を比較することで、四半期間にトーンがどのように変化しているかを理解できます。最近の変更が不整合を引き起こした場合は、以前のバージョンに戻り、作業を続けられます。

バージョン管理はコラボレーションをより安全にします。複数のチームメンバーは、競合を気にせずにボイスの変更を提案できます。なぜなら、各変更は独立した、追跡可能なイベントだからです。

## ロケールに応じた解決

エージェントが特定のロケール向けにワークフローを実行すると、Glossia はそのコンテキストの言語メモリを解決します。まずベースのボイス設定から始め、その上に任意のロケール固有のオーバーライドを適用します。用語集も同様であり、目的のロケールにローカライズされた用語を持つエントリのみが含まれます。

この解決ステップにより、エージェントは常に最も関連性の高いコンテキストで動作します。言語ごとに別設定を維持する必要はありません。一度デフォルトを設定し、必要な場所のみで上書きし、残りは解決システムに任せてください。

## どこでも使える

言語メモリはローカライズ向けに設計されていますが、テキストを作成するあらゆる場所で役立ちます。なぜなら、コンテキストはその...によってアクセス可能だからです。 [REST API](/features/rest-api) および [MCP サーバー](/features/mcp-server), ロケライゼーションを超えたワークフローに統合できます：

**マーケティングおよびソーシャルコンテンツ** -- 組織の声をコンテンツエージェントに組み込み、ソーシャルメディア投稿、メールキャンペーン、またはランディングページのコピーを作成します。用語集はブランド用語の一貫性を保ち、声設定によりトーンがブランドに合わせて維持されます。

**ドキュメンテーション** -- 言語メモリをドキュメントパイプラインに投入し、技術文書が他のコンテンツと同じスタイルルールに従います。用語集エントリはドキュメント、ヘルプ記事、および製品内コピーでのスタイル逸脱を防ぎます。

**コードレビュー** -- あなたのボイスと用語集に対して、プルリクエストのテキスト（エラーメッセージ、UI ラベル、オンボーディングテキストなど）を確認するエージェントを構築します。リリース前に不整合を指摘してください。

**カスタム エージェント** -- 任意の MCP 互換クライアントは言語メモリを読み書きできます。コーディングアシスタントに「新しい製品名を以下のように用語集に追加」または「ドイツ語ロケールのボイス・トーンプロフェッショナルに設定」と指示すると、それはあなたの意図を適切な API 呼び出しに変換します。

## 段階的な改善

\-- 使用頻度が増えるにつれ、言語メモリも向上します。レビュアーがエージェントの出力を修正するたびに、その修正は次のボイスバージョンまたは用語集にフィードバックされます。時間の経過とともに、初案と最終出力のギャップが縮まり、レビューステップも高速化します。

これは Glossia の核心にあるフィードバックループです：生成、レビュー、文脈の改善、再度生成。エージェントは単に指示に従うだけではありません。各サイクルで質が向上する文脈を活用して作業します。
