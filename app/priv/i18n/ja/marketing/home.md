# チーム向けの言語 OS: Glossia

Glossia は、音声、用語集、翻訳、改訂履歴、およびローカライゼーション分析を 1 つのシステムに統合しました。開発者、言語専門家、製品チームが Git からコンテンツを移動させることなく、複数の言語で一貫してコミュニケーションできるように支援します。

## 課題

他言語でのリリースは単語の置換だけではありません。チームは意味を保全し、適切な用語を使用し、聴衆に応じてトーンを調整し、製品の変更に合わせて翻訳を最新に保つ必要があります。スプレッドシート、プロンプト、および翻訳ツールに散らばったコンテキストは、一貫性のない執筆と繰り返しの手作業の原因となります。

LLM は翻訳のドラフトを作成できますが、それ単独ではバージョン履歴、検証、選択的な更新、および次の変更に対するフィードバックループを提供できません。

## Glossia の役割

- **言語記憶:** 共有された声のガイダンスと用語集の項目が、人々とエージェントが一貫した言語を使用するのを助けます。
- **リポジトリローカライゼーション:** リポジトリを接続し、設定でソースファイルとターゲットロケールを記述し、プルリクエストを通じて変更を確認する。
- **段階的改善:** コンテンツハッシュは変更されていない内容を翻訳するのを助けます。検証と復旧により失敗を可視化し、実行可能にします。
- **コンテンツ改訂:** 言語判断や変更の歴史を保存し、各生成を孤立したプロンプトとして扱わない。
- **ローカライゼーション分析:** プライバシーを考慮した Web 分析は、チームのオーディエンスとローカライゼーション投資の対象を理解するのを助けます。
- **エージェント統合:** OAuth 認証された MCP サーバーと REST インターフェースが、既存のワークフローに言語コンテキストを提供する。

Glossia は編集判断を置き換えるものではありません。それはコンテキスト、自動化、およびレビューワークフローを提供し、チームがその判断を繰り返し適用できるようにします。

## 検索ロボット用およびエージェント用

公開されているページは、URL に `.md` を追加することで Markdown として利用可能になり、HTML URL に `Accept: text/markdown` を指定することで取得できます。ホームページの Markdown URL は `/index.md` です。翻訳済みコンテンツは HTML と同じ地域プレフィックスを使用し、翻訳が公開されていない場合には英語にフォールバックします。

探索には [/llms.txt](/llms.txt)、統合されたドキュメントエクスポートには [/llms-full.txt](/llms-full.txt)、正規の HTML URL には [/sitemap.xml](/sitemap.xml) を使用します。アカウントダッシュボードはアプリケーションの UI 画面であり、ドキュメントではありません。Glossia に関する情報を学ぶためにこれらをクロールすることはお勧めできません。
