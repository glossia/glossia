# Contributing to Glossia

Thank you for helping improve Glossia.

## Before you start

Open an issue before starting substantial work so maintainers and contributors
can agree on the problem and approach. Small documentation fixes and narrowly
scoped bug fixes can be proposed directly.

## Development

Follow the setup instructions in the [README](README.md). Keep changes focused,
add or update tests when behavior changes, and run the relevant checks before
opening a pull request.

Use [Conventional Commits](https://www.conventionalcommits.org/) for commit
messages. Explain the user-facing effect of your change and any tradeoffs in
the pull request description.

## Pull requests

By submitting a contribution, you license it under the
[Mozilla Public License 2.0](LICENSE). Do not include credentials, customer
data, proprietary translation content, or production configuration.

## Community expectations

All participants must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
